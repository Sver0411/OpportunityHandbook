# 心理与求助

这一册处理「情绪与心理状态」：什么时候属于可以自己调整，什么时候应该找专业人士，以及在哪里能找到、流程与成本大概如何。**不做诊断、不给用药建议。**

```

情绪起伏本身是正常的。值得求助的信号是**持续性与功能受损**：状态不好连续两周以上，且已经影响到睡眠、吃饭、上课/上班或人际关系。

| 渠道 | 适合什么情况 | 大概成本 | 怎么找到 |
| --- | --- | --- | --- |
| 学校心理健康中心 | 在校生，学业压力、适应问题、轻度情绪困扰 | 多数免费或很低 | 学校心理中心/辅导员转介 |
| 单位 EAP（员工帮助计划） | 在职，工作压力、人际、家庭议题 | 通常由单位付费、对员工保密 | 问 HR 是否有 EAP 及其使用方式 |
| 综合医院精神科/心理科 | 情绪持续低落、焦虑影响睡眠与功能、需要评估或用药 | 挂号 + 诊疗费，医保按规定报销 | 医院官方挂号渠道 |
| 社会心理咨询机构 | 想定期谈话咨询、无急性症状 | 单次价格区间较大，需自己承担 | 正规机构；注意咨询师资质 |
| 心理援助热线 | 情绪危机、需要立刻有人听 | 免费 | 各地精神卫生中心与政府热线（以当地公布为准） |
| 紧急情况 | 有自伤或伤害他人的想法与计划 | — | 立即联系 120/110 或就近急诊 |

## 三个判断原则

1. **先看功能受损程度**：能不能睡觉、吃饭、完成基本工作，比「心情好不好」更能说明问题；
2. **医院不是最后一步**：精神科与心理科是常规科室，早去不等于病情严重；需要评估或用药时，医院的效率最高；
3. **咨询师要挑**：正规资质、有督导、能说清保密边界与收费方式；不合适当面换，不必勉强。

## 什么时候要谨慎

- 出现自伤念头、无法自控的情绪爆发、或完全无法入睡时，属于紧急情况，直接就医或拨打急救与报警电话，不要等预约；
- 本页不诊断、不推荐任何药物；用药与停药的调整必须由医生决定；
- 线上「心理测评」量表只作参考，不能替代专业评估；
- 涉及未成年人、严重精神障碍等情形，应由监护人陪同并就医。

last_verified: 2026-10-14
```

心理状态不是靠「想开点」维持的，它更像身体：靠日常的几个习惯累积，而不是某次顿悟。四件事最值得先做。

| 抓手 | 具体做法 | 为什么有效 |
| --- | --- | --- |
| 一段不被打断的时间 | 每天或每周固定 30–60 分钟，只做一件自己选的事（读书、运动、写点东西） | 恢复「我能决定自己做什么」的感觉，这对高压期尤其重要 |
| 两三个能说真话的关系 | 不解释背景也能被理解的人，定期联系 | 情绪不用一直靠自己消化 |
| 边界 | 明确「几点之后不处理工作消息」「哪些请求要拒绝」 | 长期失去边界，是耗竭的主要来源 |
| 把求助当常规 | 状态不好时先说出口，必要时按 [情绪持续不好时找谁](02-心理与求助.md#health-mental-support) 找渠道 | 越晚说，代价越大 |

## 三个减少内耗的做法

- **降低「应该」的密度**：把「我应该更努力」换成「我这周完成的三件事」，标准具体了焦虑就降下来；
- **区分可控与不可控**：把精力放在能改变的部分（今天的行动），接受不能改变的部分（结果与他人评价）；
- **允许低效**：要求自己时刻高效，本身就是一种长期压力源。

## 什么时候要谨慎

- 这些做法适用于日常维护，**不能替代治疗**；已持续两周以上的低落或焦虑应就医；
- 处于严重压力期（亲人重病、失业、重大失败）时，优先寻求支持而不是自我调适；
- 不要把「维护心理状态」变成又一项要完成的 KPI。
