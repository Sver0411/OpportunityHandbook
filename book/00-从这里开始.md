## 两个清单

**能换回什么**（越靠前越容易被第三方验证）：

```
学历 · 资格 · 收入 · 工作经历 · 科研经历 ·
作品 · 项目 · 论文 · 推荐信 · 奖项 · 公开贡献 ·
人脉 · 行业声誉 · 领导力 / 管理经验 · 未来选择权
```

**要付出什么**：

```
时间 · 金钱 · 精力 · 地理迁移 · 收入损失 ·
准备成本 · 失败风险 · 机会成本
```

把任何一个机会按这两行拆开，多半就能看出它的问题：收益栏空空如也的，通常只是在消耗时间；成本栏里藏着“两年”和“辞职”的，通常不是顺手能接的。

这本指南不是励志文章，也不是机会汇总。它做的事只有一件：把一个选择的**收益与代价写清楚**，让你自己判断。全书按「你会先遇到什么问题」组织，而不是按年龄或专业分类，因为同一个问题可能在任何年龄出现。

## 如果你现在完全没有方向
最有效的起点不是继续思考，而是做一次对照：挑三五个你能想象自己去做的岗位或项目，打开它们的**官方**招聘页或招生页（企业校招官网、公开招聘公告、院校招生简章都是公开信息，不要看培训机构的改写版本），把「要求」一节逐条抄下来，标注每一条：我已经有 / 我能在一学期内补上 / 我短期补不上也不打算补。出现次数最多的「能补上」的那一项，就是接下来三个月的主线目标。

这个动作只需要几次一至三小时的检索，换来的是一张写着具体缺口的清单。方向不是一开始想出来的，而是在做的过程中被结果筛出来的；一次性研究二十个方向，大部分信息在动手之前对你没有意义。三个月后重做一遍，只保留仍然存在的缺口。

## 三种读法
- **跟着主线读**：00 → 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08，按你大概会遇到问题的顺序走；
- **按阶段进入**：[10 路径时间线](11-路径时间线.md) 与 `docs/timelines/` 里的路径时间线（本科四年、保研、考研、留学、校招、转行），每条时间线把该阶段要做的事串起来；
- **按主题查**：[09 专题手册](10-专题手册.md)（科研、竞赛、国家与地区、行业与职业）只做索引，判断只有一份，都在主线正文里。

## 怎么看里面的结论
每篇都标注了**依据类型**：官方规则、研究、行业数据、实践经验、证据不足。看到「实践经验」时请把它当参考而不是结论；升学、签证、招聘规则会变，超过核实日期一年的制度性信息请回到原始出处确认。「哪些情况下应该谨慎」往往比「怎么做」更值得先读。

### 人生并不是只有一条标准路线

```meta
id: guide-no-single-path
status: complete
stages: [college, undergraduate, master, new_grad]
topics: [explore]
outputs: [optionality]

evidence: [experience_based]
summary: 人生并不是只有一条标准路线：时间表因人而异，偏离不等于落后——但非标准路线的代价也要算清，并用条件而不是年龄判断。
last_verified: 2026-10-06
```

有一条默认时间表常被当成常识：几岁该升学、几岁该进大公司、几岁该稳定下来，偏离它就会被说成「落后」。但现实里，工作后重新读书、较晚才进入某个行业、中途换方向都不罕见，其中相当一部分人后来的发展并不差。本书按「你会先遇到什么问题」组织，而不是按年龄，正是因为这条时间表并不成立。

## 为什么时间表不可靠
时间表假设所有人条件相同，而每个人的信息、资源与家庭约束差别很大。同样的选择，对一个人是机会，对另一个人可能是负担。所以「别人在这个年纪做到了什么」通常不是有用的参照。

## 非标准路线的真实代价
它并不免费：解释成本更高（要向招聘方说明空窗或转折）、试错时间更长、家庭压力更大；有些制度性安排（应届身份、报考年限）还会真的卡住时间。本书把这些代价写出来，而不是用「勇敢」「追随内心」一笔带过。

## 一个具体的对照
两个背景相近的人，都在工作两年后想转做产品：

- **A 按时间表判断**：觉得「已经工作两年了，再折腾就晚了」，于是留在原岗位，用业余时间补课，但没有留下任何可展示的产出；
- **B 按条件判断**：先用三个月争取一次内部转岗或一个小项目，拿到真实反馈后再决定要不要系统转行。

三年后，B 的简历上多了一段可讲的产品经历，A 多了一堆没学完的课程。差别不在勇气，而在于**是否把「年龄」换成了「条件」来判断**。

## 怎么用它
看每一章时，别问「正常人的做法是什么」，问**以我的条件，哪条路的收益和代价我承受得起**——判断方法见 [怎么判断一个选择值不值得](#judge-worth-it)。

### 怎么判断一个选择值不值得

```meta

status: complete
stages: [highschool, college, undergraduate, work_1_3]
topics: [explore]

effort: medium

```

判断一个选择值不值得，最容易问错的问题是「它好不好」。真正有用的是四个更具体的问题，按顺序过一遍——顺序很重要，因为硬门槛不过，后面的权衡都没有意义。

## 四步框架怎么用
**第一步：有没有硬门槛。** 目标岗位或学校有没有把某项条件写死（学历、专业、年限、语言、资格）？写死的条件优先满足，因为不给你商量空间。门槛从官方文件里查：招聘 JD 的「任职要求」、招生简章的报考条件、资格考试的报考资格。

**第二步：要付出什么。** 把成本摊开写：时间、金钱、精力、地理迁移、收入损失、机会成本（见 [什么叫机会成本](#judge-opportunity-cost)）。**只算钱不算时间**是最常见的错误。

**第三步：能留下什么。** 用可验证成果的层级衡量（见 [什么叫可验证成果](#judge-verifiable-outcomes)）：只有叙述、有痕迹、公开可检索、有外部评价。层级越高，这条路越不依赖具体环境。

**第四步：它会关掉什么。** 任何选择都有代价：读研关掉的是两到三年的工作进度与收入；进大厂边缘岗位关掉的是核心业务的判断力积累；回家乡关掉的是行业密度。**把「关掉的东西」写出来，比写「得到的东西」更能看清选择。**

## 两个反直觉结论
- **门槛优先于收益**：一个收益很高但你进不去的机会，价值为零；
- **可回退性可以抵消部分收益差**：B 比 A 多 15% 的收益，但 A 可以随时转向 B 的方向——此时 A 常常更优。

## 三种常见判断偏差
| 偏差 | 表现 | 修正 |
| --- | --- | --- |
| 沉没成本 | 「已经准备了两年，不能放弃」 | 只看下一步的净收益，历史投入不影响 |
| 从众 | 「大家都去考，我也考」 | 把别人的选择当信息，不当依据 |
| 单一维度 | 只看薪资或只看名气 | 四步逐项打分，不允许跳过第二步和第四步 |

## 把它用到极端情况
面对一个看起来很好的机会（高薪、名校、名企），走一遍四步：门槛是什么？成本里最贵的是哪一项？三年后能带走什么？会关掉什么？**如果其中几个问题答不上来，说明决策依据还不足，而不是这个机会不好。**


把两个类型不同的机会（一个保研、一份工作、一段实习）拉到同一组字段上算，是避免「感觉哪个更好」式纠结的比较稳妥的办法。

| 选项 | 能换回的成果 | 必须付出的成本 | 成果可验证性 | 接受它就要放弃什么 |
| --- | --- | --- | --- | --- |
| （示例）保研 | 学历、两年研究经历、导师推荐 | 两到三年时间与同期薪资 | 高：录取通知、论文、推荐信可核对 | 两年的行业经验与收入 |
| （示例）一份工作 | 工资、真实业务经验、同事网络 | 通勤、可能的加班、方向锁定 | 中：合同、绩效、项目记录 | 应届身份与读研窗口 |

## 四列对照表
建一张表，行是选项，列是四项：**能换回的成果 / 必须付出的成本 / 成果的可验证性 / 接受它就要放弃什么**。填表纪律比表格本身重要：

- 每格只填**三个月内能被第三方验证**的东西：录取通知、成绩、作品、工资、合同；
- 「听起来很好但无法验证」的内容单独放一栏，标为「待验证」，决策时不给它们权重；
- 用区间估计代替单点估计——「留用概率 30%–60%」，而不是「应该能留用」；
- 成本一栏别忘了社保公积金连续性与职业进度延后这类非现金项。

## 两种不适合比较的情况
只有一个选项时，该做的是核实这个选项本身的质量，而不是比较；两个选项的收益不可通约且都不可替代（「稳定」vs「自由度」）时，比较最终是价值排序不是计算——承认这一点，早点排序，不要继续假装能算。

## 收尾规则
写完放一晚再看，只改数据不改情绪。两边结论差异很小时，选**失败后还能退回来**的那个；也记住「两个都不选」本身是一个选项。做完决定后不反复改主意，把精力从「选」转到「做」。

## 三类能带走的东西
- **可复用能力**：写作、数据、沟通、项目管理、外语、领域方法；
- **可验证成果**：作品、项目、论文、证书、可展示的记录；
- **关系与声誉**：愿意为你背书的人，比头衔更耐用。

## 两类带不走的东西
只在一家公司内部有效的流程知识；只在某个时期有效的热点技能。它们值得用，但别当成长期资本。

## 怎么用时间做乘数
同一件事如果同时产出成果、能力与人，值得优先做；只产出其中一项的事可以少做。

## 应用：短期收益和长期收益怎么权衡
不要试图给「两年后的收益」算利率——你估不准行业溢价，假装能算只会制造虚假的精确感。更可靠的是三个问题：**这件事会不会占掉我做主线事情的那段时间？它能被中断吗？中断时我损失什么？** 操作上把两个选项写成同样三行：未来六个月的现金流、二十四个月后我手上多什么、中途退出的损失。按退出成本分类：可逆的低成本机会可以直接接；**不可逆的选项需要更长的论证**。两个选项在两年后产出相似时，选现金流更好的那个——这是最常见的情形，也最容易被「长期主义」的说法误导。另外，现金流已经撑不住基本生活时，短期收益不是选择题而是约束条件，先解决生存；也别用「长期价值」给明显低质量的经历贴标签——长期有没有价值，看它留下什么可验证成果。拒绝「某项投资未来回报多少倍」这类说法，这类数字通常没有可靠来源。

### 什么叫机会成本

```meta

status: complete
stages: [college, undergraduate, master, new_grad]
topics: [explore]
outputs: [optionality]
effort: low
evidence: [experience_based]
summary: 机会成本是你为了当前选择而放弃的最佳替代方案的价值；它和净收益差、可逆性、不确定性是四件不同的事。
last_verified: 2026-09-28
```

机会成本指的是：**你做了这个选择，因此放弃的那个最佳替代方案的价值**。它不出现在账单上，却常常是决策里最大的一项——读书期间放弃的工资、创业期间放弃的薪资与职级进度，都属于这一类。

## 先把四个概念分开

这几件事经常被混成一句「算算划不划算」，但它们回答的是不同问题：

| 概念 | 回答的问题 |
| --- | --- |
| 机会成本 | 我放弃了什么（最佳替代方案的价值） |
| 净收益差 | 两个方案最终差多少（含收入、能力、选择权） |
| 可逆性 | 选错了能不能退回来，退出成本多大 |
| 不确定性 | 结果的可能范围有多宽 |

机会成本只回答第一个问题。可逆性、不确定性是**独立的决策维度**，不是对机会成本的修正——「可以退回来」不会让机会成本变小，它只是让你更容易承担判断错误。把三者揉在一起算，往往得出「听起来很精确、其实没有依据」的结论。

## 什么时候必须算

- **读研 / 留学**：放弃的工资通常与学费同量级，是最容易被漏掉的一项；
- **全职创业**：放弃的薪资与职业进度；
- **脱产备考**：收入中断，加上履历连续性的影响；
- **长期高强度加班**：放弃的健康、学习与关系时间；
- **换城市**：迁移成本与原有关系网络的价值。

## 三种常见的算错方式

| 算错方式 | 表现 | 纠正 |
| --- | --- | --- |
| 用假设收入代替真实替代方案 | 「如果我去大厂能拿 40 万」 | 用你实际能拿到的 offer 数字 |
| 只算钱不算时间 | 忽略通勤、加班、备考占用 | 把时间折算进同一口径，或单独列出 |
| 把可逆性当成折扣 | 「可回退所以机会成本打折」 | 可逆性单独作为一项风险评估，不动机会成本 |

## 怎么用它做选择

1. 写下你正在考虑的两到三个选项；
2. 对每个选项写出**真实可执行**的替代方案（不是你理想中的最好情况）；
3. 机会成本单独列出，不要和净收益差混在一栏；
4. 净收益差用同一口径比较（时间跨度、是否含收入、是否含隐性收益都要对齐）；
5. 标出哪些选项不可逆、哪些结果区间很宽——这两项决定你要留多少缓冲。

注意：机会成本用来比较，不用来后悔。已经付出的部分属于沉没成本，不影响下一步决策。

### 什么叫可验证成果

```meta

last_verified: 2026-09-27
```

「可验证成果」指**第三方可以不依赖你的叙述就判断它的成色**的东西。它决定别人凭什么相信你，而不是你说了什么。

## 四层可核对程度
最弱的成果需要你解释，最强的成果别人一查就知道：

1. **只有你的叙述**：参与过某个项目、做过某件事——无法核对；
2. **有痕迹但需你指路**：你去查这个仓库、这份文档、这行记录才能看到；
3. **公开可检索**：链接可点开、论文可下载、成绩可查询、作品可体验；
4. **有外部评价**：被使用、被引用、被采纳、被推荐、拿到可核对的数字。

**升级路径清晰**：把第 1 层的内容做成第 2 层（写出文档、整理代码），再把第 2 层推到第 3 层（公开、可访问），最后争取第 4 层（有人用、有人认）。

## 不同路径的典型成果
| 路径 | 弱 | 强 |
| --- | --- | --- |
| 项目 | 「做过一个网站」 | 可访问的地址 + 使用数据 + 你的技术取舍说明 |
| 科研 | 「参与国家级课题」 | 复现报告 / 论文署名 / 被组里采用的工具 |
| 实习 | 「在某公司实习」 | 负责的模块 + 上线结果 + 主管评价 |
| 竞赛 | 「参加过比赛」 | 名次 + 作品 + 复盘记录 |
| 学习 | 「学过机器学习」 | 一个完整项目 + 报告 + 代码 |

## 为什么它决定选择权
换工作、申请学校、找合作者时，对方能依据的只有可验证的部分。**成果越可验证，你越不依赖某个具体组织或某个人的推荐**——这就是 [什么叫未来选择权](#judge-optionality) 里说的「带走的能力」。

## 常见做法（把一件事变成成果）
1. 做完之后立刻写一段说明：问题、你的动作、结果、限制；
2. 需要的话补一个可访问位置（仓库、报告、演示）；
3. 记下能证明结果的东西（截图、数据、反馈、评审意见）；
4. 找人看一次（同事、同学、导师），看对方能否复述你做了什么——复述不出，说明说明写得不清楚。

## 给经历分四层
| 层级 | 例子 | 谁看得到 | 常见用途 |
| --- | --- | --- | --- |
| 官方认定 | 学历学位、职业资格证、考试合格证明 | 任何人都能核验 | 报考资格、签证、入职审查 |
| 公开可查 | 已发表论文、公开代码仓库、公开作品、公示名单 | 有链接就能查 | 申请材料、面试追问 |
| 有据可查 | 劳动合同、实习证明、推荐信、项目验收文档 | 需你提供或第三方确认 | 背调、细节追问 |
| 自我陈述 | 参与过、组织过、学到了 | 无第三方凭据 | 只能当故事讲，不能当证据 |

判断一个新机会时先问：**结束时我能拿到哪一层的东西？** 只有第四层的机会，价值上限很低。这个标准的价值在于**投入之前**就能判断结果，而不是投入之后才发现拿不出东西。

## 三个常见混淆
- 自己写博客不等于「公开可查」——要有第三方审核或真实使用痕迹；
- 「参与证书」不是「官方认定」：很多项目参与证书只是活动方自己印的；
- 成果不必大：「一个被 20 个人使用的工具」是可验证成果，「参加了 5 次活动」不是。

纯粹以体验为目的的活动可以参加，只是别把它记成职业资本。雇主无法直接观测能力、只能依赖凭证与信号，这是劳动经济学的标准框架（教育的信号理论），这里只取「可验证比自认为有能力更重要」这一层含义。

未来选择权不是一个抽象的好东西，它可以拆成四个具体来源：**可迁移能力、被验证的成果、关系网络、财务缓冲**。四项都能用具体状态描述，也都能被消耗。

## 四项分别是什么状态
- 可迁移能力：换个行业或岗位仍然值钱的技能（写作、数据、项目管理、外语、带人）；
- 被验证的成果：别人能看到的作品、交付、论文、公开记录；
- 关系网络：在你需要时会回消息的人，以及愿意为你说一句话的人；
- 财务缓冲：能支撑你几个月没有收入的储蓄。**它不产生机会，但决定你敢不敢抓机会。**

## 什么在积累它、什么在消耗它
| 行为 | 对选择权的影响 |
| --- | --- |
| 做完一件能被验证的交付 | 增加（成果 + 能力） |
| 参加一次行业活动并建立联系 | 增加（网络，前提是后续维护） |
| 只在一个封闭系统内积累专有流程 | 减少（换环境即失效） |
| 长期只服务单一公司且无对外作品 | 减少（网络与成果都受限） |
| 背高息消费贷、没有储蓄 | 减少（缓冲被吃掉，被迫接受次优选择） |
| 连续多年不更新技能 | 减少（能力随时间贬值） |

## 怎么判断自己现在是在积累还是在消耗
用一句话自测：**「如果明天这份工作/学业结束，我手里有什么是能带走的？」** 如果答案只有「一段经历」而没有成果、技能、关系或储蓄中的任何一项，说明积累方式需要调整。

## 两种常见误用
- **把「保留选择权」当成不选择**：一边准备考研、一边投实习、一边学技能，每条都只走两步。选择权来自「已经做成的事」，不是「没放弃的选项」；
- **把「多条路」当成低成本**：并行的代价是每条进展都变慢。更实际的做法是主线加一条备选，而不是四条平行线。

## 什么时候该主动放弃选择权
选择权有维护成本。当一个方向已经明确值得长期投入时，**把资源集中上去本身就是最优策略**——前提是你判断的依据是验证过的信号（做出了成果、有人付钱、市场认可），而不是一时热情。

方向不明时，比继续做抽象判断更有效的，是**完成一次低成本的真实体验，并拿到外部反馈**。做测评、看行业报告、听长辈建议都不产生这种反馈——兴趣类量表对具体岗位选择的预测力有限，这是职业心理学的常见结论，不同工具差异较大，这里只把它当「别只靠测评」的提醒。

## 设计一次两到六周的实验
从下面挑一件**一两周内能出成品**的事，不必都和技术有关：给开源项目完成一次小贡献；参与一次志愿服务并负责一个真实交付；一次设计或写作挑战；一次小型用户调研；跟随从业者或工作坊的体验；一个维修或手工小项目；一次短周期比赛；一次公开分享；一个科研小任务（复现、整理文献、数据清理）。成本控制在每周三到八小时，随时可以中止，中止的代价只是这段时间。

## 两条纪律
- 开始前写下「我要拿出什么」，具体到「修掉 issue #1234」而不是「提交一个 PR」；
- 结束后尽快写复盘（模板见 [探索复盘模板](../docs/tools/探索复盘模板.md)），趁过程和感受还记得清楚；攒够几条再回看，找重复出现的信号。

## 把「参加」和「做完」分开
参加比赛、听完课程、加入社群都不算完成一次实验，**只有产出物才算**。另一个误区是拿高成本决定（脱产考研、辞职转行）来「试试看」——这类决定不该用于探索方向。

## 拿到什么算赢
一条真实的外部反馈（「这个你做得好」或「这个你不适合」）、一个可写进简历的最小成品、一段可能延续的合作，或者一个明确的排除项。排除项同样有价值：它降低后续所有选择的成本。

### 什么样的失败值得承担

```meta
id: judge-failure-worth-it
status: complete
stages: [highschool, undergraduate, new_grad, work_1_3, work_3_5, career_change]
topics: [explore]
outputs: [optionality]
effort: low
evidence: [experience_based]
summary: 什么样的失败值得承担：看可逆性、信息量与影响范围三个维度——可逆、能验证、只影响自己的，优先去做。
last_verified: 2026-10-14
```

有些失败是纯损失，有些是**用可控成本买信息**。区分它们，比「敢不敢试」更重要。

| 维度 | 值得承担的失败 | 要谨慎的失败 |
| --- | --- | --- |
| 可逆性 | 一年内能回到原点（换回来、重考、重新求职） | 不可逆：放弃资格、违约、毁掉健康、切断唯一退路 |
| 信息量 | 结果能明确告诉你「这条路行不行」 | 做完仍然说不清到底哪里不行（模糊目标） |
| 影响范围 | 只影响自己 | 把家人、担保人、合伙人一起拖进来 |
| 成本上限 | 有明确上限且你能承受 | 没有上限（时间、金钱、健康可以无限投入） |

## 三个可操作的做法

1. **把「试一试」写成可判定的实验**：设定时间盒（三个月）、判定标准（拿到什么结果算通过）与退出条件（什么情况就停）；
2. **留一条退路再出发**：退路不是懦弱，它让你在过程中敢于投入，而不是一路保守；
3. **只押一部分**：把风险分散到时间与资源上（例如在职尝试、兼职做、先做小规模版本），而不是一次性全押。

## 什么时候要谨慎

- 涉及唯一性的机会（应届身份、考试资格、学籍、户口）时，先确认「失去之后还能不能拿回来」；
- 连续失败已影响到基本生活与健康时，先降低风险敞口，再考虑下一次尝试；
- 情绪高涨期做的重大决定（刚被激励、刚受打击）最容易忽略可逆性，把它延后一周再定。

### 起点不平等怎么算清楚

```meta
id: judge-starting-line
status: complete
stages: [highschool, college, undergraduate, new_grad, work_1_3]
topics: [explore, care]
outputs: [optionality]
effort: low
evidence: [experience_based]
summary: 把「我起点低」拆成四类可操作的差距（信息、钱、关系、时间），分别找出最低成本的补法，而不是把它当成整体劣势。
last_verified: 2026-10-14
```

「我家里没资源」是一个无法行动的整体判断。它实际由四类**可以分别处理**的差距组成：

| 差距类型 | 具体表现 | 最低成本的补法 |
| --- | --- | --- |
| 信息 | 不知道有哪些路、什么时候该做什么、规则在哪 | 官方文件（招生简章、选考要求、招聘公告）+ 行业报告 + 三五个从业者访谈 |
| 钱 | 不能报班、不能试错、不能空窗 | 优先选公立与官方项目、利用免费资源（图书馆、公开课、校内资源）、按「可逆性」控制试错成本 |
| 关系 | 没有能问的人、没有内推 | 从弱关系入手：老师、学长学姐、社群、公开活动；用「具体问题 + 我能提供什么」建立第一次接触 |
| 时间 | 要打工、要顾家，可支配时间少 | 把目标拆成能在碎片时间推进的动作；用「本周三件最重要的事」控制总量 |

## 三个能立刻用的做法

1. **把差距写成清单而不是结论**：写下「我缺什么信息、缺哪种关系」，每一项都能对应到一个具体动作；
2. **用官方信息替代传闻**：这是唯一完全免费、且不依赖关系的资源，也是把信息差距缩到最小最快的方式；
3. **找「比你早两三年」的人**：不要只找最成功的人。早几年的人更清楚具体的坑，也更愿意回答具体问题。

## 什么时候要谨慎

- 把「没有资源」当成不开始的原因时，先做一次低成本试错（一周内能完成的一件事），用结果替代判断；
- 幸存者建议要打折听：成功者的路径里常有关键的运气与时点，无法复制（见 [只听得建议、拿不到资源](15-避坑.md#trap-survivor-advice)）；
- 涉及需要资金门槛的路径时，先把现金流与回退方案算清（见 [转行期的钱怎么安排](08-晋升、跳槽还是转行.md#career-change-cashflow)），不要用借贷硬上。

### 信息不够时怎么决定

```meta

status: complete

topics: [explore]
outputs: [optionality]

```

卡住人的通常不是「不知道怎么办」，而是「信息不够，所以不敢动」。把决定分成两类，就能立刻分开处理：

| 类型 | 例子 | 该多快做决定 |
| --- | --- | --- |
| 可逆 | 换一门课、换一段实习、换城市短住、换一个方向试两个月 | 快做。恢复成本低，试错本身就是获取信息 |
| 不可逆 / 高代价 | 退学、辞职、大额负债、签长期合同、生育安排 | 慢做。先去把该问的问清，再决定 |

## 三个问题过一遍

1. **可逆吗**？如果做错了要花多久、多少钱才能回来——超过半年或明显影响现金流，就按不可逆处理；
2. **我缺的是信息还是决心**？缺信息就去补（下面三条路径）；缺决心通常说明有一项代价你还没接受，把它写出来直面它；
3. **拖下去会让选项变少吗**？报名有截止日、应届身份有时限、岗位会被别人拿走——**拖延本身也是一种选择**，而且往往是最差的那种。

## 补信息的三条路径

| 路径 | 怎么做 | 适用 |
| --- | --- | --- |
| 查一手来源 | 官网、原文件、招生简章、岗位表、政策原文 | 规则类问题（条件、时间、材料），一次能问清 |
| 问做过的人 | 找比你早两三年的人，问具体问题（「你当时最没想到的坑是什么」） | 经验类问题（实际强度、真实门槛） |
| 小实验 | 用两到六周做一次真实体验，拿到外部反馈（见 [不知道自己想做什么时怎么办](#start-when-no-direction)） | 偏好类问题（我适不适合、喜不喜欢） |

## 什么时候不用再等

- **信息已经饱和**：再多查几篇也不改变结论，只是想找「别人替我做决定」的答案；
- **错过截止的成本高于做错的成本**：例如报名、志愿、入职时间；
- **决定可逆且成本很小**：先做，再用结果修正。

## 什么时候该等

- 关键信息只有单一来源且无法核实；
- 涉及大额资金或长期承诺，而对方还没给正式答复；
- 你正处于强烈情绪中（被拒、被夸、被催）。**不可逆的决定不要在高点或低点当天做**，隔一晚再定。

## 留一条决策记录

做决定时写三行：**我当时相信什么、依据是什么、如果错了我会看到什么信号**。三个月后回看，比事后回忆可靠得多——它也是[半年一次的复盘](#decide-periodic-review)的原始材料。

## 什么时候要谨慎

- 用「再想想」无限推迟不可逆的决定，直到被时间逼着选；
- 被「限时」「最后一天」推着签字：这类话术针对的正是决策时间（见 [信息差、机会焦虑与从众](15-避坑.md#trap-information-asymmetry)）；
- 把不确定当成不做任何准备的理由——可以晚决定，但准备现在就能开始。

### 什么时候该止损

```meta
id: decide-when-to-stop
status: complete
stages: [college, undergraduate, master, phd, new_grad, work_1_3, work_3_5, senior, career_change]
topics: [explore]
outputs: [optionality]
effort: medium
evidence: [experience_based]
summary: 止损线要在开始之前就设好：时间、结果、费用、状态四条线各设一条；每三个月自检一次，退出时把成果、手续与复盘留下，而不是硬扛到资源耗尽。
last_verified: 2026-10-16
```

止损不是认输，而是**把还剩的资源换到更有把握的地方**。它难的地方在于：投入越多，人越倾向于继续投入，哪怕证据已经很弱。

## 止损线要在开始之前设

开始之后再设线，判断会被沉没成本带偏。开一个长周期投入（备考、读研、转行、创业）之前，先写下四条线：

| 线 | 怎么设 | 举例（示例，不是标准） |
| --- | --- | --- |
| 时间线 | 到哪个时间点必须出现什么 | 「到第二次考试结束还没过线，就换路径」 |
| 结果线 | 什么算可验证的进展 | 「拿到初试过线 / 拿到面试 / 拿到付费用户」 |
| 费用线 | 最多投入多少钱、多少负债 | 「不超过 X，且不借贷」 |
| 状态线 | 出现什么就该停 | 「连续两个月睡眠与情绪明显受损」 |

四条都写下来，放在一个能定期看到的地方。只写「尽力而为」等于没有线。

## 沉没成本怎么处理

已经花掉的时间和钱**不构成继续的理由**——它们不会因为你再投一年而回来。要算的是这一句：

> 从现在起再投入一个周期（一年、一学期），我能换回什么？成功的把握有多大？

如果答案是「不知道」或「主要是想证明自己没白费」，那就是该调整的信号。判断方法见 [怎么判断一个选择值不值得](#judge-worth-it) 与 [什么样的失败值得承担](#judge-failure-worth-it)。

## 每三个月自检一次

用一个固定问题清单过一遍，比每天纠结有效：

1. 目标变了吗（还是原来那个，还是已经变成「不想承认失败」）？
2. 上一个周期出现了什么可验证的进展？
3. 我现在的状态，能再撑一个周期吗？
4. 如果现在停下来，备选是什么？

**连续两个检查点没有任何可验证进展**，就该认真考虑调整；这是最常用的止损触发条件。

## 止损有三种，不是只有「彻底退出」

| 方式 | 做法 | 适合 |
| --- | --- | --- |
| 降投入 | 从全职备考改为在职备考、从全时创业改为副业 | 目标仍想要，但资源撑不住 |
| 换路径 | 换学校、换方向、换岗位、换行业 | 目标合理，路径不合适 |
| 退出 | 完全停止并交接 | 目标本身已经不成立，或状态线已破 |

多数人想到的只有第三种，所以迟迟不做决定；前两种往往成本更低、保留更多选择。

## 什么时候不该止损

- **正常的初期困难**：任何新领域的前几个月进步都慢，这属于常态而不是信号；
- **只因为一次失败**：一次考试、一次面试、一次评审的结果，不足以判断趋势；
- **已有明确信号显示「再一个周期就能跨过门槛」**：例如已经通过初试、已经拿到复试资格、产品已有稳定复购。

## 什么时候该止损

- 连续两个检查点没有可验证进展；
- 成本已经影响到健康、家庭关系或现金流（见 [转行期的钱怎么安排](08-晋升、跳槽还是转行.md#career-change-cashflow)）；
- 门槛变了：政策、招生规则、岗位要求提高，原计划不再成立；
- 你其实已经不想做了，只是不想承认——这一条最难判断，也最常见。

## 退出时要做完三件事

1. **留住成果**：把这段经历写成可复用的东西（项目、作品、方法、人脉），失败的经历同样能写进简历与面试；
2. **办清手续**：休学退学按学校学籍管理规定办，离职的社保与档案衔接见 [离职、换工作与社保衔接](../docs/rights/离职与社保衔接.md)，别留下未结清的手续；
3. **写一页复盘**：当时的假设是什么、哪个假设错了、下次怎么发现得更早（做法见 [失败之后怎么复盘](06-从学校走向第一份工作.md#recover-failure-review)）。

### 半年一次的复盘怎么做

```meta
id: decide-periodic-review
status: complete
stages: [college, undergraduate, master, phd, new_grad, work_1_3, work_3_5, senior, career_change]

```

路线会过期。政策会变、行业会变、你自己的偏好也会变，而**不复盘等于默认沿用两年前的假设**。半年一次是个合适的粒度：比一年更能早发现问题，比每月更可能真的做下去。

## 四步，两小时

| 步骤 | 写什么 | 常见偷懒 |
| --- | --- | --- |
| 1 事实 | 这半年实际发生了什么：拿到什么、完成什么、被拒几次 | 只写感受（「挺忙的」），不写可验证的东西 |
| 2 假设 | 当时相信的判断，哪一条被证伪了 | 跳过这一步，于是同样的误判再来一次 |
| 3 状态 | 身体与精力、钱、关系、能力，四项各打一个粗分 | 只复盘「事」，不看承载事的自己 |
| 4 调整 | 继续 / 降投入 / 换路径 / 退出，选一个并写下下一步动作 | 复盘完没有结论，等于没做 |

第 1 步的写法参照 [什么叫可验证成果](#judge-verifiable-outcomes)：能被第三方核对的事情才算，比如「通过初试」「上线并有 20 个真实用户」「完成一次实习并拿到评价」。

| 方向（学业 / 职业） | | | |
| 能力（技能 / 作品） | | | |
| 钱（现金流 / 应急金） | | | |
| 身体与关系 | | | |

- 想盘点「我现在手上有什么」：用 [职业资本盘点表](../docs/tools/职业资本盘点表.md)；
- 想回看「试过什么、拿到了什么反馈」：用 [探索复盘模板](../docs/tools/探索复盘模板.md)；
- 要重新比较手上的机会：用 [机会价值判断表](../docs/tools/机会价值判断表.md)。

## 复盘之后必须有一个下一步

复盘的产出不是一份总结，而是**一个动作**：报名、投递、约一次谈话、换一门课、把项目做上线、把某个投入降下来。判断该不该调整，用 [什么时候该止损](#decide-when-to-stop) 里的四条线与三个月自检法。

## 三个常见失败

1. **只复盘失败，不复盘成功**：成功的经验同样要看能不能复制，否则下次还是靠运气；
2. **把复盘开成自我批评大会**：结论应该是「下一步做什么」，而不是「我哪里不行」；
3. **半年内反复换目标**：如果每两个月换一次方向，问题往往不是方向选错，而是遇到难点就换——这时该调整的是投入方式，不是路线本身。
