### 升学与留学


- 一句话：
  “保录取”的底层逻辑是**把信息差和概率卖给你**：正规升学从来由校方按公开标准评审，任何机构都改变不了校方的评审权。“保”的实现方式无非三种——筛选你本人（本来就能录，收钱不办事）、造假材料（被查出是你担责）、或“保”的是人设里的远程野鸡项目。三种都不值得。

- 适合谁：
  ——（没有人适合；本条目写给正在被推销的人。）

- 不太适合谁：
  ——（同上。）

- 能换回什么：
  识别与拒绝的能力；省下的数万到数十万元。

- 要付出什么：
  核查时间的半小时。

- 怎么开始：
  1. 收到“保录取”承诺时问三个问题：保的手段是什么、写进合同吗、不录怎么退（全额还是扣“服务费”）。
  2. 正规项目的真实性核查只有一条路：目标院校官网的招生页面与官方申请系统，任何“内部渠道”都绕不过校方评审。
  3. 涉及伪造成绩单、推荐信、实习证明的，不是灰色地带，是材料造假——被查出撤销录取乃至追究责任，后果由申请人承担。
  4. 留学申请找协助是合理的（文书辅导、选校建议），但边界是“帮你表达”，不是“替你达成”。

- 常见误区：
  把“往年案例多”当保票（幸存者偏差）；相信“校方合作资源”；被退费条款里的高额扣款坑过才看清合同。

- 下一步可能打开什么：
  对升学骗局的免疫力；一条正规但需要努力的申请路径（见 [留学之前先回答的三个问题](04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)）。

- 证据与来源：
  - 教育部留学服务中心多次发布关于“保录取”类虚假宣传的提示（见 CSCSE 官网公告栏）。https://zwfw.cscse.edu.cn/ （Official）
  - 各国使领馆教育处对留学中介违规行为的提醒。 （Official）

### 求职与实习

```meta
id: trap-fake-internships-and-paid-research
status: complete
stages: [college, undergraduate, master, new_grad, career_change]
topics: [explore, research, job]
outputs: [work_experience, research_experience, optionality]
effort: low
evidence: [official, uncertain]
last_verified: 2026-09-21
```

- 一句话：
  这几类东西（付费买“实习证明”、远程挂名不做事、交钱挂名论文、缴费即发的项目证书）的共同特征是：你付费买的是“证明”，不是“经历”。识别方法始终是同一条——谁在为费用负责，以及这段成果能不能被第三方核实。

- 适合谁：
  被推荐“保实习”“保科研”“保发表”服务的人；需要核查简历经历真伪的招聘方与教师；帮孩子做决定的家长。

- 不太适合谁：
  通过正规项目（学校合作、官方招募、有明确研究任务的付费项目）获得经历的人。**收费本身不等于无效**：关键在于任务是否真实、产出是否规范、验证链是否完整。

- 能换回什么：
  避免数千到数万元的损失；避免简历与学籍上的后果（发现造假可能直接导致 offer 撤销或学术处分）；把时间用在真实积累上。

- 要付出什么：
  核查的时间；放弃“快速拿到漂亮经历”这条捷径带来的心理落差。

- 怎么开始：
  1. **查招募方**：是学校、政府、企业官方渠道，还是中介？官方渠道通常直接申请，不需要付费。
  2. **查做的事**：有没有真实任务、有没有负责人、有没有交付物？如果“工作内容”只是打卡或写心得，那不是实习。
  3. **查成果归属**：论文的作者位次如何确定？能不能查到？付费挂名的成果往往无法通过第三方核查。
  4. **查验证链**：这段经历以后能不能被核实（单位可查、导师可联系、成果公开）？不能核实的经历不要写进简历。
  5. **查合同**：涉及费用时索取合同与发票，看清退款条款，以及“保证结果”类承诺的免责条款。
  6. **算替代方案**：如果目标是补经历，优先选真实但不起眼的机会（小公司实习、助研、志愿项目），它们的验证链是完整的。

- 常见误区：
  相信“保 offer”“保发表”“保录取”；把证明文件当成经历；为了简历好看接受挂名，却在面试的两个追问下暴露；忽略造假的真实后果；把“国际”“名企”当验证标准；看到社交媒体推广就报名，不查主办方；认为收费项目一定有用（回报取决于评价是否严格）。

- 下一步可能打开什么：
  真实且可验证的经历；对“资历如何被承认”更清晰的认知；把同样的钱花在真正的技能与项目上。

- 证据与来源：
  - 教育部：学历学位管理与学术诚信、留学中介服务监管的相关文件。http://www.moe.gov.cn/ （Official）
  - 各高校学术道德与学术不端处理办法（以本校规定为准；代写与买卖论文的处理后果明确）。 （Official）
  - 教育部涉外监管信息网：留学预警与国外院校信息。https://jsj.moe.gov.cn/ （Official）
  - 收费项目并非全部无效。存在有明确研究任务、有真实产出的付费项目；判断依据是任务真实性与验证链，而不是是否收费。 （Uncertain）

### 科研


科研里最伤人的坑不是做不出来，而是**把时间花在不会被承认的发表上**。
这类投入的特点是：花钱就能发，审稿极快，事后在升学与求职中不被认可，甚至成为负面信号。

## 识别清单

- **收费模式**：正常的同行评审不按篇向作者收取「发表费」；要求先付款再录用要高度警惕。
- **审稿周期**：从投稿到录用只有几天，说明几乎没有实质评审。
- **编委信息**：编委名单查不到真实主页，或大量编委与该刊领域不符。
- **收录情况**：自称被某数据库收录，但在该库里检索不到。
- **征稿方式**：主动群发邮件邀稿，且措辞里强调「快速发表」「保证录用」。

## 更稳妥的做法

先问导师与目标院系的公认列表，再决定投哪里；不确定时用「这个刊在你们领域算什么水平」直接问同行。
关于期刊、会议与预印本的区别，见 [期刊、会议与 Workshop](04-当你开始面对第一次重要分流.md#research-conference)。

### 竞赛

```meta

```

有一类竞赛的商业模式是向参赛者收费：报名费、评审费、证书工本费、奖杯邮寄费。
它们的奖项在升学与求职中通常不被承认，甚至会被识别出来。

## 核查清单

- **谁主办**：主办方能否查到实体机构与往届记录？是否只是某个新注册的公众号或公司？
- **谁评审**：评审名单是否公开、能否查证？
- **通过率**：如果获奖比例高得离谱，奖项就没有区分度。
- **收费结构**：报名是否免费、哪些环节要付费？只要交钱就能拿奖的，基本可以确定是付费拿奖。
- **往届去向**：往届获奖者在升学或求职中是否被目标单位认可。

## 更值得投入的替代

同样时间，做一个能被展示的项目、一次真实的开源贡献，产出更可验证。
判断比赛值不值得参加，见 [什么比赛值得参加](03-开始积累真正能留下来的经历.md#competition-what-worth-joining)。

## 来源与更新

### 证书与培训

```meta

last_verified: 2026-09-21
```

「再多考一个证」是最容易上瘾的低价值投入：它有明确的完成感，但不产生新的可验证产出。

## 为什么不会叠加

证书的作用是**消除某一个具体的门槛**。门槛消除了，第二本同类证书就不再增加信息量。
多本低相关度证书组合在一起，给招聘方的信号往往不是「能力强」，而是「在回避真正困难的事」。

## 什么时候该停手

- 目标岗位的招聘要求里没有提到它。
- 你已经有一本同领域的证书。
- 你考它的原因是「反正也不难」「大家都考」。

## 该换成什么

把考证的时间换成一个能被展示的产出：一个完整项目、一份可复核的分析、一次真实的实践记录。
哪些证书真正值得考，见 [哪些证书值得考](02-在学校里先把基础打好.md#certificate-what-is-worth-it)。

### 项目与履历

```meta

```

- 一句话：
  收藏课程、买了不看、同时开十几个项目却每个都停在入门——这些行为的共同点是它们带来“在进步”的感觉，却不产出任何可验证的东西。判断标准很直接：这个月除了你的记忆，还有什么能拿给别人看。

- 适合谁：
  习惯性收藏资料的人；同时开很多项目但完成率很低的人；一直很忙但没有成果的人；用“在学习”缓解焦虑的人。

- 不太适合谁：
  确实必须先系统学习才能入门的领域（数学、医学基础、部分工程方向），这时“先学后做”不是陷阱；短期集中备考的人。

- 能换回什么：
  省下的时间与钱；把精力集中到少数能产出成果的事情上；对自己学习方式的真实认识——这一点对后面所有选择都有用。

- 要付出什么：
  短期的不适：换了方法之后前期产出会变慢；以及需要放弃一些“看起来在学”的活动。

- 怎么开始：
  1. 统计上个月你收藏、购买、开始但没完成的东西有几种。数字通常比想象的大。
  2. 立一条规则：同时在做的项目不超过 1 个，在学的材料不超过 1 份。
  3. 用产出倒推：先定这个月要交付什么，再决定学什么。
  4. 想收藏时先问：我两周内会用到它吗？不会就不收藏。
  5. 每季度清理一次未完成清单，明确写成“不做了”，或纳入下一个周期。拖着不清会持续占用注意力。

- 常见误区：
  用课程数量衡量投入；把“在准备”当成进展；同时开太多方向导致每个都停在入门；用囤资料缓解焦虑；把“看完了课”当成“会做了”；把学习当成不用交付成果的活动。

- 下一步可能打开什么：
  能拿出成果的项目；作品集；更清晰的优先顺序。

- 证据与来源：
  - 本条属于行为判断类条目，不引用具体统计；相关依据见 [学技能还是做项目](02-在学校里先把基础打好.md#skill-course-or-practice) 与 [GitHub 项目做到什么程度才算项目经历](03-开始积累真正能留下来的经历.md#project-what-is-real)。 （Experience-based）

- 最后核实：
  2026-09-21

- 一句话：
  “信息差骗局”的共同结构是：**把公开信息包装成稀缺情报卖给你**——付费群里的“内部消息”、高价咨询里的“独家渠道”，绝大多数内容官方渠道免费可查。反过来也成立：真正值钱的信息（官方文件、一手数据、从业者访谈）反而是公开的，只是需要花时间读。

- 适合谁：
  所有付费买信息前的人；被“内部渠道”“独家资源”话术打动过的人。

- 不太适合谁：
  ——（核查习惯对所有人有益。）

- 能换回什么：
  一套 10 分钟的信息核查习惯；省下的大量冤枉钱。

- 要付出什么：
  每次核查十几分钟。

- 怎么开始：
  1. 付费前先自己查一遍：政策类看政府部门官网，考试类看官方考试机构，招生招聘看官方公告——能查到的就不要付第二遍钱。
  2. 对“内部消息”问一句：这个消息的原始出处是什么？给不出出处的，当营销处理。
  3. 价格是不对称的信号：越是把普通信息卖高价的，越可疑。
  4. 建立自己的信息源清单（官方渠道 + 少量可靠的一手来源），减少对二手转述的依赖。
  5. 真正的信息差存在于“解读”而不是“消息”：花时间建立自己的判断框架（本书各章都在做这件事），比买消息有用。

- 常见误区：
  以为贵的信息更准；把营销号当信息源；付费后才去查官方渠道；囤积信息不消化。

- 下一步可能打开什么：
  一套自己的信息核查流程；对付费内容的价格判断力。

- 证据与来源：
  - 信息核查习惯的普遍经验。 （Experience-based）
  - 各类官方信息渠道（本书各条目的证据与来源栏均列出对应官方入口）。 （Official）

## 高价求职辅导



- 一句话：
  高价求职辅导的常见套路是**卖焦虑 → 承诺资源 → 履行不了就甩给合同**：数千到数万元买“内推”“保 offer”“大厂导师”，其中内推本质是公开的免费渠道，导师课的内容网上多半有免费版本，真金白银的产出率极低。真正值钱的求职帮助（改简历、模拟面试）往往免费或低价就能获得。

- 适合谁：
  ——（没有人天然适合；本条目写给正在犹豫要不要付款的人。）

- 不太适合谁：
  ——（同上。）

- 能换回什么：
  识别套路的能力；省下的钱与时间。

- 要付出什么：
  一次冷静期的忍耐（付款前等 48 小时）。

- 怎么开始：
  1. 听到“保 offer”先问：合同里怎么定义 offer（哪个公司、什么岗位、什么薪资）？达不到怎么退？退款比例多少？——多数陷阱在定义与扣款条款里。
  2. 内推渠道本身免费：校友、社群、员工都能做（见 [内推](05-从学校走向第一份工作.md#job-hunting-referral)），付费买内推是在买本来免费的东西。
  3. 付费前先吃透免费资源：学校就业中心（免费简历与模拟面试）、各地公共就业服务机构的免费指导、目标公司的官方招聘流程。
  4. 若确需付费辅导：按小时付、单项付（如一次模拟面试），避免一次性大额预付与培训贷。
  5. 发现虚假宣传留存证据，可向市场监管部门投诉。

- 常见误区：
  被焦虑话术推着当天付款；相信“导师人脉”；用培训贷支付大额学费；把辅导当成不准备求职材料的替代品。

- 下一步可能打开什么：
  免费但有效的求职支持体系；对销售话术的免疫力。

- 证据与来源：
  - 人力资源社会保障部：公共就业人才服务与 12333 热线（免费职业指导）。https://www.mohrss.gov.cn/ （Official）
  - 各地市场监管部门与消协关于求职培训、培训贷的消费提示（检索当地官方发布）。 （Official）

## 追热点清零过去经验



- 一句话：
  追热点的真正成本不是学了没用的东西，是**每次清零重新开始**：三年换三个风口，每个都从入门开始，最后谁的成本都比不上你。热点可以参与，但要带着“能带走什么”的问题参与——能带走的只有可迁移能力与积累的判断力。

- 适合谁：
  发现自己反复“从零开始”的人；正考虑为热点放弃既有积累的人。

- 不太适合谁：
  ——（自省清单对所有人有益。）

- 能换回什么：
  一次清晰的自我盘点；把热点转化为增量（而不是替换）的方法。

- 要付出什么：
  一次诚实的复盘，约一小时。

- 怎么开始：
  1. 列出过去几年你追过的每个热点，问：现在还留在我手里的有什么（技能、作品、收入、判断）？
  2. 想清楚热点的结构：它涨的是行业（值得长期投入）、还是概念（值得学个基础）、还是情绪（不值得投入）。
  3. 参与热点时先定“带走物”：学它的底层能力（数据、工程、表达），而不是表层工具。
  4. 新方向优先选与既有积累有交集的入口（见 [Bridge Opportunity](07-当职业开始出现分岔.md#career-bridge-opportunity)），让过去为新方向服务。
  5. 记住：热点里赚钱的常常不是追热点的人，是卖铲子的人。

- 常见误区：
  用“拥抱变化”掩盖缺乏主线；每次转行都接受降级；把工具熟练当专业积累；三年后简历上看不出任何主线。

- 下一步可能打开什么：
  一条能持续积累的主线；把热点变成增量而非清零的参与方式。

- 证据与来源：
  - 职业积累与技能可迁移性的普遍经验。 （Experience-based）

## 机会焦虑



- 一句话：
  机会焦虑的燃料是**用别人的时间表过自己的日子**：同龄人保研了、转码了、财务自由了——但机会不是演唱会，不存在“错过就没有了”；真实世界里每条路每年都在重新开放，稀缺的从来不是机会，是把一件事做完的耐心。

- 适合谁：
  刷到“风口”与“同龄人”内容就睡不着的人；什么机会都想抓、什么都抓不深的人。

- 不太适合谁：
  ——（自检对所有人有益。）

- 能换回什么：
  把焦虑转化为筛选标准的能力；专注做一件事的整块时间。

- 要付出什么：
  少刷信息流的自制力；接受“错过一些东西”的长期练习。

- 怎么开始：
  1. 觉察触发源：焦虑感最强的内容是什么（晒 offer、晒收入、晒录取）？这类内容的生产目的是流量，不是帮你。
  2. 把“我错过了什么”改写成“我正在积累什么”：前者无法行动，后者可以。
  3. 给机会设准入标准：与我这一年的主线有关吗？投入产出能估算吗？——两个问题有一个答不上，就放过它。
  4. 接受错过是常态：任何一年被你放弃的机会都远多于抓住的，这本就是策略，不是失败。
  5. 焦虑持续影响睡眠与判断时，把它当作需要处理的信号：和人聊、做具体的事，而不是继续刷。

- 常见误区：
  用“多线操作”缓解焦虑（实际是分散到一事无成）；拿自己的幕后比别人的台前；把焦虑当成动力长期使用（它消耗的是判断力）。

- 下一步可能打开什么：
  一条能沉下心走的主线；对机会的真实筛选力（见 [怎么判断一个机会值不值得](00-从这里开始.md)）。

- 证据与来源：
  - 社会比较与错失焦虑的心理学研究（错失恐惧 FoMO 与社交媒体使用的研究是近年心理学的高频议题）。 （Research-backed）
  - 机会焦虑应对的普遍经验。 （Experience-based）
