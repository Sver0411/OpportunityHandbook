# 没有资源时怎么起步

这一册不讨论「公不公平」，只处理两件可操作的事：**把别人靠家庭传递的规则自己补回来**，以及**在没有现成关系时怎么从零开始积累**。

家里第一个上大学、第一个考公、第一个进企业的人，缺的不是能力，而是**别人通过日常聊天就获得的那部分规则**：什么时候报名、哪些坑不能踩、哪些话不必当真。

## 三步建立自己的信息源

1. **官方源优先**：把与你相关的三个官方页面固定下来（省教育考试院、学校教务处/研究生院、目标行业的招聘公告），每季度看一次。它们比任何二手解读都准，而且免费；
2. **找两位「早几年」的人**：同专业高两届的学长、已经工作的亲戚朋友、行业社群里能回答具体问题的人。问**具体**问题（「你们那年夏令营几月报名、材料要什么」），不要问「我该怎么办」；
3. **把判断写下来定期校对**：写下「我现在的计划 + 依据 + 什么时候看结果」。半年后回看，你会发现自己补上了大量原本不知道的规则。

## 三条经验

- **不要用「不好意思打扰」当理由**：多数人愿意回答具体、成本低的问题；准备好问题本身就是尊重；
- **警惕「我听说」**：家族与同乡圈的传闻往往滞后好几年，涉及报名时间、政策口径的一律回官方源核对；
- **把「不懂就问」当成能力**：问清楚规则不是丢人的事，不问导致的错过才是真正的代价。

## 什么时候要谨慎

- 家庭意见与官方规则冲突时，先拿出官方文件再讨论（见 [怎么和父母沟通升学与职业选择](07-家庭沟通与支持.md#family-talk)）；
- 付费「内部信息」「保过班」基本不可信：真规则都在公开文件里；
- 不要把「第一代」当成人设：它解释了你为什么不知道，但不决定你能走到哪。


关系网不是靠认识大人物建立的，而是靠**一连串低成本、具体、可重复的接触**。它的起点通常不是「熟人介绍」，而是你身边那些还没有被用起来的关系。

| 关系来源 | 怎么开始 | 注意什么 |
| --- | --- | --- |
| 老师与课程助教 | 课后问一个具体问题，之后汇报进展 | 别只在需要推荐信时出现 |
| 学长学姐 | 问「你当年怎么做的」，再问「如果重来会改什么」 | 越具体越容易得到回复 |
| 行业社群与开源项目 | 先回答问题、提交一次贡献，再谈自己 | 贡献在前，请求在后 |
| 公开活动与讲座 | 讲者提问环节、会后一句具体的反馈 | 一句话说明你是谁、在做什么 |
| 前同事与同行 | 保持低频但持续的同步（每季度一句近况） | 只在求职时联系，效果最差 |
| 公共资源 | 校友会、行业协会、工会、公益组织的公开服务 | 很多资源是免费的，只是没人告诉你 |

## 一次能用的开场

把「您好，想请教」换成三句：**我是谁 + 我在做什么具体的事 + 我想问的一个具体问题**。例如：「我是 XX 大学大三学生，正在准备暑期实习，想请问你们团队今年的实习一般是几月开放投递、看重哪一类项目？」——对方能直接回答，成本低，回复率高。

## 怎么维持

- **定期给反馈**：对方给过建议后，隔一段时间告诉他结果（哪怕失败了）。这是最低成本的关系维护；
- **用输出替代索取**：写复盘、做整理、在社群回答问题。别人通过你的输出找到你，比你去加人有效；
- **不做单点依赖**：只靠一个人推荐风险很高；保持同时有 3–5 个能互相提供信息的关系即可。

## 什么时候要谨慎

- 把关系当成「找机会」的工具时，回报最低且消耗最快；它的价值在信息与判断，机会是副产品；
- 涉及付费「内推」「保 offer」的服务基本是骗局——正规内推不需要付费（见 [求职与实习避坑](../14-避坑.md#trap-fake-internships-and-paid-research)）；
- 涉及利益输送、请托与合规风险时，一律不要参与；这类代价远超一份工作。
