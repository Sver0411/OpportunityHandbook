# 当你开始面对第一次重要分流

## 先决定主线

### 升学还是工作

```meta
last_verified: 2026-09-27
```

这个问题被两种声音主导：「学历越高越好」与「早点工作积累经验」。两种都不足以直接做决定——先看**你的目标职业在看什么**，再看**你现在缺什么**。

## 第一步：目标职业有没有学历硬门槛
收集二三十条目标岗位的招聘要求，只看「学历」一栏：

- 相当一部分写「硕士及以上」→ 学历是筛选线；
- 普遍写「本科及以上」或「经验优先」→ 学历的边际价值要单独算；
- 部分通道（高校教职、研究院、部分资格考试）有明确学历线 → 查官方文件。

**这一步十分钟，比任何笼统建议都有效**（方法见 [怎么看招聘 JD](02-在学校里先把基础打好.md#read-jd)）。

## 两条路各自真正换回什么
| | 升学 | 工作 |
| --- | --- | --- |
| 门槛 | 学历入场券、部分政策倾斜 | 工作经验可替代部分学历要求 |
| 机会 | 重新选择专业/城市/行业 | 更早的收入、社保年限、行业认知 |
| 产出 | 研究/项目经历、论文、推荐人 | 真实交付、业务判断、客户与同事网络 |
| 一次性资源 | 应届身份、校园招聘通道 | — |

**不能简单互换**：学历可以补，但三年后的行业位置补不回来；工作经验可以补，但应届身份与校招通道是一次性的。

## 成本要摊开算
升学：时间（两到三年 + 备考）+ 直接成本 + 机会成本（放弃的收入）；工作：可能的学历门槛 + 早期方向不确定的沉没风险。算法见 [为教育投入多少钱才合理](01-先决定下一步往哪里走.md#education-cost-budget)。

**现金流与家庭约束也是决策变量**：家里需要你尽快有收入时，短期收入不是选择题而是约束条件，此时「先工作、之后再读」通常更稳。

## 两条都能走时怎么比较
一个更简单的判据：**哪条路能让你在两年内产出可被外部验证的东西**。

- 升学路线：能不能留下作品、论文、实习；
- 工作路线：能不能留下具体交付与可迁移技能。

两条都能产出时，选**回退成本更低**的那条。

## 先后关系并不对立
- 先工作再读：在职、非全日制、海外申请都开放（见 [工作后重新读书](06-进入职场以后继续积累.md#work-study-again)）；
- 先读再转：转换成本更高，但仍常见。

所以更实际的问题不是「先选哪个」，而是**主线是什么、备选是什么、什么时候切换**，见 [怎么设置主线和备选](04-当你开始面对第一次重要分流.md#fork-main-and-backup)。

国内升学与海外留学是两套制度安排，不能只比较「哪个更好」。比较的前提是先把它们放在同一张表上，并且先回答一个前置问题：**毕业后打算留当地还是回国**——这个答案决定其余指标的权重。

## 先回答一个前置问题
**毕业后是打算留当地，还是回国？** 这个答案决定其余指标的权重：

- 留当地：身份与工作许可规则最重要，其次是当地行业密度与语言；
- 回国：学历认证、行业认可与求职时间窗口更重要。

## 六项比较指标
| 指标 | 国内 | 海外 |
| --- | --- | --- |
| 培养方式 | 学制较长，学硕/专硕定位不同 | 学制差异极大（一年制授课型到多年博士） |
| 语言成本 | 基本无额外投入 | 语言成绩 + 真实使用能力 |
| 总成本 | 学费低，但有机会成本 | 学费高，另有汇率、保险、机票等 |
| 资助 | 奖助学金 + 助学贷款体系 | 奖学金/助研/公派，覆盖差异大 |
| **身份与工作许可** | 不涉及 | **决定能否留下，必须以官方页面为准** |
| 行业与地域 | 看目标行业在哪些城市 | 看目标行业在哪些国家，以及语言门槛 |

成本算法见 [留学总成本](04-当你开始面对第一次重要分流.md#overseas-total-cost)；资助见 [怎么找全额资助机会](04-当你开始面对第一次重要分流.md#funding-full-funding)。

## 回国那一半也要算
- **学历认证**：回国使用学历需办理国（境）外学历学位认证；
- **行业认可**：部分行业对海外学历的认可度因学校、专业与实习而异；
- **时间窗口**：国内校招与应届生身份的时间规则会与海外毕业时间错位，需要提前规划（部分单位对留学回国人员有专门的招聘安排）。

## 两条路各自的回退方式
- **国内**：读完后转方向主要靠实习与项目；若想出国，可再申请（成本：时间与语言）；
- **海外**：若留不下，回国需要面对认证、时间窗口与网络重建；若想再回，需要身份与雇主支持。

**提前把回退路径写下来**，能显著降低决策焦虑，也能帮你判断哪条路的「最低结果」更能接受。

## 家庭与落地支持
海外需要资金可持续、家庭共识与长期分离的心理准备；国内需要考虑是否异地、家庭照护责任。这些不是软性因素，而是决策里权重很高的一项。

**要谈清三件事**：钱由谁出、能承受的最长分离时间，以及万一中断时的退路（回国就业、转申其他国家、先工作再申请）。

## 怎么继续比较
用 [留学选校表](../docs/tools/留学选校表.md) 把候选项目逐项填出来，用 [留学申请时间线](../docs/timelines/留学申请时间线.md) 倒排准备节奏，再对照 [国家与地区](09-专题手册.md) 各页核实制度入口。**不要用中介的口径代替官方页面。**

```meta
last_verified: 2026-09-21
```

科研和产业的差别，不是「辛苦」和「轻松」，而是**节奏、反馈和成长方式**完全不同。

## 三个维度怎么比
- **反馈周期**：科研以月和年计（实验失败几周很常见），产业以周计（上线、数据、迭代）；
- **评价标准**：科研看新颖性与严谨性，评价者是全球同行；产业看交付与业务结果，评价者是你的团队和市场；
- **成长路径**：科研往「理解更深」走，产业往「交付更稳、影响更大」走。

## 哪些情况偏向科研，哪些偏向产业
偏向科研：被某个具体问题缠住、不弄明白不舒服；目标岗位是高校、研究机构或企业研究院的核心研发；已经体验过并愿意继续这种工作方式。偏向产业：更在意可见的交付与短期反馈；希望收入与职级随经验稳步增长；对长期不确定明显不适。

## 越晚切换，代价越大
科研路线的转换成本更高（方向锁定、成果慢，转向产业时要重新补工程与作品）；产业路线转科研要补论文与推荐信，也很难。两者都不是单行道，但**越晚切换成本越高**，所以这个判断值得在大三、研一阶段就认真做一次。

## 低成本验证
各做一段真实体验（一段实验室任务 + 一段实习），记录你在两种环境下的状态差异：卡住三天还能接受吗？写第一稿痛苦吗？看到自己的东西被用户使用会不会兴奋？这些反应比任何测评都可靠。

```meta
last_verified: 2026-09-27
```

并行准备的关键不是「几条」，而是**它们之间是否共用同一批准备动作**。共用的可以并行，互斥的只能选一条。

## 什么组合可行
| 组合 | 是否可行 | 原因 |
| --- | --- | --- |
| 保研 + 考研 | 部分可行 | 前期准备（成绩、基础）共用，但报名与复试阶段冲突 |
| 考研 + 秋招 | 可行但紧 | 时间错开（考研 12 月，秋招 9–11 月），需要极强的排期 |
| 留学 + 就业 | 可行 | 材料与语言共用，投递与面试期可能重叠 |
| 考公 + 考研 | 勉强 | 考试内容差异大，且都在年底前后 |
| 全职实习 + 全职备考 | 不可行 | 时间直接冲突 |

**判断方法**：列出两条线各自的**关键时间节点**，看是否有硬冲突；再看准备内容能否复用。

## 最多并行几条
经验上**两条**比较现实，三条除非其中一条明显轻量（例如只需提交材料）。原因不是时间不够，而是**注意力切换的成本**：每换一条线都要重新进入状态。

## 怎么防止「每条都只走两步」
1. **给每条线写一个最小可交付成果**（例如考研：模考达到某分数；就业：完成两轮面试）；
2. **固定每周的时间块**（例如周一至周五早读给考研，周末给项目与投递），并在周末复盘一次；
3. **设检查点与退出条件**：到点未达标就砍掉一条，而不是三条都拖着；
4. **接受降级**：把其中一条从「完整准备」降到「保证不失去资格」（例如只保留报名与基础材料）。

## 什么时候应该只做一条
- 关键期（考研最后两个月、论文答辩、实习考核期）；
- 两条线都需要整块深度时间（例如写论文与准备考试）；
- 你已经连续两个月每条线都没进展——这是并行失败的典型信号。

## 哪些能并行
共用度高的：保研与考研共用成绩与专业基础；留学与考研共用专业课（只多语言和文书）；实习与求职共用项目经历。这类组合可以在一条主线下顺带准备。

## 哪些互斥
需要大块独占时间的准备（考研冲刺、全职实习、脱产备考语言）很难叠加——硬叠加的结果常常是两条都差一点。

## 推荐的并行方式
选两条共用度高的路线，明确一条主线（资源六成以上）加一条备选（保底即可），并设定切换点：例如「夏令营颗粒无收则九月转入考研状态」。切换点提前写下来，届时就不必再经历一轮纠结，见 [怎么设置主线和备选](04-当你开始面对第一次重要分流.md#fork-main-and-backup)。

## 并行的代价是精力分散
并行的成本是精力分散与长期疲劳，收益是保留备选。判断是否值得的简单标准：如果两条路线的准备内容重合度低于一半，就别并行；重合度高时才值得。每学期末核对一次进度，不达预期就砍掉备选。

```meta
last_verified: 2026-09-27
```

主线与备选的意义是**在不确定性下保持推进**：主线决定你把大部分资源投在哪，备选保证主线失败时不至于从零开始。

## 怎么选主线
三个判断问题：

1. **哪条最接近你的目标**（而不是哪条最容易或最有面子）？
2. **哪条能在半年内产出一个可验证成果**？
3. **如果它失败，损失能否承受**？

**主线的标准是「值得集中投入」，不是「一定成功」**。三条都答不出，说明你可能还没收集够信息，先去了解（见 [怎么了解一个行业](02-在学校里先把基础打好.md#understand-industry)）。

## 备选的三种形态
| 形态 | 例子 | 优点 | 注意 |
| --- | --- | --- | --- |
| 同方向低一档 | 第一志愿 → 第二志愿院校 / 同行业小公司 | 资源可复用 | 别把它当「随便兜底」 |
| 相邻方向 | 保研 → 考研 / 大厂 → 同行业中型公司 | 能力可迁移 | 需要确认时间线是否冲突 |
| 完全不同方向 | 升学 → 直接就业 | 分散风险 | 准备成本高，通常只保留一条 |

**推荐的组合是「一条主线 + 一条同向备选 + 一条兜底」**，而不是四条平行线。

## 什么时候切换
给每条线设一个检查点与判据，例如：

```
主线（考研）：10 月模考低于目标线 20 分 → 启动备选（就业/二战评估）
备选（就业）：秋招结束仍无 offer → 转向春招与社招
```

**切换要有触发条件，而不是靠情绪**。触发条件写在纸上，能在压力大的时候减少犹豫。

## 常见误区
- **备选形同虚设**：只在主线失败后才开始准备（例如 12 月才想起投简历）；
- **主备时间线冲突**：例如需要同时全职备考与实习，两边都做不好；
- **备选太远**：需要的能力与主线完全不同，等于两个项目同时做；
- **不断切换**：每月换一次主线，结果每条都只走两步。

## 与并行的区别
同时准备多条线（见 [可以同时准备几条路线](04-当你开始面对第一次重要分流.md#fork-parallel-tracks)）适合时间不冲突、能力可复用的组合；主备结构适合时间冲突或需要集中投入的情况。**两者不能混用**：一边说「这是我的主线」，一边每天做别的事，是最常见的内耗。

## 主线怎么设
选你最想要、且验证过有戏的那条，投入六成以上时间；定两个检查点——一个中期（例如大三上结束时的排名），一个决定点（例如夏令营结果）。每个检查点写明「达到什么算正常，不达到怎么办」。

## 备选怎么设
备选的目标不是做到优秀，是**够用**：满足最低门槛即可。给备选的时间不超过四成，且优先做与主线共用的部分，见 [可以同时准备几条路线](04-当你开始面对第一次重要分流.md#fork-parallel-tracks)。

## 切换条件提前约定
「如果 X 没达成，则 Y 月 Z 日切换到备选主线」——写下来，届时切换不需要再经历痛苦纠结；不写，多数人会在该切的时候选择再拖一拖。

## 每学期复盘

读研这笔账，常从「学历越高越好」开始算。但真正决定值不值得的，是**目标岗位有没有把硕士写成硬门槛**。门槛存在时，读研是在买一张入场券；门槛不存在时，这两三年就要靠别的东西挣回来。

## 先看目标岗位有没有学历门槛
打开招聘页，抓 20 条你真正想做的那类岗位，把“学历要求”这一栏抄下来：有多少条写“硕士及以上”，有多少条写“本科及以上”，有多少条其实只写了“相关经验”。

用招聘页而不是他人的说法来判断门槛，是这件事里唯一能从外部核实的部分。别人说“这行现在都要硕士”，你可以自己验证。

## 读研能解决什么
- **学历门槛**：需要硕士才能报的岗位（部分高校与科研机构、部分医疗岗位、部分体制内招录）。
- **换方向**：本科专业与目标方向不符时，读研是一次被承认的重新选择。
- **系统训练**：需要长时间积累的专业（医学、法学、部分工程方向），自学很难替代。
- **研究路径的入口**：想做研究，硕士通常是第一段正式训练。

它解决不了的是：方向不清、没有可展示的作品与经历、以及目标岗位根本不看学历的情况。

## 把成本算进来
时间（一般 2–3 年）＋这段时间本来能拿到的收入与工龄增长＋备考成本（通常数月到一年）＋机会成本（错过的岗位、城市与关系）。如果读研期间能参与真实项目或论文，收益要一并计入；如果只是上课，那就只买了学历本身。

经济与家庭约束要先算清楚。约束明确时，先解决约束，再谈选择。

## 哪些情况下更值得考虑
- 目标岗位把硕士写成了硬性条件，且你已经核实过。
- 需要转方向，而新方向以学历作为入场券。
- 已经确认要做研究，并且能进入目标方向的团队。

## 哪些情况下应该谨慎
- 靠技能、作品、证书就能进门的方向（设计、前端、运维、销售、手艺类职业等）。
- 把读研当成“暂时不用面对就业”的缓冲。
- 只为“提升学历”而读，目标岗位并不要求学历。

## 决定之后再看备考
如果决定要读，接下来才是选类型（学术型 / 专业型 / 非全日制 / 海外）、选学校与专业、查目标院校当年的招生简章。这些是执行问题，不要在备考期间反复重开“要不要读”的决策——那是最消耗状态的一种做法。

保研没有全国统一分数线，判断标准写在你**本校**的办法文件里：名额比例、加权成绩口径、加分项、取消资格条款。先把这份文件读完，再谈能不能保上。

## 第一步：读本校文件
打开本校研究生院官网，找到《推荐优秀应届本科毕业生免试攻读研究生工作管理办法》及当年实施细则，逐条抄下：名额比例、成绩口径、加分项、硬性排除条件（挂科重修、纪律处分、四六级或外语要求）。然后用最近一次的成绩排名估算自己是否落在名额区间内；落在边缘时，把加分项（科研、竞赛、社会工作）**按文件口径**算一遍，而不是按听说算。

## 第二步：走流程
确认有希望后，按「夏令营（多在暑期前后）— 预推免 — 推免服务系统填报」的节奏走。推免服务系统的开放时间、志愿数量与锁定规则每年由官方公布，以中国研究生招生信息网的公告为准——系统开放窗口较短，错过无法补救。材料（成绩单、排名证明、个人陈述、推荐信、科研或项目成果）要在夏令营开始前就位。「夏令营」与「预推免」是院校操作层面的通行叫法，没有全国统一的官方定义，各校时间差异很大。

## 免初试资格与提前进组的机会
推免换到的是**免初试的研究生入学资格**、提前接触导师与课题组的窗口，以及省下的一年备考时间——这一年可以用来做科研、实习或补英语。部分院校还会给推免生奖助。

代价主要在前三年：它靠的是持续的成绩与综合测评，不是最后一年冲刺。夏令营阶段还要投入材料与差旅。另一项容易被忽略——确认推免通常意味着放弃统考与联系其他学校的机会。

## 先看资格，再谈要不要走
适合：排名靠前、目标院校与本科层次匹配、愿意继续本专业或相近方向、能早做安排的人。不适合：有硬性排除条款在身的人；排名离名额区间很远还把时间押在「也许能保上」的人；目标是完全跨行业方向的人（保研通常不能换到与本科无关的学科）。

## 三个易错点
以为只看某一次考试或某一学年的成绩；忽略排除条款，到公示阶段才发现资格有问题；把「参加夏令营」当成「已拿到名额」——最终以推免系统的待录取通知为准。

考研是一条规则高度公开的路：报名时间、初试时间、国家线、复试与调剂的流程都写在教育部与中国研究生招生信息网的文件里。**先把规则读完再排复习计划**——翻车往往发生在流程细节上。

## 先读规则
读《全国硕士研究生招生工作管理规定》（每年发布）：报名条件、初试科目、成绩公布、复试与调剂规则都在里面。再看目标院校的招生简章与专业目录，确认考试科目与参考书。报名分**网上报名与网上确认**两个独立步骤，漏掉确认报名无效。

## 复试与调剂要提前排
初试结束后立即进入复试准备，不要等成绩。复试通常包含专业笔试或面、外语环节与综合面试，形式看院校复试办法。调剂要提前列备选：调剂系统通常允许一次填报若干平行志愿，提交后进入锁定状态（时长由招生单位设定但有上限），招生单位每次开放系统也有最短时长要求——具体数字以当年公告为准。记住「一志愿优先」：招生单位先完成第一志愿复试录取，合格生源不足才开放调剂，选校时把这点算进去。

## 一次重新选择学校与专业的机会
考研换到的是**硕士入学资格**、一次跨校跨专业的重新选择机会、一年高强度自学训练，以及读研期间可能的研究经历与新的校招身份。

代价是六到十八个月备考、报名相关费用、期间放弃的收入。如果没上岸，还要面对二战的成本，或转向就业的时间损失。

## 谁适合把一年押在统考上
适合：应试能力稳定、想跨校跨专业重新洗牌、能安排出整块时间、目标岗位明确要求硕士的人。不适合：备考期间被工作课程大量占用、无法连续投入的人；只准备初试不准备复试调剂的人；把考研当「暂时不用找工作」缓冲的人——读完问题还在。二战的策略问题见 [二战](04-当你开始面对第一次重要分流.md#study-retake-exam)。

### 保研和考研怎么选


保研（推免）与考研（统考）在**资格、时间与失败后果**上完全不同。选择顺序是：先看自己有没有保研资格，再决定要不要同时准备统考。

## 两条路的关键差异
| | 保研（推免） | 考研（统考） |
| --- | --- | --- |
| 前提 | 本校推免资格（成绩排名、无不及格等，**以本校办法为准**） | 符合报考条件即可 |
| 时间 | 大三下到大四上（夏令营/预推免/系统填报） | 秋季报名，12 月前后初试，次年春复试 |
| 选择面 | 可申请多所院校（规则以当年系统与院校通知为准） | 一次考试对应一个志愿（调剂另算） |
| 失败后的成本 | 错过统考准备期，可能两头落空 | 需要二战或转就业 |
| 决定权 | 目标院校考核 + 本校资格 | 初试分数 + 复试表现 |

## 先确认资格（第一步）
到本院系查当年推免办法：成绩计算口径、排名要求、是否有不及格限制、加分项认定范围、名额分配方式。**资格不具备时，保研不是选项**，问题就变成「考研还是工作」。

## 能不能并行
**部分可行**：大三下之前，两者都需要成绩与基础；但到秋季会冲突（推免系统填报与考研冲刺期重叠）。

现实的做法：

- **资格有希望**：优先推免，统考只做最低限度准备（不报班、不全力冲刺），直到资格结果明确；
- **资格无望**：直接按统考节奏走，不要在夏令营上投入过多；
- **边缘情况**（排名刚好在线上）：先把资格确认时间点写进日历，再决定资源分配。

## 各自的失败后果与退路
- **推免失败**：当年统考准备时间被压缩，通常要转向春招或次年二战；
- **统考失败**：可二战、就业、留学、专升本（专科）等，见 [继续读书](01-先决定下一步往哪里走.md#paths-continue-study-default)；
- **两者都失败**：不要空等，同步准备就业（秋招与春招仍在窗口内）。

## 判断顺序（可执行）
```
1. 查本院推免办法 → 我有没有资格？
2. 有资格 → 优先推免；同时准备一套统考底线方案
3. 无资格 → 考研 or 工作（看学历是否是目标岗位硬门槛）
4. 无论哪条 → 留一条就业备选，避免全押
```

## 先确认自己有没有推免资格
推免资格由学校与院系按公开规则分配：名额比例、加权成绩口径、加分项、取消资格的条件，都写在学院当年的实施办法里。这是最权威的口径，不要用学长学姐的印象代替。

先做这一步，是因为它决定后面要不要把保研当成主线：有资格，才谈怎么用；没有资格，就把精力放到考研、就业或其他路径上。

## 保研：变量在学校与方向
拿到资格之后，真正要比较的是三件事：能进入的学校与专业范围、导师与课题组的匹配度、以及你愿不愿意在这里待两三年。夏令营、预推免、九推的时间窗口与申请材料，各校各年都不同，需要逐校逐年核对招生简章。

## 考研：变量在科目与周期
考研是先考试再录取：报名时间、初试科目、国家线与复试规则都公开，但**目标院校当年的招生简章**决定了参考书、名额与复试形式。它的确定性来自你自己的复习，不确定性来自报考人数与分数线的年度波动。

## 怎么选
把目标放在前面，难度放在后面：

1. 先列出你想去的那几个学校和方向。
2. 查它们分别通过哪些渠道招生：有的方向几乎只招推免，有的方向统考名额很少。
3. 看自己在这两条渠道上的位置：排名够不够、考试科目熟不熟。
4. 再看时间是否冲突：保研的结果通常在推免系统开放后确定，考研的初试在年末，两者可以部分并行，但要清楚各自的准备强度。

## 同时准备两条路线时要注意什么
可以同时准备，但要把主线写下来：哪一条是主线，哪一条是备选。常见的失败不是“两条都没准备”，而是两条都按主线的强度准备，结果两边都不够。备选路线的准备应该更晚、更轻，并且明确什么时候放弃。

官方口径是两者「同等重要」：学术学位面向知识创新、培养学术创新型人才；专业学位面向行业产业、培养实践创新型人才（教育部 2023 年《关于深入推进学术学位与专业学位研究生教育分类发展的意见》）。落到个人选择上，要看的不是哪个更高级，而是**你下一步要进的门写着哪个要求**。

## 怎么查
在目标院校的专业目录里，看这个专业同时招不招学硕与专硕、各自的考试科目与参考书；看培养方案——课程结构（理论课 vs 实务课）、毕业要求（论文 vs 设计/报告 + 实习）、导师安排方式。目标是读博的：确认有没有硕博连读或申请考核通道及其前置条件；目标是就业的：去目标岗位的招聘页看对「专业」和「学位类型」的写法（部分岗位限定专业代码，很少直接写「仅学术学位」）。学制通常二到三年、以招生简章为准，专硕学费通常更高，奖助政策查该校研究生院官方说明，别用往年数字。

## 全日制与非全日制
官方规则明确：两者执行相同的招生政策和标准，学历学位证书具有同等法律地位和相同效力（教研厅〔2016〕2 号），**但非全日制毕业证书会标注「非全日制」**。问题不在法律效力，在具体招聘公告怎么写。选择流程：先查你打算报考的具体岗位最近一次公告，逐字看有没有「全日制」字样与专业代码限制；再看招生简章确认非全日制招生、上课方式与学制；为单位晋升用的，先问单位人事内部是否认可——这一步常被跳过，读完才发现内部不认。时间按「每周至少八到十小时课业投入」的量级估算。注意：非全日制通常没有完整的应届校招通道，考试标准与全日制是同一套，不要当成「更容易考」。

跨专业考研的成败，主要不取决于决心，而取决于三件事：**目标专业收不收跨考**、**你能不能补上专业课**、**复试时有没有能说服人的理由**。

## 第一步：查官方口径
到目标院校研究生院查招生简章与专业目录，逐条看报考条件里有没有「本科专业要求」「同等学力加试」等限制——这是最权威的口径。医学、部分工科与法学方向常有前置课程或专业限制。

## 第二步：评估补课成本
找该专业近三年的初试参考书与真题，评估自己从零到及格需要多久——不要以「我很有兴趣」作为评估依据。备考期间保留你在新方向上的产出：作品、代码、笔记、报告，这些在复试时比分数更能说明问题。

## 第三步：准备复试的理由
跨考生常被追问转专业理由。准备一个基于具体经历（项目、实习、自学成果）的回答，而不是基于感受——「从小就喜欢」在复试里没有说服力。

## 新方向的入场资格，代价是补课与更高风险
跨专业考研换到的是**正式学历身份与重新进入目标行业的资格**，也是一次纠正专业错配的机会。如果本科背景与新方向无关，反而可能形成交叉优势——工科背景读法学、医学背景读公共卫生。

代价是一年备考（专业课占大头）、可能的二战、隐性偏好带来的更高失败风险，以及入学后补基础课的时间。时间不够时还有替代路径：先工作再申请、读第二学位，或选择对本科背景限制更少的相近专业。

择校的难点不是「哪个学校更好」，而是**同一所学校在不同维度上的表现可能完全相反**。先看录取规则，再看维度，最后才谈排名。

## 七个维度与判断方式
| 维度 | 看什么 | 怎么核实 |
| --- | --- | --- |
| 学校平台 | 在需要学历筛选的通道里的认可度 | 目标单位 JD、招考公告 |
| 专业与项目 | 该专业的师资、方向、实验室条件 | 学院官网、近三年论文与项目 |
| 导师 | 指导方式、产出、学生去向 | 组里的学生（见 [选导师](04-当你开始面对第一次重要分流.md#study-choose-supervisor)） |
| 培养方案 | 课程结构、毕业要求（论文/设计+实习）、能否跨院选课 | 研究生院培养方案 |
| 城市 | 行业密度、实习机会、生活成本 | 招聘平台 + 租金实价（见 [城市要不要纳入选择](01-先决定下一步往哪里走.md#choose-city)） |
| 毕业去向 | 近几届实际去处（要名单，不要就业率） | 学院就业报告、问在读与毕业生 |
| 成本与资助 | 学费、生活成本、奖助与助研机会 | 招生简章、资助页面 |

**注意**：录取规则要先看——有些专业考数学、有些考专业课，考试科目直接决定你能报哪些学校。

## 什么时候排名值得看
- 目标通道靠学历筛选（部分体制内岗位、部分企业初筛）；
- 你还不确定具体方向，需要更大的平台提供选项；
- 学校所在地的行业网络明显更密。

## 什么时候不能只看排名
- 读博或进研究岗：**导师与课题方向通常比学校排名更关键**；
- 专业差异大：同一所学校 A 专业强、B 专业一般的现象很常见；
- 就业在本地：区域认可度可能高于全国排名；
- 费用与资助：全额资助的项目可能比排名更高但自费的项目更划算。

## 实操筛选顺序
```
1. 按考试科目与报考条件筛出候选（能报的）
2. 用近三年数据判断难度（招生人数、推免占比、复试线与录取名单）
3. 按七个维度给每个候选写一段判断（不允许只写排名）
4. 用真题验证难度是否够得着
5. 列出「最想去」「稳」「保底」三档
```

**推荐不要只看排名表**，尤其不要用一份来源不明的排名替代第三步。

## 常见误区
- **把学校名气当成专业实力**；
- **忽略导师**：入学后发现方向与预期不符，换导师成本很高；
- **忽略培养方案**：有的项目以课程为主，有的以科研为主；
- **忽略成本**：学费与生活成本差别可能很大，资助机会也不同。

## 什么时候学校名气更重要
目标是需要学历筛选的通道（部分体制内岗位、部分企业初筛），或你尚不清楚自己要做什么、需要更大的平台提供可选项时，学校权重要上调。这时专业方向的偏差可以用实习与项目补。

## 什么时候导师与项目更重要
目标是读博、进研究岗、或所在领域高度依赖课题组资源时，**导师与课题方向的匹配度通常比综合排名更关键**：跟对了方向，产出与推荐信都能落地；跟错了，平台再好也很难补。判断方法见 [怎么判断一个实验室](03-开始积累真正能留下来的经历.md#research-choosing-a-lab)。


选导师是选**未来几年的工作方式与心情**，不只是选头衔。判断信息分布在三个层次，越往下越可靠。

## 第一层：公开信息（会过时，但能筛掉明显不合适的）
- **近三年论文**：方向是否还在做、一作是谁、产出是否稳定；
- **实验室/课题组页面**：成员名单、设备、项目；
- **注意差异**：有的组主业是 A 方向，导师近年转向 B，你进去做的可能是 A；
- **经费线索**：论文致谢里的基金号、项目页面的在研项目。

## 第二层：组里的人（决定体验的信息）
只有问组里的人才知道：导师多久单独讨论一次、是否给具体反馈、学生能否自己定题、设备和数据是否够用、毕业要求、近三届毕业时长与去向。

**问法很重要**：不要问「老师怎么样」（对方不会说坏话），问具体事实——「你们组会多久一次？」「上次和老师单独讨论是什么时候？」「师兄毕业用了几年？」

## 第三层：制度（最容易被忽略，却常是决定性的）
- **名额在谁手上**：有的院系统一分配，导师只是有意向；
- **录取流程**：导师制还是委员会制（决定联系导师的作用大小）；
- **经费与岗位**：RA/TA 岗位由经费决定；
- **资格限制**：推免、统考、院系考核，任一不过，导师同意也没用。

**做法**：打开院系招生页面，看录取流程写的是「导师接收后报院系」还是「统一材料评审」，十分钟就能判断。

## 该问的问题清单
- 组里现在几位学生，通常同时带几位？
- 经费情况如何，学生通常怎么获得资助？
- 学生一般几年毕业，最近三位去了哪？
- 课题是学生自选还是项目驱动？
- 组会形式与频率，单独讨论多久一次？

## 什么信号说明应该换人
- 组内学生普遍回避评价指导方式（负面信号）；
- 谈过之后发现方向与你想做的不是一回事，且对方不打算调整；
- 资助与名额都无法落实，只给「欢迎报考」这类模糊答复；
- 多次沟通没有回应（且方向明确在招）。

## 常见误区
- **只看职称与头衔**：头衔高不等于指导方式适合你；
- **不问组里的学生**：只凭官网信息做决定，风险最高；
- **同一院系同时联系多位导师**：被发现会同时失去信任；
- **入学后才发现指导方式完全不合**：很多信息在面谈时其实就能问到；
- **把「欢迎报考」当成承诺**：模糊答复通常意味着名额或经费还没落实。

## 一个止损信号
面谈时，如果导师对「第一年做什么」和「经费怎么来」都答得模糊，又没有给出需要你满足的具体条件，这通常不是「随缘」，而是他自己也还没想清楚。此时不要急着确认，继续联系下一位。

## 选错的代价与更正的窗口
选错的代价是几年时间与心情；补救方式包括换组、转导师或提前明确边界——越早处理成本越低。相关判断见 [怎么判断一个实验室](03-开始积累真正能留下来的经历.md#research-choosing-a-lab)。

复试的形式与权重由**招生单位自行规定**，因此第一步不是准备内容，而是把目标院校当年的复试办法读完。

## 从复试办法里抄下来的信息
- 复试形式与环节（笔试、面试、实验/实操、英语测试等）；
- **各部分权重**（初试与复试的占比、复试内部各环节占比）；
- 是否需要提交材料（成绩单、科研证明、个人陈述）；
- 参考书目与考核范围；
- 时间与地点、是否需要政审与体检。

**这些每年可能调整，必须看当年版本。**

## 一般准备什么
| 环节 | 准备方式 |
| --- | --- |
| 专业课笔试 | 按参考书目与真题范围复习，注意题型变化 |
| 专业面试 | 能把本科项目/论文讲清三层；准备被追问的边界问题 |
| 英语面试 | 自我介绍 + 专业相关的英文问答；练听力，不必追求口音 |
| 实操/实验 | 按专业常规操作练一遍；注意规范与安全 |
| 综合面试 | 动机、规划、对专业的理解；避免空话 |

## 常见误区
- **项目讲不清**：只有功能描述，没有你的动作与取舍；
- **夸大经历**：追问细节时露馅；
- **英语准备不足**：听懂问题但答不出来；
- **对目标院校一无所知**：说不出为什么选这个方向与导师；
- **材料不全**：成绩单、证明、政审表漏交。

## 与调剂并行安排
复试与调剂的时间往往重叠，建议：

1. 先确定「最想去」的院校复试时间；
2. 同步准备调剂材料（简历、成绩单、个人陈述）；
3. 关注调剂系统的开放时间与规则（系统规则每年由官方公布）；
4. 若复试结果悬而未决，不要放弃调剂机会，除非你明确愿意二战。

## 心态与信息渠道
- 复试有主观成分，准备的重点是**把确定的东西做扎实**（专业知识、材料、表达）；
- 信息渠道以**目标院校研究生院官网与官方通知**为准，不要依赖非官方群里的说法；
- 联系导师的作用取决于该单位是导师制还是委员会制（见 [选导师](04-当你开始面对第一次重要分流.md#study-choose-supervisor)）。

## 准备清单
1. 找到目标院校的复试办法（研究生院官网公布），看清单：复试形式（线上/线下）、各部分权重、专业课范围、外语环节、面试时长与提问方向；
2. 复习本科核心课程——复试的专业问题通常来自本科主干课与目标方向的基础内容，不是初试参考书；
3. 准备两分钟与五分钟两个版本的自我介绍，以及「为什么选这个方向/这所学校」的回答——用具体经历，不用形容词；
4. 英语环节准备自我介绍、研究兴趣陈述与专业词汇；
5. 有科研、项目或实习的，准备好被追问细节：具体做了什么、遇到什么问题、怎么解决；
6. 提前确认资格材料清单（成绩单、政审表、证件）与提交截止时间。

## 一次翻盘机会，代价是两三周的集中准备
复试换到的是**录取资格**、与未来导师和同门接触的机会，以及对目标方向研究现状的实际了解。

代价是两到六周集中准备，部分院校线下复试还要差旅；同时准备调剂的要并行安排时间。如果初试成绩明显进不了复试，把时间投向调剂准备或就业更实际。

调剂是**时间窗口极短的信息战**。规则公开（系统开放时间、平行志愿数量、锁定规则都由官方规定），但你必须提前列好备选名单——等系统开放才找学校一定来不及。

## 什么时候需要调剂
过了国家线但未进入原报考单位复试、或复试未被录取的人；愿意接受与原目标不同的学校或专业的人。只认某一个学校或城市的人要明白：调剂的选择面通常远小于一志愿。

## 提前列好备选名单与调入条件
成绩出来前就做功课：列出二三十个往年有调剂名额的院校与专业，记下研究生院联系方式与往年调剂要求；逐条核对调入条件——初试科目是否一致或相近、专业是否符合、有无本科背景或加试要求，这些都写在调入单位的调剂办法里。系统开放后按官方规则填报（平行志愿数量与锁定时长以当年公告为准）；同时用邮件联系目标专业负责人，说明分数、科目与背景，书面沟通比口头可靠；保留所有系统截图与邮件记录。

## 当年上岸的机会，代价是选择面变窄
调剂换到的是**当年的录取机会**——用当年的分数去匹配其他院校，不用再等一年。

代价是成绩公布到调剂结束之间的高强度检索与投递；可能不得不接受比原目标差一些的学校或更远的城市，研究方向也可能与原先的计划不同。

三个最常见的失误：只投热门院校，浪费了锁定时间；投递前不看调入单位的科目要求，被直接拒绝；成绩出来后情绪化，错过系统开放的黄金窗口。

二战的前提不是「我要更努力」，而是**你能明确指出这一次的策略要改哪几件事**。如果第二年的方法和第一年完全一样，重复一次更可能重复同一个结果。

## 先写复盘
把第一次的每科分数、失分结构、时间分配、资料使用写清楚，找出**可归因的具体问题**——「不够努力」不算归因。然后列改动清单：换什么资料、换什么科目顺序、改什么作息。清单写不出来，就不该开始。

## 核对身份与条件
往届生的报考点选择、户籍或工作证明要求、部分专业对往届生或同等学力的限制，都以招生简章为准——应届与往届的报考差异不要想当然。

## 设止损与退路
把止损条件写下来，例如「如果第二次仍差 20 分以上就转向就业」。准备一个能同步进行的最小方案（在职备考，或同时投递几个岗位），保留退路。

## 二战值得做的前提
适合：第一年差距不大且该差距有明确补法、失败原因明确可改、家庭现金流允许、有并行退路的人。不适合：只因为不甘心的人；家里需要你尽快有收入的人；连续失败且每次原因相同的人；没有任何备选方案的人。付出的是再一年时间与收入（机会成本通常是最大一块）、备考期间的身份与心理压力。二战成功率没有权威的全国性统计，别用别人的故事估算自己。

留学值不值得，取决于你要用它换什么。与其比较排名，不如先回答三个能核对的问题：**毕业后能不能留下可用的身份或经历**、**总成本能不能承受**、**你的目标行业是否真的需要海外经历**。三个都答不上来时，先不要开始准备语言考试。

## 一、毕业后的去向想清楚了吗
如果目的是留在当地工作，那目标国的毕业后工作许可规则就是核心变量：什么专业、什么学历、多长时间、能不能带家属，全都在移民部门官网写着。近两年加拿大、澳大利亚、英国的相关规则都调整过多次，所以不要用别人一两年前的经历当依据。

如果目的是回国，那要核对的是目标行业怎么看海外学历，以及回国后学历认证的流程与材料。

## 二、总成本算过最坏情况吗
学费只是其中一项。生活费、保险、签证与医疗附加费、往返机票、押金，加上“毕业后半年没找到工作”时的缓冲资金，才是你要准备的全部。最坏情况写下来之后，如果结论是“承受不了”，那这个结论本身就省下了很多时间和钱。

## 三、语言与标化考试的时间安排对得上吗
语言成绩有效期通常是两年，考试要贴着申请时间倒排。不同项目对总分与小分的要求不同，先查目标项目的要求，再决定考哪一门、考几次。

## 什么情况下先不要急着申请
- 把留学当成“换个地方重新开始”，但说不清要换到什么。
- 资金只能覆盖最理想的情况。
- 只了解二手信息，没打开过任何官方页面。
- 所在行业对海外经历没有明显溢价。

## 决定要走之后
按“目的”筛国家，再按“成本”筛项目，最后才看排名。签证、语言、材料、认证这些环节都是执行问题，各有官方入口，不需要中介转述。

### 国家和地区怎么选


选国家不是选「哪个好」，而是选**哪套制度更匹配你的目标**。其中「身份与工作许可」最容易被忽略，却往往是决定性的。

## 六项比较指标
1. **培养方式**：一年制授课型（英国、中国香港等）vs 学制更长、研究型与授课型差别大的体系（美国）；欧洲大陆部分国家公立学费低但需本地语言；日本、韩国需语言成绩或英语项目；
2. **总成本**：学费 + 生活成本 + 一次性支出 + 机会成本，国家之间可能相差数倍（见 [留学总成本](04-当你开始面对第一次重要分流.md#overseas-total-cost)）；
3. **身份与工作许可**：毕业后能否留下、能留多久、是否需雇主担保——**这一项决定「留学」是否等于「海外就业」**；
4. **行业密度**：你的目标行业在哪些国家/城市有岗位聚集，以及语言门槛；
5. **资助可能性**：公派、政府奖学金、院校奖学金、导师经费的覆盖差异；
6. **家庭支持与承受度**：资金可持续性、是否允许中断、长期分离的承受度。

## 各国/地区的注意点（仅作入口，规则以官方为准）
| 方向 | 学制与特点 | 需要重点核实 |
| --- | --- | --- |
| 美国 | 学制较长，研究型项目资助机会多 | F-1 身份维持、CPT/OPT 与 STEM 延期规则 |
| 英国 | 一年制授课硕士为主 | 学生签证、Graduate Route 的时长与条件 |
| 加拿大 | 学制中等，部分项目与移民通道相关 | 学习许可、DLI 与 PGWP 的绑定 |
| 澳大利亚/新西兰 | 学制较长，毕业生工签规则相对明确 | 学生签证与毕业后工签的资格、年龄与学历要求 |
| 日本/韩国 | 需语言或英语项目；本地就业看重语言 | 在留/居留资格、打工许可、毕业后求职签证 |
| 中国香港 | 学制短、英语授课多、离内地近 | 学生签证、IANG 与永居的区别 |
| 欧洲大陆 | 公立学费低，但各国制度差异大 | 各国签证与居留规则（欧盟≠申根） |

制度入口见 [常用官方来源清单](../docs/sources/常用官方来源清单.md) 与 [各国制度入口](../docs/countries/美国.md)。

## 决策顺序
```
1. 排除硬约束（预算上限、语言能力、家庭照护责任）
2. 确定毕业后是留当地还是回国
3. 比较目标行业的密度与语言门槛
4. 算清总成本与资助可行性
5. 看回退路径（回国 / 换国家 / 先工作）
6. 最后比较学校与项目
```

## 注意三种常见误解
- **欧盟 = 申根**：两者范围不同，签证与居留规则按国家区分；
- **「留学就能留下」**：取决于毕业后工作许可与雇主担保规则；
- **「学费低就便宜」**：生活成本、保险与一次性支出可能反超。

## 先问三个问题，再看学校
- **我毕业后打算留在当地，还是回国？** 两条路的差别很大：留当地看身份与行业；回国看学历认可与目标行业的地域偏好；
- **我的语言能支撑学习和工作吗？** 语言授课项目必须本国语言；英语项目的当地就业面通常窄于本地语言者；
- **如果毕业后留不下，回国的路径是否顺畅？** 学历认证、行业认可、求职时间窗口都要提前查（回国使用学历需办理学历认证）。

## 三件必须核对的事
- **毕业后工作许可**：在选校阶段就查目标国移民部门官网（美国 USCIS 与 travel.state.gov、英国 gov.uk、加拿大 IRCC、澳大利亚 HomeAffairs、日本出入国在留管理厅、新加坡 ICA 等）。近两年多国有调整（加拿大学习许可上限与省级证明信、澳大利亚临时毕业生签证改革、英国毕业生签证等），本页不列具体时长，一律以官方最新公告为准；
- **资金**：按官方要求核对资金证明（金额、存期、可接受形式）与医疗保险；
- **学历认证**：计划回国使用的，在申请阶段就了解教育部留学服务中心的认证要求并保留好原始材料。

各国学费、生活成本与申请细节差异极大，按国家逐个查，见 09 专题手册的国家与地区页。别用中介转述或几年前的经验帖代替官方页面。

### 授课型与研究型

授课型硕士靠课程和学分毕业，主要换的是一份学历和职业入场资格；研究型硕士靠论文和研究训练毕业，主要换的是研究能力、推荐信和读博的跳板。两者名字相近，产出完全不同，选错的代价是一到两年加一笔学费。

## 怎么选
先确定你要的是「入场资格」还是「研究训练」，这个答案决定后面所有选择。授课型适合：需要学历门槛（部分岗位、资格、签证路径）、想换国家或行业、明确不读博的人。研究型适合：准备申请博士或目标岗位看重研究经历、且能找到愿意接收的导师与课题的人——研究型项目通常需要导师同意才可能录取，必须提前联系并确认经费或助研位置。打算读博却选了几乎进不了实验室的授课型项目，是最常见的选错。

## 六步流程
确定需求 → 到目标国家官方移民或教育部门页面确认学制与毕业后工作许可（不用中介或论坛信息）→ 到院校官网核对项目类型、毕业要求、是否有论文环节 → 研究型提前联系导师 → 用官方学费页加本地生活成本算总预算 → 确认回国学历认证要求。

## 两种学位产出完全不同
海外学位换到的是**一份境外学历学位**（部分岗位、资格与签证路径有明确用途）、语言与跨文化能力、当地的实习与就业机会。研究型项目还会额外带来论文、导师推荐信与博士申请通道。

代价是学费与生活费（国家、城市、学校差异极大，按官方学费页核实，不要用中介报价）、一到两年时间、语言与迁移成本、毕业后可能的身份限制，以及回国后的学历认证。

需要泼一盆冷水：在多数岗位，**「海归」本身只是不扣分，不是加分**。项目内容与毕业生的实际去向，才决定它的价值。

### GPA

```meta
id: overseas-gpa
status: complete
stages: [undergraduate, master]
topics: [study]
outputs: [degree]
effort: medium
evidence: [official, experience_based]
summary: 留学申请中的 GPA：怎么换算与自评、不同学位类型的权重、偏低时的补救方式。
last_verified: 2026-09-27
```

GPA 在留学申请里既是**门槛**也是**信号**：多数项目设最低要求，达到之后它与其他材料共同决定结果。

## 怎么自评（不必精确换算）
- **看目标项目的要求口径**：有的按百分制均分，有的按 4.0 制，有的按等级制——**以项目官网说明为准**；
- **看整体还是看后两年**：部分项目更看重后两年的成绩或专业课成绩；
- **不要自行用第三方换算器得出「等效 GPA」就当作结论**，它只是估算。

## 不同学位类型的权重
| 类型 | GPA 权重 | 说明 |
| --- | --- | --- |
| 授课型硕士 | 高 | 常设最低均分或 GPA 线 |
| 研究型硕士 | 中高 | 与研究经历、导师匹配、推荐信共同作用 |
| 博士 | 中 | 研究能力与匹配度权重大，但低于线通常直接筛掉 |
| 部分欧洲项目 | 中 | 更看课程匹配与学分要求 |

## 偏低时的补救方式
1. **用后两年的成绩说话**：如果趋势上升，在文书里如实说明（不要辩解，说明变化与原因）；
2. **补硬证据**：项目、论文、实习、竞赛、公开作品；
3. **选对项目**：有的项目更看研究经历或工作经验，或对均分要求不同；
4. **补充课程**：部分项目要求先修课，补课成绩也能作为参考；
5. **语言与标化**：在分数之外提供另一种可比的能力证明。

**不要做的**：修改成绩单、隐瞒重修记录。这类问题一旦被发现，后果远超成绩本身。

## 常见误区
- **只盯总分**：忽略专业课成绩与课程匹配度；
- **以为「差一点就没戏」**：不少项目允许在材料中看到补偿性证据；
- **忽略换算口径**：投递前没确认对方按什么标准评估；
- **因 GPA 放弃申请**：先查清最低要求再判断，很多项目并不设硬线。

## 三层用法
- **门槛线**：部分项目写明最低 GPA 或均分要求，低于线基本不进评审；
- **比较线**：多数项目公布往届录取者的 GPA 区间，你在区间内即可竞争，明显低于区间则要靠其他材料补；
- **趋势线**：成绩逐年上升的申请者，比高开低走的更受欢迎——评审会看你的发展轨迹。

## 不同算法的影响
国内各校算分方式不同，申请时通常要换算或提供排名证明。**排名有时比绝对分数有用**：在给分严格的学校，前 10% 的排名本身就是说服力。具体要求以目标项目官网为准。

## 补救路径
低年级课程不理想：高年级重修或选修相关课程，拉出上升趋势；专业课缺失：用在线课程证书补充先修背景；解释空间：文书中简短说明特殊原因，重点放在之后的改善——不要渲染困难，重点是可验证的改善。

留学考试分两类：**语言能力考试**（几乎所有非母语申请者都要）与**标准化能力考试**（部分国家与项目要求）。先查目标项目的要求，再决定考什么。

## 两类考试
| 类型 | 常见考试 | 用途 | 是否普遍要求 |
| --- | --- | --- | --- |
| 语言 | IELTS / TOEFL / PTE / Duolingo 等 | 证明能在该语言环境学习 | 非英语母语者通常需要 |
| 标化 | GRE / GMAT / SAT / ACT 等 | 部分国家与项目的学术能力评估 | **因项目而异** |

**注意版本差异**：某些国家签证要求特定版本的考试（例如英国的签证类考试），**以官方与项目要求为准**。

## 准备顺序
```
1. 列出目标项目清单 → 逐项抄下语言与标化要求（总分、小分、是否必须）
2. 语言优先（它是硬门槛，且几乎所有项目都要）
3. 标化按需（只在项目要求或明显加分时准备）
4. 预留一次重考的时间与预算
```

**语言先行**的另一个原因是：语言能力同时影响文书写作与面试表现。

## 时间安排要点
- 成绩通常有有效期（多为两年，以官方说明为准），注意入学时是否仍需有效；
- 从起点到达标通常需要数月，取决于起点与目标分数；
- 申请季前后考位紧张，**提前报名**；
- 送分与成绩单寄送需要时间，别卡在截止日前。

## 不必考的情况
- 项目明确接受其他证明（英文授课证明、语言班衔接、校内测试、母语豁免）；
- 项目不要求标化，且你的其他材料（研究、实习）足够强；
- 时间正挤占更关键的准备（绩点、项目、论文），且目标尚未确定。

## 备考方法（通用）
1. 用一套完整真题测起点，得到各项真实分数；
2. 先补最短的那一项；
3. 输出类（口语、写作）必须练到能自评（录音、批改、按评分标准对照）；
4. 考前两到三周做限时全套模拟，适应节奏；
5. 记录每次模考的错因，避免重复。

## 五步流程
1. 列出五个目标项目的入学要求，抄下每一项：接受哪些考试、总分与小分要求、成绩有效期、送分方式；
2. 只报考**目标项目都接受**的那一门，不要同时准备两门；
3. 用官方样题做一次完整模考确定起点，再决定备考周期（一般两到四个月）；
4. 报名走官方渠道：雅思与托福在中国内地经教育部教育考试院的官方入口；
5. 成绩有效期纳入时间表——雅思与托福有效期为两年（以官方说明为准），不要提前太久考。

## 语言成绩决定申请能否被审
语言考试换到的是**入学与签证的语言条件**、部分奖学金的语言门槛，以及一门真正可用的外语（前提是准备方式对路）。

代价是数周到数月备考、考试费用（以官方报名页为准），以及可能的重考。常见失误：不查小分要求，总分够但单项被卡；只刷题不练口语与写作；成绩过了有效期才去送分。

**达标就停，转向材料准备**：语言成绩通常只决定「申请能不能被审」，不是核心竞争力。不要为了刷分挤掉 GPA 与科研的时间——这两项没有重考机会。

```meta
last_verified: 2026-09-27
```

推荐信的作用是**用第三方视角证明你的能力与潜力**。评审真正在意的是：写信人是否了解你、能不能说出具体细节。

## 找谁写
优先级通常是：

1. **带你做过研究或项目的老师**（能写具体工作与你的判断）；
2. **上过你的课并且你表现突出的老师**（次优，但要能写出细节）；
3. **实习或工作的主管**（对研究型项目权重低于学术推荐人，对职业型项目权重高）；
4. **头衔大但不了解你的人**（最弱，容易写出空泛评价）。

**判断标准**：他能否说出你做过的一件具体的事，以及你遇到问题时的反应。

## 提前多久沟通
**至少提前四到六周**，理由：

- 推荐人需要时间回忆与写作；
- 你可能需要多轮沟通补材料；
- 提交系统可能需要推荐人注册、收邮件、上传（有技术问题的时间成本）。

## 要给推荐人什么材料
一个材料包，包含：

- 你的简历（含具体项目与你的角色）；
- 成绩单与排名（如适用）；
- 申请项目清单与每项的**截止日期**；
- 你希望被强调的三件事（不是替他写，而是提供事实）；
- 提交方式说明（在线系统链接、是否需要推荐人账号）。

## 常见的失分点
| 失分点 | 后果 | 避免方式 |
| --- | --- | --- |
| 临时通知 | 推荐人写不细或直接拒绝 | 提前四到六周 |
| 只给成绩单不给项目说明 | 内容空泛 | 附材料包 |
| 不确认提交状态 | 系统未收到导致申请不完整 | 截止前一周跟进确认 |
| 推荐信内容与文书矛盾 | 评审察觉不一致 | 与推荐人同步你的叙述重点 |
| 找一大群人写同一件事 | 重复且浪费 | 2–3 人，各有侧重 |

## 提交环节的细节
- 看清项目要求的推荐人数量与是否必须机构邮箱；
- 有的系统会问你是否放弃查看权利（**放弃通常更受信任**）；
- 提交后确认系统显示「已收到」，不要假设对方已经点了链接；
- 如有变化（换项目、延期），及时告知推荐人。

## 给推荐人准备好材料
提前至少一个月沟通，给对方三样东西：你的简历、你要申请的方向与学校清单、每一个截止日期。如果对方同意，再补充一页「希望被强调的三件事」，方便他下笔。

## 提交时要注意什么
- 看清项目要求几位推荐人、是否接受在线提交、是否要求推荐人用机构邮箱。
- 确认是否需要你放弃查看权（多数系统会问）；放弃查看权通常更受信任。
- 截止日前一周确认状态，避免推荐人漏交。

个人陈述（PS / SOP）要回答的只有三个问题：**你想做什么、你为此做过什么、为什么是这个项目**。写成「从小热爱」的叙事几乎必然失败，因为评审要的是证据，不是抒情。

## 怎么写
列出三个问题，每题先用中文写三到五句再翻译；为每个论断配一个具体事实：项目名、成果、数字、时间，删掉所有无法对应的形容词；查目标项目的官网与教师主页，把「为什么是这个项目」写得具体——提到某位老师的某项工作、某个方向、某个资源。控制长度，以各项目的字数或页数限制为准。最后找两个人读：一个懂专业（判断事实是否站得住），一个不懂专业（判断逻辑是否清楚）。

## 唯一能主动解释自己路径的材料
个人陈述的价值在于：它是申请材料里少有的、**能主动解释「我的路径为什么是这样」**的部分，同时可以弥补成绩单上的小瑕疵。写出一份底稿还能在多个项目间复用，面试时也直接能用。

代价通常是二到四周的反复修改，加上请人读稿的时间。

## 写成抒情文或官网简介
罗列成绩而不解释它们之间的关系；把「为什么选你们学校」写成官网简介；用他人模板改写导致内容与自身经历不符；超过字数限制。用一篇文书投所有项目同样不行——每个项目的「为什么是我们」都需要重写。

## 五段结构
用一句话写出研究问题（写不出来说明还没收敛，先回去做文献阅读），然后按固定结构写：问题是什么 → 为什么重要（现有工作的缺口）→ 你打算怎么做（方法与数据）→ 预期产出与判断标准 → 时间安排。控制篇幅，多数项目要求两到五页，以官网为准；写清参考文献，格式统一，只引用真实存在且你读过的文献。

## 怎么检验
找一位做过研究的人读，重点问两个问题：「这个问题清楚吗？」「这个方法能不能回答这个问题？」方法部分空泛（「将采用定量与定性相结合的方法」）是最大硬伤；写成领域综述、没有自己的问题同样不行。

## 研究型项目必须，授课型通常不需要
申请研究型硕士与博士、岗位制博士或需要预先联系导师的人必须写；还没做过任何研究的人先完成一个小研究再写，把方向综述当计划是常见误区。

## 怎么写
先读导师主页与近三年论文，找出与你兴趣相关的具体工作；按 [联系导师邮件模板](../docs/tools/联系导师邮件模板.md) 的结构写：你是谁、能提供什么 → 你要什么、什么时候要 → 附什么。附件只发必要的（简历 PDF、成绩单、代表性成果），总大小控制在几 MB 内。同一院系一次只联系一位；一周到十天后未回复，可在原邮件下简短跟进一次；收到「今年不招」也是有效信息，记入备选清单明年再问。

## 换来是否招生的准确信息
联系导师换到的是**是否招生的准确信息**、一次展示研究能力的机会，以及可能的推荐、合作或访问机会。

代价是每封邮件一到三小时的定制时间，以及一周到十天的沉默等待。常见失误：邮件里问官网已经写明的问题（名额、截止日、语言要求）；只写「我对您的研究方向很感兴趣」而没有具体内容；同时联系同一课题组的多位导师。

## 导师制项目需要，委员会制先看说明
申请研究型硕士与博士、需要海外推荐信或研究机会的人需要；申请授课型硕士且项目明确不需要联系导师的，联系反而可能被视为不理解流程。

海外资助的核心不是「有没有奖学金」，而是**四类来源能不能拼起来覆盖学费与生活**。

## 四类来源
| 来源 | 形式 | 时间 | 义务 |
| --- | --- | --- | --- |
| 政府项目 | 公派、目标国政府奖学金 | 提前 12–18 个月，窗口固定 | 常含回国服务或单位协议 |
| 学校与院系 | 全额奖学金、fellowship、学费减免 | 随申请或单独申请 | 一般无，可能有成绩要求 |
| 导师项目经费 | RA 岗位 | 需提前联系导师 | **有工作职责** |
| 外部机构 | 基金会、企业、协会 | 独立截止日 | 视条款 |

## 申请顺序（提高成功率）
```
1. 读目标项目 funding 页面：哪些自动考虑，哪些需单独申请
2. 需要单独申请的：单独记录截止日（常早于入学申请）
3. 导师制项目：联系导师时直接问经费与位置
4. 政府项目：按官方流程走（材料多、周期长）
5. 备选：先自费入学，再争取校内助研岗位
```

## 时间线要点
- 语言成绩：多数资助要求提交时已达标；
- 推荐信：提前四到六周联系推荐人；
- 政府项目：可能有单位推荐、体检、政审等环节；
- **漏掉单独截止日 = 等下一年**，所以两类截止日要分开记。

## 义务条款怎么读
签字前逐条看：

- 是否有服务年限或回国义务，违约如何处理；
- 是否要求工作时数（TA/RA）；
- 是否排他（能否与其他资助叠加）；
- 期限是否覆盖整个学制（最后一年是否需要另找）。

## 不够用时怎么办
- **校内助研/助教**：入学后争取，是最常见的补齐方式；
- **学费减免与分期**：部分学校提供分期或紧急资助；
- **外部小额奖学金**：金额不大但竞争小；
- **调整预算**：换城市、合租、缩短学制（**但要用毕业去向验证**）。

## 判断「够不够」的方法
```
学费（减免后剩余）+ 生活成本 + 保险与一次性支出
− 资助（注意税前/税后、发放周期、覆盖年限）
= 缺口
```

三个常见坑：资助按学年发放但开学要垫押金；津贴为税前；资助期限短于学制。

## 四类渠道
- **本国渠道**：国家留学基金委（CSC）的国家公派研究生项目，覆盖学费与生活费（按项目而定），有明确的申请窗口与派出要求；
- **目标国政府**：英国 Chevening、美国 Fulbright、欧盟 Erasmus Mundus、日本 MEXT、韩国 GKS、德国 DAAD——各家覆盖内容不同，必须看官方页面；
- **院校渠道**：目标院校的奖学金页面（研究生院、院系、导师项目经费）；研究型学位直接问导师是否有经费支持，这在岗位制国家是常态；
- **外部机构**：基金会与企业的资助计划。

## 执行要点
把所有截止日期排进日历——多数资助比入学申请早二到六个月；每项资助一套独立材料；一次投多个，把部分资助的叠加可能也算进去，别只盯「全额」。奖学金不只看成绩：多数还看研究计划、推荐信与服务义务条款。已到申请截止才想起找资助的，多数已经来不及。

留学成本最容易被低估的部分不在学费，而在**汇率、税、以及失败后的沉没成本**。这一页给一套可复算的口径。

## 四类支出
```
1. 学费（按学年或学分，注意是否每年上涨）
2. 生活成本（住宿、餐饮、交通、通讯、保险、教材）
3. 一次性支出（机票、签证、体检、押金、设备、安家）
4. 机会成本（放弃的收入 × 学制年数，常被漏掉）
```

**机会成本要算进去**：一年制硕士的机会成本可能是十几万到几十万，与学费同量级。

## 三项常被漏掉的部分
- **汇率与跨境手续费**：换汇时点不同可能差出几个百分点，跨境转账有手续费与额度限制；
- **税与发放周期**：有的资助或实习收入需要自行申报；奖学金发放滞后时需要先垫付；
- **失败成本**：签证被拒、延期毕业、项目中断后的重新申请费用——这些不需要默认发生，但应留一笔缓冲。

## 按时间排现金流
| 时间点 | 支出 | 收入 |
| --- | --- | --- |
| 申请期（提前 12–18 个月） | 考试费、申请费、材料寄送 | — |
| 录取后 | 押金、签证费、体检、机票、押金与首月房租 | 奖学金可能尚未发放 |
| 入学初期 | 学费首期、生活启动、设备 | 助研津贴通常按月发 |
| 学制中期 | 学费、生活、可能的差旅 | 奖学金/津贴、实习收入 |
| 毕业前后 | 求职成本、搬家、可能的签证费 | 工作收入（如已入职） |

**常见踩坑**：假设奖学金覆盖一切，结果开学第一个月要垫押金与设备，出现短期缺口。

## 怎么拿到可靠数字
- 学费与资助：目标项目官网的 tuition 与 funding 页面（逐项抄下来）；
- 生活成本：目标城市的实际租金与物价（租房平台、学校官网的生活成本估算）；
- 汇率：按当前汇率并预留波动空间，不要用历史最高汇率乐观估算；
- 机会成本：按你毕业后可预期的保守起薪算。

## 怎么判断值不值
不要只看「总共要花多少」，看三个比值：

1. **净支出 ÷ 预期年收入增量**：回本需要几年？（用保守收入，不用最好情况）
2. **净支出 ÷ 家庭可动用资源**：是否会影响家庭的其他安排（养老、医疗、其他子女）；
3. **目标达成的概率**：你想通过留学获得的东西（学历门槛、身份、行业入口、语言），是否真的需要留学才能获得？

三项里任何一项答不出，说明决策依据不足，而不是成本太高。

## 降低成本的可行方式
奖学金与资助（见 [奖学金与资助手册](../docs/manuals/奖学金与资助.md)）、助研岗位、学制更短的项目、生活成本更低的城市、以及在本国先工作几年攒钱与攒经历后再出发。

## 四块怎么算
- **学费**：从院校官网核对，区分国际学生费率与本国学生费率，以及是否逐年上涨；
- **生活成本**：用学校官网公布的估算，再用目标城市官方统计或租房平台核对住房部分——住房通常占大头；
- **一次性**：语言与标化考试、申请费、签证费与医疗附加费、机票、体检、押金（看清楚是否可退）；
- **最坏情况**：如果毕业后半年没找到工作，你需要多少钱回国或继续等待？这笔钱要提前留出。

- **汇率与跨境手续费**：换汇时点不同会带来可观的额外支出，做预算时应预留波动空间，不要用历史最优汇率乐观估算。

RA（Research Assistant，研究助理）是参与研究的起点角色：在导师或课题组安排下承担具体的研究工作。

## 通常做什么
文献整理与综述初稿、数据收集与清洗、实验操作、复现论文结果、撰写阶段性报告。别小看这些：课题组的信任就是从这些活开始建立的，做好了才有机会参与更核心的部分。

## 有没有报酬
分情况：校内课题组可能给补贴或算学分；校外的（含海外暑研 RA）通常有薪水或奖学金支持。**一开始就问清楚**：工作内容、每周时长、有没有报酬、是否有署名机会——含糊答应之后很难再改。

## 怎么找
本校：直接邮件联系做你感兴趣方向的老师，附成绩单与一句你为什么想跟他做；外校或海外：留意课题组官网的招聘页与暑期项目（见 [暑研](04-当你开始面对第一次重要分流.md#research-summer-program)）。

## 它能换来什么
一段真实的研究经历、导师的了解与可能的推荐信，以及「我适不适合科研」的答案（见 [怎么判断自己是否喜欢科研](03-开始积累真正能留下来的经历.md#research-do-i-like-it)）。做杂活不等于科研——要主动争取参与问题定义与结果讨论。

## 怎么判断这段 RA 值不值得做
用一个标准衡量：**它有没有让你接触「问题—方法—证据」这条链**。同样是 RA：

- **低价值**：连续半年只做标注与格式整理，没人解释这些数据要回答什么问题；
- **中等**：负责一个模块的复现，知道它在整篇工作里的位置；
- **高价值**：参与讨论「这个现象说明了什么」，并进入实验设计或写作。

如果半年后你还停在第一层，值得直接把想参与问题定义的意愿提出来。多数导师并不介意，只是默认你可能没兴趣。

## 什么时候该退出
- 连续两个学期只有重复性劳动，提出后仍没有变化；
- 组内没有可讨论的人（导师长期不在，师兄师姐各做各的）；
- 已经能确认自己不喜欢这类工作——此时退出不是失败，而是及时止损，把时间转到别的路径。

退出前把已做的事整理成材料（数据、脚本、复现记录），并如实向导师说明，留下一个体面的结尾。

暑期科研项目通常两到三个月，产出可以是一次完整的小研究。它的核心价值不是「去了国外」，而是**在目标课题组里做出一件可写进申请材料的事**——它是申请海外研究型学位最有效的跳板之一，也是最容易被浪费的一种经历。

## 怎么申请
选定方向后列出五到十个目标课题组，看主页的招生或访问说明（很多课题组明确写了是否接收暑期学生）；准备一份一页纸的说明：你做过什么、会什么工具、打算做什么、能待多久、是否有资助；提前四到六个月联系导师，参考 [联系导师邮件模板](../docs/tools/联系导师邮件模板.md)。出发前把研究问题、方法与预期产出与导师对齐——去了才开始想做什么，是最常见的浪费。

## 在期间与结束时
第一个月主动与组内成员对齐工作方式，明确要交付的产出。结束时确认三件事：推荐信（是否愿意写、什么时候写、写到什么程度）、成果署名、后续联系方式。

## 一段可写进申请的海外研究经历
暑研换到的是**一段可写进申请的研究经历**、海外导师的推荐信、对目标课题组研究方式的直接了解，以及后续申请的内部信息。

代价是两到四个月的暑假或学期时间、生活费与机票（部分项目有资助或津贴，部分需要自费），加上申请与签证准备。

两种情况先别急着去：还没做过任何研究的，先在本校完整做完一个小项目更划算；语言不足以参与组会讨论的，先补语言。相关形态还有访问学生（Visiting Student，三到十二个月，价值逻辑相同但时间更长）与 Summer School——注意区分正式学分课程与付费游学团，只看目标院校官网的项目，核对课程由哪个院系开设、是否给学分、能否转回本校。

### 文献阅读

```meta

status: complete

effort: medium
evidence: [official, experience_based]

last_verified: 2026-09-27
```

读文献的目标不是「读完」，而是**回答你手上的问题**。因此第一步不是打开论文，而是明确问题。

## 三轮过滤
| 轮次 | 读什么 | 时间 | 决定 |
| --- | --- | --- | --- |
| 第一轮 | 标题、摘要、图表 | 3–5 分钟 | 是否继续 |
| 第二轮 | 引言、结论、方法概要 | 20–30 分钟 | 是否精读、用什么角度读 |
| 第三轮 | 方法、实验、附录 | 1–2 小时 | 能否复现、结论边界在哪 |

**允许跳过**：与你问题无关的经典论文也不必现在读。阅读优先级由问题决定，不由「重要性」决定。

## 笔记要留下什么
每篇一条，控制在六行内：

```
它解决的问题：
方法（一句话）：
关键结论与边界条件：
与我关心的关系（支持/反驳/提供工具/无关）：
可复现性（代码、数据、环境）：
疑问与待查：
```

**不要整段摘抄**：抄下来的原文几乎不会再用。用自己的话重述结论与限制，才是能复用的部分。

## 建立文献地图
- **一篇近三年综述**：作为地图，看领域分类与主要方法；
- **往前追**：综述里被反复引用的基础工作，读三到五篇；
- **往后追**：引用它的后续工作（尤其是有没有推翻或改进）；
- **建表**：行是文献，列是「方法 / 数据 / 结论 / 局限」——这张表往往就是你的综述或开题的骨架。

## 什么时候算读够了
能回答三个问题就够：

1. 这个方向现在的主流方法是什么？解决了什么、还剩什么？
2. 我要做的问题与已有工作的差别在哪？
3. 如果要动手，最小可验证的一步是什么？

答不出第 2 条，说明还需要读；答不出第 3 条，说明读的是领域而不是问题。

## 常见效率问题
- **从摘要读到附录**：每篇两小时，一周读三篇，进度瘫痪；
- **只收藏不整理**：收藏夹很满，笔记为零；
- **只看二手介绍**：中文博客与视频常滞后且有误，尤其是方法与实验细节；
- **不写不练**：读完写不出一段自己的总结，说明没有真正理解。

## 工具
文献管理器（Zotero 等）、预印本平台（arXiv、bioRxiv 等）、引文网络（Google Scholar / Semantic Scholar）。工具的作用是减少重复劳动，不解决「读不懂」的问题。

更完整的操作流程见 [文献阅读与综述](../docs/research/文献阅读与综述.md)。

## 具体做法
建文献库（Zotero 等免费工具即可），每篇记录三行：问题、方法、与我课题的关系。从综述文章与领域内被引最高的论文入手建立地图，再向外扩展。三轮法过滤，只有第三轮做笔记；每周花一小时把本周读的连成结构——这个领域在争什么？缺口在哪？卡住的术语单独建档，而不是每篇都从头查。

```meta
summary: 研究问题怎么定：从现象出发、用四条标准筛掉假问题、把大问题拆成能验证的一小步。
last_verified: 2026-09-27
```

定研究问题是科研里最难的环节，也是决定成败的环节。它的难点不在「想不出来」，而在**分不清哪些问题值得做**。

## 从现象出发，而不是从领域出发
「我对人工智能感兴趣」不能作为起点。可用的起点是一个**具体现象**：

- 某个方法在理论上应该更好，实测却更差；
- 某类数据上大家都报告高指标，换一份数据就崩；
- 某个流程在实际使用中被绕开；
- 两个已有结论互相冲突，且都有人引用。

从一个现象出发的好处是：你能立刻说清「现在的理解哪里不够」，而这正是问题的入口。

## 四条筛选标准
1. **是不是真问题**：现有方法在什么条件下失效？失效的后果是什么？
2. **是否已被解决**：不是「没人做过」，而是「现有工作为什么不够」——需要证据，不是印象；
3. **能不能被证伪**：能否设计一个实验，让「我有道理」与「我错了」产生不同的可观察结果；
4. **做得完吗**：在你能拿到的数据、设备、时间与人手下，最小可验证的一步是什么？

四条里有一条答不出，通常是问题还没想清楚，而不是资源不够。

## 把大问题拆成一小步
例如「如何提升小样本下的模型鲁棒性」太大，可以拆成：

```
现象：在 X 数据上，方法 A 的指标比 B 高，但换到 Y 数据后反转
追问：反转是由数据分布差异导致的吗？如果是，哪一类差异最关键？
最小验证：构造两组只差一个因素的数据，重复实验，看指标是否反转
产出：一份实验报告 + 可能的改进方向
```

**能在一个学期内做完的一步**，比一个宏大的方向更有价值：它给你真实的数据与经验，让下一步的判断有依据。

## 常见假问题
| 假问题 | 问题在哪 |
| --- | --- |
| 「如何让模型更准确」 | 没有条件与边界，无法验证 |
| 「X 方向有什么值得做的」 | 这是文献综述的题目，不是研究问题 |
| 「把 A 和 B 结合起来」 | 组合本身不是理由，要说清为什么应该结合 |
| 「做一个小工具」 | 工程任务不等于研究问题（除非它能回答某个未知） |
| 「复现某论文」 | 复现是训练，不是研究问题（但扩展它可以成为） |

## 怎么知道自己定对了
- 你能用两句话向不同背景的人讲清楚「现在哪里不清楚、我打算怎么弄清楚」；
- 你能说出至少一种「如果结果是这样，说明我错了」的情形；
- 你已经找到两到三篇最相关的工作，并能说清它们的局限；
- 你能给出下一步的具体动作（而不是「再读读文献」）。

## 卡住时怎么办
- **找不到问题**：多半是文献读得不够具体，换一篇最相关的论文精读，和它的局限死磕；
- **问题太大**：强制自己把范围缩到「一学期能给出一个结论」；
- **问题被否**：先区分「导师认为不重要」还是「方法上不可行」，两者应对不同；
- **做了两个月没有进展**：回到第 4 条标准，检查是不是最小一步设定得太难。

## 怎么收敛
把问题写成一句话问句（不是陈述句）：「xx 是否/如何/为什么……」。然后三个检验：能列出验证它的数据与方法吗？查过文献吗（确定没有现成答案）？答案出来谁会关心？一句话里有两个以上抽象名词就拆开它。与导师确认可行性（数据、时间、经费）再动手；保留两到三个候选问题，主问题受阻时可切换。

## 一个能支撑整篇论文的问题
把研究问题打磨清楚，换到的是**一个能支撑整篇论文的问题**、开题答辩与基金申请里最核心的那段话，以及与导师高效讨论的基础。

代价是数轮文献阅读与收缩、与导师的多轮讨论。四类问题要避开：太大（「人工智能对教育的影响」）、已经被回答过、无法验证，以及为了新颖而新颖、与自己的能力不匹配。

实验设计的目标不是「做出结果」，而是**让结果能被相信、能被重复**。这一页给初学者可执行的最低标准。

## 把假设写成可证伪的句子
「A 比 B 好」无法验证。可用的写法是：

> 在条件 C 下，方法 A 的指标 M 高于方法 B，且差值超过测量误差范围。

三个要素缺一不可：**条件、指标、可判断的差异阈值**。写成这样之后，「需要哪些对照组」基本自动就出来了。

## 对照组与变量控制（最低要求）
- **必须有基线**：当前主流方法或最简单的可行方法；
- **一次只改一个变量**：同时改数据、参数、环境，就无法归因；
- **消融（ablation）**：逐个去掉你的设计模块，看指标变化——这是审稿人最常要求补充的部分；
- **警惕混杂因素**：数据划分、随机种子、机器负载、试剂批次、操作者差异。

## 重复：多久才算够
- 单次结果无法区分「真实差异」与「随机波动」；
- 实验科学通常区分**生物学重复**与**技术重复**；计算实验通常要求多随机种子；
- 样本量取决于效应大小与噪声：先做小规模预实验估计噪声，再决定规模；
- 报告时给出**均值、方差与样本量**，而不是只报最好的一次；
- **不要用调整阈值的方式「凑显著」**，这在方法上是错的。

## 数据记录（最低标准）
```
原始数据：不覆盖，按日期与条件命名
处理脚本：能一键从原始数据复现中间结果
环境记录：依赖版本、随机种子、设备型号与参数
日志：每次运行做了什么、观察到什么异常
说明文件：目录结构、文件含义、如何重跑
```

数据管理的通用原则可参考 FAIR（可发现、可访问、可互操作、可复用）。

## 结果不对时的排查顺序
按「最容易出错、最容易验证」的顺序：

1. **数据**：标签对齐、是否泄漏、单位与量纲；
2. **代码**：随机种子、参数是否真的生效、评估脚本是否与训练一致；
3. **设置**：对照组是否公平（同样的数据量与调参预算）；
4. **测量**：仪器校准、环境条件、操作差异；
5. **假设**：以上都排除后，才考虑原假设不成立。

**把每次排查结论记下来**，组里的人会反复遇到同一个坑。

## 什么算「做完了」
- 多次重复下结果稳定，并给出不确定性；
- 有合理基线与消融说明；
- 换一份数据或换环境仍能得到方向一致的结论（或明确指出适用边界）；
- 别人拿你的代码与说明能复现。

更完整的流程见 [实验设计与数据（deep dive）](../docs/research/实验设计与数据.md)。

## 记录什么
每个实验开始前写下：假设是什么、预期看到什么。结束后记录：实际结果、与预期的差距、可能的失败原因。只记录成功的实验，等于丢弃了一半信息；审稿人问「为什么这样设计」时，这些记录就是答案。

## 口径先行
数据层面最容易出错的是口径：样本包含谁、异常值怎么定义、指标怎么计算。开始分析前把口径写下来，分析过程中不改口径——事后改口径凑结论，是很危险的滑坡。

## 可复现性
把数据、代码、参数整理到别人（包括三个月后的你）能重新跑出同样结果的程度。做到这一点，论文的实验部分就立得住，也能避免「结果无法重复」的尴尬。

## 与写作的衔接
图表在分析阶段就按「能直接进论文」的标准做，写论文时会省一大半时间，见 [论文写作](04-当你开始面对第一次重要分流.md#research-writing-and-submission)。

论文写作的关键不是文采，是**结构先行**：先定目标期刊或会议，再按其格式与篇幅反推每部分写什么。动笔前的顺序是：图和表先定，结论先写，引言最后写——多数痛苦来自顺序反了。

## 写作流程
1. 定投稿目标：读目标期刊/会议近两年收录的文章，判断你的结果是否匹配（层次与主题）；
2. 搭骨架：目标格式下每节写三句话提纲，**先给导师看骨架而不是初稿**；
3. 图表先行：每张图表配一段「这张图说明了什么」，它们就是正文的核心段落；
4. 写作顺序：方法 → 结果 → 讨论 → 引言 → 摘要 → 标题；
5. 投稿前过三道：自查清单（格式、引用、署名一致）、合作者审读、英语润色（如需外语投稿）；
6. 被拒是常态：认真读审稿意见，修改后转投，意见通常让论文变好。

## 署名规则
作者位次反映**贡献大小，不是资历或关系**：一作是主要完成人，通讯作者对研究整体负责。署名要在动笔前谈清楚，事后争议几乎都会伤人伤己。项目开始时确认谁贡献什么、谁一作谁通讯；保留自己的工作痕迹（实验记录、代码、脚本）——既是署名依据也是自我保护；可参考 ICMJE 的作者资格建议（实质参与、起草或审阅、批准终稿、对工作负责），不同学科惯例有差异。把自己写进没做的工作、或不给别人应得的署名，都属学术不端。

## 学术红线
红线很短：**不造假数据、不抄袭剽窃、不代写代考、不买卖论文与署名**。触碰任何一条的代价不是「一次失败」，而是记录在案、撤销学位或资格的终身影响。灰色地带（数据选择性呈现、不当署名、一稿多投）同样在监管范围内。入学或进组时读一遍本校学术规范文件与教育部《高等学校预防与处理学术不端行为办法》；涉及人的研究先过伦理审查；AI 工具使用遵守学校与期刊的现行规定，不把 AI 生成内容当原创成果提交。

学术会议的价值有三层：**发表（投稿）**、**获取前沿信息（听会）**、**建立联系（社交）**。第一次参会通常只能拿到第二、三层，这很正常。

## 投稿与参会流程
```
1. 选会议：看范围（scope）、往届论文、评审方式（全文/摘要）、截稿日期
2. 投稿：按模板写论文，注意页数限制与匿名要求
3. 评审：周期从数周到数月；结果可能是接收/海报/拒稿
4. 注册与安排：早鸟注册通常更便宜；需要签证的要提前准备邀请函
5. 现场：做报告或海报，参加会议与社交活动
```

**注意时间差**：会议截稿日与开会日可能相差半年以上，要按截稿日规划，而不是开会日。

## 会议上的实际作用
- **听会**：最直接的价值是知道别人在做什么、什么问题正在被解决（比读论文快）；
- **报告**：把你的工作介绍给同行，得到现场提问——**这是最有信息量的环节**；
- **社交**：与同方向的人建立联系，为之后的合作、访问、求职铺路；
- **找工作**：部分会议的招聘环节是研究岗的重要渠道。

## 报告怎么准备
- **结构**：问题 → 为什么难 → 我们的方法（关键取舍）→ 结果（带数据）→ 局限 → 未来工作；
- **时间控制**：报告时长通常 10–20 分钟，提前演练并留提问时间；
- **准备三类提问**：方法细节、与已有工作的比较、适用条件（这几乎是必被问的）；
- **海报**：一页讲清问题、方法、结果，**准备 30 秒、2 分钟、5 分钟三个版本**。

## 第一次参会的具体做法
1. 提前看议程，标出三个最相关的报告，其余时间用于交流；
2. 听完报告后上前问一个具体问题（从「关于 X 的设置，你们是否考虑过 Y」这类入手）；
3. 晚餐与海报环节是社交的主要场合，准备三句话的自我介绍（做什么、在哪、在找什么）；
4. 会后尽快给聊过的人发一封简短邮件，回顾交流内容。

## 费用与资助
参会成本包括注册费、机票、住宿与签证。资助渠道见 [Travel Grant](04-当你开始面对第一次重要分流.md#funding-travel-and-conference-grant)；多数会议提供学生优惠与志愿者减免。

## 常见误区
- **只投「好中的」会议**：低质量会议对履历帮助有限（见 [科研避坑](11-避坑.md#trap-predatory-journals)）；
- **把参会当旅游**：没有听会与交流，收获接近于零；
- **不做准备就去社交**：没有自我介绍与问题，很难建立有效联系；
- **报告只讲结果不讲取舍**：最能体现水平的部分被跳过。

## 怎么选投稿目标
问导师与同方向的人：本领域公认的顶刊顶会是哪几个、常规发表在哪；查候选期刊是否被主流索引收录（Web of Science、Scopus、中文核心目录），并到官网核实投稿要求；核对版面费与开放获取政策——正规期刊收费公开透明且通常有减免机制，警惕「快速见刊」的收费诱惑。会议类看三点：论文是否全文同行评审、论文集是否公开、往届论文被引用情况——只收录摘要或海报的「国际会议」分量完全不同。Workshop 与 Poster 是新人入场的合理起点，不必一步到位顶会。

## 怎么参与会议
看会议的征稿与参会信息、学生资助与志愿者机会（学生志愿者是低成本参会的常见通道）；会议的价值在于同行反馈与学术网络——带着自己的工作去，比只听报告收获大。

## 谁来写
带你做过课题的人最有分量：他能写清你做了什么、遇到问题怎么解决、在同期学生中处于什么位置。只上过课、写不出细节的大牌教授，效果常常不如了解你的青年老师。

## 提前一个月沟通
给推荐人三样东西：你的简历（含具体项目与你的角色）、申请方向与项目清单、每个截止日期。再加一页「希望被强调的三件事」，帮助对方下笔——不是替他写，而是省他的时间。**截止日前一周确认状态**，避免漏交。

## 提交环节的细节
看清项目要求几位推荐人、是否接受在线提交、是否要求推荐人用机构邮箱；系统可能问你是否放弃查看权，放弃通常更受信任。提交后确认系统显示「已收到」，而不是假设对方已经点了链接。

## 常见误区
找只挂名、写不出细节的推荐人；临时通知（提前三天）；材料只给成绩单不给项目说明；不确认提交状态。国内考研与推免的推荐信要求不同，以院校通知为准。

### 日常实习

```meta
effort: medium
evidence: [official, experience_based]

```

日常实习指**学期内进行的、非暑期集中的实习**：每周去两三天，与上课并行。它的价值与代价都与这种时间结构有关。

## 与暑期实习的差别
| | 日常实习 | 暑期实习 |
| --- | --- | --- |
| 时间 | 学期内，每周 2–3 天 | 集中 6–12 周全职 |
| 招聘 | 零散、团队直招 | 统一批次、流程完整 |
| 留用 | 不一定有机制 | 常有明确评估与转正通道 |
| 深度 | 单次投入少，但周期长 | 单次投入多，项目完整 |
| 适合 | 想早开始积累、时间零散 | 想走留用通道 |

**判断取舍**：想要「完整项目经验」选暑期；想要「早点开始、边学边做」选日常。

## 怎么让它更值
- **每周固定同步**：三行邮件（做了什么、卡在哪、需要什么），让带教人知道你的进度；
- **主动要完整环节**：从「帮忙做一部分」到「负责一个小模块」，哪怕很小；
- **做记录**：把做的事、遇到的问题、解决方式记下来，结束时就是简历素材；
- **要一段书面评价或实习证明**（有比没有好）。

## 常见的时间问题
- **课程冲突**：与必修课同一时段——**优先保课程**，可改为远程或缩短时长；
- **通勤成本**：每天两小时通勤会挤掉学习时间，尽量选近的或谈判远程安排；
- **强度过高**：如果实际要求全职但只给实习待遇，要和对方明确边界；
- **影响成绩**：日常实习最容易被忽略的代价是绩点下降，而绩点可能影响保研与升学（见 [GPA 与排名到底重要吗](02-在学校里先把基础打好.md#gpa-matters)）。

## 什么时候该结束
- 已经三个月没有新任务（重复劳动）；
- 明显影响核心课程或健康；
- 与目标方向偏离，又无法调整内容。

## 它的特点
录取门槛较低、招聘节奏随时进行（不集中在暑期）；深度有限——每周三四天、通常持续两三个月，接触的多是执行层工作，很难完整跟进一个长周期项目；但换回的是灵活试错的机会。

## 需要第一段实习或想低成本试方向的人
还没有任何实习经历、需要第一段经历的人；方向未定、想低成本试错的人；为争取暑期实习或留用做铺垫的人。学期中课业繁重的，用假期集中解决更划算，见 [什么时候开始找第一段实习](03-开始积累真正能留下来的经历.md#internship-types)。

```meta
last_verified: 2026-09-27
```

暑期实习是校招体系里最接近「试用」的一环：**很多公司的主要招聘来源是暑期实习转正**。因此它的准备时间比不少人以为的更早。

## 时间线（按常见节奏）
```
前一年 9–12 月：岗位陆续开放（部分公司更早）
当年 1–3 月：笔试面试高峰
当年 3–5 月：发实习 offer、办入职手续
当年 6–9 月：实习期，末尾评估转正
```

**关键**：如果你在当年 3 月才开始关注，很多岗位已经招满。**提前一年关注目标公司的招聘页面是正常节奏**（各公司差异大，以官方公告为准）。

## 准备什么
- **简历**：一页，突出与岗位相关的项目与实习（见 [简历怎么写](05-从学校走向第一份工作.md#job-hunting-resume)）；
- **笔试**：不少公司有在线测评，按题型准备（见 [在线测评](05-从学校走向第一份工作.md#job-hunting-written-test)）；
- **面试**：项目要能讲三层（做了什么、为什么这么做、条件变了怎么办）；
- **可投入时间**：明确写出能实习的起止时间与每周天数。

## 留用机制
- **有明确评估的公司**：末尾会有转正答辩或主管评估，通过后给正式 offer；
- **没有明确机制的**：需要在实习中期主动问「是否有转正评估机会、往届是否有先例」；
- **实习证明**：无论是否留用，都要一段书面评价或证明。

## 没拿到暑期实习怎么办
三条可执行的替代：

1. **日常实习**（学期内进行，积累真实经历）；
2. **科研或项目**（做出一件可展示的成果）；
3. **备战秋招**（把暑假用于补齐短板：项目、笔试、面试表达）。

**不要空等**：暑假两三个月没有产出，秋招时的简历不会有变化。

## 常见误区
- 只看大厂，忽略同行业中型公司与产业链公司（竞争小、参与度高）；
- 面试时说不清可实习周期，导致被筛掉；
- 实习期间只做杂活却不主动争取（见 [日常实习](04-当你开始面对第一次重要分流.md#internship-daily)）；
- 把留用当成必然，不做两手准备。

## 与日常实习的区别
暑期实习的项目周期更完整（能跟完一个阶段性任务），并且有明确的转正评审，是秋招之外最重要的 offer 来源。日常实习则门槛更低、更适合积累第一段经历，见 [日常实习](04-当你开始面对第一次重要分流.md#internship-daily)。

## 按校招节奏提前一季准备
简历按 [简历怎么写](05-从学校走向第一份工作.md#job-hunting-resume) 打磨；笔试与面试题库与秋招共用，见 [在线测评](05-从学校走向第一份工作.md#job-hunting-written-test)；拿到多个 offer 的比较见 [Offer 怎么比较](05-从学校走向第一份工作.md#offer-comparison)。

Off-cycle（非周期 / 非暑期）实习指**不在暑期集中招聘的实习**：通常在学期内、淡季或团队临时缺人时开放，时间更灵活、竞争相对小。

## 与暑期实习的区别
| | 暑期实习 | Off-cycle 实习 |
| --- | --- | --- |
| 时间 | 集中在 6–9 月 | 全年零散，学期内常见 |
| 招聘规模 | 大、有统一流程 | 小、多为团队直接招 |
| 留用机制 | 常有明确的转正通道 | **不一定有**，逐家确认 |
| 竞争 | 激烈 | 相对小 |
| 适合 | 想走校招留用通道 | 想快速积累经历、时间不匹配 |

## 适合谁
- 暑期没拿到合适实习，想补一段经历；
- 学期内有稳定空档（每周 2–3 天可到岗）；
- 想验证某个方向但没有长期时间；
- 已经在做项目，需要一个真实业务环境补充。

## 怎么找
- **公司官网的「实习」栏目**：不少公司会随时挂出零散岗位；
- **团队直接发布**：技术社区、行业群里常有「急招实习生」的帖子；
- **内推与老师推荐**：Off-cycle 往往走内部渠道；
- **创业公司与中小企业**：需求更灵活，决定更快。

## 现实预期
- **工作量与收获不一定小**：因为人少，你可能接触更完整的工作；
- **留用不确定**：务必在面试时问清「是否有转正评估机会、往届是否有先例」；
- **流程可能不规范**：合同、报酬、社保要问清并留书面记录（**无薪且无实质工作内容的实习要警惕**）。

## 与校招的衔接
Off-cycle 的经历可以直接用于秋招与春招简历；如果是同一家公司，可以问 HR 是否需要重新走校招流程（多数情况需要）。

## 它的特点
时间灵活（学期中或假期、长度由双方约定）；竞争错峰——不与暑期实习大军正面竞争，适合简历已达标但错过批次的人；名额不定——取决于某个团队当时是否有需求，信息主要靠校友与内部推荐获取（见 [内推](05-从学校走向第一份工作.md#job-hunting-referral)）。

## 值不值得去
如果团队做的事与你方向一致，它的含金量不低于统一批次——同一间办公室、同样的活。如果只是「有实习就行」的方向不相关岗位，优先级应低于方向匹配的岗位，见 [怎么判断一段实习值不值得](03-开始积累真正能留下来的经历.md#internship-remote)。

## 成本
与线下同等的投入时间，加上主动获取信息的成本；这类机会很少公开挂网，需要你主动联系目标团队的人。

```meta
last_verified: 2026-09-27
```

留用实习（可转正的实习）的价值在于**跳过校招初筛，直接获得评估机会**。它不是保票，而是一次提前的、时间更长的面试。

## 转正评估通常看什么
- **交付质量**：任务是否按时、按标准完成，返工率如何；
- **独立程度**：从需要指导到自己能推进；
- **协作方式**：沟通是否主动、是否造成额外负担；
- **与团队的匹配**：能否一起工作（这一项常被低估）；
- **学习速度**：接手新任务的上手时间。

## 实习期间要做的事
1. **前两周问清标准**：转正评估由谁做、看哪些方面、有没有书面标准；
2. **第一件任务做到零返工**：这是建立信任最快的方式；
3. **每周主动同步**：三行（做了什么、卡在哪、需要什么）；
4. **主动要更完整的任务**：从辅助到负责一个小模块；
5. **记录成果**：做了什么、结果如何、用什么方法（结束时就是转正材料与简历素材）；
6. **中期确认一次**：直接问「按目前情况，转正评估会怎么看？差距在哪？」——这句话能提前暴露问题。

## 没拿到留用怎么办
- **先问原因**：是名额问题（编制/预算）还是能力问题？两者的应对不同；
- **要书面评价**：即使不留用，一段评价对下一次求职有用；
- **要推荐人**：带教人或主管愿意做推荐人，价值很高；
- **转入校招或秋招**：这段经历仍是简历上的真实经历。

## 常见误区
- **把留用当必然**，不准备其他机会；
- **只顾埋头做事，不沟通**：评估时才第一次反馈；
- **只做辅助工作**：没有可展示的交付；
- **忽略团队协作**：实习生最容易被记住的往往是「是否好用」。

## 与其他实习的区别
日常实习与暑期实习都可能有留用机制，但**明确性差异很大**。判断方法：入职前直接问「是否有转正评估机会、往届是否有先例」，得到模糊答复时按「没有」准备。

## 接 offer 前就问清楚
这个岗位有没有留用名额、往年大致留用情况、考核在什么时间、由谁评估。这些直接决定这段实习的期望值；实习岗位所在业务线在收缩的，留用名额与业务景气度直接相关，更要问。

## 实习期间怎么做
把带教和团队关键成员变成你的「证据链」：让他们知道你做成了什么。在留用评估前完成一件可量化的事，并整理成简短的汇报。同时保留校招参与——**别把留用当唯一路径**，留用与校招 offer 可以拿来比较（见 [Offer 怎么比较](05-从学校走向第一份工作.md#offer-comparison)）；留用失败而错过秋招，是最贵的错误。

## 一次提前的录用评估，但不是保票
实习转正换到的是**确定性更高的录用可能**、对目标团队工作方式的提前了解，以及校招季里的心理余裕；即使最终没转成，这段经历也是校招的重要材料。

代价是一段完整实习的投入、持续的绩效压力，以及——转正答辩不是走过场。

海外实习的核心难点不在「怎么投」，而在**身份与成本**：不少国家的学生签证对实习有明确限制，做错了可能影响签证。

## 先确认三件制度性的事
1. **你的签证是否允许实习**：很多国家的学生签证允许在校期间有限时数打工，但**实习可能算工作**，需要许可或课程关联（例如美国的 CPT 与课程相关、部分国家需要 work permit）；
2. **实习是否必须有学分或课程背书**：有的学校要求实习注册为课程才能合法进行；
3. **时长与报酬限制**：时数上限、是否允许带薪、超出会不会影响身份。

这三项**必须查官方移民部门与学校国际学生办公室页面**，不要按学长经验推断。相关入口见 [常用官方来源清单](../docs/sources/常用官方来源清单.md)。

## 三类机会与各自的门槛
| 类型 | 例子 | 门槛 | 收益 |
| --- | --- | --- | --- |
| 校内研究助理 | 实验室 RA、暑研项目 | 需要提前联系导师（3–6 个月） | 研究经历 + 推荐信 |
| 企业实习 | 跨国公司暑期实习 | 语言、笔试面试、有时需要工作许可 | 本地工作经验 + 转正通道 |
| 海外远程实习 | 远程为海外公司做项目 | 语言、时区、合同与报酬合规 | 跨文化协作经验，成本低 |

**远程实习是成本最低的切入点**：不需要签证，但要注意报酬结算与合同形式（是否合法、如何纳税）。

## 成本要算全
```
机票 + 签证费 + 保险 + 住宿 + 生活成本 + 期间的学费/机会成本
− 实习报酬或补贴
= 净支出
```

很多海外实习**名义有报酬但扣除成本后是负数**。判断标准不是「值不值这个钱」，而是「它能换来什么在本地无法获得的东西」：本地工作经验、语言环境、行业网络、后续的转正或申请加分。

## 什么样的收益是真的
- **可写进简历的具体交付**（做了什么、结果如何），而不是「在 X 国实习过」；
- **一位能写推荐信的主管**（这常是最实际的收获）；
- **语言与工作方式的适应**（对之后在当地求职帮助最大）；
- **一条转正或回访的通道**（部分公司暑期实习有留用机制）。

**不是真收益**：朋友圈里的经历、只有一段时间的「海外背景」。

## 时间与准备节奏
- 目标暑期实习：提前 6–9 个月开始投递（有的公司在前一年秋天就截止）；
- 需要签证或工作许可：再往前 2–3 个月，避免材料与排期来不及；
- 需要语言的岗位：语言成绩通常要提前准备。

## 什么时候不建议去
- 成本远超家庭承受能力，且收益主要是「经历好看」；
- 签证与许可存在合规风险（可能影响后续身份）；
- 你已经有一个更匹配目标的本地实习机会（本地深度通常优于海外广度）。

## 机会从哪来
学校交换与合作项目（部分含实习安排）、国际组织与研究所的固定申请季（竞争激烈、需提前准备）、跨国公司官网的实习招聘页。学校的国际交流处是最容易被忽略的入口，先去问。

## 签证、语言与放弃的国内机会
成本包括签证与机票、住宿、放弃的国内机会，以及时间窗口（通常两到六个月）。回退成本可控：多数海外实习不影响后续校招，反而常是简历亮点。判断值不值，看它是否带来可验证产出与推荐人——见 [怎么判断一段实习值不值得](03-开始积累真正能留下来的经历.md#internship-remote)。

科研实习（research intern）是在**课题组、研究院或企业研究部门**参与真实研究工作的实习。它与普通实习的差别在于：产出偏向研究结论（报告、论文、专利），而不是产品交付。

## 三类场所与差别
| 场所 | 日常 | 产出 | 适合 |
| --- | --- | --- | --- |
| 高校/研究所课题组 | 做实验、跑数据、复现、组会 | 报告、论文参与、推荐信 | 想读研/读博、想验证是否适合科研 |
| 企业研究院 | 面向产品的研究探索、原型验证 | 原型、内部报告、专利 | 想了解工业界研究方式 |
| 假期科研项目（暑研等） | 8–12 周集中项目 | 一段完整研究经历 | 时间有限、想快速体验 |

## 能真正得到的四样东西
1. **一段可讲的研究经历**（做了什么、遇到什么问题、结果如何）；
2. **一位了解你的推荐人**（这是研究型申请中最实际的收获）；
3. **方法训练**：读文献、设计验证、写报告的能力；
4. **答案**：你适不适合做研究（比任何自测都可靠）。

**不是真收益**：只在组里做数据清洗与跑腿三个月，却没有一点自己的判断——这种情况要主动争取更接近问题的任务，或考虑换组。

## 怎么找
- **本校课题组**：直接邮件联系做你感兴趣方向的老师（附简历与一段具体兴趣）；
- **外校/海外暑研**：留意课题组主页的招聘页与学校暑期项目公告，**提前 3–6 个月准备**；
- **企业研究院**：按官方招聘渠道投递（研究与工程岗位常分开）；
- **通过师兄师姐**：内部推荐在课题组里同样有效。

## 什么时候该主动争取
进组两三个月后，如果只做重复性工作，可以这样提出：

> 「我这段时间在做 X，比较熟了。我想试试自己做一小块，比如 <具体任务>，可以吗？」

带着具体任务去要机会，成功率远高于抱怨没有机会。

## 值不值得投入的判断
- 目标是研究型升学或研究岗 → 优先级高，越早越好；
- 目标是工程/产品岗 → 仍值得，但优先级低于相关实习与项目；
- 已有一段科研经历 → 优先考虑产出深度（能否形成论文或完整报告）而非数量。

## 想先看工业界问题的人
研究生阶段想验证「产业研究是否适合自己」的人；计划读博但想先看工业界问题长什么样的人；目标就是企业研究岗的人。它同时也常是毕业后进入同类团队的入口。

## 工业界研究经历与一条入职通道
工业界研究实习换到的是**一段工业界研究经历**、可能的论文或专利、业界导师与人脉，以及一条区别于校招的入职通道。

代价是二到六个月时间。**成果归属与发表政策要在开始前问清楚**——企业研究对发表通常有审批流程，这一点与高校不同。

Scholarship（奖学金）是**按成绩或综合表现授予个人的资助**，通常不需要承担工作职责。它与 Fellowship、Assistantship 的区别在于评选依据与是否附带义务。

## 与相邻概念的区别
| | Scholarship | Fellowship | Assistantship（TA/RA） |
| --- | --- | --- | --- |
| 依据 | 成绩、综合素质 | 研究潜力、项目匹配 | 岗位需要 |
| 义务 | 一般无（可能有成绩要求） | 一般不要求工作，可能有汇报义务 | **有工作职责** |
| 期限 | 常按学年评定 | 较长（多年） | 按学期/年 |
| 决定方 | 学校/院系/外部机构 | 资助方评审 | 导师/院系 |

**多数情况下可以组合**（例如入学奖学金 + 助研岗位），具体以录取通知与院系说明为准。

## 评审通常看什么
- **成绩与排名**：多数是硬条件；
- **标准化考试或语言成绩**：部分项目要求（如美国研究生项目的 GRE/托福）；
- **经历与产出**：项目、实习、论文、竞赛、公开作品；
- **文书与推荐信**：解释动机与匹配度，推荐信要能写出具体评价；
- **面试表现**：部分奖学金有单独面试。

## 是否需要单独申请
两种情况要分清：

- **随录取自动评估**：很多院校在录取时一并考虑；
- **单独申请**：外部机构、校级或企业奖学金常设独立窗口，**截止日往往早于入学申请**，漏掉就等下一年。

**做法**：读目标项目 funding 页面，列出两类并分别记截止日期。

## 常见义务与影响
- 维持一定的成绩（低于线可能取消）；
- 全职学生身份要求（不能同时全职工作）；
- 部分奖学金限定用途（学费只能用于学费）；
- 可能不可与某些资助叠加（**以条款为准**）。

## 判断它够不够
按「学费 + 生活成本 + 一次性支出 − 资助金额」算缺口，注意税前/税后与发放周期（见 [Stipend](04-当你开始面对第一次重要分流.md#funding-stipend) 与 [留学总成本](04-当你开始面对第一次重要分流.md#overseas-total-cost)）。

## 三类来源
- **政府/国家类**：面向国际学生的政府奖学金（各国项目不同，查目标国官方页面）；
- **学校类**：目标院校官网的奖学金页，分「入学自动评审」与「单独申请」两种——自动评审也有资格条件，不是人人都有；
- **机构类**：企业、基金会与行业协会的奖学金，通常有特定限定（专业、地区、背景）。

## 每条都要核对四件事
申请资格（国籍、阶段、专业）、金额与覆盖范围（学费全免还是只免部分）、是否附带义务（服务期、绩点要求）、截止日期（多数比入学申请早）。信息一律以官方页面为准，见 [奖学金与 Funding](04-当你开始面对第一次重要分流.md#overseas-funding)。

Fellowship 是**授予个人的资助**（而非授予项目的经费），通常覆盖学费与生活津贴，有时还包含研究经费。它与奖学金的核心区别是**评选更看重研究潜力，金额通常更大、期限更长**。

## 与相邻概念的区别
| 名称 | 授予对象 | 是否要求工作 | 常见期限 |
| --- | --- | --- | --- |
| Fellowship | 个人 | 一般不要求（可能有汇报义务） | 1–5 年 |
| Scholarship | 个人（成绩/表现导向） | 否 | 按学年 |
| Assistantship（TA/RA） | 岗位 | **有工作职责** | 按学期/年 |
| Grant | 项目（PI 负责） | 参与项目 | 按项目周期 |
| Stipend | 发放形式 | 视背后类型 | — |

**重要**：Fellowship 常与 TA/RA 可组合（例如第一年 fellowship、之后 RA），具体以录取通知与院系说明为准。

## 评审通常看什么
- **研究潜力与匹配度**：研究计划是否清晰、是否与该机构方向一致；
- **推荐信**：内容（了解你的人写的具体评价）比头衔重要；
- **成绩与语言**：多数是硬门槛；
- **个人陈述**：为什么是你、为什么现在、为什么这里；
- **过往产出**：论文、项目、公开作品。

## 是否需要单独申请
两种情况：

- **随项目自动考虑**：多数美国研究型项目在录取时一并评估资助；
- **需要单独申请**：校级/外部 fellowship 常有独立截止日，**常早于入学申请**，漏掉就等下一年。

**做法**：把目标项目的 funding 页面读一遍，列出「自动考虑」与「需单独申请」两类，分别记截止日期。

## 附带义务与风险
- **汇报义务**：定期提交进展报告；
- **工作时数**：若与 TA/RA 组合，需按规定工作；
- **排他性**：部分 fellowship 不接受同时领取其他同类型资助；
- **税务**：津贴的税务处理因国家与身份不同，以自己的报税义务为准（学校通常提供说明）。

## 怎么判断值不值得申请
- 金额能否覆盖学费 + 生活（按实际城市成本算）；
- 期限是否覆盖整个学制（最后一年是否需要另找资助）；
- 义务是否影响你的研究时间；
- 是否限制其他资助来源。

## 两类资助的判断方式
面向人的资助，看你的研究潜力、履历与方向。通常直接发给个人，使用相对自由（学费、生活费）。竞争激烈，评审材料的核心是研究陈述与已有成果。

## 它对你这几年的意义
找导师时问清组里的经费状况，它直接影响你的研究条件；高年级与博后阶段可以自己申请小型 Fellowship 与差旅资助，见 [Travel Grant](04-当你开始面对第一次重要分流.md#funding-travel-and-conference-grant)。

## Grant：资助「这个项目」
面向研究项目的经费，由项目负责人（通常是导师）持有。研究生接触 Grant 的方式是**进入有经费的课题组**——组里有 Grant 意味着有设备、数据与补贴，见 [怎么判断一个实验室](03-开始积累真正能留下来的经历.md#research-choosing-a-lab)。

Grant（项目经费）是**给「一件事」的钱**，不是给「一个人」的奖励。这笔钱属于项目或实验室，用于支付研究活动所需的人力与材料。理解这一点，就能明白为什么学生通常不能直接「申请一个 grant」。

## 和相邻概念的区别
| 名称 | 给谁 | 决定权 | 学生的角色 |
| --- | --- | --- | --- |
| Grant | 项目（PI 负责） | 资助机构评审 | 参与项目、间接获得支持 |
| Fellowship | 个人 | 资助方评审个人 | 可以独立申请 |
| Scholarship | 个人 | 学校/机构 | 通常随录取评估 |
| RA/TA 津贴 | 岗位 | 导师/院系 | 用工作换取 |
| Travel Grant | 具体支出 | 会议/院校 | 独立申请 |

## 学生最常接触的三类经费
1. **导师在研项目**：决定组里有没有位置、有没有设备与差旅预算。**这是最直接的资源来源**；
2. **校级/院级小额项目**：面向研究生的创新基金、科研训练项目，金额不大但门槛低，适合练手；
3. **面向学生的科研计划**：如本科生科研训练项目、研究生创新计划等（名称与规则各校不同）。

想申请真正的科研项目（青年基金、面上项目等），通常需要博士学位与依托单位，学生阶段一般不满足条件，**以国家自然科学基金委等机构的当年指南为准**。

## 经费怎么影响你的读研/读博体验
- **有没有在研项目**：直接决定你做什么、用什么设备、能不能出差参会；
- **经费能覆盖什么**：人力（助研津贴）、材料、测试、差旅，覆盖范围差异很大；
- **结题压力**：项目有交付与结题要求，你的研究节奏常受项目节点影响。

**所以「问导师经费情况」不是冒昧，而是必要的**。可以这样问：「老师，组里目前在研项目大概有哪些方向？如果我来做 X，大概会依托哪一类项目？」

## 怎么判断经费是否可靠
- 论文致谢里的基金号（可判断项目类型与年份）；
- 课题组页面上的「在研项目」列表（注意更新时间）；
- 学校科研管理部门的公示（部分单位公开立项信息）；
- 直接问组里的学生：设备是否够用、有没有出差预算、津贴发放是否正常。

## 学生可以学的「申请」能力
即使不能申 grant，也可以从写项目申报材料中练到三件事：**把问题写清楚、给出可执行的计划、说明资源需求**。这三件事在求职、升学、申请资助时反复用到，方法见 [奖学金与资助手册](../docs/manuals/奖学金与资助.md)。

## 怎么了解一个组的经费状况
组主页与近期论文的致谢部分通常列出资助来源；直接问组内学生最准确——「组里经费紧张吗？开会和设备支持怎么样？」这是选导师与选组时的必问项，见 [怎么判断一个实验室](03-开始积累真正能留下来的经历.md#research-choosing-a-lab)。

## 一个提醒
经费充足不等于组好，经费紧张也不必然做不出东西。但它会影响效率与体验，值得作为选组的一个权重——而不是全部。与面向个人的 Fellowship 的区别见 [Fellowship 与 Grant](04-当你开始面对第一次重要分流.md#funding-fellowship-grant)。

Stipend（生活津贴）是**资助的发放形式**，不是资助的类型。同一个博士可能同时拿到「学费减免 + 每月 stipend」，其中 stipend 来自 fellowship 或助研/助教岗位。理解这一点能避免把它误当成「额外的钱」。

## 与相邻概念的区别
| 名称 | 性质 | 是否要干活 | 常见来源 |
| --- | --- | --- | --- |
| Stipend | 发放形式（按周期给的生活费） | 取决于背后的资助类型 | 学校、导师项目、政府项目 |
| Scholarship | 奖励性质（按表现给） | 通常不用 | 学校、基金会、企业 |
| Fellowship | 资助类型（常覆盖学费+生活） | 一般不要求工作，但可能有义务 | 学校、政府、基金会 |
| Assistantship（TA/RA） | 工作性质（用劳动换资助） | **有明确工作职责** | 院系、导师项目 |
| Salary | 雇佣关系下的工资 | 是 | 岗位制博士、雇主 |

## 关键区别：有没有职责
- **纯 stipend（如 fellowship）**：一般不要求固定工作，但可能有成绩要求或汇报义务；
- **TA/RA 的 stipend**：是报酬，**有每周工作时数与考核**，占用研究时间，需要和导师明确平衡方式；
- **岗位制博士（如欧洲部分国家）**：本质是雇佣关系，有合同、假期与劳动保护，权利义务与其他类型不同。

## 发放与税务
- **发放周期**：按月、按学期或按学年，有的滞后发放（需要先垫付前期开销）；
- **税前/税后**：不同国家与资助类型的处理方式不同，报税义务也不同，**以官方与学校财务部门的说明为准**；
- **是否覆盖假期**：有的资助按学年发放，暑假需要另行安排（例如暑期助教或实习）。

## 怎么判断够不够
按目标城市的实际开支列一张表：住宿、餐饮、交通、保险、书本与设备、一次性支出（机票、押金、签证）。再用 stipend 减去这些项目，看缺口与是否需要额外打工（注意签证对打工的限制）。

最容易出错的地方是只看 stipend 的数字，忽略当地生活成本与是否有学费减免——同额 stipend 在不同城市与不同资助结构下的实际差距很大。

## 谈资助时要问清的问题
- 资助由什么构成（学费减免 + stipend + 保险？）；
- 由谁提供、持续几年、是否需要每年重新评估；
- 是否附带工作职责（多少小时、做哪些事）；
- 暑期与假期的资助如何处理；
- 是否包含税费与保险，是否需要自行申报。

## 核对四件事
- **金额与频率**：每月多少、一年发几个月（有的只发十个月）；
- **附带义务**：每周要工作多少小时、做什么（助研绑定课题，助教绑定授课任务）；
- **与学费的关系**：补贴是覆盖生活费，还是已含学费减免；
- **稳定性**：依赖课题经费的补贴，在课题结束或经费中断时会受影响。

## 在哪核实
招生简章写的是标准线，组里的真实情况要问在读学生：实际到手多少、有没有拖欠、义务重不重。想了解资助的全貌见 [全额资助怎么找](04-当你开始面对第一次重要分流.md#funding-full-funding)。

```meta
last_verified: 2026-09-27
```

Fee Waiver 最常见的意思有两种，**先分清是哪一种**：

1. **申请费减免**（application fee waiver）：免除或退还学校/考试机构的**申请费用**；
2. **学费减免**（tuition waiver / tuition remission）：减免**学费**，常与助研/助教岗位或奖学金绑定。

两者性质、申请方式与金额差别极大，混在一起谈会误导判断。

## 申请费减免
- **常见获得条件**：经济困难证明、参加宣讲会或校园活动、特定项目合作院校、退伍军人、部分奖学金申请者；
- **申请方式**：多数需要单独提交表单或代码（fee waiver code），**不能默认自动减免**；
- **材料**：财务说明、在读证明、有时需要推荐人或项目联系人确认；
- **注意**：减免通常按学校/项目分别申请，不是一份通用的。

## 怎么找与怎么申请
```
1. 打开目标项目官网 → 搜 "fee waiver" / "application fee" / "funding"
2. 看清是否有自动减免（例如通过特定渠道申请）
3. 需要单独申请的：把截止日写进日历（常早于申请截止）
4. 准备材料：财务说明、在读/收入证明、必要时的推荐说明
5. 提交后确认是否生效（在申请系统里核对费用栏）
```

## 容易拿到减免的情况
- 经济困难（有可证明的材料）；
- 参加过该项目的宣讲会、开放日或线上说明会（部分学校给参与码）；
- 属于合作院校或特定计划（如部分交流项目、公派项目）；
- 申请博士或研究型项目（部分学校对博士申请者免申请费）。

## 常见误区
- **以为「困难」就能免**：需要按流程提交材料，且各校标准不同；
- **漏掉截止时间**：减免申请往往和申请同期或更早；
- **把学费减免当成收入**：减免不免除义务，也不等同于可支配收入；
- **不问清覆盖范围**：有的减免只覆盖部分学期或部分课程。

## 学费减免
- **常见形式**：与 assistantship 绑定的 tuition waiver、fellowship 内含的学费覆盖、专项减免；
- **义务**：多数与岗位绑定，有工作时数与考核要求；
- **税务与保险**：减免部分是否计税取决于当地规定，保险是否覆盖要单独确认。

Travel Grant（差旅资助 / 会议资助）是**为参加学术会议、竞赛或交流活动提供的部分或全额旅费支持**。金额通常不大，但它是很多学生第一次「凭自己申请到钱」的经历。

## 谁提供这类资助
| 提供方 | 常见形式 | 特点 |
| --- | --- | --- |
| 会议主办方 | Student Travel Grant / Volunteer 减免 | 需要注册并单独申请，名额有限 |
| 所在学校 / 院系 | 研究生院或学院的参会资助 | 通常按学年申请，有额度上限 |
| 导师项目经费 | 从在研项目列支差旅 | 需要与导师确认预算 |
| 学会 / 基金会 | 学会的 student grant | 有的要求会员身份 |
| 政府与交流项目 | 公派短期交流、访学资助 | 流程长，通常需要提前数月 |

**优先级建议**：先问导师与院系（最容易拿到），再申请会议资助（评审看论文与理由），最后考虑外部基金（周期长）。

## 申请要准备什么
- **参会证明**：论文被接收的通知、报告安排、邀请函；
- **预算表**：注册费、机票、住宿、签证费，按实际价格列，不要只写「约 X 元」；
- **理由**：为什么必须现场参加（做报告、海报、合作者会面），而不是「想去看看」；
- **个人情况**：是否有其他资助来源（多数资助方不接受重复报销，需要如实说明）；
- **时间表**：申请截止通常早于会议注册截止，注意两者关系。

## 常见规则与坑
- **先垫付后报销**：多数需要自己先付，保留所有票据（含登机牌、发票抬头要求）；
- **不重复资助**：同一笔支出通常不能从两个来源全额报销，申请时要说明已获得的资助；
- **额度上限**：常见做法是「按实际支出报销，上限 X」；
- **时限**：出差前申请与出差后报销都有截止日期，逾期作废。

## 申请不上怎么办
- 问导师能否从项目经费列支（**这是最常见的解决方案**）；
- 申请会议志愿者（以服务换注册费减免）；
- 只参加线上会议或区域性会议（成本低，仍有报告机会）；
- 与同学合住、提前订票降低实际支出。

## 它值得投入时间吗
值得。原因不只是钱：申请材料要求你写清「为什么参加、有什么产出」，这本身就是一次学术表达训练；而且**有过一次成功申请记录，第二次会容易得多**。

## 三条线去找
- **会议主办方**：多数正规会议设有学生资助（student grant / travel award），在征稿页或参会页单独申请，常与论文或海报投稿绑定——有产出的人拿到的概率高得多；
- **学会与协会**：专业学会面向会员的学生差旅资助，部分要求入会（学生会费通常很低）；
- **院校与国家渠道**：学校研究生院的学术交流资助、国家留学基金委的相关项目（以当年公告为准）。

### 怎么找全额资助机会

```meta
id: funding-full-funding
status: complete
stages: [undergraduate, master, phd]

outputs: [degree]
effort: high
evidence: [official, experience_based]
summary: 怎么找全额资助：三类可以覆盖全额的渠道、申请顺序与时间线，以及怎么判断一个资助是否真的够用。
last_verified: 2026-09-27
```

「全额资助」通常由几项拼起来：**学费减免 + 生活津贴 + 保险**。找资助的核心不是「找最有钱的项目」，而是**找到与你的目标最匹配的渠道，并按要求提前准备**。

## 三类能覆盖全额的渠道
| 渠道 | 典型形式 | 覆盖范围 | 申请时间 |
| --- | --- | --- | --- |
| 政府项目 | 公派留学、目标国政府奖学金 | 学费 + 生活费（可能含机票） | 提前 12–18 个月，窗口固定 |
| 学校与院系 | 全额奖学金、fellowship、TA/RA | 学费 + 津贴 | 随申请或单独申请 |
| 导师项目经费 | RA 岗位（研究型项目） | 学费 + 津贴（取决于经费） | 需要提前联系导师 |

**英国、欧洲部分项目**的全额资助多由学校或导师经费提供；**美国研究型项目**常见 TA/RA 或 fellowship；**政府奖学金**（公派、GKS 等）通常带服务义务。

## 申请顺序（提高成功率）
```
1. 先看目标项目是否自动考虑资助（很多美国项目随录取发 TA/RA）
2. 有导师制的项目：联系导师时直接问经费与位置
3. 需要单独申请的奖学金：把截止日期单独记下来（常早于入学申请）
4. 政府项目：按官方流程与时间线走（材料多、周期长）
5. 备选：自费方案 + 入学后争取助研岗位
```

## 时间线要点
- **语言成绩**：多数资助要求提交时已达标，要提前半年准备；
- **推荐信**：需要提前 4 周联系推荐人；
- **政府项目**：通常需要单位/学校推荐、体检与政审，时间更长；
- **奖学金单独申请**：截止日常与入学申请不同，**漏掉就等下一年**。

## 判断「是否真的够用」
```
学费（减免后剩余）
+ 生活成本（目标城市实际水平）
+ 保险与一次性支出（机票、押金、签证）
− 资助额度（注意税前/税后、发放周期）
= 缺口
```

**三个常踩的坑**：资助按学年发放但开学要垫押金；津贴为税前，实际到手更少；资助期限短于学制（最后一年需要自筹）。

## 申请材料的关键
- **研究计划或学习计划**：写清目标、路径与未来用途（评审关注匹配度）；
- **推荐信**：内容（了解你的具体工作）比推荐人头衔重要；
- **成绩与语言**：多数项目是硬门槛；
- **个人陈述**：说清「为什么是这个人、为什么是现在、为什么是这里」。

## 义务与风险
- 政府奖学金常附带回国服务年限或单位协议；
- 助研岗位有工作量（每周小时数）；
- 接受资助后变更学习计划可能触发违约。

**签字前逐条看清：义务、期限、违约后果**。具体条款以官方文件为准。

## 三条线
- **岗位制项目**（确定性最高）：岗位制博士与部分研究型硕士本质是「带薪工作」——工资覆盖学费与生活，常见于欧洲多国与部分研究机构。这类机会在院校与课题组官网直接发布，核心是找到有经费的导师，见 [怎么判断一个实验室](03-开始积累真正能留下来的经历.md#research-choosing-a-lab)；
- **政府与机构奖学金**：CSC 国家公派、目标国政府奖学金（MEXT、GKS、Chevening、Fulbright、DAAD 等）覆盖学费与生活，但有自己的申请窗口、服务义务与名额限制，见 [奖学金与 Funding](04-当你开始面对第一次重要分流.md#overseas-funding)；
- **院校资助叠加**：学费减免、助教助研津贴、院系奖学金分开申请，部分可以叠加——只盯「全额」一项而忽略叠加组合，是常见的漏。

## 执行纪律
把所有截止日期排进日历（资助截止普遍早于入学申请）；材料与学位申请高度重合，可以复用；同时申多个不冲突的资助是常规操作。任何「保证全额奖学金」的中介宣传都要警惕——资助结果由资助方决定，不以任何人的承诺为准。
