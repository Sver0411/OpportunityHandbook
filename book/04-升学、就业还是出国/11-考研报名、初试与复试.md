# 考研报名、初试与复试

流程类信息以**教育部、研招网与目标院校当年公告**为准（https://yz.chsi.com.cn/）。这一册写的是「每一步交什么、卡在哪、怎么不出错」，不是日期表。

考研有一半的失败不是「考不上」，而是「没报上」或「信息填错被退回」。这两个环节的特征是：**硬截止、几乎没有补救窗口**。

这一页按环节列出每步要交什么、最容易错在哪里。

## 一、九个环节总表

| # | 环节 | 你要做的事 | 常见翻车原因 |
| --- | --- | --- | --- |
| 1 | 关注报名时间 | 盯研招网与院校通知 | 只等院校短信，错过预报名 |
| 2 | 预报名 | 提前填好信息 | 以为预报名等于正式报名 |
| 3 | 正式报名 | 报名 + 上传照片 | 照片规格不符被退 |
| 4 | 网上/现场确认 | **独立于报名的一步** | 以为报完名就完事了 |
| 5 | 缴费 | 按时完成 | 忘记缴费，报名无效 |
| 6 | 下载准考证 | 记录考点与时间 | 临考找不到入口 |
| 7 | 初试 | 四科按考试时间表作答 | 单科放弃导致连锁崩盘 |
| 8 | 成绩查询 | 关注成绩与国家线公布 | 只等院校通知 |
| 9 | 复试/调剂确认 | 按时确认录取或调剂 | 错过确认，被递补 |

第 4 步和第 5 步是**最高频的低级错误来源**。两者的共同点是：不做就没有任何后果通知，只有一条「报名无效」。

## 二、预报名与正式报名不是一回事

预报名是提前填好信息，正式报名期间再确认一次。**两个环节都要做**。

预报名期间完成的：信息填报、照片上传（部分年份）、考点选择。
正式报名期间完成的：信息确认或修改、缴费。

关于**报考点选择**：报考点通常可选招生单位所在地或户籍/工作所在地，具体可选范围由各省当年公告规定。选考点时要看清楚它对应的报考点，不要凭「离得近」随便选——一旦错过更改时间，变动成本很高。

## 三、网上确认在做什么

网上/现场确认的核心是**核验你的身份与学历信息**，不是走形式。常见要求：

| 材料 | 说明 |
| --- | --- |
| 身份证与学生证/毕业证 | 学历信息要与报名时填的一致 |
| 报名号与确认单 | 确认后系统生成 |
| 学历/学籍在线验证报告 | 部分省份要求 |
| 缴费 | 与报名同一步或紧随其后 |

**学历信息不一致是最常见的退回原因**：填写的毕业时间、学历层次、专业名称与学信网信息不符，都要退回重填。所以报名时的信息必须**与证件和学信网逐字一致**，而不是与你的记忆一致。

## 四、初试当天：准备清单与答题原则

准备清单：身份证、准考证（建议多打印一份）、黑色签字笔、2B 铅笔、橡皮、直尺。考前一天确认考点位置与路线。

答题原则：

- **按平时模考的节奏答题**，不要临场改策略；
- **单科崩了就放过它**：某一科失手后，立刻把注意力切到下一科——连锁崩盘的代价远大于单科损失；
- **放弃也要有策略**：实在做不出的题跳过，把时间留给会做的题。这一条在数学和专业课尤其重要；
- **涂卡与誊写留出时间**：主观题与选择题的涂卡时间要单独留，不要压到最后几分钟。

## 五、考完之后

成绩与国家线由教育部及研招网公布（https://yz.chsi.com.cn/），院校复试线由各招生单位公布。**不要只等院校通知**，国家线公布日通常在院校线之前，用它做初步判断。

如果初试当天某一科明显失常，也照样把复试准备做完——初试结束到成绩公布之间有若干周，此时开始准备复试的时间成本最低（见 [复试前两周的准备安排](11-考研报名、初试与复试.md#kaoyan-retest-schedule)）。

## 什么时候要谨慎

- 报名、确认、缴费、准考证下载都有**硬截止**，错过通常没有补救渠道，只以当年研招网与院校公告为准（https://yz.chsi.com.cn/）；
- 报考点可选项由各省当年公告规定，不要凭往届经验选；
- 学历信息必须与证件和学信网一致，这一条每年都有人因此被退回；
- 「预报名完成了就不用正式报名」是最普遍的误解，务必两次都做。

复试是**最后一次机会**，也是最容易被「等成绩」耽误的环节。它的内容多、边界模糊（导师问什么无法预测），所以必须在初试结束后就开始，而不是出分后才动手。

内容层面（有哪些环节、权重怎么看）见 [复试](02-国内升学.md#study-second-round-interview)；这一页是**时间安排层面**：按天倒排做什么。

## 一、为什么要初试后立刻开始

| 做法 | 后果 |
| --- | --- |
| 等成绩公布再准备复试 | 只剩几天，准备不完整 |
| 出分后立刻准备 | 时间勉强够，但材料可能来不及盖章 |
| **初试结束当天开始准备** | 时间充裕，且心理上不再悬着 |

初试结束当天可以做的事很少：把复试材料列成清单、把院校复试办法找出来、把本科项目与论文的要点整理成一页。这些事零散但耗时。

## 二、前两周按天倒排

| 时段 | 任务 | 产出物 |
| --- | --- | --- |
| 第 1–2 天 | 读当年复试办法、确认形式与权重 | 一份要求清单 |
| 第 3–5 天 | 材料：成绩单、政审表、证件、证明 | 装在一个文件袋里的材料包 |
| 第 5–8 天 | 专业课：本科主干课 + 目标方向基础 | 问答清单 + 两版自我介绍 |
| 第 8–10 天 | 英语：自我介绍、研究兴趣陈述、专业词汇 | 三段可默写的内容 |
| 第 10–12 天 | 个人陈述、科研/项目讲述与追问预案 | 一页纸的项目讲述 |
| 第 13–14 天 | 联系导师（如该单位需要）、确认时间地点与差旅 | 邮件已发、行程已定 |

**材料包要在第一周就备好**，因为证明盖章、政审表填写需要时间，而且常常需要回学校或找原单位。

## 三、联系导师的时机与内容

是否需要提前联系导师，取决于该单位是导师制还是委员会制（见 [选导师](02-国内升学.md#study-choose-supervisor)）。如果需要：

| 时点 | 做什么 |
| --- | --- |
| 复试前两周 | 发第一封邮件：初试分数、研究兴趣、你的相关经历 |
| 复试前一周 | 若未回复，礼貌跟一次，不追问结果 |
| 复试当天 | 若安排面谈，把提前准备的内容用出来 |

**第一封邮件别写成绩承诺、别问「老师您收我吗」**。自我介绍 + 研究兴趣 + 具体经历是合适的写法。

## 四、复试当天的三个失分点

| 失分点 | 表现 | 怎么避免 |
| --- | --- | --- |
| 项目讲不清 | 只有功能描述，没有你的动作与取舍 | 每个项目准备「我做了什么/遇到什么问题/怎么解决」三句 |
| 夸大经历 | 细节追问时露馅 | 只说自己真做过的；不熟的就说「这部分是团队做的，我负责的是」 |
| 对目标院校一无所知 | 说不出为什么选这个方向 | 提前读该导师近两三年的论文摘要或公开项目 |

## 五、并行准备调剂

复试时间与调剂系统开放时间经常重叠。建议**从准备复试的第一天起就把调剂材料一起备好**（材料包基本可共用），这样无论结果如何都有路可走，详见 [调剂系统怎么操作](12-考研调剂与二战.md#kaoyan-adjustment-system)。

## 什么时候要谨慎

- 复试形式、权重、参考书目**每年由各招生单位自行规定**，必须读当年版本；
- 政审表、材料盖章需要回学校或原单位，提前一周准备；
- 线下复试要订票订房，越早越便宜且有备选；
- 复试名单与录取结果在研招网与院校研究生院官网同时发布（https://yz.chsi.com.cn/），两边都盯。
