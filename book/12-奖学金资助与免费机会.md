# 奖学金、资助与免费机会

资助不是“额外的运气”，而是一套有固定入口的资源。多数人拿不到，是因为不知道入口在哪，或者错过截止时间，而不是因为不够优秀。

按钱的用途分六类：

| 类型 | 用途 | 常见来源 |
| --- | --- | --- |
| 奖助学金（Scholarship / Bursary） | 学费、生活费 | 学校、政府、基金会、企业 |
| 研究资助（Grant / Fellowship） | 做研究、买设备、发论文 | 政府基金、学会、机构 |
| 助研助教津贴（Stipend / RA / TA） | 覆盖生活、换取劳动 | 导师项目、学校 |
| 差旅与会议资助（Travel Grant / Fee Waiver） | 参会、展示、注册费减免 | 会议、学会、学校 |
| 交流与公派资助 | 交换、访学、联培 | 政府项目、学校、接收方 |
| 开源与项目资助 | 支持具体项目或社区工作 | 基金会、企业、社区计划 |

一句提醒：正规资助不会要求你“先交钱才能拿到钱”。凡是先付费再谈资助的，按第 16 章的陷阱清单处理。

## 本章条目

### 学生能拿到的资助有哪几类、去哪里找


- 一句话：
  查资助的正确方式是按“你的身份 + 你要做的事”去对应官方页面找，而不是等通知。顺序是：先拿几乎不需要竞争的材料型资助（奖助学金、助学贷款），再申请需要计划书的项目型资助（研究、会议、交流）。

- 适合谁：
  在校生与应届生；需要钱参会、做研究、出国交流的人；家庭经济困难的学生——这一类有专门通道，但很多人不知道它的存在；研究生阶段需要助研助教津贴覆盖生活费的人。

- 不太适合谁：
  把申请资助当成主要收入来源、用“申请”替代“做事”的人。多数项目型资助都要求你已经有具体成果或明确计划，空手申请基本不会中。

- 能换回什么：
  直接的现金支持（学费、生活费、差旅、材料费）；减少兼职压力，把时间留给主业；部分资助附带导师、社群与人脉；政府奖助学金本身也是履历的一部分；公派或交流资助还附带一段海外经历。

- 要付出什么：
  申请材料时间（项目型资助常需要数周）；计划书撰写与推荐信沟通；等待与被拒；部分资助有后续义务（结题报告、公开致谢、成果标注）。

- 怎么开始：
  1. 写下你的身份关键词：学历阶段、学校与院系、专业、家庭经济状况是否在政策覆盖范围、以及你要做的事（学业、研究、会议、交流、开源）。
  2. 按类别找入口，不要只搜“奖学金”：
     - 学校：学生资助管理中心、研究生院、教务处、国际合作处。
     - 政府：教育部门的学生资助政策、国家公派留学、地方人才政策。
     - 学会与基金会：专业协会的学生奖学金与差旅资助。
     - 企业与社区：公开的资助计划与开源项目资助。
  3. 先申请材料型资助（多数按条件发放，竞争压力小），再申请计划型资助。
  4. 面对截止日期倒排时间表，推荐信至少提前两周沟通。
  5. 一次投多个，把被拒当成常态。
  6. 记录每笔资助的后续义务，按期完成报告。

- 常见误区：
  不知道学校有资助通道，只找社会上的商业机构；错过截止时间；只申请一个项目；把申请资助当成“求人”而不好意思；不看条款就签（有些资助附带服务期或成果归属要求）；通过非正规渠道借贷；忽略汇率与税费对实际到手金额的影响。

- 下一步可能打开什么：
  用资助支撑的科研与合作；会议展示带来的机会；公派与交流项目；部分资助是更大项目的敲门砖。

- 证据与来源：
  - 教育部：学生资助政策体系说明（国家奖助学金、助学贷款等）。http://www.moe.gov.cn/ （Official）
  - 全国学生资助管理中心（中国学生资助网）：资助政策与申请入口。https://www.xszz.edu.cn/ （Official）
  - 国家留学基金管理委员会：国家公派留学与相关资助项目的官方信息。https://www.csc.edu.cn/ （Official）
  - 各类资助的具体条件以当年度官方项目公告为准，逐年变化。 （Official）

### 差旅资助和会议奖学金怎么申请

```meta

status: complete
stages: [undergraduate, master, phd, new_grad]
topics: [funding, research]
outputs: [income, network, research_experience, reputation]
effort: low
evidence: [official, experience_based]
last_verified: 2026-09-21
```

- 一句话：
  这类资助大多面向“已经被接受做展示的学生”，金额通常覆盖机票与住宿，申请窗口常在录用通知之后、会期前数月。关键是你手里有一份被接受的材料（论文、Poster、报告），申请书本身很难弥补这一点。

- 适合谁：
  论文或 Poster 被会议录用、需要到现场的学生；参加学术活动或竞赛的学生；想第一次进入某个学术或行业圈子的新人。

- 不太适合谁：
  没有具体产出、只想“去感受一下”的人（多数资助要求展示或现场志愿服务）；会期与考试、答辩等硬性安排冲突的人。

- 能换回什么：
  差旅与注册费的现金支持；现场展示与被提问的机会；与合作者、评审、雇主的直接接触；一段“曾获会议资助”的履历记录。

- 要付出什么：
  申请材料（录用通知、摘要、预算、有时需要导师支持信）；等待结果的时间；很多项目的报销流程需要**先垫付再报销**，现金流压力是真实成本；现场展示的准备时间。

- 怎么开始：
  1. 一收到录用通知，立刻去会议官网找 Student Travel Grant / Scholarship / Volunteer 页面，记下截止日期。
  2. 同时查本校研究生院、国际合作处或学院是否有会议资助。很多学校有，但必须提前申请，且名额有限。
  3. 查你所属学会或专业协会的学生差旅资助。
  4. 准备材料：录用证明、摘要、预算明细（往返机票 + 住宿 + 注册费）、导师支持信。
  5. 申请会议志愿者通常能减免注册费，代价是现场服务时间。
  6. 结果未出前先确认是否需要垫付，并准备报销所需的发票与行程材料。

- 常见误区：
  拿到录用通知后忘记申请截止时间；只申请会议本身的资助，漏掉学校的通道；预算写得过高或没有明细；不看清报销要求（发票抬头、报销窗口期）；把参会当旅游，没有准备展示与交流；忽略签证与保险的额外成本。

- 下一步可能打开什么：
  现场交流带来的合作与实习机会；加入学会并参与志愿工作（见 [社群、导师与行业影响力](13-社群导师与行业影响力.md)）；把会议产出扩展成期刊论文。

- 证据与来源：
  - 各会议官网的 Student Grant 与 Volunteer 页面，是唯一权威来源，逐年变化。 （Official）
  - 各高校研究生院或国际合作处发布的会议资助办法（逐校核实）。 （Official）
  - 专业学会与协会的学生资助页面（以官方公告为准）。 （Official）
  - 报销流程往往比申请更耗时间，这一点来自普遍经验。 （Experience-based）
