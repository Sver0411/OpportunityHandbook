## 每章的写法

- 章首是一段判断框架或分类表，说明这一章处理什么问题、不处理什么问题。
- 章内条目用 `### 标题`，标题下是 ```meta 元数据块与固定字段的正文，字段定义见 [条目格式](../meta/条目格式.md)。
- 未写完的条目保留标题、`status: todo` 与一条写作说明，不会进入搜索结果。

## 条目完成状态

`tools/build_index.py` 会统计每章的完成数与待写数：

```bash
python3 tools/build_index.py --report
```

正文修改后重新构建，在线页面的内容、搜索索引与筛选条件会一起更新。
