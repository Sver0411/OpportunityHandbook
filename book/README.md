# 正文目录

正文全部在 `book/` 目录下。Markdown 是唯一正文来源，在线页面由构建工具从这些文件生成。

内容较长的章节会按分组拆成多个分册：章节文件保留为**导读页**（开篇说明 + 分册目录表），
具体条目放在同名目录里，例如 `book/04-升学、就业还是出国/02-国内升学.md`。
拆分只换文件位置，条目 id、锚点、导航与搜索都不变；工具见 `tools/split_chapter.py`。

## 五种读法

1. **按主线读**：从 00 顺着读到 08，跟着人生问题往前走。
2. **按阶段进入**：从[路径时间线](11-路径时间线.md)找到你所在的阶段（本科四年、保研、考研、留学申请、校招、转行），再跳进对应内容。
3. **要动手时**：[工具与模板](12-工具与模板.md)给表格，[完整案例](13-完整案例.md)给别人的完整过程，[操作手册](14-操作手册.md)给可以照着执行的分步流程。
4. **按专题查**：从 [09 专题手册](10-专题手册.md)按主题、国家与行业检索；它只补充资料，判断仍以正文为准。
5. **不知道从哪开始**：[内容地图](18-内容地图.md)把三种找法列在一页里。

五种入口共享同一份正文：同一件事只写一遍，其他位置放链接。

## 每章的写法

- 章首是一段判断框架或分类表，说明这一章处理什么问题、不处理什么问题。
- 章内文章用 `### 标题`，标题下是 ```meta 元数据块，正文按问题自己组织段落（不再强制固定栏目），写法见 [条目格式](../meta/条目格式.md)。
- 未写完的条目保留标题、`status: todo` 与一条写作说明，不会进入搜索结果。
