## 四种读法

1. **按主线读**：从 00 顺着读到 08，跟着人生问题往前走。
2. **按阶段进入**：从[路径时间线](10-路径时间线.md)找到你所在的阶段（本科四年、保研、考研、留学申请、校招、转行），再跳进对应内容。
3. **要动手时**：[工具与模板](11-工具与模板.md)给表格，[完整案例](12-完整案例.md)给别人的完整过程，[操作手册](13-操作手册.md)给可以照着执行的分步流程。
4. **按专题查**：从 [09 专题手册](09-专题手册.md)按主题、国家与行业检索；它只补充资料，判断仍以正文为准。

四种入口共享同一份正文：同一件事只写一遍，其他位置放链接。

## 每章的写法

- 章首是一段判断框架或分类表，说明这一章处理什么问题、不处理什么问题。
- 章内文章用 `### 标题`，标题下是 ```meta 元数据块，正文按问题自己组织段落（不再强制固定栏目），写法见 [条目格式](../meta/条目格式.md)。
- 未写完的条目保留标题、`status: todo` 与一条写作说明，不会进入搜索结果。
