# 留学语言考试怎么准备

[IELTS / TOEFL / TOEIC](../02-在学校里先把基础打好/05-语言.md#english-standardized-tests)回答的是「三者怎么选、备考顺序」；这一册回答**操作层**：报名、考位、机考还是纸笔、出分、送分、复议。

**一个前提**：考试政策（机考范围、成绩有效期、送分规则、复议费用）**由考试主办方定，且会变**。本册只写「要查什么、去哪查、怎么排」，具体规则以官方为准——雅思见教育部教育考试院（https://ielts.neea.cn/）与雅思中国（https://www.chinaielts.org/），托福见 ETS（https://www.ets.org/toefl/）。

排期用 [留学语言考试排期表](../../docs/tools/留学语言考试排期表.md)。

「雅思还是托福」这个问题问错了。**正确的问题不是哪个容易，而是你的目标项目接受哪个。** 难度差异远小于准备质量带来的差异，而选错考试会直接浪费一整轮。

这一页只解决三件事：选哪个考试、报名时哪几项容易填错、时间怎么倒排。

## 一、按地区与用途倒推

| 你的目标 | 通常需要 | 判断依据 |
| --- | --- | --- |
| 英国、澳大利亚、加拿大、欧洲多数项目 | 雅思为主，部分接受托福 | 项目官网的语言要求栏 |
| 美国及以北美为主的项目 | 托福为主，部分接受雅思 | 同上 |
| 部分欧洲项目（荷兰、德国、北欧） | 可能接受其他考试或校内语言证明 | 同上 |
| 部分外企、日韩企业求职 | TOEIC 等职场类 | 招聘公告 |

**查证方式**：去目标项目官网找语言要求原文，看它写的是「接受 IELTS」还是「要求 TOEFL iBT」，以及是否指定版本（Academic / General）。**不要凭中介说法或学长经验。**

三类考试的用途差异详见 [IELTS / TOEFL / TOEIC](../02-在学校里先把基础打好/05-语言.md#english-standardized-tests)，本页只讲操作。

## 二、机考还是纸笔

近年多数考点在往机考迁移，但**不同考点、不同考次的可用形式不同**，这是报名时必须逐项确认的。

| 维度 | 机考 | 纸笔 |
| --- | --- | --- |
| 出分速度 | 通常更快 | 通常较慢 |
| 考场地点 | 考点较少，需去指定考场 | 考点较多 |
| 口语 | 与笔试同日，在考场完成 | 常另设日期，需再跑一趟 |
| 作答与修改 | 打字为主，修改方便 | 笔答，写错难改 |
| 熟悉度 | 需要提前适应键盘输入与屏幕阅读 | 更接近过去的考试体验 |

**实务建议**：如果你以前没考过机考，尽量早约一场机考适应，不要留到申请季最紧的时候。

## 三、报名时最容易选错的四项

| 容易错的 | 后果 | 怎么避免 |
| --- | --- | --- |
| **考试类型**（Academic / General） | 类型不符，部分项目不接受 | 学位申请通常要学术类；确认项目要求 |
| **考位城市** | **影响你能报哪些学校**——不同考位有区域限制 | 报考前确认目标项目是否接受该考位出的成绩 |
| 场次时间 | 与申请截止日、实习冲突 | 按申请截止日倒排，不按自己方便 |
| 身份信息与证件 | 与证件不符，进场受阻 | 姓名拼写与护照完全一致 |

**第三项是本册最重要的判断**：考位不是「随便找个考点」，它决定你的成绩被哪些项目接受。这一条各省各校各项目不同，必须在报名前逐个确认目标项目的要求。

## 四、按申请截止日倒排

把时间线倒过来排：

```
申请截止日 → 材料截止（多数比申请早）→ 语言成绩必须到手的日期
→ 出分周期 → 考前复习周期 → 报名
```

**关键动作**：算出「语言成绩最晚什么时候必须在手」，往前推出考试日期。常见错误是按「我准备好了」来定考期，而不是按「截止日」倒排。

| 情况 | 应对 |
| --- | --- |
| 时间紧 | 约更早的考位，宁可多留缓冲 |
| 可能重考 | 一次约两场不同月份，第二次当缓冲 |
| 目标未定 | 先考一次拿到分数，很多项目接受多校提交同一成绩 |

## 什么时候要谨慎

- **先查项目官网的语言要求原文**，不要用中介说法或学长经验；
- 考位与成绩认可范围有关联，报名前确认目标项目是否接受；
- 机考与纸笔的可用形式、出分周期、有效期**每年可能调整**，以官方为准（https://ielts.neea.cn/ 、https://www.ets.org/toefl/）；
- 成绩有效期通常两年，但**申请时是否仍需有效**要按项目要求核对（见 [分数与小分怎么看](../02-在学校里先把基础打好/05-语言.md#english-standardized-tests)）；
- 报名与考位数量有限，热门考位要早约。

### 小分不达标、成绩复议与二刷

语言考试最折磨人的地方在于：**总分够不等于达标**。很多申请者准备了半年，总分超出要求两三分，却因为某一项差 0.5 被拒。

这一页处理四个已经考完（或快要考完）才发现的问题。

## 一、小分不达标的信号与三种补救

| 信号 | 说明 |
| --- | --- |
| 总分达标、单项差 0.5–1 分 | 最常见的拒信原因，通常只有一两项差 |
| 口语/写作低于要求 | 输出类项目提分最慢，是短板高发区 |
| 单项低于学校自设的更严口径 | 部分项目对小分的要求高于官方门槛 |

三种补救路径，按推荐顺序：

| 路径 | 做法 | 适用 |
| --- | --- | --- |
| 1 换项目 | 找一个接受「总分够、小分稍低」的项目 | 时间紧、来不及二刷 |
| 2 二刷 | 集中补短板后重考 | 还有时间（通常要 2–3 个月） |
| 3 换其他证明 | 部分项目接受校内语言测试或语言班结业证明 | 目标项目明确接受 |

**顺序很重要**：先确认目标项目能不能接受、能不能换项目，再考虑二刷。二刷三个月，代价不小。

## 二、成绩复议能解决什么、不能解决什么

「成绩复议」（score review / 成绩复核）能解决的问题很有限，这一点必须先想清楚：

| 能解决 | 不能解决 |
| --- | --- |
| 部分考场的评分异常 | 真的答错/答得不好 |
| 成绩录入或计算错误 | 你确实没达到水平 |
| 违规或缺考记录有误 | 小分本来就低于目标 |

**判断标准**：如果你考完的感觉是「我该拿的分都拿到了，成绩却明显偏低」，复核有意义；如果是「我确实没考好」，复核不会改变结果。

复核有时限与费用（以官方当年说明为准），而且多数考试只有一次机会——申请赶时间时，等复核再送分往往来不及。**如果时间紧，先按现有成绩投，别把希望押在复核上。**

## 三、二刷的最优间隔

| 间隔 | 适合 |
| --- | --- |
| 太短（< 1 个月） | 基本等于重考同一个分数 |
| **2–3 个月** | 通常最合理：够把短板练到稳定 |
| 太长（> 5 个月） | 状态可能回落，要重新进入节奏 |

**二刷前要改变的**：这次不能只是「再考一遍」，要针对上次的具体问题做定向训练（见 [雅思还是托福](03-留学语言考试怎么准备.md#lang-test-choice) 里说的短板定位）。

## 四、申请季的时间冲突

这是留学语言考试最实际的问题：考期往往卡在申请季中间。

| 冲突 | 应对 |
| --- | --- |
| 申请截止在出分之前 | 提前约考，往前挪一个考期 |
| 材料截止比申请截止更早 | 以材料截止为准倒排 |
| 需要多次送分 | 查清送分要多久（以官方当年说明为准） |
| 实习/工作与考试冲突 | 周末与晚间考点优先，但可选范围变小 |

**一条经验规则**：如果你的目标院校还没定，考虑「先考一次拿到分数」——多数项目接受同一份成绩投多所，比追求满分更实际。

## 什么时候要谨慎

- 小分要求要**逐校逐项目**核对，部分项目严于官方门槛（见 [分数与小分怎么看](../02-在学校里先把基础打好/05-语言.md#english-standardized-tests)）；
- 成绩复核的结果与时限以官方当年说明为准，**别把申请材料压在复核结果上**；
- 二刷至少留 2 个月，否则提升有限；
- 有效期通常两年，但**申请时是否仍需有效**要按项目要求核对；
- 送分规则、机考范围、考位政策每年可能调整，以官方为准（https://ielts.neea.cn/ 、https://www.ets.org/toefl/）。
