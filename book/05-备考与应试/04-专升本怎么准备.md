# 专升本怎么准备

[专升本](../01-先决定下一步往哪里走/03-专科与职业教育.md#study-zhuanshengben)回答的是「哪条路值不值得走」；这一册回答「怎么报、怎么排、什么时候能放弃」。

**各省差异极大**：考试名称、科目、时间、志愿规则、录取方式都不一样。常见叫法有统招专升本、专接本、专转本、普通高校专升本——**同一个词在不同省份指不同东西**。这一册只写各省共通的判断方法与操作顺序，具体规则**一律以本省教育考试院当年文件为准**。

节奏见 [专升本时间线](../../docs/timelines/专升本时间线.md)，完整步骤见 [第一次准备专升本](../../docs/playbooks/第一次准备专升本.md)。

「专升本」这个词下面藏着性质完全不同的几条路。**选错之后最难改的不是学历本身，而是第一学历标注**——它会跟着你很多年，并且影响后面的每一次报考。

这一页只解决一个问题：**你要的是哪一种**，以及怎么确认。

## 一、四条路的差别

| 路径 | 学习形式 | 学制 | 第一学历 | 报考时点 |
| --- | --- | --- | --- | --- |
| **统招专升本** | 全日制 | 通常 2 年（医学等更长） | **本科** | 专科应届或符合条件时，通常只有一次 |
| 成人高考 | 非全日制 | 通常 2.5–3 年 | 仍为专科 | 有年限要求 |
| 自考 | 无固定学制 | 按考试通过情况 | 仍为专科 | 报考条件各省不同 |
| 开放大学 | 业余/网络为主 | 2.5–3 年 | 仍为专科 | 有年限要求 |

**关键判断**：如果你的目标是「让硕士/考公/国企的报名条件通过」，只有统招专升本通常能改变第一学历；其余三条改变的是学历层次而非第一学历标注。

这不是说后者没用——职称评定、内部晋升、部分岗位确实认可。**但它不能替代前者。**

## 二、影响最大的是「目标单位认不认」

选之前必须做一件事：**把你未来 2–3 年最可能去的 3 类单位，各找 3–10 份招聘公告，看学历要求怎么写。**

| 招聘公告里的写法 | 意味着 |
| --- | --- |
| 「本科及以上」 | 通常不区分全日制，条件较松 |
| 「本科及以上（全日制）」 | **非全日制被排除** |
| 「普通高等教育本科」 | 一般指统招，成人教育可能不算 |
| 「本科及以上，且学士学位」 | 还要看有没有学士学位 |

**这一步不能省**。反例很常见：花三年拿了个本科，考公时发现岗位要求「全日制本科」，报名资格不通过。

## 三、报考资格要逐项核对，不靠印象

统招专升本的资格条件各省不同，但核对项基本是这五类：

| 核对项 | 常见要求 | 怎么核 |
| --- | --- | --- |
| 学历层次 | 专科在读或已毕业 | 学信网可查（https://www.chsi.com.cn/） |
| 专业限制 | 需与专科专业对口或相近 | 本省文件的「可报考专业目录」 |
| 应届身份 | 通常限最后一次报考机会 | 本省文件的应届口径说明 |
| 成绩或前置条件 | 部分省份要求专科期间无挂科或成绩达标 | 本校教务处 |
| 专项通道 | 退役大学生士兵等单独通道 | 本省文件的专项政策 |

**专业限制是最大的坑**：很多省份不允许跨专业，报考目录里能报的专业可能和你想的完全不同。所以第一步是**先看目录，再定目标**，不是反过来。

另外注意：**退役大学生士兵通常有单独的免试或专项通道**，条件往往更宽松，有这类身份的人应该先查专项政策而不是走普通通道。

## 四、几个不可逆的地方

选之前要知道这几件事是**没法回头**的：

| 不可逆项 | 说明 |
| --- | --- |
| 报名时填的专业 | 录取后一般不能改 |
| 入学后放弃录取 | 通常只能等下一次，且下一次未必有资格 |
| 专科毕业证与档案 | 升本期间不能提前办结，否则可能影响入学 |
| 成人教育的形式标注 | 毕业时标注已定，无法事后改成全日制 |

**档案和专科毕业证这两条最容易被忽略**：很多人录取后才去办，结果卡在手续上。

## 什么时候要谨慎

- 「专升本」在不同省份含义不同，**别用别省经验套自己**，先查本省文件；
- 目标单位若写「全日制」，非全日制路径基本走不通——**先查公告再决定**；
- 统招专升本通常**只有一次机会**（应届或最后一年），错过的成本比考研错过更高（见 [考研调剂与二战](../05-备考与应试/08-考研调剂与二战.md)）；
- 专业限制按目录走，不接受「应该差不多」这种判断；
- 退役士兵等专项通道的条件通常更宽，**先查专项再走普通**。

专升本的失败很少是「分数不够」，更多是**流程环节**：资格审核被退回、专业选错、志愿没填、录取后没在期限内确认。

这一页按环节列每一步要交什么、卡在哪。**具体时间与材料清单以本省教育考试院当年文件为准。**

## 一、八个环节

| # | 环节 | 你要做的事 | 常见翻车原因 |
| --- | --- | --- | --- |
| 1 | 查本省文件 | 确认考试名称、科目、时间、志愿规则 | 用别省经验推断 |
| 2 | 查专业目录 | 确认哪些专业能报 | 想报的专业根本不在目录里 |
| 3 | 资格初审 | 提交学历学籍信息 | 专科专业名称与目录不一致 |
| 4 | 正式报名 | 填报信息、缴费 | 缴费没完成，报名无效 |
| 5 | 打印准考证 | 确认考点与时间 | 错过打印窗口 |
| 6 | 考试 | 考公共课与专业课 | 只准备了专业课，公共课拉低总分 |
| 7 | 查分与志愿 | 填志愿，等录取 | 不知道有征集志愿，错过就落榜 |
| 8 | 录取确认 | 在规定期限内确认，办理专科毕业手续 | 没确认，或专科毕业证卡住 |

**第 4 步与第 8 步是最常见的两个低级错误点。**

## 二、第 1–2 步：先看目录，再定目标

正确顺序是「先查能报什么，再定要报什么」。

| 要查到 | 在哪查 | 为什么关键 |
| --- | --- | --- |
| 考试名称与科目 | 本省教育考试院当年文件 | 名称各省不同，不能套用 |
| 可报考专业目录 | 本省文件附的专业目录 | **决定你能报哪些专业** |
| 志愿规则 | 本省文件 | 平行志愿还是志愿清表、能否调剂 |
| 应届口径 | 本省文件 | 决定你有没有资格 |

**专业目录这一栏是整个流程的起点**：先列一遍能报的专业，再在这个范围内定目标。反过来做（先定好学校和专业，再去查能不能报）会浪费大量时间。

## 三、第 3 步：资格审核最常见的退回原因

| 退回原因 | 怎么避免 |
| --- | --- |
| 专科专业名称与目录不一致 | 用学信网上的**正式专业名称**逐字比对，不用自己叫法 |
| 学历信息查不到 | 先在学信网确认能查到自己的专科信息（https://www.chsi.com.cn/） |
| 不满足应届条件 | 按本省文件的应届口径，不要按「我还没毕业」推断 |
| 不满足成绩或前置条件 | 提前问本校教务处，别等审核被退 |
| 错过改报窗口 | 报名时一次填对，填完再核对一遍 |

**核心做法**：报名前一天在学信网把自己的学历学籍信息调出来截图对照，而不是凭记忆填。

## 四、第 7 步：志愿怎么排

各省志愿规则不同，但共通的排序逻辑是：

| 原则 | 说明 |
| --- | --- |
| 拉开梯度 | 不要把几个志愿填成同一层次，落榜时无处可去 |
| 服从调剂要慎重 | 调剂可能把你送到完全不想去的学校/专业 |
| 征集志愿要盯 | 常规志愿落榜后还有征集志愿，**时间短、名额少** |
| 保底要真实 | 保底志愿应该是你确实能接受的，不是「随便填的」 |

**征集志愿是最容易被忽略的机会**，也是很多人「明明够分却落榜」的原因。它通常时间短、需要立刻决定，所以在这之前就把可接受的其他院校专业先查好。

## 五、第 8 步：录取后必须在期限内确认

录取之后有两件事要做，顺序不能反：

1. **在规定期限内确认录取**（各省时长不同，以本省文件为准）——逾期不确认可能被视为放弃；
2. **办理专科毕业手续与档案转递**——这是入读本科的前提。

第 2 点最麻烦：专科毕业证要等毕业时才能办，档案在哪儿（学校、户籍地、工作地）也要提前问清楚。**录取后先去问档案在哪、什么时候能转，别等学校催。**

## 什么时候要谨慎

- 报名、缴费、准考证、志愿填报、录取确认**全部按本省当年文件的硬截止执行**，错过通常没有补救（各省级教育考试院官网，逐省核实）；
- 专业目录是起点，先查再定目标；
- 专科毕业证与档案是入读前提，录取后第一件事就是问清档案位置；
- 征集志愿时间短、名额少，事先查好备选而不是临时找；
- 退役大学生士兵等专项通道条件通常更宽，先查专项再走普通（见 [统招专升本与成人教育怎么选](04-专升本怎么准备.md#zsb-path-choice)）。
