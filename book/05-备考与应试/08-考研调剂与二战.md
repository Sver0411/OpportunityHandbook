# 考研调剂与二战

这两件事都属于「第一次没走通之后怎么办」，但性质完全不同：**调剂是当年就能完成的流程，二战是一次新的年度决策**。把两者混在一起谈，最常见的错误是「反正还有调剂，先不准备了」。

判断层见 [调剂](../04-升学、就业还是出国/02-国内升学.md#study-transfer-adjustment) 与 [二战](../04-升学、就业还是出国/02-国内升学.md#study-retake-exam)；这一册讲操作。

调剂是**有时间窗、有锁定、有顺序**的一套流程。它最大的特点是：大部分规则由官方在当年公告里写明，不需要猜，只需要按时做完。

**前提认知**：一志愿优先。招生单位先完成第一志愿复试录取，合格生源不足时才开放调剂。所以调剂开放时，你面对的是一个已经筛过一轮的剩余名额池。

## 一、五个步骤

| # | 步骤 | 你要做的事 | 卡点 |
| --- | --- | --- | --- |
| 1 | 确认资格与范围 | 分数过国家线且符合调入要求 | 部分专业有单独要求 |
| 2 | 提前建备选名单 | 初试结束就该列好 | 等系统开放才找，范围太窄 |
| 3 | 填报志愿 | 在研招网调剂系统提交 | 提交后进入锁定状态 |
| 4 | 参加复试 | 去调入单位参加复试 | 时间紧、要求不同 |
| 5 | 确认录取 | 在规定时间内确认 | 逾期不确认视为放弃 |

## 二、第 1 步：可调剂范围不是「都能调」

| 条件 | 说明 |
| --- | --- |
| 分数 | 初试成绩需达到国家线（部分年份/专业有单独要求） |
| 专业背景 | 通常要求初试科目相同或相近，具体口径逐年公布 |
| 培养方式 | 全日制与非全日制的要求不同 |
| 特殊限制 | 部分专业不接受调剂，或有单独规定 |

**具体口径每年由官方公告写明**，不要按往届经验推断（https://yz.chsi.com.cn/）。

## 三、第 2 步：备选名单要在初试后就列好

这是整个流程里最容易被跳过、也最致命的一步。系统开放时你只有很短的时间找学校，而那时你手忙脚乱，很容易只填一两个志愿。

可执行的备选名单准备方法：

1. **按初试科目筛选**：只考虑专业课与你的科目一致或相近的；
2. **按分数线倒排**：从略低于你估分的院校往上列，列 10–15 所；
3. **每所写清楚三件事**：复试形式、复试参考范围、往年是否开放过调剂；
4. **区分「能接受」和「想去的」**：前者是保底，后者是首选——混在一起会让你在开放时乱填。

## 四、第 3 步：填报与锁定

填报在研招网的调剂系统里完成（https://yz.chsi.com.cn/）。需要知道的规则：

| 规则 | 说明 |
| --- | --- |
| 志愿形式 | 通常可填多个平行志愿，按考生填报顺序检索 |
| 锁定 | 提交后进入锁定状态，锁定时长由官方设定（当年公告为准） |
| 投递规则 | 一次只能被投到一个单位，投出后等待复试通知 |

**锁定期间不能改**，这是调剂流程里最大的不可逆点。所以在提交前把备选名单再核一遍。

## 五、三个最常见的操作失误

| 失误 | 后果 |
| --- | --- |
| 等系统开放才开始找学校 | 只能填很少的志愿，且都是没查过的 |
| 没查目标单位的复试要求 | 复试内容与初试完全不同，临时准备来不及 |
| 提交后才发现名单有问题 | 锁定期内无法修改，只能等下一轮开放 |

## 什么时候要谨慎

- 调剂系统开放时间、志愿数量、锁定时长、投递规则**每年由研招网与教育部公告确定**，必须看当年公告（https://yz.chsi.com.cn/）；
- 调入单位的复试形式、参考书目与初试完全不同的很常见，别用初试思路去准备复试；
- 调剂不成功不等于必须二战，先评估「二战 vs 直接就业」的成本（见 [二战该不该打](08-考研调剂与二战.md#kaoyan-retake-decision)）；
- 部分招生单位在复试后要求在规定时间内确认录取，逾期可能递补，务必留意通知。

### 二战该不该打：复盘、止损与三条替代方案

「要不要二战」是一个**决策**，不是一个情绪问题。多数二战失败的复盘里都指向同一个原因：上一年没搞清楚自己为什么没考上，就直接把同样的方法再来一遍。

这一页给的是决策顺序：先复盘，再止损判断，再看替代方案，最后才算成本。

## 一、第一步：复盘差距在哪

| 归因 | 怎么判断 | 对应动作 |
| --- | --- | --- |
| 方法问题 | 做了很多题但同类题还错 | 换方法，不是加量 |
| 投入问题 | 时间不够、做题量不足 | 加量，但先砍别的科目 |
| 状态问题 | 会做的题考场上做不出来 | 练考场节奏与压力下的稳定性 |
| 执行问题 | 计划没做完 | 降低计划规模，而不是提高意志力 |
| 择校问题 | 分数够但学校不够 / 学校够但分数差太多 | 换目标，不是加倍努力 |

**归因顺序很重要**：先排除执行问题（最常见也最易改），再考虑方法问题，最后才考虑投入和择校。跳过这一步直接「加倍努力」，很可能只是把执行问题做得更彻底。

## 二、第二步：四个止损信号

| 信号 | 说明 |
| --- | --- |
| 两次备考是同一套方法 | 没有新变量，结果大概率重复 |
| 分数差距 > 30 分且方法没变 | 差距量级需要方法改变，不是时长改变 |
| 已经完全不想复习 | 动力耗尽时投入效率极低 |
| 已有一份可接受的工作或 offer | 二战的机会成本从「无」变成「很高」 |

**止损不等于放弃**：止损是「换一条路」，包括就业、申请其他项目、先工作再考。这三条见下一节。

## 三、第三步：三条不需要二战的替代方案

| 方案 | 适合谁 | 说明 |
| --- | --- | --- |
| 直接就业，用工作再决定 | 已有工作或可立即入职的人 | 收入 + 经验是真实资产，不是失败 |
| 申请境外 / 交叉方向 | 有语言或作品基础的人 | 换一条赛道的成本往往低于二战一年 |
| 先就业一年再考 | 考研是为了转行的人 | 带着明确目标再考，成功率更高 |

判断依据见 [读研值不值得](../04-升学、就业还是出国/02-国内升学.md#grad-school-worth-it) 与 [保研和考研怎么选](../04-升学、就业还是出国/02-国内升学.md#baoyan-vs-kaoyan)。

## 四、二战的时间成本

| 成本项 | 说明 |
| --- | --- |
| 时间 | 一年（应届）或少半年到一年（在职） |
| 收入 | 备考期间放弃的收入，尤其对已工作的人 |
| 心理 | 上一次的失败会持续影响复习状态 |
| 简历 | 空窗期在求职时需要额外解释 |
| 机会 | 同届同学已就业，落后一年 |

**这些成本要具体化，不要笼统地「再拼一年」**。特别是收入损失，在职考生往往比应届考生付出更高。

## 五、二战怎么准备才不是重复

如果决定二战，至少要有三个「新的变量」：

1. **新的方法**（不是同一套书同一批题再来一次）；
2. **新的目标**（分数或学校上做实质调整，或换赛道）；
3. **新的节奏**（针对上一年执行不到位的部分做结构性改变）。

三个都没有，那大概率是把上一年重复一遍。

## 什么时候要谨慎

- 二战的精神压力需要提前准备，最好有可倾诉的人或咨询渠道，不要一个人闷着；
- 已工作的读者尤其要先算清机会成本再决定，见 [转行前先判断什么](../08-晋升、跳槽还是转行/05-转行.md#switch-before-decide)；
- 二战的报名、考试科目与招生单位要求**每年重新公布**，不是延续上一年；以教育部、研招网当年公告为准（https://yz.chsi.com.cn/）；
- 不要把二战当成「必须」，也不要把就业当成「退而求其次」——两者都可能比对方更值得。
