# 笔试：行测与申论

笔试是公考里唯一**完全靠自己**的一环。这一册只讲方法：行测怎么排顺序与取舍，申论怎么找点与成文。

前置：先按 [岗位表怎么读](09-考公与考编怎么准备.md#exam-job-table) 确定考哪类卷，再看下面两篇。不涉及押题与范文。

行测考的不是知识量，而是**在固定时间内把会做的题全部做对**。所以备考的重点是模块取舍与时间分配，不是刷更多题。题量与时长以当年度考试大纲为准（通常在一百多道题、两小时左右），但「做不完」是常态——这本身就是考试设计的一部分。

## 一、五模块：考什么、怎么提分

| 模块 | 典型题型 | 建议解法顺序 | 提分速度 | 练习重点 |
| --- | --- | --- | --- | --- |
| 资料分析 | 增长率、比重、平均数、增长量计算与比较 | 先看问题再看材料定位数据 | **最快** | 速算（估算、截位）与题干定位，正确率目标接近满分 |
| 判断推理 | 逻辑判断、图形推理、定义判断、类比推理 | 按题型模板做，不临场发明方法 | 快 | 题型固化，按类连做几天形成条件反射 |
| 言语理解 | 逻辑填空、片段阅读 | 先读题干要求再看文段 | 中 | 高频词与成语积累；逻辑填空靠语境而非语感 |
| 数量关系 | 工程、行程、排列组合、概率、几何等 | 只攻高频题型，其余跳过 | 慢 | 学 5–8 类固定题型的解法，练到 60 秒内出结果 |
| 常识判断 | 政治、法律、经济、人文、科技、地理 | 会就选，不会就快速排除 | 最慢 | 靠日常积累；考前不值得突击 |

**用时目标是自己的，不是别人的**。建议先做一套真题，按「正确率 × 用时」给每个模块打分，再决定投入顺序：正确率低且耗时高的模块优先，正确率高但耗时高的模块练提速，正确率低且耗时低的模块直接放弃。

## 二、四步备考法（含时间估算）

每一步都有明确的产出：定位表、模块错题归类、套卷复盘三行、考前错题清单。按顺序走，不要跳。

## 第一步：定位（1 套真题，约 3 小时含复盘）

做完整一套并严格计时，填一张定位表：

| 模块 | 做了几题 | 对几题 | 用时 | 结论（攻/提速/放弃） |
| --- | --- | --- | --- | --- |
| 资料分析 | | | | |
| 判断推理 | | | | |
| 言语理解 | | | | |
| 数量关系 | | | | |
| 常识判断 | | | | |

结论只写一个词：**攻（集中练）、提速（练速度）、放弃（只保底）**。

## 第二步：模块攻坚（每个模块 3–5 天）

- 一天只做一到两个模块，按题型连做（例如「增长率」题型连做 30 题）；
- 做完立刻复盘：把错题按下面的四类错因归类，而不是抄题；
- 一个模块的正确率稳定到目标值，再换下一个。

## 第三步：限时套题（后期每周 2–3 套）

这一步练的不是知识点，而是**取舍与节奏**：什么题先做、什么时候跳、最后 10 分钟做什么。每套卷之后写三行复盘：哪块超时、哪块丢了不该丢的分、下次改什么。

## 第四步：回炉（考前两周）

只做两件事：看错题归类、重做高频题型。**不再开新资料**，避免临考焦虑。

## 三、错题本只用四类错因

| 错因 | 含义 | 对应动作 |
| --- | --- | --- |
| 知识缺口 | 方法根本不会 | 回教材补这一类解法 |
| 方法不当 | 会做但用了慢方法 | 记下更快的解法 |
| 看错题 | 题干条件看漏、单位看错 | 养成圈出关键条件与单位的习惯 |
| 时间不够 | 会做但没时间 | 调整顺序，把它挪到前面 |

四类里，「看错题」和「时间不够」造成的丢分往往比「不会做」更多——但它们最容易被忽略。

## 四、一周排期样例

| 时间 | 在校生（每天 3–4 小时） | 在职（每天 1.5–2 小时 + 周末） |
| --- | --- | --- |
| 周一 | 资料分析专项 60 题 | 资料分析 30 题 |
| 周二 | 判断推理专项 | 判断推理 30 题 |
| 周三 | 言语理解专项 | 言语理解 30 题 |
| 周四 | 数量关系（只攻高频题型） | 数量关系 15 题 |
| 周五 | 常识 + 错题回看 | 错题回看 |
| 周六 | 限时套题 1 套 + 复盘 | 限时套题 1 套 + 复盘 |
| 周日 | 补短板 + 休息半天 | 补短板 + 休息 |

**休息半天要写进计划**：行测考的是注意力，长期睡眠不足会让正确率整体下滑（见 [长期高强度怎么不垮](../17-身体与心理的可持续性/01-节奏与身体.md#health-sustainable-pace)）。

## 五、考场取舍清单（考前写好，考场上照做）

示例（按自己的情况调整）：

1. 开考先做资料分析（正确率高、收益最大）；
2. 数量关系放到最后，只做看得出思路的题，超过 90 秒立刻跳；
3. 常识放在中间换脑子，30 秒没思路就选一个走；
4. 涂卡分两次（中部、结束前），全部做完再回头补涂一次；
5. 剩余 5 分钟只做一件事：检查答题卡有没有漏涂。

## 六、六条常见误区

1. 只刷题不复盘：题量上去了，错因没解决；2. 从最难的模块开始攻：信心与时间都被消耗；3. 迷信技巧与「秒杀法」：多数题靠的是熟练而不是技巧；4. 不做整套限时卷：单模块正确率高，套卷做不完；5. 考前换新资料：把已经建立的题型感打乱；6. 和别人比正确率：不同卷类、不同岗位的分数线差别很大。

## 什么时候要谨慎

- 不要买「押题密卷」「内部题库」：行测靠能力，押题没有稳定收益；
- 题库以历年真题为主，模拟题只作补充；题型与卷类（副省级／地市级／行政执法类等）以当年度考试大纲与真题为准；
- 长期熬夜刷题拖垮状态时，先修作息，再谈提分；
- 本页的模块排序、时间目标与排期建议为本项目整理的经验性内容，不替代真题与大纲。

申论是「按材料写答案」的考试：**得分点在材料里，不在你的观点里**。所以练法和大作文完全不同——先练找点，再练组织，最后才谈语言。

## 一、五类题型与作答骨架

| 题型 | 常见问法 | 作答骨架 | 最常见失分 |
| --- | --- | --- | --- |
| 归纳概括 | 「概括…的主要问题／做法」 | 分条列点，每条一个角度，用材料原词 | 要点不全、把例子当观点 |
| 综合分析 | 「谈谈你对…的理解／评价」 | 是什么（定性）→ 为什么（原因/影响）→ 怎么办（对策） | 只表态不分析、脱离材料 |
| 提出对策 | 「提出解决建议」 | 主体 + 动作 + 目的（谁做什么，达到什么效果） | 对策空泛、主体错位 |
| 应用文写作 | 「写一份建议书／倡议书／汇报」 | 标题 + 称谓 + 开头（背景） + 主体（分条） + 结尾 + 落款日期 | 格式与语境不符、对象错 |
| 大作文 | 「围绕…写一篇文章」 | 开头亮观点 → 2–3 个分论点（各带论据） → 结尾回扣 | 立意偏、堆口号、无逻辑 |

**每类题型都要练到「不用想结构」**：考场上想结构的时间就是丢分的时间。

## 二、读材料：把「找点」当第一能力

1. **先读题干再读材料**：读题时圈出「范围、对象、要求（概括/分析/建议）」；
2. **按要素勾画**：问题、原因、影响、做法、主体、时间、数字——不同要素用不同标记；
3. **标主体**：政府、企业、群众、社会组织，做对策题时主体错了分数就没了；
4. **不抄原句成段**：要点用来答题，但表述要转写成自己的概况，避免整句照搬。

**判断自己找点能力的方法**：做完题的要点个数与参考答案比对。全而准说明找点过关；漏点说明勾画不系统。

## 三、作答四步（考场上按顺序执行）

1. **审题（1–2 分钟）**：明确题型、范围、字数、分值；
2. **找点（按材料顺序）**：先勾画，后归类，避免边读边写；
3. **归类（合并同类项）**：把要点按「主体／领域／层面（思想、制度、资源、技术）」合并成 3–5 条；
4. **成文（分条 + 序号）**：一条一段，序号统一（一、二、三 或 1. 2. 3.），每条控制在 40–80 字。

## 四、字数与卷面

| 项目 | 做法 | 常见问题 |
| --- | --- | --- |
| 字数 | 先写要点再补句子，写完数一遍（标点算字，以题干要求为准） | 少于下限要多写，超上限会扣分 |
| 分行 | 每条之间空行或换行，避免一坨 | 阅卷老师找点困难 |
| 序号 | 全文统一一种 | 一会儿「一」一会儿「①」 |
| 字形 | 写得清楚比写得漂亮更重要 | 潦草直接损失印象分 |
| 修改 | 不涂大块，错字画一横即可 | 大面积涂改影响卷面 |

## 五、大作文：结构比文采重要

- **开头（约 100 字）**：点题 + 亮明观点，别用空泛的背景铺陈；
- **主体（2–3 段）**：每段一个分论点，写法是「分论点 + 解释 + 论据（材料里的案例/数据或积累的例子） + 回扣」；
- **结尾（约 80 字）**：回扣总论点，落到这个题目要求的层面（治理、服务、发展等），不要喊口号；
- **素材从哪来**：材料里给的事实最安全；平时积累政策表述与案例，但**只用在合适的位置**，不要堆砌。

## 六、一次完整练习怎么做（每周一次）

1. **限时**：按题目要求的总时间做完整一套（含大作文），用手机计时；
2. **自评**：先自己改一遍，标出「漏掉的点」与「写多了的点」；
3. **对照**：再对参考要点，把漏点补进「要素库」（按问题/原因/对策分类积累）；
4. **存档**：把每次的答案与漏点存一个文件，考前只看这份。

一周一次完整练习 + 每天 30 分钟找点训练，通常比每天写一整篇更有效。

## 七、六条常见误区

1. 背「万能模板」：与材料无对应关系，痕迹重反而扣分；2. 大段抄材料原句：被判为抄袭式作答；3. 只练大作文：前几道小题占分不少；4. 不写字数：超限与不足都扣分；5. 只读不写：找点能力必须靠手写练出来；6. 指望押题方向：材料主题每年变，练的是方法不是内容。

## 什么时候要谨慎

- 不要相信「万能开头结尾」「押题素材包」这类材料，也不要为它们付费；
- 声明要严格遵守：**本页不提供范文与押题**；题型、题量与作答要求以当年度考试大纲与真题为准；
- 申论提分慢，若只剩两周，优先保证小题的找点与卷面，而不是硬啃大作文；
- 手写慢的人要提前练手速：考场上写不完是常见的失分原因。
