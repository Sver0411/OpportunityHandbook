# 面试与后续环节

笔试决定你能不能进面，面试与后面的环节决定你能不能上岸。这一册讲面试的两种主要形式，以及容易被忽略的体检与考察。

前置：[从报名到上岸的完整流程](09-考公与考编怎么准备.md#exam-apply-to-onboard)；判断层入口见 [考公、选调与事业单位](../01-先决定下一步往哪里走/01-认识你面前的几条主要路线.md#paths-public-sector)。

### 结构化面试怎么准备

```meta
last_verified: 2026-10-15
```

结构化面试是「同一组题目、同一套评分表」的面试。它考的不是知识，而是**在压力下把想法组织成有条理的话**。

## 先搞清评分维度

考官通常按几项打分（综合分析、计划组织、人际沟通、应急处理、岗位匹配、语言表达等，名称与权重各地不同）。**看官方公布的面试公告与大纲**，再决定把练习时间放在哪几项上。

| 维度 | 考什么 | 常见低分表现 |
| --- | --- | --- |
| 综合分析 | 对政策、现象的理解与立场 | 只表态、无分析、没有层次 |
| 计划组织 | 办一件事的流程与细节 | 只说「我会做好」、缺步骤与风险预案 |
| 人际沟通 | 与同事、群众、上级的矛盾处理 | 一味妥协或一味强硬 |
| 应急处理 | 突发情况的处置顺序 | 顺序错（先处置还是先报告） |
| 岗位匹配 | 为什么是这个岗位与地区 | 空话、套话、答不出与岗位的具体关系 |

## 三步练习法

1. **按题型建框架**：每类题固定一个作答结构（是什么—为什么—怎么办；先处置—再报告—后复盘），练到不用想；
2. **开口计时**：每题 3 分钟准备、3–4 分钟作答，用手机录音。**不录音的练习基本无效**；
3. **对照复盘**：听录音，只改三件事——删空话、补细节（具体主体与步骤）、控制时间。

## 三个加分习惯

- **先给结论再展开**：考官一天听几十个人，「结论在前」最省他的力气；
- **说具体动作**：把「加强沟通」换成「当天下午先当面沟通、拿到书面确认」；
- **留一句岗位相关**：结尾把答案落到这个岗位与地区，而不是泛泛而谈。

## 什么时候要谨慎

- 不要背模板化的「金句」：一听就知道是背的，且与题目无对应关系；
- 不要编造经历：追问一层就露；宁可讲一段真实的小事；
- 面试形式（结构化/无领导/面谈）、题量与时间以当次面试公告为准（[一次真实的结构化面试](../../docs/career-guides/公共部门.md)）；
- 心理压力大时先解决状态问题（见 [情绪持续不好时找谁](../17-身体与心理的可持续性/02-心理与求助.md#health-mental-support)）。

### 无领导小组讨论怎么应对


无领导考的是**在团队里有用**：你能不能让讨论往前走、能不能让结论更清楚。抢话最多的人往往不是最高分。

## 评分看什么

| 观察点 | 高分的表现 | 低分的表现 |
| --- | --- | --- |
| 推进 | 提出标准、划分步骤、把跑题拉回 | 反复表态、只说感受 |
| 归纳 | 在讨论卡住时小结「目前共识是…分歧在…」 | 从不总结，任由重复 |
| 倾听与协作 | 接住别人观点并补强，请沉默的人发言 | 打断、抢话、否定人 |
| 时间感 | 主动提醒剩余时间并收口 | 时间到了还没结论 |
| 表达 | 简短、有序、有依据 | 长、乱、只讲立场 |

## 三种角色怎么选

- **推进者**：适合表达清晰、能快速抓问题的人——负责定标准、控节奏；
- **归纳者**：适合听得细、能整合的人——负责做小结、写提纲、收口；
- **务实贡献者**：适合有具体方案的人——给出可执行的步骤与风险预案。

**选一个并做扎实**，比三种都沾一点得分高。若讨论一开始就有人抢推进，你要做的是补位（归纳或补充标准），而不是竞争同一个位置。

## 四个具体动作

1. **开头 30 秒定框架**：给出讨论标准（例如「按可行性、时效、成本排序」），把讨论变成有结构的任务；
2. **中场做一次小结**：明确共识与分歧，推动进入下一环节——这是最容易拿分的时间点；
3. **点名补位**：对没发言的人说「刚才您提到 X，能否展开」，既拉人入局也显示协作；
4. **收尾替团队收口**：在时间结束前给出结论与理由，并说明如何分工落实。

## 什么时候要谨慎

- 不要为了表现而否定他人：考官听的是「这个人进团队后好不好用」；
- 不要背金句与口号：无领导没有「正确答案」，看的是过程；
- 组内出现明显抢话者时，不要和他对抢：改为承担归纳与收口，性价比更高；
- 形式（是否包含无领导、时长与人数）以当次面试公告为准。


走到体检与考察，说明笔试面试都过了。这两关通常不淘汰人，但**一旦出问题就是终局**，所以值得提前自查。

## 体检

- **标准从哪查**：招录公告会写明适用的体检标准文件（公务员录用体检通用标准与操作手册，特殊岗位另有标准），**按文件逐项看**，而不是听别人说；
- **常见复检情形**：血压、心率、肝肾功能、视力等指标受当天状态影响，通常会安排复检；复检仍不合格才作结论；
- **提前准备**：体检前几天别熬夜、别剧烈运动、别喝酒，避免因临时状态影响指标；
- **长期用药或慢性病**：先对照岗位标准确认是否影响，必要时提前咨询主治医生与招录机关。

## 考察（政审）

考察看两块：**档案材料**与**现实表现**。

| 看什么 | 常见问题 | 怎么提前自查 |
| --- | --- | --- |
| 档案 | 缺件、材料不实、档案在校或人才机构但未及时转 | 提前确认档案存放地与完整性（见 [离职、换工作与社保衔接](../../docs/rights/离职与社保衔接.md)） |
| 学历学位 | 学历认证、学位信息与报名填写不一致 | 在学信网核对信息，确保与报名表一致 |
| 现实表现 | 原单位/学校的评价，是否有违法违纪记录 | 在职人员需单位配合出具意见 |
| 诚信记录 | 考试违纪、失信被执行、被举报核实 | 有历史问题的，提前说明而不是隐瞒 |

## 三个提醒

1. **在职人员要提前沟通**：考察会联系原单位，且需要单位出具意见——瞒着报考风险很高；
2. **报名信息保持一致**：从报名到考察的所有材料（学历、经历、时间）必须能互相印证，前后矛盾是常见的被卡原因；
3. **公示期不要松懈**：公示期内被举报并核实会取消录用资格，如实、低调地走完流程。

## 什么时候要谨慎

- 体检标准与考察要求逐岗位不同，**一律以招录机关公布的文件为准**；本页只讲自查顺序；
- 有既往病史、手术史、心理就诊史时，先按文件核对是否属于影响录用的情形，必要时向招录机关咨询（询问本身不影响资格）；
- 涉及档案缺失、学历认证等历史问题，越早处理越好，临时补办常赶不上公示前的时限。
