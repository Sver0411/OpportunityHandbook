# 四六级分数的用途与校内规定

判断层在 [四六级与校内英语](../02-在学校里先把基础打好/05-语言.md#english-cet)：它卡哪些场合、值不值得投入。这一册是**具体对照表**：哪个场景卡多少分、卡在哪个环节、校内规定怎么查、规定了但你不想按它办时怎么办。

分项训练见 [四六级分项怎么练](01-四六级怎么准备.md#cet-section-training)，完整步骤见 [Playbook：第一次考四六级](../../docs/playbooks/第一次考四六级.md)。

四六级分数在多数场景里**只是筛选门槛，不是能力证明**。搞清这一点，能避免把时间投在不产生实际差异的地方。

这一页按场景列四行：作用是什么、查哪个文件、卡在哪个环节。

## 一、四类场景对照

| 场景 | 四六级的作用 | 查哪个文件 | 卡在哪个环节 |
| --- | --- | --- | --- |
| 毕业与学位 | **可能是硬条件** | 本校教务处/学院的文件 | 论文答辩前、学位申请时 |
| 保研/推免 | 常见为加分项或门槛 | 目标院校的研究生招生文件 | 申请材料审核 |
| 考公/事业编 | 少数岗位在报名条件里写明 | 招考公告的「其他条件」栏 | **资格审查** |
| 校招网申 | 少数单位设硬线，多数只初筛 | 招聘公告与网申页面 | 网申筛选 |

## 二、毕业与学位：唯一真正「硬」的一类

这是唯一会造成实质后果的硬条件：**不过可能影响按时毕业或申请学位**。

要查清三件事：

| 要查的 | 在哪查 |
| --- | --- |
| 四级是否与毕业挂钩 | 本校教务处、学院教务办公室 |
| 挂钩的是四级还是六级 | 同上 |
| 有没有替代路径（校内英语考试、其他等级） | 同上 |

**替代路径是重点**：很多学校在毕业要求里留了口子（校内英语等级考试、更高等级证书、其他语种等）。有替代路径时，先确认它是否比四六级更容易。

## 三、保研：加分项通常比门槛更常见

多数院校的推免申请条件里，四六级是**加分项或参考项**，少数写成硬门槛。

| 看什么 | 说明 |
| --- | --- |
| 是门槛还是加分 | 门槛写「须达到」，加分写「同等条件下优先」 |
| 适用方向 | 有些院校只在某些学院或某些方向要求 |
| 分数口径 | 是否要求单科、是否要求具体分数段 |

详见 [保研和考研怎么选](../04-升学、就业还是出国/02-国内升学.md#baoyan-vs-kaoyan) 与 [保研](../04-升学、就业还是出国/02-国内升学.md#study-baoyan)。

## 四、考公：写在报名条件里才算

公务员与事业单位的招考公告里，「其他条件」栏可能写「大学英语四级及以上」。**这一条如果写在公告里，就是资格审查的硬条件**，复审时会核验成绩单。

排查方法：把目标岗位的招考公告逐字看一遍，重点看「其他条件」和「报考条件」两栏（见 [岗位表怎么读](../05-备考与应试/09-考公与考编怎么准备.md#exam-job-table)）。公告在各人事考试网与国家公务员局官网（http://www.scs.gov.cn/、http://www.cpta.com.cn/）。

## 五、校招：写了但常不查

市场化招聘里，六级多数只做**初筛信号**，真正的语言能力考核在面试（英文自我介绍、读英文文档）。

判断「写了但没人查」的方法：看岗位是否涉外、是否有海外业务、面试是否有英文环节。都不涉及的岗位，四六级更像是筛简历的统一标准。

判断依据见 [英语为什么仍然重要](../02-在学校里先把基础打好/05-语言.md#skill-english) 与 [怎么判断一个选择值不值得](../00-从这里开始.md#judge-worth-it)。

## 六、成本对照：刷到多少分才值得

| 目标 | 建议投入 |
| --- | --- |
| 校内毕业要求 | 一次过线即可 |
| 推免门槛 | 刚过门槛即可，加分部分收益递减 |
| 考公报名条件 | 一次过线即可 |
| 校招硬线 | 按硬线准备 |
| 「以防万一」 | **不建议投入**——概率低、回报低 |

**判断原则**：按四类场景里最硬的那条准备，超出部分边际收益很低。

## 什么时候要谨慎

- **校内规定逐校、逐院不同**，任何用别校规则套自己的判断都可能出错；
- 毕业与学位的四六级要求**以本校教务处/学院书面文件为准**，口口相传的信息不可靠；
- 招考公告里的英语条件写「四级及以上」时，**审查时会核验成绩单**，不是自我声明；
- 政策会变：既不能假定某校一直不查，也不能假定某校一定会查，以当年文件为准。

「四级不过不给毕业」是很多学校确实存在的规定。它听起来严重，但**多数学校留有替代路径**——问题在于大多数学生不知道，也不去问。

这一页只解决两件事：怎么核实这条规定是什么、核实之后有哪些路。

## 一、先核实规定本身（不要信转述）

| 核实路径 | 怎么做 | 可靠度 |
| --- | --- | --- |
| 教务处书面文件 | 查学校官网教务处栏目的学籍管理规定 | 高 |
| 学院通知 | 问辅导员或教务老师要文件链接 | 中高 |
| **书面咨询** | 邮件问教务处：适用范围、替代路径、例外条件 | 高 |
| 同学转述 | 「听说不过不给毕业」 | 低 |

**最有效的一步是发一封邮件问教务处**，把三个问题一次问清：

1. 英语成绩要求的具体文件名称与适用范围（全校/某学院/某专业）；
2. 除四六级外，还有哪些认定途径（校内英语等级考试、其他语种、其他证书）；
3. 有没有例外或补考机制，最晚时间节点是什么。

邮件留底，将来如果有争议，这是凭证。

## 二、四条替代路径

| 路径 | 说明 |
| --- | --- |
| 校内英语等级考试 | 很多学校自设有四级替代考试，难度相当或更低 |
| 其他语种等级 | 日语、德语等语种的等级考试常被认可 |
| 其他等级证书 | 部分学校接受 PETS、雅思、托福等换算（以本校文件为准） |
| 重考下一次考次 | 如果时间允许，最直接 |

**关键**：这些路径**必须在报名之前向教务处确认**，不能自己假设。因为「认定」这件事只有学校能做。

## 三、例外与申诉

如果确实无法在期限内取得合格成绩，通常可以走的流程是：

| 环节 | 做什么 |
| --- | --- |
| 说明情况 | 生病、家庭变故等**可核实**的原因 |
| 提交书面申请 | 向学院/教务处提交书面说明与证明 |
| 等待审核 | 结果通常需要时间，不要等到毕业前一个月才提 |
| 确认替代方案 | 审核通过后一般会指定替代方式 |

**注意时间**：这类申请通常有截止节点，且越晚越被动。发现问题时立刻问，不要先拖一个学期。

## 四、如果核实下来没有硬要求

那就不需要为它投入。理由见 [四六级分数在各场景的用途对照](02-四六级分数的用途与校内规定.md#cet-score-usage)：把时间花在真实使用（读专业文档、开口说）上的回报更高（见 [英语为什么仍然重要](../02-在学校里先把基础打好/05-语言.md#skill-english)）。

## 什么时候要谨慎

- 「不过不给毕业」这个说法本身需要核实——**不同学校、不同学院、不同专业的规定可能完全不同**；
- 替代路径必须由学校书面确认，不能自己推定；
- 例外申请需要可核实的证明，且时间节点通常很早；
- 政策会变，任何结论都以**当年的教务处文件**与书面答复为准。
