# 专题手册

这一章不做判断，只做索引。

主线（00–08）回答的是「值不值得、怎么选、什么时候做」；这一章只把同一主题下的资料集中起来，方便你一次查全。遇到需要判断的地方，仍然回到主线的那篇文章，那里才有完整的代价与收益分析。

资料分三类：**主题手册**（按事情分）、**国家与地区**（按地方分）、**行业与职业**（按方向分）。

## 深度教程 · 项目与作品

从选题到发布：把「知道该做什么」变成「真的做完并留下证据」。

- [项目选题与问题定义](../docs/projects/选题与问题定义.md) —— 从问题找题而不是从技术找题：三类问题的找法、适合学生的题目特征、scope 怎么切、第一版的可完成标准、什么时候该换题。
- [从教程 Demo 到真正作品](../docs/projects/从教程到作品.md) —— 从照教程跑通到可以展示的作品：十三个步骤的完整路径，以及 Web / AI 数据 / IoT 三类项目各自的落地方式。
- [MVP 与范围控制](../docs/projects/MVP与范围控制.md) —— 最小闭环的定义、MVP 不等于做得烂、必须与延后的功能划分、feature creep 的识别、scope freeze 与停止加功能的判断。
- [工程项目的测试、指标与证据](../docs/projects/测试与指标体系.md) —— 「跑通」为什么不算测试：从功能与失败路径到 benchmark、丢包率、功耗、可用性、可复现与样本量，含软件 / 数据 / IoT 三套完整实验表。
- [日志、可观测性与故障分析](../docs/projects/日志与故障分析.md) —— 从日志级别、上下文到崩溃与看门狗：学生项目也能用的轻量可观测性，以及故障复现、根因分析与事后复盘的完整流程。
- [README 的技术写作（三档对比）](../docs/projects/README对比.md) —— 差 / 普通 / 优秀三档 README 逐段对比：从 Overview 到 License 十一个段落，以及哪些项目不需要全写。
- [Demo 怎么做（30 秒 / 2 分钟 / 面试 / 比赛）](../docs/projects/Demo制作.md) —— 不同场合的 Demo 目标与做法：脚本与分镜、录制与部署、硬件与无法在线部署的替代方案、失败时的兜底。
- [项目如何写进简历与面试（5 组 Before / After）](../docs/projects/项目写进简历.md) —— 从项目本体到面试追问的完整链路，以及五组「原文 / 改写 / 理由」对照，覆盖无结果、有数据、硬件、开源与转行场景。
- [项目类型专项：什么证据才算做得好](../docs/projects/项目类型专项.md) —— Web、AI/Data、嵌入式、硬件机器人、开发者工具、开源与科研项目各自的验收证据与常见自欺，不再用「真实用户」统一衡量。

## 深度教程 · 科研方法

研究问题、基线、消融、实验设计、可复现与同行评审的方法层。

- [如何提出 Research Question](../docs/research-deep/研究问题的提出.md) —— 从观察到缺口再到可检验的问题：observation → gap → hypothesis → RQ → contribution 的完整链条，以及好坏问题的大量对照。
- [Baseline 怎么设计](../docs/research-deep/Baseline设计.md) —— 为什么需要基线、弱基线与强基线的区别、公平比较的前提、oracle 与对照组，以及把基线做弱为什么是严重问题。
- [Ablation 怎么设计](../docs/research-deep/消融实验.md) —— 消融回答什么问题、组件移除与参数消融的区别、敏感性分析与交互作用，以及怎么避免「为了表格而消融」。
- [实验设计：变量、对照与统计](../docs/research-deep/实验设计进阶.md) —— 假设、自变量与因变量、混淆因素、随机化、重复试验、样本量、统计功效、多重比较、效应量与不确定性，以及不同学科的设计差异。
- [数据管理与可复现性](../docs/research-deep/数据与可复现.md) —— 数据版本、预处理、数据泄漏、随机种子、环境锁定、artifact 与 FAIR；区分 reproducibility 与 replicability，并给出自查清单。
- [读论文的高级方法](../docs/research-deep/论文精读方法.md) —— 定位真正贡献、把 claim 与 evidence 对齐、识别偷换基线、读图表与附录、找限制、追引文图并画文献地图。
- [Peer Review 与 Rebuttal](../docs/research-deep/同行评审与回复.md) —— 审稿人关注什么、如何模拟评审、意见分类与取舍、哪些该接受哪些可以反驳，以及 response letter 的结构。
- [科研失败案例：从数据泄漏到缩小主张](../docs/research-deep/科研失败案例.md) —— 一个完整的研究案例：从查文献到最终贡献，中间经历首次实验失败、发现数据泄漏、结果不显著、缩小 claim 的全过程。

## 深度教程 · 求职训练

拆 JD、改简历、过面试、诊断漏斗、看懂 Offer 与合同。

- [一份 JD 到底怎么拆](../docs/job-search/JD拆解.md) —— 用完整 JD 逐行分析：硬性要求、偏好、wishlist、日常工作、关键词、资历与隐藏信号，最终产出岗位画像与准备优先级。
- [简历从差到好（六种背景完整改写）](../docs/job-search/简历改造.md) —— 无实习、有项目无结果、有科研、有实习、转行、工作 1–3 年六种背景：原文、问题、两轮改写与理由。
- [技术面试全流程](../docs/job-search/技术面试.md) —— 知识题、项目题、调试、系统设计、编程与领域题的考法与准备；不会时怎么办、如何澄清与思考出声、如何复盘。
- [行为面试：不机械用 STAR](../docs/job-search/行为面试.md) —— 冲突、失败、领导力、ownership、模糊情境、意见分歧、优先级与截止时间的完整好坏回答对照，以及 STAR 的适用边界。
- [项目面试：从第一句开始的追问链](../docs/job-search/项目面试.md) —— 「介绍一下你的项目」之后的完整追问链，以及每一层该怎么答：为什么做、为什么这样设计、有没有别的方案、性能、测试、失败、重做、你负责什么。
- [求职失败诊断：从 0 回复到 Offer 质量差](../docs/job-search/求职漏斗诊断.md) —— 把求职结果按环节拆开：0 回复、有回复无测评、测评挂、一面挂、终面挂、Offer 少、Offer 质量差，各自对应的问题与检查动作。
- [Offer、薪酬结构与劳动合同](../docs/job-search/Offer与合同.md) —— base、bonus、RSU、option、sign-on、试用期、社保公积金、加班、竞业、vesting 与 severance 的逐项核对，含一个完整 Offer 案例。
