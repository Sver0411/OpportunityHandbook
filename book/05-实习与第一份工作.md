# 实习与第一份工作

实习和第一份工作有一个共同点：它们的价值主要不体现在当下的工资单上，而体现在**你从这段经历里能带走什么**。

判断一段经历值不值，最快的办法是问自己：结束时我能写出哪三行字放进简历，这三行字能不能被别人核实（有交付物、有数据、有作品链接）。写不出来，这段经历就只是消耗了时间。

### 第一份工作最应该换回什么

```

- 一句话：
  第一份工作最该换回的是能带走的东西：可迁移的技能、能讲清楚的项目、行业里认识你的人、以及下一份工作的选择权和议价能力。只有这家公司认的熟练度，和换不来任何成果的忙碌，都不算。

- 适合谁：
  所有刚毕业或刚开始第一份全职工作的人；在几个 Offer 之间做选择的人；担心“第一份工作选错就完了”的人。

- 不太适合谁：
  已经明确要在同一家机构长期发展的人（例如部分体制内岗位、家族事业），此时“内部认可与资历”本身就是主要收益；处于极端经济压力下、必须先解决收入的人——先拿收入是正确的选择，但要清楚知道自己暂缓了什么。

- 能换回什么：
  可迁移的技能；能讲述、能被验证的项目与成果；行业人脉与未来的推荐人；下一份工作的议价能力；对某个行业的真实认知（这一点常被低估，它直接影响后面所有选择）；工作习惯与协作方式。

- 要付出什么：
  1–3 年时间与精力；可能偏低的起薪；加班挤占的学习与健康时间；地理迁移；以及进错岗位的沉没风险——岗位本身不产出可迁移成果时，时间不会自动变成资本。

- 怎么开始：
  1. 面试时就问三个问题：半年后我会独立负责什么？我会有具体的交付物吗？谁给我反馈、多久给一次？回答含糊的岗位要谨慎。
  2. 做一次“三行字测试”：假设一年后离职，你能写进简历的三行字是什么？如果写不出来，说明这段工作对你的职业资本贡献很小。
  3. 优先选能见到真实用户、有真实交付、有明确评审机制的环境。流程再规范，没有交付也不算积累。
  4. 入职前三个月主动要反馈，把产出整理成能保存的文档与作品（注意公司保密要求）。
  5. 每半年更新一次简历。如果半年写不出新的一行，就该考虑调整，而不是再等一年。

- 常见误区：
  只看起薪不看成长；把大公司的流程熟悉度误认为可迁移能力；把“很忙”当成“在成长”；入职初期不敢问“我该做到什么程度”，一年后才发现方向偏了；把第一份工作当成终身决定——它真正的作用是给下一份工作当筹码；为了“大厂title”接受一个永远做边角工作的岗位。

- 下一步可能打开什么：
  第二份工作的议价空间；内部晋升与转岗；转行（见 [工作后转行为什么不应该清零过去经历](07-工作后的晋升跳槽与转行.md#career-change-keep-capital)）；带经验读研或出国。

- 证据与来源：
  - 各城市人力资源和社会保障部门、统计部门发布的工资与就业统计（用于核实现实收入水平，而不是用他人转述的数字）。http://www.mohrss.gov.cn/ （Official）
  - 招聘平台公开的岗位要求分布可作为抽样材料，用于观察“学历 / 经验 / 技能”要求的组合，但统计口径不一，只作参考。 （Industry-data）
  - “第一份工作与长期职业发展的关系”目前缺少统一口径的统计研究，本条的判断来自招聘与职业发展领域的普遍实践。 （Experience-based）

### 大公司、小公司和初创怎么选

effort: medium
evidence: [industry_data, uncertain]

```

- 一句话：
  大公司换的是流程规范、品牌背书和同行网络；小公司和初创换的是更大的职责范围和更快的决策参与。还没想清楚方向的人更适合先要体系，已经确定方向、愿意承担不确定性的人更适合要职责。

- 适合谁：
  大公司：应届生、需要体系化训练、需要简历背书、希望有稳定节奏的人。小公司：想快速负责完整模块、能接受流程缺失与职责模糊的人。初创：认可它的具体业务、能接受公司随时转向或消失的人。

- 不太适合谁：
  需要明确分工和培训的人不适合初创；想做快速决策、承担完整模块的人不适合层级深、流程长的大组织；对现金收入有硬性要求的人要谨慎对待以股权为主的薪酬结构。

- 能换回什么：
  大公司：品牌背书（在招聘筛选中确实起作用）、规范的工作方法、内部同行网络、离职后的行业认知度。小公司 / 初创：完整项目的负责经验、跨职能协作能力、与决策层近距离工作的机会，有时还包括股权。

- 要付出什么：
  大公司：职责范围较窄、较多的流程与协调时间、晋升节奏较慢。小公司：流程缺失带来的返工、职责不清、资源不足、公司层面的生存风险。初创还额外付出高波动性：业务转向、裁员、公司关闭。

- 怎么开始：
  1. 先确定你现在缺的是“体系”还是“职责范围”。这个答案比公司名气重要。
  2. 大公司要看**部门与汇报线**：同一个岗位名在不同部门差别很大，先问清业务线。
  3. 小公司与初创要看：现金流与融资阶段、核心业务是否已经跑通、你要负责的模块此前由谁负责、团队里有没有懂这一块的人。
  4. 谈清楚职责、汇报对象、薪资结构。涉及期权或股权时，看清算条件、行权价与稀释条款的书面文件，不要只听口头描述。
  5. 判断不了时，选那个“行业下滑时也能带走技能”的位置。

- 常见误区：
  把公司规模当成唯一变量（直属上级和部门的影响通常更大）；把期权当现金算；忽略试用期条款与竞业限制；在小公司只做杂活，一年下来没有可写进简历的交付物；为了“氛围好”接受没有产出标准的工作。

- 下一步可能打开什么：
  在两类公司之间互换；内部转岗；跳到更大或更小的平台；创业。

- 证据与来源：
  - 招聘平台公开的岗位与要求分布（用于观察两类公司对经验、技能的要求差异），口径不一，仅作参考。 （Industry-data）
  - 薪酬结构、期权与股权的法律含义必须按具体合同与法律文件判断，不存在通用结论。 （Uncertain）
  - 关于公司规模与个人成长速度的关系，公开数据不足以支持统一结论。 （Uncertain）
