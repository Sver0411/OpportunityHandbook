# tools/migrations —— 一次性迁移脚本

这些脚本用于**历史结构迁移**，日常内容维护不需要运行它们。保留在这里是为了
能够在需要时复现迁移过程，而不是作为常规工具使用。

| 脚本 | 用途 | 是否还需要日常运行 |
| --- | --- | --- |
| `apply_articles.py` | 按 entry_id 把写好正文与 meta 的条目写回章节文件（Canonical IA 映射 + 章节归属）。批量补写正文时仍会用到。 | 可用 |
| `restructure_chapters.py` | 按 `meta/navigation.json` 重建章节骨架（分组标题、条目顺序与标题）。仅在目录结构需要重新对齐时使用，会跳过 09/10 索引章节。 | 极少 |
| `migrate_ia.py` | IA 重构期的一次性迁移（旧分类 → Canonical IA）。 | 否 |
| `refactor_book.py` | 旧书稿拆分与重组。 | 否 |
| `naturalize.py` / `naturalize_fields.py` | 把旧模板字段（一句话/适合谁/能换回什么）转成文章结构。**本轮已改为逐篇手写重写，这两个脚本不再作为最终产出手段**，仅保留作参考。 | 否 |

## 注意事项

- 运行前先确认 `git status` 干净，这类脚本会批量改写 `book/*.md`；
- 批量替换 meta 字段时，**正则必须行有界**（例如 `[^\]\n]*`），
  `[^]]*` 会跨行匹配并吞掉整段内容——本项目曾因此损坏过 meta 与条目；
- `apply_articles.py` 的条目块边界在「## 来源与更新」处截断，
  重写后需要用一次尾部清理（删掉残留的旧合并段落）并重建分组标题。
