# 证据与来源规范

这本书的目标不是让人相信作者，而是让人能自己核对。所以每条条目都要标出它的依据属于哪一类。

## 证据状态

| 标记 | 含义 | 典型来源 |
| --- | --- | --- |
| **Official** | 政府、大学、考试机构、企业官方制度或官方项目规则 | 招生简章、政府政策原文、官方招聘页、签证与认证规定、学术机构章程 |
| **Research-backed** | 经过同行评审的研究或系统综述 | 期刊论文、系统综述 / 元分析、正式学术研究报告 |
| **Industry-data** | 可靠的行业调查、招聘数据、公开统计 | 官方统计年鉴、行业协会年度报告、公开招聘数据的统计口径说明 |
| **Experience-based** | 有普遍性的实践建议，但缺少严格统计证据 | 从业者公开复盘、导师与招聘方的通行做法 |
| **Uncertain** | 信息有争议，或现有来源不足 | 说法互相冲突、只有二手转述、时间敏感且未见官方更新 |

`evidence` 字段填英文值：`official` / `research_backed` / `industry_data` / `experience_based` / `uncertain`，可以多选。多选表示这条判断由多类依据共同支撑。

## 三条硬规则

1. **不把判断伪装成事实。**
   “读研值不值得”这种问题在不同行业、不同阶段的答案不同。写法应是“在 X 条件下回报明确，在 Y 条件下不确定”，而不是“读研是好的”。
   凡是作者判断，用「我们的判断是……」「按第 02 章的框架算下来……」这类句式明确标出。

2. **不编数字。**
   没有把握的薪资、录取率、通过率、比例，一律不写具体数值。可以写“不同行业差异很大，需要按目标岗位抽样核实”。
   引用数字必须能追到来源，并在同一条目里给出链接。

3. **二手来源要标出来。**
   只能用二手来源时，在来源行注明「二手，未经官方核实」。常见二手来源：培训机构文章、自媒体解读、SEO 拼接页、招聘平台的营销报告。

## 来源优先级

优先顺序（高 → 低）：

```
政府 / 监管部门
大学或机构官方页面（招生、教务、就业、实验室）
考试与认证机构官方
国际组织与官方统计
正式学术论文与系统综述
企业官方招聘页与官方公告
行业协会公开数据
从业者公开复盘（Experience-based）
```

尽量避免作为唯一依据：

```
培训与中介机构的招生软文
以引流为目的的自媒体解读
内容农场与 SEO 拼凑文章
无法追溯原始出处的"据说"
```

## 怎么在正文里写来源

「证据与来源」一栏用列表写，每条一行，行末标出证据类型，链接给到原始页面（不是转载页）：

```markdown
- 证据与来源：
  - 教育部研招网：硕士招生与推免服务系统的官方入口。https://yz.chsi.com.cn/ （Official）
  - 教育部政府门户网站：教育统计数据。http://www.moe.gov.cn/jyb_sjzl/ （Official）
  - 招聘平台对学历要求的统计口径不一，只能作为参考，不作为结论依据。（Industry-data，需按目标行业抽样核实）
```

## 允许写“不知道”

以下表述是合格内容，不是偷懒：

- 暂未找到可靠依据。
- 不同情况差异很大，需要按具体项目核实。
- 该说法目前只有二手来源，未经官方确认。

相反，把不确定的事情写得很确定，是这个项目最严重的错误类型。

## 时效

升学、考试、招聘、签证、证书的规则每年都可能变化。

- 每条条目必须有 `last_verified`，同时出现在 meta 块和正文的「最后核实」栏（两者必须一致）。
- 在线页面显示「最后核实：YYYY-MM-DD」。
- 超过 12 个月未核实，页面自动显示「可能需要重新核实」，并把它排进 `tools/build_index.py --report-stale` 的清单。
- 政策原文链接失效、官方页面改版，都算需要重新核实的信号。
