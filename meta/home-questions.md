# 首页常见问题

### 我到底要不要读研？

```meta
id: q-grad-school
kind: question
status: complete
link: grad-school-worth-it
summary: 先看目标岗位有没有把硕士写成硬门槛，再比较保研、考研与留学的路径与成本。
topics: [study]
stages: [undergraduate, new_grad, work_1_3]
```

看目标岗位的学历门槛是不是硬门槛：是，则回报明确；只是“想提升一下”，则回报最不确定。
见 [怎么判断“读研值不值得”](../book/04-升学、就业还是出国.md#grad-school-worth-it)。

### 保研和考研应该怎么选？

```meta
id: q-baoyan-kaoyan
kind: question
status: complete
link: baoyan-vs-kaoyan
summary: 先确认有没有推免资格；有资格再比较保研与考研的学校、方向与时间成本。
topics: [study]
stages: [undergraduate]
```

先查本校推免办法，看自己有没有资格；先确认自己是否具备推免资格；如果具备，再比较保研能够进入的学校和方向是否符合目标；没有推免资格时，再把考研、就业或其他升学路径作为主要选择。
见 [保研和考研应该怎么选](../book/04-升学、就业还是出国.md#baoyan-vs-kaoyan)。

### 本科生怎么开始科研？

```meta
id: q-undergrad-research
kind: question
status: complete
link: research-undergrad-start
summary: 从一个具体问题、几篇核心论文、一个真实课题组开始，用小任务换取第一次研究经历。
topics: [research]
stages: [undergraduate]
```

本科生开始科研前，不需要先达到“能独立完成研究”的程度。更需要的是具备所在领域最基本的课程基础，并能在导师或高年级成员指导下完成一个可验证的小任务——不同学科的小任务差别很大：复现代码、整理文献、协助实验、数据清理、访谈编码、档案整理、田野记录、设计调研都可以。
见 [本科生什么时候值得开始科研](../book/03-做项目、打比赛、进实验室.md#research-undergrad-start)。

### 投了很多简历都没回音，问题在哪？

```meta
id: q-no-reply
kind: question
status: complete
link: job-hunting-long-search
summary: 把求职拆成投递、回复、测评、面试、Offer 五环，先算出转化率，再只改最弱的一环。

stages: [undergraduate, new_grad, career_change]
```

### 怎么联系导师 / 要不要套磁？

### 家里预算有限，还能留学吗？

```meta
id: q-funding-limited
kind: question
status: complete
link: overseas-funding
summary: 先算总成本（学费 + 生活 + 一次性支出 + 回退成本），再逐项对照奖学金、助研与公派渠道。
topics: [funding, study]
stages: [undergraduate, master]
```

把「学费 + 生活 + 一次性支出 + 最坏情况的回退成本」四项算全，再按顺序找钱：院校奖学金 → 助研/助教 → 政府或机构资助（如 CSC 类公派）→ 贷款；**能覆盖多少决定你去哪个国家。**
见 [怎么找全额资助机会](../docs/admissions/选校与短名单.md) 与 [奖学金与资助手册](../docs/manuals/奖学金与资助.md)。

### 要不要考公 / 进体制？

```meta
id: q-public-sector
kind: question
status: complete
link: paths-public-sector
summary: 先分清国考省考、选调与事业单位三条通道，再看岗位表的硬条件、服务期与日常工作内容。
topics: [job]
stages: [college, undergraduate, new_grad, work_1_3]
```

「考公」其实是三条通道，条件与日常差别很大：先读当年公告与职位表（专业代码、学历、政治面貌、基层年限是最硬的筛子），再确认服务期与地域，最后判断自己能否接受材料与协调为主的日常。
见 [考公、选调与事业单位](../book/01-先决定下一步往哪里走.md#paths-public-sector) 与 [公共部门与事业单位](../docs/career-guides/公共部门.md)。
