# 条目格式

正文的每个可检索条目都是 `### 标题` 级别的三级标题，标题下紧跟一个 ```meta 代码块（机器可读的元数据），然后是固定字段的正文。

## 最小骨架

````markdown
### 本科生什么时候值得开始科研

```meta
id: research-undergrad-start
status: complete
stages: [undergraduate, master]
topics: [research]
outputs: [research_experience, recommendation, paper]
effort: high
evidence: [official, experience_based]
last_verified: 2026-09-21
```

- 一句话：
  用普通人能看懂的话说明结论。

- 适合谁：
  哪些人值得重点考虑。

- 不太适合谁：
  哪些情况下价值可能比较低。

- 能换回什么：
  可能获得哪些现实成果。

- 要付出什么：
  时间、金钱、精力、风险和机会成本。

- 怎么开始：
  给出可执行步骤。

- 常见误区：
  最容易踩的坑。

- 下一步可能打开什么：
  它可能通向哪些后续机会。

- 证据与来源：
  官方文件、大学官网、政府、研究、行业报告等。

- 最后核实：
  2026-09-21
````

## 字段说明

| 字段 | 是否必填 | 写法要求 |
| --- | --- | --- |
| 一句话 | 必填 | 只写结论，不写铺垫。控制在 100 字内。 |
| 适合谁 | 必填 | 写具体条件（学历、专业、目标岗位、经济状况），不要写“有上进心的人”。 |
| 不太适合谁 | 必填 | 这一栏是本书与成长鸡汤最大的区别，不要省略。 |
| 能换回什么 | 必填 | 用 `outputs` 里的词表，写成人话。 |
| 要付出什么 | 必填 | 至少覆盖时间、金钱、机会成本中的两项。 |
| 怎么开始 | 必填 | 给 2–5 步可执行动作，能今天就做。 |
| 常见误区 | 必填 | 写“大多数人会怎么想错”，不是泛泛提醒。 |
| 下一步可能打开什么 | 必填 | 写这条路的后续分叉；确实没有就写“没有明显的后续门”。 |
| 证据与来源 | 必填 | 见《证据与来源规范》，每条来源后标证据类型。 |
| 最后核实 | 必填 | `YYYY-MM-DD`，与 meta 中的 `last_verified` 一致。 |

## TODO 占位条目

第一阶段不要求每章写全。尚未撰写的条目保留标题与一条说明，用 `status: todo` 标记：

````markdown
### 参军

```meta
id: paths-military
status: todo
```

> TODO：说明参军的现实收益（技能、学历、安置、身份）与代价，以及退役后如何衔接升学与就业。
> 需要引用《兵役法》、全国征兵网与地方安置政策原文。
````

占位条目会被构建工具收进“本章待写清单”，不会进入搜索结果，因此不会让读者点进空页面。

## 硬性规则

1. 一个 `### ` 标题下必须有且只有一个 ```meta 块。
2. `id` 全仓库唯一，只用小写字母、数字和连字符。
3. 标题不要与字段重复（例如标题里已经有“怎么开始”，正文里就不用再写一遍）。
4. 不编造数字、比例、薪资、录取率。没有可靠来源就写“暂未找到可靠依据”或“不同情况差异很大”。
5. 有争议的做法必须写清“什么情况下低价值、什么情况下仍可能有用”，不做绝对化表述。
6. 不使用 `在当今快速发展的时代`、`毫无疑问`、`强烈推荐`、`逆天改命` 之类表述，完整清单见《写作规范》。
