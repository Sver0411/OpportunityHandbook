# 机会与成长指南

**一本写给普通人的路径判断手册。**

升学、工作、科研、竞赛、技能、开源、转行、方向探索——人这一生会站上好几个岔路口，而真正难的往往不是努力，是**判断**：这条路值不值得走？要付出多少、要付多久？多久能换回东西？如果走错了，能不能退回来？

## 它是什么

一份公开、免费、可以查很多年的中文参考手册。不是课程，不是励志书，也不是某个人的成长记录——它不假设你的专业、学历、年龄与职业，也不替你做决定。

它只做两件事：把一条路**能换回什么、要付出什么**写成你可以自己核对的形式；在信息会变的地方标出日期与官方入口，让你知道什么时候该重新查。

它想解决的，是这类内容最常见的三个毛病：

**只有结论，没有成本。**“强烈建议读研”“一定要去大厂”“早点考公”——听着都对，但没人告诉你代价是什么。这本书把成本拆开写：时间、金钱、机会、地理位置、失败风险。让你自己算，而不是被告知该感动。

**只有热情，没有出处。**规则到底怎么定的、哪一年改过、在哪个官网能查到。每篇文章都给出原始页面，并标明这个依据属于哪一类。

**只讲适合谁，不讲谁不该来。**大部分内容默认对所有人有效。需要筛选的地方，文章会写清“什么情况下这条路对你价值不高”——这是替读者省时间的地方，不是可有可无的礼貌。

## 一条内容长什么样

**每篇文章按照它真正要解决的问题自然组织，不强制使用同一套小标题。** 决策类文章会把「先看什么、什么情况偏向哪一边、成本分别是什么、判断错了能不能退回来」写清楚；行动类文章会让你看完就能动手；概念类条目则回答「它是什么、什么时候有用、怎么做、最容易错在哪」。

所有文章共享的不是结构，而是几条纪律：

- **事实有来源**：官方规则、政策文件、院校与机构页面直接给到原始出处，并标出依据类型（官方规则 / 研究 / 行业数据 / 实践经验 / 暂无可靠来源）。
- **判断有边界**：经验性判断会写明它的适用条件与反例，不把实践经验写成统计结论；「什么情况下这条对你价值不高」必须写出来。
- **容易变化的信息有最后核实日期**：升学、考试、招聘、签证、资助的规则每年都在变，超过一段时间未核实会在页面上提示“可能需要重新核实”。
- **不编数字**：比例、薪资、录取率、成功率这类数字，没有可靠来源就不写，需要时改成有边界的表述并指向官方查询入口。
- **正文只保留一份**：同一判断不在多处重复维护，其他位置用交叉引用指向它。

举三种形态（只是示意，不是模板）：

- *决策型*：先讲这个问题为什么会难判断，再分情况说明各自适用的条件，最后给出成本与回退方式；
- *行动型*：把步骤写到可以照着做，并给出自检标准（例如「关掉教程能不能复现」）；
- *概念型*：解释术语与真实含义，指出最容易与什么混淆，并给出官方查询入口。

## 它怎么处理“不确定”

- **事实与判断分开。**出处就在那里，判断也可以被反驳；作者的观点不会被写成事实。
- **不编数字。**比例、薪资、录取率这类数字，没有可靠来源就不写；写不清的地方直接写“不同情况差异很大”。
- **有争议的事不绝对化。**比如付费竞赛、考研二战、裸辞创业，都会写清“什么情况下价值不高、什么情况下仍然值得”。
- **会过期就标出来。**凡是容易变的条目都有核实日期，超过一段时间未核实的，页面会提示“可能需要重新核实”。

## 怎么用它

**卡在某个具体问题上**——从下面的问题入口进，或者直接搜关键词（保研、实习、转行、博士、比赛、证书……）。

**想按自己的处境找**——在线页面支持叠加筛选：人生阶段、方向、能换回什么、投入大小、证据类型。例如“专科 + 想拿学历 + 低投入”，或“工作 3–5 年 + 想转行 + 能接受降薪”。

**想系统读一遍**——从 [从这里开始](book/00-从这里开始.md) 顺着主线读：先决定往哪走，再打基础、积累经历、面对第一次分流、进入职场、处理职业分岔，最后是其他同样成立的路径。目录按「你会先遇到什么」排列，不按学科分类。

**想按阶段进入**——`docs/timelines/` 里的路径时间线（本科四年、保研、考研、留学申请、校招、转行）把每个阶段该看的东西串成一条线。

**想查一件事**——专题手册（科研、竞赛、国家与地区、行业与职业）与工具模板只做检索入口，判断仍然只有一份，都在正文里。

## 能在这里找到什么

**升学**：专升本、保研、考研、学硕与专硕、跨专业、复试、调剂、二战、博士、直博与申请考核制、工作后回炉。
**留学与海外教育**：项目类型、语言与标化考试、推荐信与文书、联系导师、成本与资助、签证、学历认证，以及国家与地区专题。
**工作**：实习、第一份工作、校招与社招、简历与面试、谈薪与 Offer 比较、三方协议、晋升与跳槽、转岗与转行。
**科研**：找导师、读文献、复现、提研究问题、实验设计、投稿与署名、学术伦理与垃圾科研识别。
**项目、竞赛与开源**：什么算真正的项目、作品集、Issue 与 PR、Maintainer，以及各类赛事和认证的实际价值。
**技能、证书与资助**：技能取舍、语言考试、职业资格与行业认证、奖学金与全额资助、开源资助。
**社群与影响力**：专业协会、导师关系、审稿与演讲、会议志愿者。
**创业、自由职业与副业**：先验证再入场、现金流、注册与融资、副业转主业。
**方向探索与避坑**：低成本实验、测评的边界、付费拿奖、假实习、水刊、保录取、高价求职辅导、机会焦虑。

## 它不做什么

- **不替你决定。**没有“你就该……”这种句子，只有条件和代价。
- **不推荐付费机会。**不收钱、不返佣，也没有需要扫码的入口；营销软文与培训机构文章不作为依据。
- **不追热点。**追着风口写的内容，两年后就过期了；这里写的是变化更慢的判断方法。
- **不替代专业意见。**法律、医疗、投资与具体岗位的最终决定，请找对应领域的专业人士与官方公告。

## 想找现在还能参加的真实机会？

这本书负责建立认知。如果你已经大概知道自己的方向，可以用 [OpportunityRadar](https://github.com/Sver0411/OpportunityRadar)，按你的背景、时间和目标搜索并核实**当前**的机会。

两个项目互相独立：这份手册不依赖任何外部项目，本身就是一套完整、可长期查阅的公共参考。

## 维护工具

| 命令 | 作用 |
| --- | --- |
| `python3 tools/build.py --strict` | 元数据、内部链接与构建校验（严格模式） |

| `python3 tools/check_markdown_quality.py` | Markdown 格式检查 |
| `python3 tools/check_content_quality.py --hard` | 内容质量硬门（旧模板 / 缺 summary / 过薄） |

| `python3 tools/metadata_audit.py` | 人生阶段（stages）与 docs front matter 审计 |
| `python3 tools/check_html_ids.py` | HTML id 唯一性与条目锚点前缀 |
| `python3 tools/audit_article_structure.py` | 文章结构审计（发现批量模板感） |
| `python3 tools/audit_timeline.py` | 时间线专项审计（经验节奏 vs 统一规则） |

| `python3 tools/smoke_test.py` | 浏览器冒烟测试 |
