# 机会与成长指南

**升学、工作、科研、竞赛、技能、开源、转行、方向探索。**

这里不谈“努力就会有回报”。它做的是把每条路**能换回什么、要付出什么、依据是什么**摊开写清楚——成本、收益、条件、反面适用人群，都摆在明面上，让你自己算这笔账。

大多数成长类内容的问题不在于不真诚，而在于不可核对：只有结论，没有成本；只有热情，没有出处；只讲适合谁，不讲**什么人其实不该来**。这份手册想补的就是这三处空白。

## 它凭什么和别的不一样

**一、每个条目都必须写“不太适合谁”**

这是硬性要求，不允许省略。只讲适合谁的内容，等于把筛选成本转嫁给读者；把“什么情况下这条路价值不高”写在开头，才是真的替你省时间。

**二、判断不会被伪装成事实**

每个条目的依据都标注证据类型，并如实给出分布——不是所有结论都同样硬：

| 证据类型 | 含义 | 当前条目数 |
| --- | --- | --- |
| Official | 政府、考试机构、院校、企业与项目的官方规则 | 77 |
| Research-backed | 论文与系统研究 | 6 |
| Industry-data | 权威统计与行业调查 | 13 |
| Experience-based | 有普遍性的实践判断，但缺严格统计 | 121 |
| Uncertain | 存在争议或来源不足 | 11 |

写清楚的地方写清楚；写不清的地方直接写“不同情况差异很大”“暂未找到可靠依据”。**不编数字**，也不把作者判断写成结论。

**三、会过期的事，标上日期**

升学、考试、招聘、签证、资助的规则每年都在变。这类条目全部带 `last_verified`，超过约 12 个月未核实，页面会提示“可能需要重新核实”，并进入每月自动检查的清单。已经改过多次的规则（如签证与工签政策）不写死时长与金额，只给官方入口，避免给你一个过期答案。

**四、来源指向原始页面**

265 处引用、109 个唯一链接，主要来自教育部、研招网、人社部、中国政府网、留学基金委、国家统计局、自然科学基金委、教育部教育考试院等官方站点。营销软文、培训机构文章与自媒体不作为依据。

**五、不接推广，不做“机会推荐”**

不收录未核实的数据、无来源的经验结论、以及带付费推广性质的推荐。这里没有返佣入口，也没有需要你扫码的东西。

## 这本书不假设你是谁

使用者可能是高中生、中专或职校学生、专科生、本科生、研究生、博士生、应届生、工作 1–3 年或 3–5 年的人、资深从业者、转岗转行者、自由职业者、创业者、重返职场的人，也可能是暂时说不清方向的人。

专业同样不默认是计算机：理工、医学、生命科学、商科、设计、艺术、教育、法律、人文、社科、农业、环境与技能型职业的判断标准并不相同，条目里给的是可核对的条件，不是某个圈子的经验。

## 内容是怎么写出来的

每个条目都是同一组字段：一句话、适合谁、不太适合谁、能换回什么、要付出什么、怎么开始、常见误区、下一步可能打开什么、证据与来源、最后核实。字段定义与写作标准是公开的，见 [条目格式](meta/条目格式.md)、[元数据规范](meta/元数据规范.md)、[证据与来源规范](meta/证据与来源规范.md)、[写作规范](meta/写作规范.md)。

这套标准不是写在文档里就算数：每次改动都会跑一次构建，检查元数据是否完整、id 是否重复、内部链接与锚点是否存在、`last_verified` 是否规范、正文与首页问题列表是否一致；不合规的内容在 CI 就会被拦下。正文以 Markdown 为唯一来源，阅读页、搜索索引与筛选词表全部由构建产出——所以你在线上看到的内容，与仓库里的原文逐字一致。
