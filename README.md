## 这本书不假设你是谁

使用者可能是高中生、中专或职校学生、专科生、本科生、研究生、博士生、应届生、工作 1–3 年或 3–5 年的人、资深从业者、转岗转行者、自由职业者、创业者、重返职场的人，也可能是暂时说不清方向的人。

专业也不默认是计算机。正文与专题需要同时照顾理工、医学、生命科学、商科、设计、艺术、教育、法律、人文、社科、农业、环境、技能型职业等方向。

## 每条长什么样

每个条目都是 `### 标题`，下面依次是：一句话、适合谁、不太适合谁、能换回什么、要付出什么、怎么开始、常见误区、下一步可能打开什么、证据与来源、最后核实。

- 「不太适合谁」是这本书与成长类内容最大的区别，不允许省略。
- 「证据与来源」给到原始页面，并标出证据类型：Official、Research-backed、Industry-data、Experience-based、Uncertain。
- 作者判断不会被写成事实。写不清的地方直接写「不同情况差异很大」或「暂未找到可靠依据」，也不编数字。
- 容易变化的条目都有 `last_verified`。超过 12 个月未核实，在线页面会显示「可能需要重新核实」，并进入 `tools/build_index.py --report-stale` 的清单。

字段定义见 [条目格式](meta/条目格式.md)，取值枚举见 [元数据规范](meta/元数据规范.md)，来源标准见 [证据与来源规范](meta/证据与来源规范.md)，写作与用词标准见 [写作规范](meta/写作规范.md)。

## 技术结构（简短版）

Markdown 是唯一正文来源，站点与索引都是构建产物。

```
book/ docs/ meta/     Markdown 正文（唯一事实来源）
tools/                零依赖 Python：校验、索引、静态页面、外链检查
site/                 纯静态阅读页（无框架、无后端、无数据库）
data → site/data/     构建产出的搜索索引与筛选词表
```

```bash
python3 tools/build.py          # 校验 + 生成索引 + 渲染页面
python3 -m http.server 8000 --directory site
# 打开 http://localhost:8000
```

其它命令：

```bash
python3 tools/build_index.py --report        # 每章条目完成 / 待写统计
python3 tools/build_index.py --report-stale   # 超过 12 个月未核实的条目
python3 tools/check_links.py                  # 外部链接可达性
```

构建工具会检查：front matter 与元数据是否完整、id 是否重复、取值是否合法、内部链接与锚点是否存在、`last_verified` 是否规范、README 与首页问题列表是否一致。

## 想找现在还能参加的真实机会？

这本书负责建立认知。如果你已经大概知道自己的方向，可以用 [OpportunityRadar](https://github.com/Sver0411/OpportunityRadar)，按你的背景、时间和目标搜索并核实**当前**的机会。

两个项目相互独立：OpportunityHandbook 不依赖 OpportunityRadar 也能单独使用，它本身是一套完整的公共知识库。
