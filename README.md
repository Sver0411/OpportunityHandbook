> **很多人以为自己缺的是答案。后来才发现，真正缺的是一张能看见代价、出口和回头路的地图。**

学校教你完成眼前的课程，招聘网站告诉你哪些公司正在招人，社交媒体不断给出新的“正确路线”。但很少有人认真解释：

- 读研、工作、科研、实习、竞赛和项目之间到底是什么关系；
- 哪些事情现在不做，以后仍然能补，哪些窗口错过后代价会突然变高；
- 哪些经历能留下作品、论文、推荐信、收入或公开贡献，哪些只是看起来很忙；
- 一条路失败以后还能不能回来，它会打开什么，又会关掉什么。

OpportunityHandbook 想补上的，就是这张地图。

它不替你决定人生，也不承诺一条“成功路线”。它把散落在不同学校、行业、国家、招聘体系和过来人经验里的路径放到一起，把收益、成本、门槛和证据写清楚，让你知道自己究竟在选择什么。

## 信息差之前，还有一层更隐蔽的差距

如果你从没听过暑研、RA、提前批、Graduate Program、Student Chapter、Travel Grant、开源导师计划或 Bridge Opportunity，就不可能主动搜索它们。

搜索引擎可以回答一个已经被提出的问题，却很难告诉你：**还有哪些问题，是你甚至不知道应该问的。**

因此，这份手册最重要的工作不是收集更多链接，而是扩展你的“机会词汇表”：

```text
看见一条原本不知道的路
        ↓
理解它需要什么、能换回什么、最坏会失去什么
        ↓
判断它是否值得进入你的选择范围
        ↓
用一次低成本行动获得真实反馈
        ↓
让下一次选择不再只靠想象
```

当一个人看见的路径更多、判断的依据更清楚，他得到的不只是信息，而是选择权。

## 这不是一本“大学生攻略”

它从学校里的第一次重要选择写起，但不会在毕业时结束。

| 你所处的阶段 | 这里会处理的问题 |
| --- | --- |
| **还在学校** | 专业与学校怎么选，实习、科研、竞赛、项目该先做什么，是否值得读研或出国 |
| **准备毕业** | 第一份工作怎么看，校招怎么准备，两个 Offer 如何比较，平台、工资和成长怎么取舍 |
| **刚进入职场** | 怎样积累可以被证明的成果，什么时候跳槽，怎样让工作经历真正变成职业资本 |
| **准备晋升** | 技术还是管理，怎样补领导力与影响力，什么经历能为下一层级提供证据 |
| **准备转行** | 哪些能力可以带走，哪些需要重建，怎样设计一条不把过去清零的过渡路线 |
| **准备跨国发展** | 学历、语言、签证、成本与地区差异如何进入同一套判断框架 |
| **想重新开始** | 工作后再读书、重返职场、自由职业、副业和创业，什么时候值得尝试 |
| **完全没有方向** | 怎样用低成本实验代替空想，让方向在真实行动中逐渐变清楚 |

人生不会因为毕业就停止分流。很多人在三十岁、四十岁以后，仍然会重新面对“继续走、换一条路，还是回到学校”的问题。

## 先学会拆开一个选择

面对一个看起来不错的机会，最容易问错的问题是：“它好不好？”

更有用的是依次问四个问题：

| 问题 | 你真正要查清的事 |
| --- | --- |
| **有没有硬门槛？** | 学历、身份、毕业时间、语言、资格和地区要求，哪些没有商量空间 |
| **我要付出什么？** | 时间、金钱、精力、迁移、收入损失、失败风险和真实的机会成本 |
| **最后能留下什么？** | 学历、资格、收入、作品、论文、推荐信、公开贡献、关系与声誉 |
| **它会关掉什么？** | 接受以后，哪些路会更容易，哪些路会暂时或永久变难 |

这四个问题能把“我感觉这个机会不错”，变成一场可以核实、可以比较、也可以向家人和合作者解释的讨论。

> **一个选择真正的价值，不只在于它眼前给你什么，还在于做完以后，你是否拥有更多下一步。**

## 什么值得长期积累

判断一件事值不值得长期投入，可以看它的产出能不能跟着你走：换公司、换行业、换城市以后，它还在不在。

- **可复用能力**：写作、数据、沟通、项目管理、外语和领域方法；
- **可验证成果**：作品、代码、项目、论文、证书和真实使用记录；
- **关系与声誉**：了解你做事方式、愿意为你背书的人；
- **对自己的认识**：知道自己愿意长期承受哪一种困难，也知道哪种生活并不适合自己。

同一件事如果能同时留下能力、成果和可信关系，通常比只有一个漂亮名称的经历更值得优先投入。

## OpportunityHandbook × OpportunityRadar

现实里有两类问题，看起来相似，实际上需要完全不同的工具。

| | [OpportunityHandbook](https://github.com/Sver0411/OpportunityHandbook) | [OpportunityRadar](https://github.com/Sver0411/OpportunityRadar) |
| --- | --- | --- |
| **它回答什么** | 我有哪些路？这条路意味着什么？代价和退路是什么？ | 现在有哪些真实机会？哪些仍开放？我符合条件吗？ |
| **信息特点** | 相对稳定，适合长期阅读和反复查阅 | 高度动态，需要搜索并核实当前状态 |
| **它帮你得到什么** | 判断框架、路径认知、机会词汇与长期选择权 | 经过核实的候选、资格判断、优先顺序与下一步行动 |
| **什么时候用** | 方向模糊、面对分岔、需要比较重大选择时 | 方向已经较清楚，准备寻找此刻可参与的机会时 |

最简单的理解是：

```text
Handbook 帮你看清应该寻找什么
                  ↓
Radar 帮你找到此刻真实存在的机会
                  ↓
行动留下作品、经历、关系和新认识
                  ↓
你带着更多选择权，再回到地图上
```

两个项目保持独立是有意的。稳定的知识不应该每天因为报名截止日期而改动；动态的机会搜索也不应该在每次回答里重新讲完整套人生路径。

### 一次完整的搭配方式

假设你突然想：“我是不是应该试试科研？”

1. 先在 Handbook 里弄清科研平时在做什么、它与项目和实习有什么区别、第一次尝试应该留下什么，以及怎样判断一个实验室；
2. 把模糊愿望变成一个更真实的目标，例如：“我想用每周 8 小时，低成本验证自己是否喜欢机器人方向的研究，并留下可展示的成果”；
3. 再把这个目标交给 Radar，让它寻找目前仍开放的实验室项目、暑研、研究实习或相关开源项目，并核实资格与时间；
4. 当手上出现多个候选，再用 Handbook 的机会价值判断表、导师筛选表或时间线做最后比较。

这比一开始就搜索“有什么科研推荐”更有效，因为你已经知道自己究竟要验证什么。

## 为什么没有直接让 AI 给答案

AI 很擅长生成一个完整、顺滑、听起来合理的回答。路径类问题真正困难的部分却是：

- 这是全国规则，还是某个学校、地区或公司的做法？
- 这是官方事实、研究结论、行业数据，还是个人经验？
- 这个规则现在还有效吗？
- 这句话对哪些人成立，又在哪些情况下不成立？

因此，本书为不同内容保留证据边界：

| 标记 | 含义 |
| --- | --- |
| **官方来源** | 政策、法规、学校、考试机构或组织的正式说明 |
| **研究支持** | 有研究证据，但仍需要注意适用范围 |
| **行业数据** | 有统计或行业材料，需要保留时间和口径 |
| **实践经验** | 可以参考，但不应被写成普遍结论 |
| **证据不足** | 暂无可靠来源，或现实中仍存在争议 |

容易变化的内容带有最后核实日期。超过合理时效后，在线页面会提醒读者重新确认。

## 这里不会做什么

- **不替你决定。** 这里提供条件、代价和判断方法，不会用“你就应该”结束讨论。
- **不制造虚假的精确。** 没有依据时，不编造录取率、成功率、未来薪资或回报倍数。
- **不推荐付费机会。** 项目没有返佣，也不会把培训机构的营销内容当作事实依据。
- **不追逐短期风口。** 重点是变化较慢的判断方法，而不是每隔几个月更换一次“最有前途的方向”。
- **不替代专业意见。** 法律、医疗、投资、签证和具体岗位的最终决定，应以专业人士和官方文件为准。

## 内容是怎样维护的

正文使用 Markdown 编写，在线阅读页由仓库内工具构建。新增或修改内容需要说明依据、适用范围和最后核实日期，并通过内容结构、链接、元数据与发布检查。

如果你发现规则已经变化、官方链接失效、经验被写得过于绝对，或某个重要路径还没有覆盖，欢迎提交 Issue 或 PR。开始前请阅读 [参与贡献说明](CONTRIBUTING.md)。
