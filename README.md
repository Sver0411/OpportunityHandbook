# 机会与成长指南

**一本写给普通人的路径判断手册。**

升学、工作、科研、竞赛、技能、开源、转行、方向探索——人这一生会站上好几个岔路口，而真正难的往往不是努力，是**判断**：这条路值不值得走？要付出多少、要付多久？多久能换回东西？如果走错了，能不能退回来？

## 它是什么

一份公开、免费、可以查很多年的中文参考手册。不是课程，不是励志书，也不是某个人的成长记录——它不假设你的专业、学历、年龄与职业，也不替你做决定。

它只做两件事：把一条路**能换回什么、要付出什么**写成你可以自己核对的形式；在信息会变的地方标出日期与官方入口，让你知道什么时候该重新查。

它想解决的，是这类内容最常见的三个毛病：

**只有结论，没有成本。**“强烈建议读研”“一定要去大厂”“早点考公”——听着都对，但没人告诉你代价是什么。这本书把成本拆开写：时间、金钱、机会、地理位置、失败风险。让你自己算，而不是被告知该感动。

**只有热情，没有出处。**规则到底怎么定的、哪一年改过、在哪个官网能查到。每个条目都给到原始页面，并且标明这个依据属于哪一类。

**只讲适合谁，不讲谁不该来。**大部分内容默认对所有人有效。这里的每个条目都必须写清“不太适合谁”——什么情况下这条路对你价值不高。

## 一条内容长什么样

每个条目都是同一套字段，没有例外：

> **一句话** · 适合谁 · **不太适合谁** · 能换回什么 · 要付出什么 · 怎么开始 · 常见误区 · 下一步可能打开什么 · **证据与来源** · **最后核实**

其中四栏决定了它和普通指南的区别：

- **不太适合谁**：不许省略。筛选成本写在开头，才谈得上替你省时间。
- **能换回什么**：用现实成果描述，不用情绪词。学历、资格、收入、作品、项目、论文、推荐信、人脉、选择权——这些才是可以比较的东西。
- **证据与来源**：给到原始页面，并标出依据类型。官方规则、学术研究、行业统计、实践判断、以及“目前说不清”的，读者的信任度应该不一样。
- **最后核实**：标日期。升学、考试、招聘、签证、资助的规则每年都在变，一个不标日期的答案，可能比没有答案更糟。

## 它怎么处理“不确定”

- **事实与判断分开。**出处就在那里，判断也可以被反驳；作者的观点不会被写成事实。
- **不编数字。**比例、薪资、录取率这类数字，没有可靠来源就不写；写不清的地方直接写“不同情况差异很大”。
- **有争议的事不绝对化。**比如付费竞赛、考研二战、裸辞创业，都会写清“什么情况下价值不高、什么情况下仍然值得”。
- **会过期就标出来。**凡是容易变的条目都有核实日期，超过一段时间未核实的，页面会提示“可能需要重新核实”。

## 怎么用它

**卡在某个具体问题上**——从下面的问题入口进，或者直接搜关键词（保研、实习、转行、博士、比赛、证书……）。

**想按自己的处境找**——在线页面支持叠加筛选：人生阶段、方向、能换回什么、投入大小、证据类型。例如“专科 + 想拿学历 + 低投入”，或“工作 3–5 年 + 想转行 + 能接受降薪”。

**想系统读一遍**——从 [从这里开始](book/00-从这里开始.md) 顺着章节读；每章的判断框架比单个条目更值得读。

## 能在这里找到什么

**升学**：专升本、保研、考研、学硕与专硕、跨专业、复试、调剂、二战、博士、直博与申请考核制、工作后回炉。
**留学与海外教育**：项目类型、语言与标化考试、推荐信与文书、联系导师、成本与资助、签证、学历认证，以及国家与地区专题。
**工作**：实习、第一份工作、校招与社招、简历与面试、谈薪与 Offer 比较、三方协议、晋升与跳槽、转岗与转行。
**科研**：找导师、读文献、复现、提研究问题、实验设计、投稿与署名、学术伦理与垃圾科研识别。
**项目、竞赛与开源**：什么算真正的项目、作品集、Issue 与 PR、Maintainer，以及各类赛事和认证的实际价值。
**技能、证书与资助**：技能取舍、语言考试、职业资格与行业认证、奖学金与全额资助、开源资助。
**社群与影响力**：专业协会、导师关系、审稿与演讲、会议志愿者。
**创业、自由职业与副业**：先验证再入场、现金流、注册与融资、副业转主业。
**方向探索与避坑**：低成本实验、测评的边界、付费拿奖、假实习、水刊、保录取、高价求职辅导、机会焦虑。

## 它不做什么

- **不替你决定。**没有“你就该……”这种句子，只有条件和代价。
- **不推荐付费机会。**不收钱、不返佣，也没有需要扫码的入口；营销软文与培训机构文章不作为依据。
- **不追热点。**追着风口写的内容，两年后就过期了；这里写的是变化更慢的判断方法。
- **不替代专业意见。**法律、医疗、投资与具体岗位的最终决定，请找对应领域的专业人士与官方公告。

## 想找现在还能参加的真实机会？

这本书负责建立认知。如果你已经大概知道自己的方向，可以用 [OpportunityRadar](https://github.com/Sver0411/OpportunityRadar)，按你的背景、时间和目标搜索并核实**当前**的机会。
