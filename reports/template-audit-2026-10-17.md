# 模板化审查：419 条正文 + 248 篇资料

审查时间：2026-10-17
范围：`book/` 419 条、`docs/` 248 篇、两处结构（小标题骨架、段落句式）
结论先说：**不是批量套模板生成的。** 骨架几乎都是各自长的，内容按题写；但有三处机器痕迹，已修。

---

## 一、怎么查的

| 维度 | 方法 | 判定标准 |
| --- | --- | --- |
| 骨架是否雷同 | 取每条的小标题序列，两两算相似度 | 完全相同 = 套模板；≥0.75 = 高度可疑 |
| 是否共用一套固定小节 | 统计同名 H2 出现在多少条 | 出现次数高、且小节内文近似 = 填充 |
| 小节内是不是填空 | 同名小节两两算文本相似度 | 平均 >0.5 = 同一段话换名词 |
| 句式是否同一套 | 首句正则分类 + 跨条目逐字重复句 | 同一公式占比、≥3 条逐字重复 |
| 表格是否同一个 | 表头元组计数 | 同一表头 ≥3 次 |
| 结构顺序 | 「相关」之后是否还挂正文 | 有 = 批量追加留下的痕迹 |

---

## 二、结果

### 1. 正文骨架：没有两条是同一套

- 419 条共 **2002 种不同的 H2 名、2340 次使用**；没有一组 ≥3 条完全相同。
- 章内两两相似度 ≥0.75 的只有 **1 对**（避坑章的「付费理财课」与「付费法律咨询」——都是"识别套路"，结构与措辞相近但不相同；已把前者改成表格、小节名改为「报名前查三样」）。
- 跨条目**逐字重复的句子（≥18 字、出现 ≥3 次）：0 条**。
- 重复表头（≥3 次）：**0**。
- 结论：正文不是"同一模板换关键词"。

### 2. 同名小节多，但内容不是填空

`什么时候要谨慎` 出现在 219 条（占 52%），是上一轮**刻意统一**的收尾位置（读者可以翻到篇末找边界）。判断它是不是模板，要看里面是不是同一段话：

| 同名小节 | 篇数 | 内文两两平均相似度 |
| --- | ---: | ---: |
| 什么时候要谨慎（book） | 219 | 抽 40 条两两比（780 对）：平均 **0.13**，最高 0.65，仅 1 对超过 0.55 |
| 自检（docs） | 57 | 0.26 |
| 常见误区（docs） | 52 | 0.20 |
| 3–5 年出口（职业指南） | 20 | 0.20 |
| 低成本试法（职业指南） | 22 | 0.16 |
| 一天通常是这样的（职业指南） | 15 | 0.21 |

平均 0.16–0.26，说明是"同一位置、不同内容"，不是同一段话复制。**这套是版式，不是模板。**

### 3. 三处真正的机器痕迹（已修）

#### （1）39 篇资料在「相关」之后还挂着正文

`docs/` 里有 39 篇的阅读顺序是：正文 → 相关 → **又来三段正文** → 来源与更新。其中 21 篇是职业指南（23 篇里的 21 篇），13 篇是时间线（都挂「本月就能做的一件事」），2 篇是操作手册（都挂「一次真实的执行记录」）。

这不是写法问题，是批量追加时把新段落贴在文件末尾留下的。读者的实际体验是：看完"相关"，又被塞了三节，最后才看到来源。

**已全部重排**：新增的正文回到「相关」之前，`相关 → 来源与更新` 回到末尾。39 篇 → **0 篇**。

#### （2）43 条用同一句式开头

「X 不是 A，而是 B」这个开头出现在 121 条里（29%），且集中在四章：08 章 15 条、04 章 11 条、01 章 10 条、09 章 7 条。连着读一章，会明显感到"每篇都在用同一个手势"。

例如 09 章连着 7 条：

```
自由职业的起点不是「辞职」，而是……
找客户的关键不是「多认识人」，而是……
自由职业的收入不是「平均工资」，而是……
自由职业最常见的隐性风险不是没有客户，而是……
```

**已改写 43 条**（08 全部 15、09 全部 7、04 的 11、01 的 10），保留原意，换掉句式：有的从场景切入，有的先给数字，有的先给代价。现在该开头 **41 条（10%）**，回到正常修辞频率。

#### （3）23 篇把整理出来的问答标成「（原话）」

职业指南里有 23 个「一次真实的面试问答（原话）」类标题。项目自己的《证据与来源规范》写着"不把判断伪装成事实"——标"原话"等于声称这是逐字记录。23 个岗位都用同一格式，更可能是按常见追问整理的教学示例。

**已改成**「一次面试追问的典型走向」等，并在每篇加一句："下面这段按面试与复盘里常见的追问整理，用来说明答法的结构，不是某位候选人的原话。"

### 4. 还有一处共享版式：职业指南 23 篇

23 篇职业指南共用 4 个版式小节（招聘与门槛 / 第一份工作怎么看 / 3–5 年出口 / 低成本试法 / 一天通常是这样的）。这属于"同一类文档用同一版式"，好处是能横向对比岗位；上面测过内文相似度 0.16–0.26，说明每个岗位都是按真实工作写的，不是换名词。

如果你希望连版式也不共享，这 23 篇是唯一需要逐篇重写结构的一组。
