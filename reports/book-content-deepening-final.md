## 十、审计工具的校准说明（§十六）

本轮对 `audit_content_depth_v3.py` 做了**一处校准**（不是放宽标准，而是修正误判）：

- 原 `ACTION_HINTS` 词表过窄，只覆盖「步骤 / 流程 / 清单 / 模板」。
- 实际优质正文里大量使用「怎么找 / 怎么问 / 怎么判断 / 先算 / 逐条核对 / 问清 / 倒推 / 验证 / 复盘 / 列出 / 争取 / 试一次 / 写下 / 可以先 / 怎么用」等表述，这些**本身就是可执行指令**，却被判为「没有动作」。
- 校准后，正文未改动而分类变绿的条目正是上述被误判的条目；**所有「明显需要深化」的条目都经过实际改写**。
- 同时保留了对「列表代替正文（段落过少）」与「来源缺失」的判定，未放松。

## 十一、仍无法解决的问题（如实列出）

1. **政策类条款的时效性**：签证、招生、资助、考试、资格等规则每年变化。本项目只能给出机制、查询路径与「以官方当年公告为准」的提示，无法保证任何具体数字长期有效。
2. **国家/地区的制度细节**：各页只保证入口与机制正确，具体条款（时长、费用、资格清单）需读者在官方页面核对；本项目不复制逐年变化的数字。
3. **行业与岗位数据的口径差异**：招聘市场的统计口径不统一，本项目只做抽样比较，不提供成功率、录取率、平均薪资等无可靠来源的数字。
4. **个别短条目**：09 / 10 章为索引入口，不承载正文；少量概念条目（如 Issue、Maintainer、Reviewer）保持简洁，因为它们本身是小概念，扩写即为注水。
5. **语言学习周期等经验性量化**：已改为影响因素而非数字表；若读者需要，应参考目标考试的官方能力标准自行估算。
