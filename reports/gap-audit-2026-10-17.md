# 缺口审查：站在真实读者的位置，这本手册还缺什么

审查时间：2026-10-17
范围：`book/` 419 条、`docs/` 248 篇、站点交互
方式：按人生阶段走一遍真实提问 → 关键词核验 → 元数据覆盖统计
本轮**只审查，不改内容**。

---

## 一句话结论

它不是"文章不够多"，而是**少了几类人**。现在的 419 条主要写给：在校本科生、应届生、工作 1–5 年、身体健康、未婚、家里能兜底、走学历路线的人。

四类人几乎没有入口：**准备结婚生育的人、遭遇歧视与骚扰的人、高考分数刚过线的人、身体或家庭有状况的人。**

---

## 二、P0：四个成体系的缺口

### 1. 婚育与职业（只在社保表里出现过，没有一条讲它怎么影响选择）

| 词 | 命中 |
| --- | ---: |
| 产假、婚假、孕期、哺乳 | 0 |
| 婚育、育儿、单亲、异地夫妻、彩礼 | 0 |
| 生育 | 10 处，但都在两处：16 章"五险"表格里的生育保险、00 章"生育安排属于不可逆决策"的一句话 |

也就是说：书里知道"生育要连续缴社保""生育是不可逆决定"，但**没有一篇回答"要不要现在要孩子、要了之后工作怎么办"**。

**为什么是 P0**：26–35 岁的人换工作、读研、转行，第一约束常常不是能力而是"什么时候要孩子、产假怎么算、异地怎么安排"。手册把"跳槽/转行/读研"当成纯职业决策来写，对这个年龄段是失真的。

**具体缺的问题**：

- 面试被问婚育计划，怎么回答、哪些问法已经越界；
- 产假、陪产假、生育津贴的算法与申领（各地不同，需要给官方入口）；
- 怀孕或哺乳期被调岗、降薪、辞退时，哪些是违法的；
- 双职工异地、谁迁就谁，怎么算这笔账；
- 育儿前三年对职业节奏的影响，以及"晚两年再要"的真实代价。

**放哪**：16 章（钱与生活）加一组"婚育与家庭财务"，或 08 章"照护与职业节奏"扩成一组。现有 `care-family-role`、`care-elder-medical` 只覆盖了照护老人。

---

### 2. 歧视与职场霸凌（0 命中）

| 词 | 命中 |
| --- | ---: |
| 歧视（学历/性别/年龄/婚育） | 0 |
| 霸凌、PUA | 0 |
| 35 岁 | 0（只有「40 岁以后」一篇） |

**为什么是 P0**：这是读者最常遇到、又最不知道该怎么处理的事。手册教了"怎么比较机会""怎么谈薪"，却没教"对方明确不要你这类人时怎么办"。

**具体缺的问题**：

- 招聘写明"限男性/限 35 岁以下/限全日制"，哪些能投诉、向谁投诉；
- 入职后发现同岗不同酬、晋升被跳过，怎么取证、怎么谈；
- 被上级长期贬低、甩锅、孤立（PUA/霸凌），什么信号说明该走，走之前要留什么证据；
- 学历歧视（专升本、双非、非全日制）在简历与面试里怎么处理——**书里只有"第一学历"这个概念，没有应对**。

**放哪**：15 章避坑加两条（招聘歧视、职场霸凌），07 章"和同事或上级起了冲突"扩一节。

### 3. 高考的多元升学路径（几乎全部缺失）

| 通道 | 命中 |
| --- | ---: |
| 强基计划 | 0 |
| 高校专项 / 国家专项 / 地方专项 | 0 |
| 艺考 / 体育单招 | 0 |
| 公费师范 / 免费医学定向 | 0 |
| 军校 / 警校 | 0 |
| 综合评价 | 1（一笔带过） |

**为什么是 P0**：手册自称"让你看清世界上到底有哪些路"，但从"填志愿"开始，只写了"学校 vs 专业 vs 城市"。而**降分录取、免学费、包分配、毕业有编**这些最像"机会"的通道，一条都没写。农村与县城读者受影响最大——专项计划正是给他们的。

**证据补充**：`highschool` 阶段只有 35 条（占 8%），`secondary_vocational` 24 条（6%）。

**放哪**：01 章"选学校与选专业"前后加一组"高考的六条通道"，每条给门槛、时间、代价、官方入口。

### 4. 志愿填报的操作层（只有判断，没有操作）

| 词 | 命中 |
| --- | ---: |
| 一分一段 | 0 |
| 专业级差 | 0 |
| 赋分（新高考） | 0 |
| 体检受限（专业受限） | 0 |
| 退档 | 1 |
| 平行志愿 | 4（提及，未展开） |

**为什么是 P0**：一个 18 岁读者拿到分数后最需要的不是"学校重要还是专业重要"，而是"我的位次能报哪些、怎么排冲稳保、什么情况会被退档"。手册停在了判断题，没进操作题。

**放哪**：`docs/playbooks/` 加一篇「第一次填志愿」，或 01 章加一条"按位次定位"。

## 三、P1：特定人群的关键缺口

### 5. 入学第一周与在校事务（0–5 命中）

| 词 | 命中 |
| --- | ---: |
| 迁户口 / 户口迁移 | 0 |
| 绿色通道（困难新生先入学后缴费） | 0 |
| 入学准备、军训、室友 | 0 / 0 / 0 |

**真实场景**：录取通知书到了，家里在问"户口迁不迁、学费凑不齐怎么办、被子要不要自己带"。`docs/timelines/本科四年` 写的是学业节奏，不覆盖这些行政事务。

### 6. 学生金融安全：只防了"培训贷"，没防"校园贷"

| 词 | 命中 |
| --- | ---: |
| 校园贷、套路贷、传销 | 0 |
| 培训贷 | 2（02 章与 15 章各一处） |

15 章覆盖了"收费实习、付费科研、付费内推、付费理财课"，02 章提了培训贷；但学生最常踩的三类——**校园贷/裸贷、兼职刷单诈骗、被同学或亲戚拉进传销**——一条都没有。

### 7. 心理危机：判断线有了，具体操作还差一层

17 章已经写了：

- "有自伤或伤害他人的想法与计划 → 立即联系 120/110 或就近急诊"；
- "心理援助热线：各地精神卫生中心与政府热线（以当地公布为准）"；
- "保密例外：涉及自伤或伤人风险时会被突破"。

**缺的是三样**：

1. **具体号码**：正文只写"各地热线"，没有给全国统一的 12356（心理健康热线）；读者在最需要的那一刻，不应该还要去搜；
2. **身边人怎么陪**：朋友状态很差时说什么、不说什么、要不要替他联系家人；
3. **求助之后的安排**：请假、复诊、药物副作用、告诉不告诉单位/学校。

这一条不算"空白"，算"关键处差最后一层"。

### 8. 身体的具体问题（0–2 命中）

近视、口腔、营养、饮食相关：0–2。健康章集中在睡眠、久坐、运动、就医，但**近视手术、牙齿正畸、体检异常项复查**这些"花钱又常见"的决定没有。

### 9. 基层与非典型就业出口（0–1 命中）

| 出口 | 命中 |
| --- | ---: |
| 军队文职 | 0 |
| 辅警、网格员 | 0 |
| 社区工作者 | 1（提及） |
| 国际组织、NGO | 0 |
| 打工度假、数字游民 | 0 |

手册的"出路"集中在：读书、考公考编、企业、自由职业、创业。中间一层——**军队文职、社区工作者、辅警、国际组织实习、打工度假**——完全空着。

### 10. 职业指南偏科

23 篇岗位指南里，技术类 13 篇（软件/前端/后端/数据/算法/运维/测试/嵌入式/硬件/研究工程师/FDE/解决方案/技术支持），其余 10 篇。

**没有**：医生、护士、律师、HR、销售、运营、审计、建筑、军警。`docs/careers/` 有行业概览（医疗健康、法律与公共事务），但读者要的是"这份工作每天什么样、怎么进去、3–5 年往哪走"这一层。

对读护理、临床、法学、师范的读者（每年毕业生数量很大），手册目前只到"行业"层，不到"岗位"层。

## 四、P2：使用方式上的缺口

| 缺口 | 现状 | 影响 |
| --- | --- | --- |
| 收藏 / 阅读进度 | 站点只有搜索与筛选，无收藏、无进度 | 读者找到一篇好文，下次还得再搜 |
| 打印 / 分享 | 无打印样式、无分享按钮 | 志愿填报、和父母讨论时，最需要一页纸 |
| 家长入口 | `家长` 仅 7 处提及，无入口页 | 志愿与升学的实际决策者常是家长，但书只对"你"说话 |
| 勘误与更新记录 | 只有「最后核实」日期 | 读者无法知道某条数字改过没有 |
| 可核对的学校材料 | 「就业质量报告」0 命中 | 判断学校/专业就业最靠谱的公开材料，书里没教怎么用 |
| 双一流 / 学科评估 | 0 / 1 命中 | 选校时的通用语言，缺解释 |

## 五、不建议加的（避免误伤定位）

- **投资建议、理财产品**：手册已经声明不做，保持；
- **医疗诊断与用药**：健康章已明确边界，保持；
- **代填志愿、包录取**：这是 15 章要防的东西，不能自己变成它；
- **成功学与个人故事集**：15 篇案例已是上限，再多会稀释判断框架。

## 六、如果只补三件事

1. **婚育与职业**（P0-1）：补一组 5–6 条，覆盖面试、产假、歧视、异地、育儿节奏；
2. **高考六条通道 + 志愿操作**（P0-3、P0-4）：补 1 组判断 + 1 篇操作手册，`highschool` 条目从 35 提到 55 左右；
3. **歧视、骚扰与心理危机的最后一层**（P0-2、P1-7）：补 3 条——招聘歧视怎么应对、职场霸凌怎么取证、危机的具体号码与「身边人怎么陪」。

三组补完，手册对"18 岁到 35 岁、身体和家庭状况各异"的读者才算完整；剩下的入学事务、基层出口、职业指南偏科可以按季度慢慢补。

## 七、这轮没覆盖的

- 没有逐条读 248 篇 `docs/` 的正文（只按关键词与结构抽检）；
- 没有访谈真实读者（判断基于"一个人会问什么"的推演与语料核验）；
- 没有评估政策类内容在 2027 年的失效风险（只看了 `last_verified` 是否在 180 天内）。
