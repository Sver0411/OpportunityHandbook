# 第二批考试操作层补全收尾报告（专升本 / 留学标化 / 保研 / 专科生动线，15 轮）

范围：`reports/exam-expansion-plan2-2026-10-15.md` 计划的第 1–15 轮。
起因：`reports/exam-gap-audit-2026-10-15.md` 审计出的三个真缺口 + 一个结构性问题。

## 为什么做这一批

第一批（考公/考研/四六级，15 轮）补完后，审计发现剩下的缺口不是「再补几个考试」，而是：

- **专升本**：判断层有、操作层缺，且**错过通常没有第二次**；
- **雅思/托福**：判断层有、操作层缺，空白全在最卡人的地方（考位、小分、复议）；
- **保研**：判断层反而是齐的，操作层只有几行；
- **专科生上升通道**：五条通道散落在 01、04 两章，读者要自己拼。

这一批按审计给的优先级做，**并且不补审计明确排除的内容**。

## 这一批踩到的坑

1. **在 IA 里插入分组时缩进错了**：`事业单位与基层项目` 被降级成了上一分册「面试与后续环节」的子条目，`test_nav_group_target_matches_entry_files` 立刻报错。**在 IA 里插入新分组要从上一个同层分组的完整块之后插，并确认缩进是两格。**
2. **重构文件时丢了 front matter**：把章节首段改成条目时用 Python 重写整个文件头，漏掉 `---` 块，报「缺少 front matter / 缺少必填字段」。**重构前先读原文件的 front matter。**
3. **`test_ia.py` 的基线是全局共享的**：`python3 - <<PY` 里做 `t.replace("A\nB","C\nD")` 如果 old_string 不匹配会**静默不改**，测试在几轮之后才报 `test_counts_match_baseline` 失败。**改完基线要立刻 grep 确认写进去了。**
4. **施工语言门禁误伤正常句子**：「学历以后再补」命中 `LEAK_WORDS` 里的「以后再补」。**写「以后」「后续」相关句子时避开这几个词**（表里有：计划中 / TODO / 待补 / 待写 / 施工 / roadmap / 尚未撰写 / 后续补充 / 以后再补 / 待补充 / 暂未覆盖 / 尚未覆盖）。
5. 写长文本时中文被替换成乱码字这一轮出现三次（`在校���`），每次都要 `grep -rn '�'` 才能发现。

## 判断与边界

- **保研不写通用流程**：推免的名额、加分项、排除条款逐校甚至逐院系不同，写成流程会误导。只写「先读本校文件」这个动作，加上材料与时点这些与校无关的部分。
- **专升本不写各省规则**：只写「先查目录再定目标」这个顺序，以及各省共通的卡点。省份细节一律指向本省文件。
- **留学语言考试不承诺分数**：不写「多少分能进哪所学校」这种会过期的对照，只写查证方法。
- 剩余可做但本轮没做的：专升本各省细则的横向对照（各省每年变，写了很快过期）、雅思与托福的分数换算表（官方口径与申请口径不一致，容易误导）、专科生各专业的升学路径细分（依赖具体专业）。
