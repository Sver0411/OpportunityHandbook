# 桌面 Web 目录重组

## 基线与范围

以 `/Users/mac/WorkBuddy/OpportunityHandbook` 的 `dcaf9ea` 为基线，修改前本地 main 与 GitHub main 一致，工作区干净。
保留既有正文文件、条目 ID、旧地址重定向、灰白配色、毛玻璃侧栏与字体；只调整桌面 Web。

## 最终结构

唯一目录采用十个内容分组：选择与方向、升学与继续教育、学习与技能、科研与学术、项目竞赛与开源、
实习与求职、考公考编与公共服务、职场成长与职业转换、自由职业副业与创业、生活与保障。
另设国家地区、行业岗位、资料工具三个查阅入口。已取消「按主题查」切换与独立主题首页。

十三个一级栏目都有专门撰写的章节导读文章，说明本章问题、范围、使用方法和后续行动，文末附内容入口。
导读保存在 `reader/overviews/`，沿用原有正文排版与右侧目录；三级及更深层标题改为正常正文色。
一级栏目保留显式概览入口；二级标题直接进入已有分册或专题中的概览与正文，
二级没有额外的概览跳转行。箭头只负责展开收起。阅读滚动不改变目录结构和侧栏位置。

## 内容关联

632 个既有来源目标均保留一处主要归属。联系导师、考研、求职等任务关联的步骤、时间线、模板、案例，
在现有正文后提供配套资料。国家的制度说明和申请操作汇合为一个国家入口；行业与具体岗位分开查阅。
跨阶段内容按任务归位，例如工作后读研进入继续教育，职业中断返回进入职业转换。

具体条目的深链只显示该条正文，并提供所在分册全文入口；整组标题仍打开整组原有内容。
浏览器异步加载结果会核对当前地址，避免快速切换后被旧请求覆盖。

阅读索引去除全文文本，完整搜索索引在首次搜索时加载。原始来源目录仍供覆盖检查使用，避免目录迁移丢文。
新增内容未明确归类时构建失败，不会默默落入其他栏目。

## 验证

内容与导航测试检查覆盖完整性、主要归属唯一性、二级概览可达、跨阶段归属、国家资料合并与未知来源阻断。
桌面浏览器检查覆盖 1440×1000、1024×900：一级概览、二级直接跳正文、概览链接层级、配套资料、阅读稳定性、
旧深链、全文搜索、条件叠加与横向溢出。现有发布门禁继续检查正文、HTML ID、来源、路线图与排版层级。

真实读者树测试尚未进行；此处是已实现的设计方案，不把自动化检查表述为真实用户研究。
