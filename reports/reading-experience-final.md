# Reading Experience & Content Completion Round

生成时间：2026-09-22

本轮定位：**Reading Experience & Content Completion**。不新增功能、不改信息架构，
只处理四件事：右栏目录跟随滚动、来源与更新默认折叠、一级目录显示名、剩余过短正文。
Canonical IA、`meta/navigation.json` 的节点结构、`nav_id`、`entry_id`、旧 URL 全部保持不变。

## 一、TOC：右栏跟随滚动切换主题

### 问题

此前 `buildToc(entryId)` 只在路由进入时构建一次：滚到下一个条目后，右栏仍显示上一个条目的结构。

### 实现（双层跟踪）

| 层 | 做法 |
| --- | --- |
| 当前条目 | `watchEntries(location)`：读取**实时几何位置**（`getBoundingClientRect()`），以「视口顶部 + 120px 阅读线」为准，取最后一个「顶部已在阅读线上方」的 `section.entry` 为当前条目 |
| 条目内小节 | 复用既有 `IntersectionObserver`；条目切换时重建目录并重新绑定观察目标 |

切换时机与稳定性：

- 用**阅读线**而不是 `isIntersecting`（多个 entry 可能同时相交），避免交界处 A/B 抖动；
- 时间戳节流 80ms（不用 `requestAnimationFrame`：无头 Chrome 的虚拟时间会饿死 rAF）；
- 高度变化（例如展开来源折叠块）不影响判定——每次都用实时几何位置，不缓存 offset。

### URL 与 history

滚动只同步**视觉状态**（右栏目录 + 左栏高亮），**不修改 `location.hash`，也不 pushState**。
用户点浏览器「后退」不会逐个条目回退。测试断言：滚动前后 `history.length` 与 `location.hash` 均不变。

### 右栏标题

| 场景 | 显示 |
| --- | --- |
| 正在阅读某个条目 | 该条目的标题（如「国内还是海外」） |
| 章节根页（未进入具体条目） | 「本章目录」 |

### 测试结果（无头 Chrome）

| 用例 | 结果 |
| --- | --- |
| 03 第一个个人项目 → 目录项数 = 该条目 H2 数（4 vs 4） | PASS |
| 04 保研（6 vs 6）/ 05 Offer 比较（7 vs 7）/ 06 Mentor（3 vs 3）/ 07 技术还是管理（6 vs 6）/ 08 自由职业（3 vs 3） | PASS |
| 目录只含本条目标题、锚点全文档唯一、点击跳到正确位置 | PASS |
| 04 从「升学还是工作」滚到「国内还是海外」：右栏主题切换、目录属于新条目、左栏高亮跟随 | PASS |
| 滚动不产生 history 记录、不改变 URL hash | PASS |

## 二、来源与更新：默认折叠

- **构建期转换**：`build_site.wrap_sources()` 把渲染后的「来源与更新」小节包成
  `<details class="sources-details"><summary>来源与更新</summary><div class="sources-body">…</div></details>`。
  **Markdown 仍是唯一正文源**，没有改动任何 `.md` 文件；
- **条目前缀 id 保留**：`<details id="{entry_id}--来源与更新">`，旧锚点仍然可用；
- **不进入右栏目录**：折叠块里的标题已不是 `h2`，同时在 `buildToc` 里加了 `.sources-details` 过滤；
- **核实日期仍然可见**：条目 badge 与文档头部继续显示「最后核实：YYYY-MM-DD」与证据类型，无需展开；
- **样式克制**：13px、muted 颜色、上方一条细分隔线、箭头 `▸/▾` 旋转；移动端一致（原生 `<details>`）。

| 检查项 | 结果 |
| --- | --- |
| 全站「来源与更新」小节数 | 290+（覆盖主线条目与所有 `docs/` 页面） |
| 默认折叠 | 是（无 `open` 属性） |
| 进入右栏 TOC | 0 |
| 可展开 / 可再次折叠 | 是（冒烟用例：展开后正文可见、再次点击收起） |
| 移动端 | 同样默认折叠（原生 details） |

## 三、一级目录显示名（nav_label）

`meta.build_nav_from_ia()` 用 `nav_label` 作为左栏显示名（`label`），并保留 `title` 供其他用途。
正文 H1 仍取自 Markdown 的章节标题，URL 与锚点不变。
