## 这张矩阵怎么读

这一版不再把「有文件」等同于「内容已经够深」。矩阵只回答**知识链有没有入口**；正文质量另由人工阅读与 `tools/audit_depth_quality.py` 辅助审查。

本轮重点修复了上一版矩阵掩盖的问题：

- 奖学金与资助原来只有 Book/Manual，现在补了 Funding Package Deep Dive 与申请 Playbook；
- 技能学习、社群人脉、证书资格原来缺少执行入口，现在各有可直接照着做的 Playbook；
- Career Guide 从 22 增至 23，补上 Forward Deployed Engineer（FDE）；
- 22 个原有 Career Guide 不再只是同模板职业卡片，已逐篇补岗位特有的真实工作链与能力证据；
- 11 个 Country Playbook 均增加本地制度差异、申请机制、就业/资金/退路等纵深内容。

说明：Book 列为 complete 条目按 topics 归类；Case / Playbook / Tool 仍按 metadata topics 统计，因此同一文档可能服务多个知识域。矩阵适合看覆盖，不适合拿来给文章质量打分。
