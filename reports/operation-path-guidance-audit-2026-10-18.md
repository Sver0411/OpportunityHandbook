# 操作级引导审查：要去哪个网站、点哪一栏

审查时间：2026-10-18
口径：**操作引导**——读者在某个真实网站上「从哪进、点哪一栏、看到什么算成功」。
不含阅读动线（那部分见 `visual-and-offline-gap-audit-2026-10-18.md`，其中第四节把「引导」理解成了阅读入口，已在该文件顶部加注更正）。
性质：只审查，未改动任何正文与站点文件。

---

## 一、结论

**你的判断是对的，而且比「缺图」更严重一层：现在连放图的地方都没有。**

1. **几乎不写位置。** 431 条里 168 条带官方链接，只有 **1 条**写出了点击层级（05 章「考研怎么定目标校」：`学科门类 → 一级学科 → 专业（代码）→ 招生单位`）。另有 5 条出现过「系统里 / 栏目 / 点「」这类词，多数是顺带一提，不构成路径。
2. **最该写位置的一类文档，反而一条都没写。** 26 篇 `docs/playbooks/`（填志愿、考研报名、四六级、社保、档案……）里 12 篇给了链接，**0 篇**出现任何位置描述。
3. **入口速查页是三列。** `docs/sources/官方入口速查.md`（112 行）的列是「你要办的事 / 去哪办查 / 官方入口」，第三列就是一个域名。它回答「去哪个网站」，不回答「在网站的哪里」。
4. **书上自己写过读者会卡在这里。** 05 章「考研报名与初试」的原话是：「下载准考证 —— 临考找不到入口」，但它给出的全部信息是 `https://yz.chsi.com.cn/`。它知道卡点在哪，只是没写位置。
5. **渲染器不支持图片。** `tools/mdrender.py` 的 `_inline()` 只处理链接、粗体、斜体、行内代码。实测 `![学信网学籍报告入口](assets/chsi-report.png)` 输出为 `!<a href="assets/chsi-report.png">…</a>`——一个感叹号加一个链接。1074 个 HTML 里 `<img>` 数量为 **0**。

---

## 二、读者真正卡住的那一格

链接不承载、而读者必须知道的信息，至少四类。这正是图或路径卡能补、纯域名补不了的部分：

| 类型 | 例子 | 为什么链接不够 |
| --- | --- | --- |
| 入口是否常驻 | 研招网的调剂服务系统只在开放期出现 | 平时打开首页看不到，读者会以为「今年没有」或走错到别的系统 |
| 登录前后的差别 | 学信网查学籍 / 申请在线验证报告 | 不登录只能看介绍页；报告入口在登录后的某个板块里 |
| 同名入口分叉 | 个税 App 里「专项附加扣除填报」与「年度汇算」是两条不同的路 | 走错一条会以为「今年不用报」 |
| 省级系统各长一样 | 各省考试院的志愿填报入口 | 全国统一写不了，只能省级逐个说，而这恰恰最需要图 |

第 4 类是矛盾点：**它最需要图，也最难维护**——31 个省级系统，界面各不相同，每年还可能改版。

---

## 三、为什么会写成现在这样（不是懒）

项目已有的约定是「只放可达的官方入口，硬信息以官方页面为准，正文不复述会过期的数字」。
这个约定在防「写死一个会变的数字」上是对的，但它有一个副作用：

> **位置描述和分数、时间一样会过期，于是被一并省掉了。**

省掉之后，读者拿到的是一串**永远不会过期、但也永远不够用**的域名。链接稳定、位置易变，安全的选择就变成了不写位置——这不是判断失误，是规则没有为「不稳定的必要信息」留位置。

所以真正的修法不是「多放几张截图」，而是给这类信息一个**能标注时效的容器**。

## 四、如果要补，什么形式能活下来

三层，成本和寿命完全不同：

### 第 1 层：路径条（文字，必做，几乎不过期）

用网站上的**原文按钮名**，从首页写到目标页，末尾加一句「看不到这个入口时怎么办」。

模板（这是一个可直接抄的格式，不是排版建议）：

```
【路径】研招网 → 硕士专业目录
首页顶部「硕士目录」→ 按专业查询 → 输入六位专业代码 → 选择学习方式
不登录也能查；查不到时换成「按招生单位查询」，同一代码下院校名单一致。
核实：2026-10 · yz.chsi.com.cn/zsml/
```

为什么这条最该先做：可检索、可被屏幕阅读器读、能被 diff（改版时一行就能改）、不增加站点体积、不需要图片管线。

### 第 2 层：标注图（少而精，只给「不看图认不出来」的位置）

适用判断标准只有一条：**如果按钮名本身足够独特（如「下载准考证」），不需要图；如果页面里有五个长得很像的入口，才需要图。**

规范建议：
- 只截目标区域，不搬整页（避免版权与「整页搬运」的观感）；
- 编号 ①②③ 对应路径条里的步骤，图内不写解释文字（解释放正文，方便翻译与改版）；
- 图上或图注里带**核实日期**，和条目的 `last_verified` 分开记——图比文字更容易过期；
- `alt` 写完整路径，保证看不到图的人拿到的信息不打折；
- 点击可放大（手机上是主要阅读场景）。

### 第 3 层：动图 / 录屏（不建议）

一次改版就全部作废，且无法检索、无法复制、体积大。收益比不过第 1 层。

## 五、现在做不了，是因为缺三样基础设施

这是「为什么全书 0 张图」的技术答案，不是审美选择：

| 缺什么 | 现状 | 补起来要动哪里 |
| --- | --- | --- |
| Markdown 图片语法 | `mdrender._inline()` 无 `![]()` 分支，输出 `!` + 链接 | 加 image 分支 + `figure/figcaption` |
| 资源管线 | `site/` 下没有 assets 目录，构建不复制静态文件 | 源图 → 压缩/webp → 输出，并在 `build_site.py` 里接上 |
| 图片失效检查 | `check_links.py` 只查超链接 | 加一条：引用的图片文件不存在就报错（否则会静默出裂图） |

顺带一条布局要求：图片必须写死 `width/height` 或用 `aspect-ratio` 占位，否则长文里图片加载会造成大面积跳动——这个项目每页文字量很大，跳动会比别处更明显。

## 六、按「没写就真会办错」排序

| 级别 | 场景 | 理由 |
| --- | --- | --- |
| P0 | 考研报名 / 网上确认 / 准考证下载 / 成绩查询 | 硬截止、无补救窗口，本书已自认「临考找不到入口」 |
| P0 | 学信网学籍 / 学历在线验证报告 | 报名、政审、入职都要用，入口在登录后的板块里 |
| P0 | 省级考试院志愿填报 | 只在几天内开放，走错入口的代价最大（省级差异大，先做 3–5 个人口大省） |
| P1 | 研招网调剂系统、四六级报名、个税 App 专项附加扣除 | 入口分叉多、平时不常驻 |
| P1 | 社保 / 公积金 / 档案查询 | 各地平台不同，至少给「国家政务服务平台」这一条统一路径 |
| P2 | 证书查询、赛事白名单、投诉举报 | 频次低，给准域名通常够用 |

---

## 七、代价要说清楚

- **每张图都是一次核实 + 每年复查。** 考研类内容每年报名季必须过一遍，否则图上写的是去年的界面。
- **省级入口不适合全国统一配图。** 可行做法：路径条写到「省考试院 → 普通高校招生 → 志愿填报系统」，图只做 3–5 个省，其余写「以本省公告为准」。
- **截图的法律边界。** 政府网站界面用于说明操作路径，属于说明性引用；但仍应只截局部、标注来源与日期，不整页搬运、不裁掉站点标识。

---

## 八、一句话

**这本书已经把「该做什么」写得很细，缺的是「在哪一格」；而「在哪一格」恰恰是会过期的那部分信息，所以它需要一个带核实日期的容器（路径条 + 少量标注图），而不是更多域名。**
