## 每轮的固定动作（与第一批一致）

1. 内容写入 `book/<章>/NN-<分册>.md`（新分册需 front matter：id / title / section /
   section_order / status / topics / stages / summary / last_verified）；
   **front matter 之后直接进 `### 标题` + ```meta 块，不要先铺正文**；
2. IA：`tools/ia_canonical.py` 加 `分组 @d:<location>` 与它的 `@e` 子条目；
3. 章导读页的分册表补一行；
4. `tools/tests/test_ia.py` 的 `BASELINE_ENTRIES` / `BASELINE_COMPLETE` 按新增条目数递增；
5. 新增首页问题时**必须同步 README 的「你可以直接从这些问题开始」**，否则
   `build_index.py --strict` 失败；
6. docs 新文件的 `order` / `sub_order` 接该目录现有最大值往后排；
7. 写完先 `ls` 确认目录名、`grep -rn '�'` 扫乱码字；
8. 跑 `bash /tmp/oh_finish.sh`（重建导航 → 严格构建 → 内容测试 → 发布校验 → 提交推送）。

## 四条写作边界

- **硬信息一律指向官方**：各省教育考试院（逐省核实）、学信网 `chsi.com.cn`、
  教育部教育考试院 `neea.edu.cn`、雅思中国 `ielts.neea.cn` / `chinaielts.org`、
  托福 ETS `ets.org`。**省级与校级入口写「以本省/本校公告为准」，不硬编 URL。**
- **不押题、不给范文、不推荐机构**：只写方法、节奏、材料清单与「去哪核」。
- **保研不能写成通用流程**：推免口径逐校不同，只能强调「以本校文件为准」，
  加厚现有条目而不新开分册。
- **各省专升本规则差异极大**：涉及名称、科目、时间、志愿的一律写「以本省文件为准」，
  同时给出**叫法对照**（统招专升本 / 专接本 / 专转本）。
