# 离职、换工作与社保衔接

离职的麻烦几乎都不在「走」，而在**衔接**：一个月没接上，买房资格、医保待遇、贷款月数都可能受影响。按下面顺序办，基本不会漏。

## 离职前（最后两周）

| 事项 | 为什么必须做 | 怎么确认 |
| --- | --- | --- |
| 拿到书面离职证明 | 下家入职常需要，也是劳动关系结束的凭证 | 加盖公章，写清在职起止时间 |
| 确认社保缴到哪个月 | 决定你的衔接窗口有多长 | 问 HR 要缴纳月份，次月到人社 App 查记录 |
| 结清年假、奖金、报销 | 事后追讨成本高 | 逐项写明金额与发放时间 |
| 看清竞业与保密条款 | 影响下一份工作 | 有竞业则确认补偿标准与期限 |
| 留好推荐人联系方式 | 背调与求职都要用 | 至少两位，离开前确认 |

## 衔接的三种情形

- **同城换工作**：多数城市只要下家当月参保即可不断。入职时主动告知「上家缴到 X 月」，让人事对好时间；
- **跨城市换工作**：养老与医保需要办**转移接续**（有的险种只转关系不转资金，具体以两地规则为准），公积金可办理异地转移或提取。顺序通常是：新城市先参保 → 再申请转入；
- **空窗期**：可以以灵活就业身份自己缴（通常限于养老与医疗），并考虑是否需要申领失业待遇（需满足非本人意愿离职、缴费年限等条件）。

## 失业待遇：什么时候能领

三个常见前提：**失业前用人单位和本人已缴费满一定年限**、**非因本人意愿中断就业**、**已办理失业登记并有求职要求**。主动辞职通常不符合第二条。金额、期限与办理方式以当地人社部门为准，渠道是各地人社 App 或线下经办窗口（12333 可咨询）。

## 档案与户口

- **人事档案**：多数人毕业后存放在人才服务机构或原单位；换工作时需要办理转递，**不要自己拆封**；
- **集体户口**：离职后若需迁出，问清迁往地（新单位、租房所在地或原籍）与所需材料，留足时间。

## 什么时候要谨慎

- 「社保挂靠代缴」属于违规操作，可能被清退且影响连续记录，别用它来补月数；
- 口头承诺的补偿与结清没有书面确认，事后追讨非常被动——所有约定落到邮件或文件上；
- 各地经办规则差异大，本页只给顺序；具体材料清单请以当地人社部门与公积金中心的一次性告知为准。
