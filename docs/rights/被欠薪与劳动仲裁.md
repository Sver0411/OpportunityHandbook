# 被欠薪与劳动仲裁

遇到欠薪或违法解除，最忌讳的是「先离职、后追讨」——证据会随离职迅速消失。顺序是：**固定证据 → 沟通留痕 → 官方渠道 → 仲裁**。

## 第一步：先固定证据（当天就能做）

| 证据 | 具体形态 | 怎么留 |
| --- | --- | --- |
| 劳动关系 | 劳动合同、录用通知、工牌、工作群记录 | 拍照 + 云端备份 |
| 工资标准 | 工资条、银行流水、Offer 中的薪资页 | 导出流水，标注月份 |
| 出勤与加班 | 打卡记录、排班表、加班审批、工作交付时间戳 | 截图带日期，或申请导出考勤 |
| 欠薪事实 | 催要工资的聊天记录、录音、书面催告 | 书面催告用邮件并抄送自己 |
| 解除过程 | 解除通知、谈话录音、门禁与账号被停的时间 | 保留原件，不要只留口头描述 |

## 第二步：渠道顺序

1. **先内部沟通并留痕**：邮件或即时消息确认欠薪事实与承诺时间，这一步往往就能解决；
2. **投诉举报**：拨打 12333 或到当地劳动保障监察机构投诉，监察可责令限期支付；
3. **调解**：可通过企业劳动争议调解委员会、基层调解组织或工会调解；
4. **劳动仲裁**：向劳动合同履行地或用人单位所在地的劳动人事争议仲裁委员会申请，**仲裁是诉讼的前置程序**；
5. **诉讼**：对仲裁裁决不服的，可在法定期限内向人民法院起诉。

## 时效与费用

- **仲裁时效**：一般为当事人知道或应当知道权利被侵害之日起**一年内**；劳动关系存续期间的欠薪争议不受这一年限制，但**劳动关系终止后应在一年内提出**；
- **费用**：劳动仲裁不收费；诉讼阶段的诉讼费按标的额计算，小额争议适用简易程序；
- **法律援助**：符合条件的可申请免费法律援助（12348 法律援助热线），工会也有职工法律援助渠道。

## 三个现实建议

- **不要用「先签放弃声明换离职证明」换速度**：一旦书面放弃，后续追讨会非常困难；
- **集体欠薪时分开办、但可以共享证据模板**：各自立案更稳妥，材料可以互相核对；
- **金额不大也值得走完流程**：监察投诉与仲裁的成本主要是时间，且不请律师也能完成基本流程。

## 什么时候要谨慎

- 涉及工伤、竞业、股权、违法解除赔偿金等复杂情形时，先做一次专业咨询（法律援助或执业律师）再决定路径；
- 各地仲裁受理材料与流程略有差异，提交前先打电话或到窗口确认清单；
- 本页只讲流程与通用规则，不针对个案；具体主张与证据组合应由专业人士评估。
