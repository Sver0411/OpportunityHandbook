# 劳动合同要看哪些条款

合同是唯一能在事后说话的东西。签之前逐条核对下表，比记住法条有用。

| 条款 | 要看清什么 | 常见问题 |
| --- | --- | --- |
| 用人单位主体 | 签约主体名称与你会去工作的公司是否一致 | 与关联公司签约、主体是空壳 |
| 合同期限 | 固定期限 / 无固定期限 / 以完成任务为期限 | 期限与试用期长度不匹配 |
| 试用期 | 时长与工资。法定上限与期限挂钩，试用期工资不得低于本单位相同岗位最低档或约定工资的 80%，且不低于当地最低工资 | 试用期超长、工资畸低 |
| 工作内容与地点 | 岗位、职责、工作地点 | 地点写「全国」或「公司指定」 |
| 薪酬 | 结构（基本/绩效/奖金）、发放日、调薪机制 | 只写「按公司制度执行」 |
| 工时 | 标准工时 / 综合计算 / 不定时（后者需审批） | 写了不定时但没有审批依据 |
| 加班与休假 | 加班如何认定与结算、年假与调休 | 只口头说「不提倡加班」 |
| 社会保险与公积金 | 是否明确缴纳、基数口径 | 「以现金补贴代替社保」 |
| 解除与终止 | 双方解除条件、通知期、经济补偿 | 只写员工违约责任不写公司 |
| 违约金 | 只有培训服务期与竞业限制两种情形可约定违约金 | 出现「未满一年赔付 X 元」等条款 |
| 竞业限制 | 范围、期限（最长两年）、补偿标准 | 要求竞业但不提补偿 |

## 三个动作

1. **要电子版**：签约前把合同文本拿到手，给自己一天时间逐条看，不必当场签字；
2. **对照 Offer 与口头承诺**：把面试时谈的薪资结构、报到时间、岗位写进合同或书面确认；口头承诺在争议时几乎无法证明；
3. **留存一份**：签完自己留一份原件或扫描件，与工资条、录用通知一起归档。

## 关于「三方协议」与「劳务派遣」

- **三方协议**：应届生与学校、单位之间的就业协议，**不是劳动合同**；入职后仍要签劳动合同。毁约通常涉及违约金，签前看清条款；
- **劳务派遣**：你与派遣公司签约、在被派遣单位工作。待遇与稳定性通常弱于直签，签约前确认派遣主体、期限与用工单位的角色。

## 什么时候要谨慎

- 与不同主体签约（劳动合同一家、发薪另一家、社保第三家）时，先问清法律关系，这直接影响发生争议时找谁；
- 合同里出现「自愿放弃社保」「自愿加班不结算」这类条款，属于违法或无效约定，签字不等于认账，但会显著增加你维权的举证成本；
- 涉及竞业、股权、服务期等长期约束的岗位，建议让专业人士过一遍文本。
