# 遇到纠纷找谁：求助顺序

慌乱时最该做的不是打第一个电话，而是**先把证据固定下来**：截图带时间、录音、保存合同与转账记录、记下对方主体名称。有了这些，选哪条渠道都容易；没有这些，哪条渠道都难办。

| 情形 | 先做什么 | 找谁 | 大概会发生什么 |
| --- | --- | --- | --- |
| 欠薪、违法解除、不缴社保 | 固定劳动关系与工资证据 | 12333（人社）、当地劳动保障监察、劳动仲裁 | 监察可责令支付；仲裁是诉讼前置 |
| 网络诈骗、被盗刷 | 立刻冻结账户、改密码、保存聊天与转账记录 | 110 报警、银行与支付平台客服、国家反诈中心 App | 越早冻结追回概率越高 |
| 消费与预付卡纠纷 | 保存合同、付款凭证、服务记录 | 12315（市场监管）、平台投诉入口 | 调解为主，可转行政处理 |
| 租房押金不退、中介违规 | 保存合同、转账与房屋现状照片 | 12345 政务热线、住建部门、消费者协会 | 通常先调解，必要时小额诉讼 |
| 个人信息被泄露或滥用 | 截图与来源链接 | 涉事平台投诉入口；涉嫌犯罪的报警；个人信息保护相关举报渠道 | 平台通常要求举证，先留证据 |
| 学历学位、档案问题 | 找到原始凭证 | 学信网、原学校学籍部门、人才服务机构 | 需要原始材料，尽早补齐 |
| 劳动与消费以外的一般纠纷 | 分清是民事还是行政 | 12345 问渠道；民事走调解或法院小额诉讼 | 12345 不处理个案裁判，但能指路 |

## 三个通用原则

1. **先书面、后口头**：任何诉求都用邮件或带记录的渠道发出，口头的承诺等于没有；
2. **先小成本渠道、再升级**：平台投诉与热线基本免费且响应快，仲裁与诉讼成本更高但更有强制力；
3. **设时间预期**：调解通常几天到几周，仲裁一般数月；把时间成本算进去再决定要不要走到底。

## 该保存的通用证据清单

合同与协议、付款与转账记录、聊天与邮件、通话录音（注意合法取得）、发票与收据、对方主体名称与统一社会信用代码、时间线（把关键事件按日期排一行）。

## 什么时候要谨慎

- 涉及金额较大、刑事嫌疑、股权与竞业等复杂情形时，先咨询专业人士再行动，避免自行处置导致证据失效；
- 不要相信「付费包追回」「包删帖」的服务：正规渠道基本免费；
- 各地热线与受理范围略有差异，拨不通时可用 12345 要求转接对应部门。
