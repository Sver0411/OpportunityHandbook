# 工伤与职业伤害怎么处理

工伤这件事有时间限制，而且**顺序错了会丢权利**：先救人、再留痕、按时限申请认定、最后才是谈赔偿。这份页把顺序和材料列清楚，具体认定以当地人社部门为准。

本页只讲流程与材料，不判断个案。涉及争议时按[遇到纠纷找谁：求助顺序](遇到纠纷找谁.md)逐级处理。

## 第一步：救治优先，但别忘留痕

1. **先就医**。伤情优先，不要为了先谈责任耽误处理；
2. **说清是工作相关**。就诊时说明受伤的时间、地点与经过，病历上的记录是后续认定的重要依据；
3. **留现场信息**。拍照、记下在场同事、保留监控时间点；上下班途中的事故要拿到**交警的责任认定**；
4. **书面告知单位**。微信、邮件、书面报告都可以，关键是留下时间点——口头说过的，事后往往无法证明。

## 第二步：工伤认定（限时，这一步不能拖）

- **谁申请**：用人单位有申报时限（一般为事故发生之日起 30 日内）；单位不申请的，**职工本人、近亲属或工会可以在 1 年内直接申请**。两个时限都以《工伤保险条例》与当地人社部门口径为准，超过时限会直接影响权利；
- **去哪里**：用人单位所在地的人力资源和社会保障部门（工伤认定窗口，多地可线上提交）；
- **常见材料**：
  - 工伤认定申请表；
  - **劳动关系证明**（劳动合同、工资记录、考勤、工作群记录、工牌、社保缴费记录）；
  - 医疗机构出具的诊断证明或病历；
  - 事故情况材料（目击者证言、监控、交警认定书、单位事故报告）；
  - 身份证明。

**卡点一：单位不承认存在劳动关系。** 那就先确认劳动关系（可申请劳动仲裁），再申请工伤认定，两者可以并行准备材料，但不要因为等劳动关系而错过认定时限。

**卡点二：单位说「走医保就行」。** 工伤医疗费用应按工伤保险处理，用医保结算可能给后续认定与报销带来麻烦。就医时说明是工伤，并要求单位按规定办理。

## 第三步：劳动能力鉴定

收到工伤认定决定、伤情相对稳定后，可以申请**劳动能力鉴定**（由设区的市级劳动能力鉴定委员会组织）。鉴定结论与伤残等级直接决定一次性补助与长期待遇，本人或单位都可以提出申请，对结论不服可以按规定申请再次鉴定。

## 待遇大致包含哪些

| 项目 | 大致内容 | 由谁承担 |
| --- | --- | --- |
| 医疗费用 | 符合规定的工伤医疗费用 | 单位已参保的由工伤保险基金支付 |
| 停工留薪期工资 | 治疗与恢复期间的原工资待遇 | 用人单位 |
| 住院伙食补助、交通食宿 | 按规定标准 | 基金或单位（按当地规定） |
| 一次性伤残补助金 | 依伤残等级 | 基金支付 |
| 生活护理费、辅助器具 | 达到条件时 | 基金或单位 |
| 解除或终止劳动关系时的补助 | 一次性工伤医疗补助金与就业补助金 | 按当地规定 |

**单位没有参保的**，上述由基金承担的部分由单位承担——这也是为什么「没交社保」比看起来严重得多，见[社保到底保什么](../../book/16-钱与生活基本盘.md#money-social-insurance)。

## 职业病：另一条路径

职业病不是靠一次就诊确定，而是由**职业病诊断机构**按诊断标准作出，通常需要：职业史与接触史材料、工作场所职业病危害因素检测资料、职业健康监护档案。

- 上岗前、在岗期间、离岗时的**职业健康检查**由用人单位组织，这些记录是后续诊断的关键材料；
- 怀疑与工作环境有关时，先向单位或当地卫生健康部门了解诊断机构与所需材料；
- 单位不配合提供资料的，可以向卫生健康部门与人社部门反映。

## 四个最容易丢掉权利的卡点

1. **超过申请时限**：以为「单位会办」而不自己盯时间；
2. **用医保结算工伤医疗费**，事后认定与报销都变复杂；
3. **私下一次性了结**：签了「放弃全部权利」的协议后很难反悔，签之前先做完认定与鉴定、算清待遇总额；
4. **没有劳动关系证据**：没合同、现金发薪、没有工作记录，维权成本会成倍上升。平时就该留存这些材料，见[劳动合同要看哪些条款](劳动合同要看哪些条款.md)。

## 求助渠道

- **12333**：人社政策咨询与劳动权益投诉（https://12333.gov.cn/）；
- **12348 中国法律服务网**：法律援助与公共法律服务，工伤案件多地可申请免费法律援助（https://www.12348.gov.cn/）；
- **工会**：单位或地方总工会可提供协商与援助；
- **劳动仲裁**：涉及待遇争议时走仲裁，流程与时效见[被欠薪与劳动仲裁](被欠薪与劳动仲裁.md)。

## 什么时候要谨慎

- 单位以「先私下解决」为由阻止你申请认定：认定的时限与权利是你的；
- 让你在空白文件或「自愿放弃」声明上签字；
- 只有口头承诺的赔偿方案，没有书面金额与支付时间；
- 涉及严重伤残、长期护理或工亡的情形，建议在签署任何协议前先咨询专业人士或法律援助机构。
