# 灵活就业与自缴社保

只要有一段时间没有单位替你缴社保——自由职业、副业为主、离职过渡、毕业后还没入职、或者准备二战考研——社保就从「公司的事」变成「你的事」。这篇讲怎么自己接着缴、怎么选档、以及哪些做法有风险。

判断层（社保到底保什么、断缴影响什么）在主指南：[社保到底保什么](../../book/16-钱与生活基本盘.md#money-social-insurance)。本页只讲操作。

## 谁需要自己缴

| 情形 | 典型处理 |
| --- | --- |
| 自由职业 / 以副业为主要收入 | 以灵活就业身份参加职工养老与职工医疗 |
| 离职到入职之间的空窗 | 当月衔接或过渡期自缴，避免断缴（见[离职、换工作与社保衔接](离职与社保衔接.md)） |
| 毕业后暂未就业 | 按当地规则以灵活就业身份参保，或参加居民医保兜底 |
| 准备二战考研 / 备考期 | 通常只能自缴养老与医疗，注意资格类事项对连续缴纳的要求 |
| 个体经营 | 可按灵活就业参保，或按当地规定以其他形式参保 |

多数地区已放开在就业地参保的户籍限制，但**具体以当地社保经办机构口径为准**，办理前先打 12333 或查当地人社 App（https://12333.gov.cn/）。

## 办理入口与要准备的材料

- **入口**：国家社会保险公共服务平台（https://si.12333.gov.cn/）、当地人社或税务的线上渠道、社保经办窗口；
- **常见材料**：身份证、参保登记表、本人银行卡（用于签扣款协议）、部分地区需要居住或就业证明；
- **关键动作**：签好**代扣协议**并确认每月扣款成功。断缴最常见的成因不是不想缴，而是扣款账户余额不足或协议没签成。

## 缴费基数与档次怎么选

- 灵活就业人员通常在**当地公布的缴费档次区间内自选**基数，档次越高，当期缴费越多、将来养老金与个人账户越多；
- 医疗待遇与**连续缴费**关系更紧：断缴后待遇通常暂停，恢复需要重新缴并可能有等待期（各地不同）；
- 收入波动时的实用做法：先按能长期坚持的档次缴，把「不断缴」放在「缴得高」前面；收入稳定后每年调整一次。

单位参保与自缴的差别要清楚：单位参保时单位承担的那一部分，自缴时由你自己承担；同时**工伤、失业、生育通常不包含在内**（个别地区对灵活就业有部分险种政策，以当地为准）。这意味着意外与医疗的缺口要自己补，见[该买与不该买的保险](../../book/16-钱与生活基本盘.md#money-insurance-basics)。

## 公积金能不能自缴

部分城市已向灵活就业人员开放自愿缴存，缴存后可按规定申请公积金贷款或提取。是否开放、缴存比例与贷款条件**逐城不同**，以当地住房公积金管理中心发布为准（https://www.mohurd.gov.cn/）。

## 断缴的真实影响

- **资格类事项**：购房资格、落户积分、车牌摇号、子女入学等常看连续缴纳月数，断一个月可能就要重新起算；
- **待遇类事项**：医保待遇暂停、生育津贴与部分补贴的连续缴费要求；
- **累计类事项**：养老按累计年限计算，断缴不影响已缴月数，但会减少总年限。

所以「要不要自己缴」的答案取决于你未来 12 到 24 个月有没有用到连续记录的计划，而不是每月省下多少。

## 关于「代缴」机构

市面上有机构提供「社保代缴」：把劳动关系统挂在某家公司名下由你出全部费用加服务费。这件事的风险要说清：

- 缴费建立在**虚构的劳动关系**之上，与真实就业状态不符；
- 一旦被核查（落户、购房、补贴申领等场景会核验劳动关系与个税、社保的一致性），已缴记录可能不被认可，钱也可能不好追回；
- 服务费通常不低，而你自己办灵活就业参保多数是免费的。

需要连续记录时，优先用合法路径：真实就业、灵活就业参保、或按当地规则补办。拿不准就先咨询当地人社部门，而不是听中介的承诺。

## 什么时候要谨慎

- 承诺「一次性补缴多年」「包落户资格」的中介服务；
- 只缴医疗不缴养老（或相反）却以为两种资格都能保住；
- 长期按最低档缴、又指望较高养老金：两者对不上，可先按当地养老金计发办法估算；
- 签了大额服务合同却拿不到缴费凭证与参保记录。
