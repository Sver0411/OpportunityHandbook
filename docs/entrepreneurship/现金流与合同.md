# 现金流、发票与合同边界

自由职业与副业最常见的死法不是「没有客户」，而是**有客户却收不到钱，或收到钱之后发现成本吃掉利润**。

## 现金流三条纪律

1. **预付款**：开工前收 30%–50%。一个不愿付预付款的客户，往往也是尾款最难收的；
2. **里程碑付款**：把交付切成 2–4 个节点，每个节点绑定一笔款；
3. **缓冲金**：账户里常备 3–6 个月生活开支。收入高的月份不代表可以高消费（要预留税款与淡季）。

## 应收账款管理

| 账龄 | 动作 |
| --- | --- |
| 到期前 1 天 | 友好提醒，附发票 |
| 到期当天 | 正式催收，说明合同条款 |
| 逾期 1 周 | 电话/会议沟通，确认是否对交付有异议 |
| 逾期 1 月 | 书面催告，明确后续措施 |
| 长期拖欠 | 评估是否值得走法律程序（成本通常高于小额尾款） |

**关键前提**：先拿到「交付无异议」的书面确认，否则催款会被拖入质量争议。

## 税务与开票

- 收入达到持续经营规模时，通常需要办理个体工商户或公司登记，并依法申报纳税；
- 个人劳务报酬与经营所得的计税方式不同，规则以税务部门规定为准；
- 开票资格、税率与申报周期因主体类型与地区而异——**注册前先看当地政务服务平台的办理指引**，或咨询专业人士。

官方入口：[国家税务总局](https://www.chinatax.gov.cn/)（政策与申报）、各地政务服务平台（登记与开票）。

## 合同要写清的六件事

1. **服务范围**：交付物、格式、数量，以及明确不包含什么；
2. **修改轮次**：含几轮，超出如何计费；
3. **时间与验收**：交付时间、验收标准、反馈期限（超期未反馈是否视为通过）；
4. **付款结构**：预付比例、里程碑、尾款期限；
5. **知识产权**：成果归属、你能否用于作品集展示；
6. **终止与违约**：如何中止、已完成部分如何结算、违约处理。

## 变更与边界

- 所有变更走书面（邮件也算），写明对时间与费用的影响；
- 「顺手帮个忙」是利润的隐形杀手：把它变成「这次包含，下次计费」的规则；
- 客户要求超出能力范围时，直接说明并给出替代方案，不要硬接。

## 自检

- 我这单有没有预付款与明确的付款节点？
- 我的交付确认拿到了书面记录吗？
- 我预留了税款与淡季缓冲吗？
