# 第一个客户：从发现到复购

第一个客户的目标不是赚钱，而是**跑通一次完整的交易链路**：从找到人、谈成、交付到收到钱。

## 完整链路（八步）

### 1. 发现客户

来源按转化率排序：前同事与前雇主 > 行业社群 > 熟人推荐 > 平台。判断标准：他**已经有这个问题**，而不是「可能需要」。

### 2. 第一次沟通（30 分钟）

只问不推：现在怎么做的、最烦哪一步、多久做一次、如果解决对业务有什么影响。结束时说清「我理解你的问题是 X，交付物是 Y」，并确认是否需要报价。

### 3. 报价

按 [定价与报价](定价与报价.md) 的方法给区间，附交付物与「不包含」清单。**不要口头报价**，发书面（邮件或文档）。

### 4. 合同

哪怕只有一页也要写：范围、修改次数、时间节点、付款结构、知识产权、终止条款。见 [现金流、发票与合同边界](现金流与合同.md)。

### 5. 范围变更

客户中途加需求是常态。处理方式：**先记录，再评估，再报价**。不要在现场直接答应「顺便做一下」。

> 例：「这个可以做，需要额外 2 天，费用 X；要加进这一期还是放到下一期？」

### 6. 交付

按里程碑交付，每个节点让客户**书面确认**（邮件一句「确认」即可）。交付时附一份简短说明：做了什么、怎么用、已知限制。

### 7. 修改

按合同轮次执行。超出轮次时提前说明计费方式，而不是做完再要钱。

### 8. 收款与复购

- 尾款按合同节点催：到期前一天提醒，到期当天正式发一次；
- 尾款拖延时：先确认交付无异议（拿到书面确认），再谈付款计划；
- 交付后两周回访一次：使用情况、有没有新问题、下一阶段要不要继续。

**复购率是自由职业能否持续的关键指标**，比单笔价格重要。

## 失败分支与补救

| 情况 | 补救 |
| --- | --- |
| 客户中途失联 | 发送阶段性成果与进度说明，保留记录；按合同条款处理 |
| 客户说「和预期不一样」 | 回到验收标准逐条对；先确认是范围问题还是质量问题 |
| 尾款拖延 | 先拿交付确认，再给分期方案；保留聊天与合同记录 |
| 需求不断扩张 | 立刻停止新增，重新报价并书面确认 |
| 自己延期 | 提前告知 + 给出新的时间点与补救方案，不要等到截止日 |

## 这一单结束后

- 写一页复盘：报价是否偏低、沟通哪里费时、哪些条款有用；
- 请客户给一句可公开的评价（长期最值钱的资产）；
- 把这次的流程整理成自己的「标准件」（报价单、合同模板、交付说明）。

## 自检

- 我的交付物与验收标准写清了吗？
- 范围变更我有没有记录并重新报价？
- 交付后我做了回访吗？
