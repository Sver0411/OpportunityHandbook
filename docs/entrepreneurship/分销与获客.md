# 分销与获客

做出东西只是开始，**有人知道它**才是生意。获客不是「推广」，是找到可重复的触达方式。

## 渠道分类

| 渠道 | 特点 | 适用阶段 |
| --- | --- | --- |
| 熟人 / 前同事 | 转化率最高，量小 | 最早 |
| 垂直社群 | 精准，需要遵守规则 | 早期 |
| 内容（文章、视频、教程） | 慢，但会积累 | 中长期 |
| 平台市场（应用市场、插件市场） | 有自然流量，竞争激烈 | 产品成熟后 |
| 付费投放 | 快，需要算清转化成本 | 已验证转化后 |

原则：**先做前两类，再谈后三类。** 早期用付费投放掩盖「没人要」的问题，是最贵的错误。

## 冷启动的具体做法

1. 列出 50 个可能用得上的人的来源（社群、校友、同行、老客户）；
2. 一对一发消息，说明你做了什么、为什么想到他、希望他试用（不要群发广告）；
3. 门槛降到最低：一个链接、几分钟能试完；
4. 用完立刻问三个问题：哪里卡住、你会继续用吗、你愿意为它付多少钱；
5. 记录每位用户的来源与反应，找出「哪一类人最容易接受」。

## 转化漏斗

关注四个数字：触达 → 试用 → 复用 → 付费。每一环的流失都要有解释。

**留存比拉新重要**：一批人用了一次就再没回来，说明问题在产品而不在渠道。

## 低成本验证一个渠道

给每个渠道限定一个周期（例如两周）与一个动作（发 5 条内容 / 联系 20 人），记录触达与转化。

达到「能算出转化率」的样本量之后再决定加不加投入——**别在一个渠道只发过两条内容就判断它没用**。

## 内容为什么有效

内容的作用是让人**在被推销之前就信任你**：写清你解决过什么问题、遇到过什么失败。技术类与服务类尤其如此。

写什么：一次真实的解决过程、一个常见错误的纠正、一份可复用的清单。

## 自检

- 我现在的用户，最早是从哪个渠道来的？
- 我的留存数字是多少（不是注册数）？
- 我有没有在一个渠道上做出可判断的样本量？
