# 实验设计：变量、对照与统计

实验设计的目的是让**结论可以被归因**：结果变化是因为你改的那一项，而不是别的东西。

## 先把变量说清

- **自变量（independent variable）**：你主动改变的因素（算法、参数量、界面形态、教学方式）；
- **因变量（dependent variable）**：你测量的结果（准确率、延迟、完成时间、错误率）；
- **控制变量**：必须保持不变的（硬件、数据版本、时间、样本来源）；
- **混淆因素（confounder）**：你没想到但会影响结果的（机器负载、被试疲劳、数据时间跨度差异）。

混淆因素是论文被拒的常见原因。发现它的办法是问：「还有哪些能同时影响自变量和因变量的东西？」

## 对照与随机化

- 只改一个变量，保留一个对照条件；
- **随机化**：被试、样本、运行顺序随机分配，避免顺序效应与选择偏差；
- **盲法**：能盲测就盲测（评分者不知道条件）；
- 有多个因素时用**析因设计**，而不是一次改一堆。

## 重复、样本量与功效

- 每次条件至少跑多次（机器实验常见 3–5 次，人因实验通常需要更多被试）；
- **样本量与统计功效**：样本太小的结果是噪声；事前估算需要多大才能看出预期差异；
- 报告**效应量**（差异有多大）而不只是 p 值（差异是否显著）；
- **多重比较**：比较的组合越多，偶然出现的「显著」越多；需要校正或事先限定主假设。

## 不确定性要写出来

均值 + 标准差 / 置信区间 / 分布图，至少给一个。只给均值的结果，读者无法判断差异是否真实。

## 不同学科的设计差异

| 领域 | 关键考虑 |
| --- | --- |
| 计算机系统 | 硬件与负载可控，重复运行可行；重点在基准与环境说明 |
| 机器学习 | 数据划分、随机种子、多次运行、与强基线对齐预算 |
| HCI / 人因 | 被试数量、任务设计、学习效应、伦理审查、主观量表的信度 |
| 工程 / 材料 | 批次差异、测量仪器误差、破坏性试验的样本不可复用 |
| 实验科学 | 对照组与随机化是基本要求，需记录全部条件 |

## 记录与可复现

实验计划、原始数据、脚本、环境版本、随机种子全部留档；失败的运行也要记录，否则「从未失败」是假象。见 [数据管理与可复现性](数据与可复现.md)。

## 自检

- 我的自变量、因变量、控制变量分别是什么？
- 有没有可能同时影响原因和结果的混淆因素？
- 每个条件跑了几次？波动多大？
- 我比较了几组？需要校正吗？
- 结论是「差异存在」还是「差异有多大」？
