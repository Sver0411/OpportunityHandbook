# 创业与自由职业

创业与自由职业共用同一套底层能力：**让陌生人愿意为你的交付付钱**。区别在于规模与结构——自由职业是「一个人卖交付」，创业是「组织资源持续交付」。这一页按验证顺序讲清楚。

## 先验证「有人愿意付钱」

所有后续动作（注册公司、做网站、租办公室、招人）都应该发生在验证之后：

1. **谁会为它付钱**——越具体越好。「大学生」不是答案，「准备考研的三线城市二本学生」才是；
2. **为什么是现在**——需求是一直存在还是刚出现？晚一年做会怎样？
3. **最小可交付是什么**——能不能在下周用手工方式给第一个客户交付一次？
4. **付费意愿**——免费试用不算验证。**第一笔真实收入是最有信息量的信号**。

## 自由职业：从第一单到稳定

| 阶段 | 关键动作 | 卡点 |
| --- | --- | --- |
| 第 1–3 单 | 从已有的工作关系、校友、社群接单 | 不敢报价、按工时定价 |
| 第 4–10 单 | 明确交付物范围、签书面约定、按交付定价 | 需求蔓延、尾款难收 |
| 稳定期 | 复购与转介绍占多数收入 | 客户结构过于单一 |
| 扩张期 | 提价、筛选客户、可能组建小团队 | 时间被管理与沟通吃掉 |

具体做法见 [找客户](../../book/08-其他同样成立的人生路径.md#freelance-clients)、[定价](../../book/08-其他同样成立的人生路径.md#freelance-pricing)、[合同与付款](../../book/08-其他同样成立的人生路径.md#freelance-contract)、[收入稳定性](../../book/08-其他同样成立的人生路径.md#freelance-stability)。

**必须提前处理的边界**：劳动合同里的兼职限制与竞业条款、不要使用雇主的设备与时间、收入达到一定规模后按规定登记与纳税（以当地税务与市场监管部门要求为准）。社保医保按灵活就业身份自行参保。

## 创业：从副业到主业的门槛

- **先做副业验证**（见 [创业前应该验证什么](../../book/08-其他同样成立的人生路径.md#startup-validate-before-quit)）：有稳定付费用户再考虑全职；
- **最小可行版本**（[MVP](../../book/08-其他同样成立的人生路径.md#startup-mvp)）：只跑通核心闭环，不做完整产品；
- **商业模式**（[商业模式](../../book/08-其他同样成立的人生路径.md#startup-business-model)）：能算清单位经济——获客成本、客单价、复购、毛利；
- **扩张工具**：孵化器（[Incubator](../../book/08-其他同样成立的人生路径.md#startup-incubator)）、加速器（[Accelerator](../../book/08-其他同样成立的人生路径.md#startup-accelerator)）能提供场地、辅导、资金与同期网络，但**条款与条件差异很大**（股权、期限、退出约束），逐项核对；
- **融资**（[Funding](../../book/08-其他同样成立的人生路径.md#startup-funding)）：拿钱意味着放弃控制权与时间表，先想清楚需要这笔钱做什么。

## 副业：低风险试水

内容创作、接单、咨询、小生意的共同点是**用业余时间换一次真实验证**。判断标准是：有没有人付费、能不能重复交付、投入产出比是否可接受（见 [副业](../../book/08-其他同样成立的人生路径.md#side-gig-orders) 与 [第二职业](../../book/08-其他同样成立的人生路径.md#second-career)）。

## 失败方式与退出

| 失败方式 | 表现 | 应对 |
| --- | --- | --- |
| 用忙碌代替进展 | 每天都在做，但没有付费用户 | 每周核对一次「收入与用户」这两个数字 |
| 先投入再验证 | 先做完整产品再找人用 | 回到手工交付 |
| 定价过低 | 单量大但没钱，客户质量差 | 提价并筛选客户 |
| 现金流断裂 | 项目回款慢、开支固定 | 预留 6 个月开支，或先保持在职 |
| 无法退出 | 欠款、合同纠纷、税务问题 | 从一开始就签合同、开发票、记账 |

**退出标准要提前定**：给一个时间点与一个数字（例如「六个月后月收入低于 X 就回到全职工作」），避免无限期消耗。
