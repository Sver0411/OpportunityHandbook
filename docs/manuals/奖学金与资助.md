# 奖学金与资助

资助体系里最容易混淆的是**「给钱的名义」不一样，义务与审查方式也完全不一样**。这一页把常见的资助类型、申请逻辑与判断标准讲清楚。

## 先把词分清

| 名称 | 通常含义 | 是否需要单独申请 | 常见义务 |
| --- | --- | --- | --- |
| Scholarship（奖学金） | 按成绩/综合表现给的钱 | 有的随录取自动评估，有的需单独申请 | 一般无义务，可能有成绩要求 |
| Fellowship | 面向研究生的资助，常覆盖生活+学费 | 通常随项目或独立申请 | 可能需要承担助教/助研职责 |
| Assistantship（TA/RA） | 用工作换取资助 | 由院系/导师安排 | **有工作职责，是工作不是奖励** |
| Grant | 项目经费，用于具体研究活动 | 需提交申请材料 | 有结题与用途限制 |
| Stipend | 生活津贴（分发形式） | 依附于 fellowship/RA 等 | 视来源而定，可能需报税 |
| Tuition Waiver | 学费减免 | 常与 assistantship 绑定 | 视学校规定 |
| Fee Waiver | **申请费**减免 | 需单独申请 | 无，通常有资格条件 |
| Government Scholarship | 政府项目（如公派、GKS 等） | 独立申请窗口 | **可能附带服务承诺或回国义务** |

**最容易踩的坑**：把 stipend 当成「额外的钱」。它通常是资助的一部分，若同时承担 RA/TA 职责，工作时间与学业时间需要自己平衡。

## 资助从哪里来

1. **政府与国际组织**：公派留学、目标国政府奖学金（如 GKS）、国际组织项目。额度通常较高，但**申请窗口固定、竞争激烈、多带义务**；
2. **学校层面**：入学奖学金、院系奖学金、学费减免。多数随录取评估，也有需单独提交材料的；
3. **导师与课题组**：研究型项目常见，取决于导师在研项目的经费。**判断方式很直接：问导师「这个方向目前有在研项目和资助位置吗」**；
4. **外部机构与企业**：行业协会、基金会、企业奖学金，名额少但竞争有时也小——**知道的人越少，命中率越高**；
5. **校内与本地**：助研助教、勤工助学、地方人才政策（给在校生或毕业生的补贴与奖励）。

## 申请逻辑：评审看什么

- **奖学金**：成绩与排名、竞赛与科研产出、社会工作与领导经历、推荐信、个人陈述；
- **助研/助教**：导师是否了解你、你的技能是否匹配课题需求（**这条最实际**）；
- **政府奖学金**：项目匹配度、语言成绩、研究计划质量、推荐信、有时还有体检与背景审查；
- **企业奖学金**：与岗位/专业的相关性、企业活动参与度。

**共同点**：材料要能回答「为什么给你」。泛泛的成绩单不如一段具体的成果加一段清晰的计划。

## 判断一个资助是否真的覆盖成本

逐项列出来再算：

```
学费（或减免后剩余）
+ 生活成本（住宿、餐饮、交通、保险）
+ 一次性支出（机票、签证、押金、设备）
− 资助金额（注意是税前还是税后、按学年还是按学期发）
= 真实缺口
```

**三个容易漏的地方**：税与发放周期（有的奖学金滞后发放，需要先垫付）、汇率与跨境手续费、以及资助期限是否覆盖整个学制。

## 义务与回退

- 接受 Tuition Grant 类补助（如新加坡 MOE）通常需要在当地工作一定年限，**违约可能涉及赔偿**；
- 公派项目常要求回国服务年限；
- 助研助教有工作量与考核；
- **签署任何资助协议前，逐条看清：义务、期限、违约后果、能否变更**。这些内容以官方条款为准，不要按他人经验推断。

## 一条实用的执行顺序

1. 先确定目标项目/学位，再看它提供哪些资助（读项目官网的 funding 页面）；
2. 分清「随录取自动考虑」与「需单独申请」两类，把截止日期写进日历；
3. 需要导师资助的，在联系导师时就问清经费情况（见 [联系导师与套磁](../research/联系导师与套磁.md)）；
4. 同时准备两条腿：申请资助 + 准备自费方案的现金流；
5. 拿到资助后核对发放方式与义务，再签字。
