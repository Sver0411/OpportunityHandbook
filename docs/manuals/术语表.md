# 术语表

看书时遇到不认识的词，先在这里查。**同一个东西常有两种叫法**（官方名称与口头简称），下表把它们放在一起，避免你以为它们是两件事。

用法：查到词 → 看一句话解释 → 需要细节时点右侧链接。

## 求职

| 术语 | 也叫 | 一句话解释 | 深入阅读 |
| --- | --- | --- | --- |
| 秋招 | 秋季招聘 | 面向应届生的主招聘季，多在 9–11 月 | [校招时间线](../timelines/校招时间线.md) |
| 春招 | 春季招聘 | 次年 3–4 月的补录与二次机会，岗位少于秋招 | [校招时间线](../timelines/校招时间线.md) |
| 提前批 | — | 秋招前的提前招聘批次，多在暑期前后，竞争较小但岗位有限 | [校招时间线](../timelines/校招时间线.md) |
| 内推 | Referral | 由在职员工把你的简历直接送进流程，改变的是被看到的概率 | [内推](../../book/05-从学校走向第一份工作.md#job-hunting-referral) |
| 测评 | OT / 网测 | 公司用来自动筛人的在线笔试，常有限时与一次机会 | [在线测评](../../book/05-从学校走向第一份工作.md#job-hunting-written-test) |
| 总包 | TC | 现金 + 奖金 + 股权 + 补贴的合计，不能与「月薪 × 12」混为一谈 | [薪资和总包怎么看](../../book/05-从学校走向第一份工作.md#offer-total-comp) |
| base | 基本工资 | 每月固定发放的部分 | [Offer、薪酬结构与劳动合同](../job-search/Offer与合同.md) |
| bonus | 奖金 | 通常与个人与公司绩效挂钩，兑现情况要看历史 | [Offer、薪酬结构与劳动合同](../job-search/Offer与合同.md) |
| RSU / option | 限制性股票 / 期权 | 股权激励的两种形态，需看授予数量、归属节奏与离职处理 | [Offer、薪酬结构与劳动合同](../job-search/Offer与合同.md) |
| sign-on | 签字费 | 入职时的一次性款项，常带最低服务期要求 | [Offer、薪酬结构与劳动合同](../job-search/Offer与合同.md) |
| 试用期 | — | 入职初期的考察期，长度与工资比例有法定要求 | [Offer、薪酬结构与劳动合同](../job-search/Offer与合同.md) |
| 三方协议 | — | 应届生、学校与用人单位之间的就业协议，与劳动合同是两回事 | [三方协议](../../book/05-从学校走向第一份工作.md#job-hunting-tripartite-agreement) |
| 竞业限制 | 竞业禁止 | 离职后一定期限内不得从事竞争业务，单位需按月支付补偿（最长两年） | [在职跳槽](../career-growth/在职跳槽.md) |
| JD | 职位描述 | 招聘公告里的岗位描述，拆 JD 是求职第一步 | [一份 JD 到底怎么拆](../job-search/JD拆解.md) |
| STAR | — | 行为面试的一种叙事结构（情境/任务/行动/结果），不是万能模板 | [行为面试](../job-search/行为面试.md) |
