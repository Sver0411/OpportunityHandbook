# 语言与考试

语言与考试是最容易「用错力」的一类准备：**先确定目标（要申请什么、要什么证明），再决定考什么、考到几分、什么时候考**。这一页按这个顺序讲。

## 第一步：先确定目标，再选考试

| 目标 | 常见考试 | 关键注意点 |
| --- | --- | --- |
| 海外本科申请 | IELTS / TOEFL / Duolingo，部分要求 SAT/ACT | 学校可能对小分有要求；部分国家需要 UKVI 版本 |
| 授课型硕士 | IELTS / TOEFL / PTE | 不同项目总分与小分要求不同；部分接受语言班衔接 |
| 研究型硕博 | 同上 + 可能 GRE | 导师更看研究匹配度，语言是门槛不是亮点 |
| 国内升学与就业 | 四六级、专业英语 | 四六级多为门槛；涉外岗位可能看口语能力 |
| 日本 / 韩国 / 欧洲大陆 | JLPT / TOPIK / 德法等本国语言考试 | 语言授课项目必须本国语言；英语项目另有要求 |
| 职业与移民类 | 各行业与各国官方考试 | **以官方要求为准**，不要用旧经验推算 |

**不要先考再选校**：同一门考试在不同项目的分数要求差别很大，而且有效期不同（雅思托福通常两年），考早了可能过期。

## 第二步：搞清楚「分数怎么用」

- **总分与小分**：很多项目总分达标但小分不达标，报名前逐项抄下来；
- **有效期**：不同考试与机构规则不同，注意考试日期而不是出分日期；
- **是否接受替代**：语言班（pre-sessional）、校内测试、英文授课证明、母语豁免——条件与限制要逐条看清；
- **送分方式**：是否需要官方送分、送分是否收费、是否必须在截止日前到达。

## 第三步：备考的现实节奏

- **先测一次**：用一套完整的真题模拟，得到真实起点分数。**备考计划要基于这个分数，而不是基于「我英语还行」**；
- **弱项优先**：总分提升最快的路径通常是补最短的板（口语或写作常是短板）；
- **口语与写作必须输出**：只输入不输出，分数很难提高。找人批改、录音回听、按评分标准自查；
- **时间预留**：从达标到出分通常要 2–6 个月；如果目标分数比起点高 1 分以上，按 3–6 个月规划；
- **考试日期要留缓冲**：出分、复议与再次考试都需要时间，**不要把第一次考试安排在截止日期前两周**。

## 第四步：什么时候该停

- 已经达到目标项目的要求 → 停止加考，把时间转移到文书与项目上；
- 连续两三次没有提升 → 先改方法（批改、老师、换练习材料），不要只增加次数；
- 目标本身需要重新评估 → 有的项目接受语言班或条件录取，可以考虑这条路径，但要看额外时间与费用。

## 与升学、求职的衔接

- 语言成绩是申请的**门槛条件**，不是加分项：达标即可，超额分数的边际价值通常低于同一时间投入在项目或研究上；
- 但**真实使用能力**是加分项：面试中的英文表达、能读英文文档与文献、能写清技术方案，这些是长期资产；
- 国内就业中，四六级的作用主要在筛选环节（部分单位有硬线），实际沟通能力在面试里体现。
