# 证书

证书的价值取决于两件事：**招聘方是否真的看它**，以及**它是不是法定准入要求**。这一页按这个顺序讲清楚，附一条可直接执行的判断流程。

## 第一步：查它是不是法定要求

打开人力资源社会保障部公布的《国家职业资格目录》：

- **准入类**：无证不得上岗（如教师资格、医师资格、法律职业资格、注册类工程师等）。**这类必须考，是硬门槛**；
- **水平评价类**：多为能力分级，由社会培训评价组织或行业机构实施；
- **目录之外**：属于社会培训证书，价值完全由市场定价——**拿招聘市场来验证**。

2021 年版目录已把大量水平评价类技能人员职业资格退出目录、改为职业技能等级认定。查询入口与最新目录以人社部与技能人才评价工作网为准。

## 第二步：用招聘市场验证

- 收集十五到二十条目标岗位 JD，统计证书被提到的次数；
- 区分「要求」与「优先」：要求是硬门槛，优先是加分；
- **看有没有替代路径**：有些岗位用项目经历或工作经验可以替代证书；
- 判断结论只有三种：必须考、可以考（加分）、不用考。

判断方法与「不要为了证书而考证」见 [法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates) 与 [不要为了证书而考证](../../book/02-在学校里先把基础打好.md#certificate-not-for-certificates)。

## 第三步：算投入产出

| 维度 | 要问的问题 |
| --- | --- |
| 时间 | 备考周期多长？会不会挤压更重要的证据（项目、实习、论文）？ |
| 金钱 | 报名费、培训费、教材费、可能的差旅费；有效期多长？ |
| 机会成本 | 同样的时间投在项目或实习上，回报是否更高？ |
| 有效期与维护 | 是否需要继续教育、年审、注册？ |
| 地域与身份 | 是否只在本国有效？跨地区使用是否需要重新认证？ |

## 常见的四类证书

- **准入类**：不考不能干，优先级最高。例如教师资格、注册会计师（部分岗位）、注册建筑师、执业医师等——**报考条件（学历、专业、年限）必须逐条核对官方公告**；
- **行业认可类**：协会或国际组织认证（如部分 IT、金融、项目管理认证）。价值取决于目标企业是否真的看，**用 JD 验证**；
- **技能等级类**：职业技能等级证书，联网可查（技能人才评价工作网），常与补贴、落户积分等地方政策挂钩；
- **培训机构证书**：行业协会、商业机构或平台颁发的培训证明。多数时候等于「上过一门课」，写进简历时要写清学到的具体能力而不是证书名字。

**关于「证书能挂靠」「包过」以及培训机构承诺的通过率，一律按风险处理**：正规考试不会承诺通过率，挂靠多数违规。

## 证书怎么放进履历

- 在简历里写**证书名 + 发证机构 + 取得时间**，必要时加一句它能证明什么；
- 准入类证书放在显眼位置（它是资格）；
- 与岗位无关的证书不必全列；列表越长越稀释重点。

## 什么时候该停

- 已经拿到目标岗位要求的准入类证书 → 停止继续考同方向的加分证书，把时间放到经历上；
- 发现目标岗位根本不提这项证书 → 及时止损；
- 备考周期超过半年且与关键节点冲突 → 重新排期，不要两边都做一半。
