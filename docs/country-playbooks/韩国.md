# 韩国申请手册

## 院校与学制

韩国高校分国立、公立与私立。语学院（韩语进修）→ 学位课程是常见路径之一，但**不是必经步骤**：部分项目（尤其研究生）可英文授课，需要英语成绩。

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科（韩语） | 韩语能力（TOPIK）+ 高中成绩 + 材料 |
| 本科（英文项目） | 英语成绩 + 高中成绩 |
| 研究生 | 成绩、语言、研究计划与导师联系（研究型需要） |

**每所学校与专业的语言要求不同，逐校核实。**

## 政府奖学金（GKS）

韩国政府奖学金（Global Korea Scholarship）分本科与研究生项目，覆盖学费与生活津贴，有独立申请窗口与义务条款（如语言培训、成绩维持）。**以官方公告为准。**

## 签证与就业

- 学生签证（D-2 等类别）由韩国出入境管理部门管理；
- 毕业后留韩工作需要转换相应工作签证类别，规则可能调整，以官方公告为准。

## 成本与生活

学费因国立/私立差异大；首尔圈生活成本明显高于地方城市。预算方法与 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost) 一致。

## 常见误区

- 以为必须先读语学院；
- 只看学校名气不看专业与语言要求；
- 忽略奖学金义务条款与续期条件。

## 必须核实的官方入口

- 韩国法务部出入境·外国人政策本部（签证）：[https://www.immigration.go.kr/](https://www.immigration.go.kr/)
- 韩国教育部：[https://www.moe.go.kr/](https://www.moe.go.kr/)
- 韩国留学综合系统（Study in Korea，含 GKS）：[https://www.studyinkorea.go.kr/](https://www.studyinkorea.go.kr/)
- 各校国际处招生页：逐校核实
