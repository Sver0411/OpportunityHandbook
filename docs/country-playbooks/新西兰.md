# 新西兰申请手册

## 院校与学历框架

新西兰有统一的学历框架（NZQF），把证书、文凭、学位按等级排列——**判断学历层次时按 NZQF 等级看，而不是按名称**。高校以公立大学与理工学院为主。

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科 | 高中成绩、语言（部分接受国际课程成绩） |
| 授课型硕士 | 本科成绩、语言、文书 |
| 研究型 | 研究计划 + 导师接收 |

## 学生签证与毕业后工作权利

- 学生签证由新西兰移民局（Immigration New Zealand）管理，需录取通知、资金证明与保险；
- 毕业后工作权利（Post Study Work Visa）与学习等级、专业及政策相关，**规则会调整，以移民局最新公告为准**。

## 成本与生活

学费相对英国/美国低，但生活成本（尤其奥克兰住房）不低。预算方法与 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost) 一致。

## 常见误区

- 用学历名称判断层次（应按 NZQF 等级）；
- 忽略毕业后工作权利与专业/等级的绑定关系；
- 只看学费不看住房与交通。

## 必须核实的官方入口

- 新西兰移民局（签证与毕业后工作权利）：[https://www.immigration.govt.nz/](https://www.immigration.govt.nz/)
- 新西兰学历认证局（NZQA，学历框架）：[https://www.nzqa.govt.nz/](https://www.nzqa.govt.nz/)
- 新西兰教育部：[https://www.education.govt.nz/](https://www.education.govt.nz/)
- 各校招生页：逐校核实
