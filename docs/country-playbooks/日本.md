# 日本申请手册

## 先分清四个概念（最容易混）

| 名称 | 是什么 | 关键点 |
| --- | --- | --- |
| 语言学校 | 日语教育机构 | **不是大学，也不是必经步骤** |
| 研究生（Research Student） | 大学院的非学位预备身份 | 不等于中国的「硕士」 |
| 修士（博士前期课程） | 正式硕士学位课程 | 通过入试或申请制项目进入 |
| 博士（博士后期课程） | 正式博士学位课程 | 通常需研究成果 |

这四个词的混淆是本领域最常见的错误，详见 [日本页](../countries/日本.md)。

## 两条常见路线

1. **直接参加入试**：语言与研究能力达标，直接报考修士/博士（部分研究科有英文项目）；
2. **先作研究生再考**：先以非学位生身份进研究室，在导师指导下准备正式入试。

**不是唯一路径**，也不需要先读语言学校。具体到每所学校与研究科，以**该研究科的出愿要项**为准。

## 导师与入试

- 修士入试常含专业课笔试 + 面试 + 英语；备考方式按目标研究科的**过去问（历年真题）** 准备；
- 是否需要提前联系导师因研究科而异，研究型项目建议提前联系（见 [Playbook：第一次联系导师](../playbooks/第一次联系导师.md)）。

## 资助

国费（MEXT）、日本学生支援机构（JASSO）与各大学/财团的奖学金与减免。入口以官方页面为准。

## 在留资格与打工

在留资格（留学）由日本出入国在留管理厅管理；资格外活动（打工）有许可与时间限制，**超出许可范围会影响在留资格**，以官方规定为准。

## 就业与回国

在日就业需注意在留资格变更（工作类）与招聘节奏；回国发展需做学历学位认证。

## 常见误区

- 以为必须读语言学校；
- 把「研究生」当成硕士；
- 只听中介口径，不读研究科出愿要项。

## 必须核实的官方入口

- 日本出入国在留管理厅（在留资格）：[https://www.moj.go.jp/isa/](https://www.moj.go.jp/isa/)
- 日本学生支援机构（JASSO）：[https://www.jasso.go.jp/](https://www.jasso.go.jp/)
- 文部科学省（MEXT 奖学金等）：[https://www.mext.go.jp/](https://www.mext.go.jp/)
- 目标大学/研究科的出愿要项：逐校逐年核实
