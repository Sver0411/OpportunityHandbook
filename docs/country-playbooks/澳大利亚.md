# 澳大利亚申请手册

## 院校与学制

澳大利亚高校以公立大学为主，另有职业教育（VET/TAFE）体系。本科通常 3 年（部分荣誉学位 4 年）；硕士分授课型与研究型。

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科 | 高中成绩（部分接受高考成绩，按校核实）、语言 |
| 授课型硕士 | 本科成绩、语言、文书；常见 1–2 年 |
| 研究型 | 研究计划 + 导师接收 + 资助 |

## 学生签证与毕业后路径

- 学生签证（Subclass 500）由澳大利亚内政部管理，需 CoE、资金与健康保险（OSHC）；
- 毕业后临时毕业生签证（485 类）近年经历改革（年龄、时长与专业要求有调整），**以官方最新公告为准**；
- 技术移民通道（如打分制）与毕业后路径是两套体系，不要混为一谈。

## 成本与生活

学费按学校与专业差异大；生活成本（悉尼、墨尔本较高）。学生签证允许的打工时长有规定，**以官方说明为准**。

## 常见误区

- 把「毕业后能工作」当成自动获得的长期居留；
- 忽略 485 签证的改革（用旧经验判断）；
- 只比学费不比城市生活成本。

## 必须核实的官方入口

- 澳大利亚内政部（学生签证与毕业生签证）：[https://immi.homeaffairs.gov.au/](https://immi.homeaffairs.gov.au/)
- 澳大利亚教育部：[https://www.education.gov.au/](https://www.education.gov.au/)
- 各校招生页：逐校核实
- 教育部留学服务中心（回国学历认证）：[https://zwfw.cscse.edu.cn/](https://zwfw.cscse.edu.cn/)
