# 加拿大申请手册

## 院校与学制

加拿大高校分大学与学院（College，偏应用与就业导向）。本科通常 4 年；硕士分授课型与研究型，研究型需导师接收。**公立体系为主体，各省监管。**

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科 | 高中成绩、语言、部分专业需补充材料 |
| 授课型硕士 | 本科成绩、语言、文书 |
| 研究型硕士/博士 | 导师匹配、研究经历与计划、资助情况 |

## 学习许可（Study Permit）与省级差异

- 学习许可由加拿大移民、难民和公民部（IRCC）管理；
- **各省可能有额外要求**（如部分省份要求省级证明信），且近年政策多次调整（如学习许可数量上限、资金证明要求）；
- 资金证明的形式与金额有明确要求（如 GIC 类担保投资证明），**以 IRCC 最新说明为准**。

## 毕业后工作许可与居留

毕业后工作许可（PGWP）的资格与时长与学习项目、院校与政策相关；各省还有各自的省提名通道。**规则会变，必须以 IRCC 与各省官方页面为准。**

## 成本

学费因省份与学校差异明显；生活成本（尤其大多伦多、温哥华地区住房）较高。见 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost)。


## 加拿大申请要把“学校录取”和“移民想象”分开

学校项目是否适合你，首先仍然看课程、研究、导师、成本和就业。学习许可、毕业后工作许可和省级政策属于另一条制度线，规则会调整，不能把某个项目简单当成“移民项目”。

因此选校时最好维护两张表：
- 学术/职业价值；
- 身份与工作许可条件。

两张都过关，才是稳妥选择。

## 项目类型差异会直接影响结果

Course-based、thesis-based、research master、college graduate certificate 等路径不能只按“学制多久”比较。要继续确认：
- 是否有导师；
- 是否有研究产出；
- 是否含 co-op / internship；
- 项目对目标岗位是否被认可；
- 国际学生能否参与相关实习；
- 继续读博是否顺畅。

## Co-op 不是自动就业

看到 co-op 时要问：学校是保证 placement，还是提供求职支持；岗位主要集中在哪些城市和行业；国际学生的参与条件是什么。

“项目有 co-op”与“我一定能拿到实习”是两件事。

## 地域差异比很多人想得大

多伦多、温哥华、蒙特利尔以及其他省份的行业、语言、生活成本和政策环境不同。选校时要把“城市/省份”当成项目的一部分，而不是毕业后再考虑。

法语区尤其需要单独核实语言和就业条件。

## 常见误区

- 用往年政策判断今年（近两年调整频繁）；
- 忽略省级要求；
- 把「毕业后工作许可」当成自动获得（有资格条件）。

## 必须核实的官方入口

- 加拿大移民、难民和公民部（IRCC，学习许可与毕业后工作许可）：[https://www.canada.ca/en/immigration-refugees-citizenship.html](https://www.canada.ca/en/immigration-refugees-citizenship.html)
- 加拿大各省移民提名项目官方页面（逐省核实）
- 各校招生页：逐校核实
- 教育部留学服务中心（回国学历认证）：[https://zwfw.cscse.edu.cn/](https://zwfw.cscse.edu.cn/)
