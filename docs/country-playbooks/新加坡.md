# 新加坡申请手册

## 院校与学制

新加坡的高等教育以公立大学为主（自治大学），另有私立院校与合作办学项目。授课型硕士通常 1–2 年，研究型硕士与博士以研究为主并需导师接收。**具体以院校官网为准。**

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科 | 高中成绩/国际课程成绩、语言、面试（部分专业） |
| 授课型硕士 | 本科成绩、语言、文书与工作经历 |
| 研究型（MEng/PhD） | 研究计划、导师匹配、GRE/语言（部分要求） |

## 资助与服务义务

新加坡的资助体系中有**带服务义务**的项目（如部分政府资助或研究奖学金要求毕业后在当地企业服务一定年限）。**申请前务必读清资助条款**：金额、覆盖范围与义务年限。

## 学生签证与就业

- 学生签证由新加坡移民与关卡局（ICA）管理；
- 毕业后留新工作需要符合相应工作签证要求（由人力部 MOM 管理），规则会调整，以官方公告为准。

## 成本与生活

学费与生活成本较高（住房是主要开支）。预算时把住宿、保险与往返机票计入，方法见 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost)。


## 先分授课型、研究型和奖学金绑定项目

新加坡项目数量不算多，但同一学校里不同项目的资助、服务义务和就业关联差异很大。先确认：
- coursework 还是 research；
- 是否需要导师；
- 学费是否含 subsidy；
- subsidy / scholarship 是否附带服务义务；
- 项目时长与毕业要求；
- 国际学生的实际就业路径。

不要只看“学费打折”，要看它为什么打折、附带什么条件。

## 研究型项目更看导师和经费来源

PhD/MPhil 申请里，导师、项目 funding 和院系统一奖学金可能同时存在。拿到导师口头兴趣不等于 funding 已确定，最好确认正式 offer 与奖学金文件的关系。

## 就业要把“城市机会多”拆成行业

新加坡整体国际化，但岗位分布高度集中。金融、科技、半导体、生物医药、物流等行业的招聘结构与语言要求不同。

在申请前就抽样看目标岗位，确认：
- 是否普遍要求本地经验；
- 国际学生是否常见；
- 工作准证路径由谁负责；
- 课程项目和实习能否连接到行业。

## 成本判断要看住房和生活方式

国土小不代表生活成本低。住宿、通勤和校内宿舍资格会显著改变预算。预算时把“能否住校”作为单独情景，不要只用一个月均数字。

## 常见误区

- 只看排名不看专业方向与资助条款；
- 忽略服务义务的年限与违约责任；
- 用几年前的签证规则判断现在。

## 必须核实的官方入口

- 新加坡移民与关卡局（ICA，学生签证）：[https://www.ica.gov.sg/](https://www.ica.gov.sg/)
- 新加坡人力部（MOM，工作签证）：[https://www.mom.gov.sg/](https://www.mom.gov.sg/)
- 新加坡教育部：[https://www.moe.gov.sg/](https://www.moe.gov.sg/)
- 各公立大学招生页：逐校核实
