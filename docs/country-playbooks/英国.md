# 英国申请手册

## 学制与两类硕士

- 本科通常 3 年（苏格兰体系略有不同）；
- 授课型硕士通常 1 年，课程密集；研究型硕士（MRes/MPhil）与博士以研究为主，需要导师接收。

**「一年制」意味着节奏紧、几乎没有实习空白期**，选之前想清自己的目标。

## 申请机制

| 类型 | 重点 |
| --- | --- |
| 本科 | 统一申请渠道 + 个人陈述 + 推荐信（以官方渠道说明为准） |
| 授课型硕士 | 本科成绩、语言、文书；滚动录取，**早申有利** |
| 研究型 | 研究计划 + 导师沟通 + 资助 |

## ATAS 与签证

- 部分敏感专业需要 ATAS 证明（以英国政府官方页面为准）；
- 学生签证由英国政府内政部管理，材料含 CAS、资金证明、语言与医疗附加费（IHS）；
- 毕业后工作路径（如毕业生签证）规则近年有调整，**以 gov.uk 最新公告为准**。

## 成本

学费 + 生活成本（伦敦显著更高）+ 医疗附加费 + 机票。一年制项目总成本虽低于两年制，但单位时间支出高，且几乎没有合法兼职空间来补贴。见 [留学总成本](../../book/04-升学、就业还是出国.md#overseas-total-cost)。

## 常见误区

- 以为一年制硕士「省时间就等于省钱」（要算总账与机会成本）；
- 忽略 ATAS 与签证准备时间；
- 用旧政策判断毕业生签证。

## 必须核实的官方入口

- 英国政府学生签证页：[https://www.gov.uk/student-visa](https://www.gov.uk/student-visa)
- 英国政府 ATAS 说明（按专业核实）：[https://www.gov.uk/guidance/academic-technology-approval-scheme](https://www.gov.uk/guidance/academic-technology-approval-scheme)
- 英国政府毕业生签证页：[https://www.gov.uk/graduate-visa](https://www.gov.uk/graduate-visa)
- 各校招生页：逐校核实

## 一年制不等于“内容少”，关键是节奏和目标

英国授课型硕士常把课程、项目和 dissertation 压在较短周期里。它适合需要快速获得学位、换方向或进入当地求职市场的人，但也意味着找实习、求职和课程会重叠。比较项目时不要只比“是不是一年”，而要看课程密度、项目形式、career service、毕业生去向和你是否有时间同时求职。

## Taught 和 Research 路线要分开

MSc/MA 等授课型通常按统一申请流程；MRes/MPhil/研究型项目则更依赖研究计划与导师匹配。后者可能需要提前联系 supervisor。看项目名称不够，要读 assessment、dissertation/research component 和 progression 说明。

## 申请材料怎样真正拉开差距

英国不少项目是 rolling 或分轮审理，但具体机制不同。SOP/PS 要用已有经历证明你能完成课程与未来目标，而不是复述学校宣传。推荐信也应证明学术或工作能力。跨专业申请尤其要把先修课和已有证据讲清。

## 成本要把“短”带来的现金集中考虑进去

一年制虽然机会成本可能较低，但学费和生活费集中发生，伦敦与非伦敦差异也大。预算里还要考虑押金、签证、医疗相关费用、通勤和求职空档。最终金额以学校和英国政府页面为准。

## 毕业后路径要在申请前想清

如果目标是留英就业，选项目时就要同时看行业分布、雇主签证能力、招聘时间和 Graduate Route 等规则，而不是毕业后再研究。签证政策变化快，必须按当年 gov.uk 信息核实。
