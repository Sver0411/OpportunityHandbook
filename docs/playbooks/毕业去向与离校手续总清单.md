# Playbook：毕业去向与离校手续总清单

这篇是**总入口**：把分散在升学、就业、出国、考公里的事务串成一张表，细节指向已有文章。各地各校流程不同，一律以本校就业中心、教务处、学院通知与你适用的招录公告为准。

## 一、先分清三件事：毕业资格、毕业证、学位证

| 名称 | 是什么 | 由谁决定 | 常见误区 |
| --- | --- | --- | --- |
| 毕业资格 | 培养方案学分、必修课、论文/设计、体测等是否达标 | 学院与教务处审核 | 以为"修满学分"就自动毕业，忽略实践环节与论文 |
| 毕业证（学历证书） | 证明你完成学业 | 学校 | 与学位证混为一谈；结业/肄业也发证明，但不是毕业证 |
| 学位证 | 证明达到学士/硕士/博士学位水平 | 校学位评定委员会 | 以为有毕业证就有学位证；挂科、论文未过、违纪都可能影响学位 |

**四年的准备要落到这三样上**：学分（含实践与创新学分）、论文/设计、以及处分与学术诚信记录。

## 二、所有毕业生都要办的共同事项

- [ ] **培养方案核对**：总学分、必修、实践环节、创新学分，缺哪一项、什么时候能补；
- [ ] **毕业论文/设计**：开题、中期、查重、答辩、最终稿与附件归档（见 [本科毕业论文与毕业设计](本科毕业论文与毕业设计.md)）；
- [ ] **毕业资格审核**：学院初审 + 学校终审，关注公示名单与异议截止时间；
- [ ] **学位申请**：成绩、论文、外语或学校规定的其他条件；学位评定时间一般在毕业前；
- [ ] **离校手续单**：图书馆（还书、赔书）、实验室（设备与门禁）、宿舍（退宿、水电）、财务（欠费）、校园卡注销；
- [ ] **费用结清**：学费、住宿费、补考/重修费、赔偿；
- [ ] **材料留存**：成绩单（中英文）、毕业证明、学位证明、在读期间获奖与实习证明；
- [ ] **档案与户口**：见下一节，**毕业当年必须明确去向**；
- [ ] **党团组织关系**：按学校通知线上转接（如"智慧团建"），转往单位、学校或户籍地；
- [ ] **联系方式与地址**：留一个毕业后一年内可用的手机号与收件地址，很多材料会在这期间寄出。

## 三、档案与户口：2023 年后的规则

**报到证已经取消**：自 2023 年起，不再发放就业报到证，也不再作为招聘录用、落户、档案转递的必需材料（人社部发〔2023〕26 号）。**任何要求你"补办报到证"的说法都要先核实**，旧材料里的报到证继续保存即可，缺失不用补。

**档案去向**（按你的去向对号）：

| 去向 | 档案转往 |
| --- | --- |
| 机关、国有企事业单位、定向就业 | 就业单位或定向单位 |
| 非公单位就业、灵活就业、自主创业 | 就业创业地或户籍地的公共就业人才服务机构 |
| 暂未就业 | 户籍地公共就业人才服务机构，或按规定在学校保留两年 |
| 国内升学 | 录取学校（按录取通知书/调档函要求） |
| 出国留学 | 户籍地公共就业人才服务机构（多数情况），以学校与当地规定为准 |

**两条硬规则**：档案**个人不能自带和保管**；转递要按学校通知填准确接收单位与地址。

**户口**：可以迁往就业创业地（超大城市按当地规定），也可以迁回入学前户籍所在地。迁与不迁，先问清迁入地政策与家里意见。

**去向登记**：毕业去向登记是离校手续的必要环节（全国高校毕业生毕业去向登记系统），学校会统一组织填报，别拖到最后一天。

## 四、按去向：五条分支

### A. 直接就业

- **三方协议 ≠ 劳动合同**：三方是就业意向（学校、单位、学生），劳动合同才建立劳动关系；用工之日起一个月内应订立书面合同；
- **入职材料**：身份证、学历学位证明、体检报告、离职证明（如有）、银行卡；
- **档案与户口**：按上面表格对号，入职前问清单位是否接收；
- **时间冲突**：入职时间早于毕业手续时，先与单位协商报到时间，同时问学校能否提前办离校或委托他人代办；
- **社保与公积金**：入职当月是否起缴、按什么基数缴，第一个月就要问清。

细节见 [从学校走向第一份工作](../../book/06-从学校走向第一份工作.md) 与 [Offer 与合同](../job-search/Offer与合同.md)。

### B. 国内升学

- **拟录取后**：按录取单位要求交材料（政审表、体检、档案调档函）；
- **档案**：凭调档函由学校寄出，**不要自己拿**；
- **时间安排**：研究生入学报到时间可能早于本科离校，提前问两边；
- **仍需满足的条件**：毕业证与学位证通常要在入学前取得（或按录取单位规定），录取后挂科、论文未过都可能影响入学。

### C. 出国留学

- **材料**：中英文成绩单、毕业证明、学位证明、推荐信、语言成绩；离校前多开几份密封件；
- **签证与资金**：按目的国要求准备，资金证明的冻结期要覆盖签证审理；
- **保险**：多数国家要求医疗保险，注意生效日期；
- **原始文件**：毕业证、学位证、成绩单扫描件与纸质件都留好，日后学历认证与求职要用；
- **学历认证**：回国后如需认证，通过教育部留学服务中心办理，以官方要求为准。

### D. 考公、考编与其他公共部门岗位

- **资格条件**：学历、学位、专业、政治面貌、基层年限，逐条对着公告核；
- **资格复审与政审**：按公告时间提交材料，档案与组织关系要能对上；
- **应届生身份**：国考一般按"择业期两年、未落实工作单位、户口档案保留在学校或人才机构"认定；多地已放宽到 2–3 年、不限制工作经历与社保（如北京、湖北、湖南、新疆等，**以你报考的公告为准**）；
- **毕业时间**：部分岗位要求在指定日期前取得学历学位，别把答辩拖到最后一刻。

### E. 自由职业、创业或暂时没有确定去向

- **档案**：转回户籍地公共就业人才服务机构，或按规定在学校保留两年；**不要放在自己手里**；
- **社保与医保**：可以灵活就业身份参加职工社保（多数地区只能缴养老与医疗），或参加城乡居民医保；毕业当年医保衔接要问清；
- **现金流**：先算清每月最低支出与可支撑月数，再决定接活还是找工作；
- **三个月计划**：写清收入来源、技能投入、求职或接单动作，每两周复盘一次；
- **保留后路**：保留应届身份的可能性（档案、社保、就业协议），别为了短期收入把后续报考资格弄丢。

## 五、时间线：毕业前、毕业当月、离校后

| 阶段 | 硬性事项（有截止日） | 建议提前做 |
| --- | --- | --- |
| 毕业前 3–6 个月 | 论文/设计中期、学位申请材料、就业协议或录取确认 | 成绩单、证明文件多开几份；问清档案与户口流程 |
| 毕业前 1 个月 | 答辩、查重、毕业资格公示、去向登记 | 离校手续单逐项跑；退宿与设备归还 |
| 毕业当月 | 领证、档案转递、户口迁移、党团关系转接 | 扫描所有证书与材料；确认收件地址 |
| 离校后 1 个月 | 入职/入学/落户/社保起缴 | 核对档案是否到达；确认医保与社保状态 |

**硬事项与软事项的区别**：有明确截止日、错过要等下一年或产生违约的，是硬事项（答辩、学位申请、去向登记、档案转递、入职报到）；其余尽量提前，但不影响资格。

## 六、必须向学校/单位确认的问题

问学校（就业中心/教务处）：

1. 我们学校的毕业去向登记在哪填、什么时候截止？
2. 档案由谁寄、寄到哪、多久能查到（有没有查询单号）？
3. 户口迁移证怎么开，迁往地址写什么？
4. 三方协议违约怎么处理，是否影响再次领取？
5. 离校手续单有哪些部门要盖章？

问单位/录取单位：

1. 是否接收档案与户口？接收地址与联系人？
2. 入职/入学报到时间能否调整？
3. 社保与公积金从哪个月起缴？
4. 需要哪些原件、哪些复印件？

## 七、毕业材料归档清单

- [ ] 毕业证、学位证（原件 + 扫描件 + 复印件）
- [ ] 成绩单（中英文，密封件至少 2 份）
- [ ] 毕业论文/设计最终版与附件（按学校要求归档）
- [ ] 三方协议/劳动合同/录取通知书
- [ ] 档案转递单号、户口迁移证
- [ ] 党团组织关系转接记录
- [ ] 获奖、实习、项目证明
- [ ] 体检报告、接种记录（出国或入职可能用）

## 八、毕业后第一个月做什么

1. 查档案是否到达（打接收单位电话或线上查询）；
2. 确认社保/医保状态（单位是否起缴、灵活就业是否已参保）；
3. 核对劳动合同或录取材料上的信息（岗位、薪资、报到日期）；
4. 把毕业材料统一存到一个云盘文件夹，命名规范；
5. 写下未来三个月要完成的三件事，设一个复盘日。
