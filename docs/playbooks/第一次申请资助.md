# Playbook：第一次申请奖学金或研究资助

不要先写申请文书。第一步是确认：**这笔钱到底资助谁、资助什么、你是否真的符合资格。**

## 先读官方规则并做资格表

至少记录：
- 申请对象；
- 国籍/身份；
- 学历阶段；
- 专业或研究方向；
- 成绩/语言等条件；
- 需要谁提名；
- 截止时间；
- 覆盖内容；
- 服务、回国、报告或其他义务；
- 是否允许与其他资助叠加。

任何一项不确定，优先向项目办公室或资助机构确认，不用论坛帖子补空白。

## 把“为什么给你钱”翻译成评审证据

不同资助目标不同：
- merit：学术/能力表现；
- need-based：经济需求；
- research：问题、方法与可行性；
- mobility/travel：活动价值与预算；
- leadership/community：影响与贡献。

先找官方 selection criteria，再为每条准备证据。不要写一篇万能个人陈述投所有项目。

## 预算要和活动对应

研究或 travel funding 尤其要写清楚：
- 钱花在哪；
- 为什么需要；
- 有没有更低成本替代；
- 哪些已有资源可以覆盖；
- 如果只拿到部分资助，计划如何调整。

“越多越好”的预算通常比有依据的预算更弱。

## 推荐信/导师支持要提前准备材料

如果需要推荐或导师确认，给对方：
- 资助项目链接；
- 截止时间；
- 评审标准；
- 你的简历；
- 你希望对方能具体证明的经历；
- 提交方式。

不要只发一句“老师能帮我写推荐信吗”。

## 提交前做一次反向审查

假设你是评审，只看材料能否回答：
- 为什么是这个人；
- 为什么是这个项目/活动；
- 为什么现在；
- 钱为什么这样花；
- 结果如何验证；
- 有什么风险。

任何一个答不出来，就回到对应材料补证据。

## 拿到 award 后还没结束

确认：
- 实际金额和覆盖项；
- 发放方式；
- 报销规则；
- 持续条件；
- 税务/签证影响（如适用）；
- 报告义务；
- 能否与其他 funding 同时持有。

把“获奖”与“资金真正可用”分开。
