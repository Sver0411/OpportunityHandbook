# Playbook：研究生入学第一个月

节奏与排期见 [硕士阶段](../timelines/硕士阶段时间线.md) 与 [博士阶段](../timelines/博士阶段时间线.md)。这篇只讲第一个月要落地的事。

研究生入学和本科入学最大的区别：**没有人再替你排课表**。培养方案是一份文件，不是一个学期计划；导师是合作方，不是班主任。第一个月把下面四件事办完，后面两年的节奏就顺了。

所有规定与材料**以本校研究生院、院系与导师的要求为准**，各校差异很大。

## Step 0 · 报到前（1–2 周）

1. **确认报到时间、校区与住宿**。研究生校区常与本科不同，别按本科印象走；
2. **档案与组织关系**：应届生由学校转递，往届生需要调档函；党员团员关系同样要转；
3. **先给导师发一封邮件**。内容三条就够：我是谁、我什么时候到、入学前你希望我先读什么或做什么。不要写长信，也不要空手问"老师我需要准备什么"；
4. **查一遍培养方案**（多数学校在研究生院网站或迎新系统可下载），把关键时间点先看一眼，带着问题去报到。

## Step 1 · 报到第一周：把手续办完

| 要办的事 | 去哪 | 备注 |
| --- | --- | --- |
| 报到注册、学籍信息核对 | 院系研究生教务 | 姓名、专业、导师、学习形式要核对 |
| 校园卡、门禁、网络账号 | 信息中心 | 没有账号进不了实验室、查不了文献 |
| 宿舍与工位 | 后勤/院系 | 工位比宿舍更影响科研效率 |
| 培养方案与选课系统 | 研究生院系统 | 确认选课开放与截止时间 |
| 奖助学金、助教助研岗位申请 | 研究生院/院系 | 有申请窗口，错过要等下一学期 |
| 医保与体检 | 校医院 | 部分学校要求入学体检 |

**第一周就要问清的两个电话**：院系研究生教务的办公电话、导师或师兄师姐的联系方式。后面所有"不知道找谁"的问题，都能从这两个入口解决。

## Step 2 · 第一个月的四件事

### 一、把培养方案读成一张日期表

不要只数要修多少学分。要读出五个日期：

1. **学分与必修环节**：课程之外通常还有学术活动次数、社会实践、教学实践（助教）；
2. **开题的学期与要求**：什么时候必须开题、开题报告要不要查新或外请专家；
3. **中期考核**：是不是分流节点、看什么材料；
4. **学位申请的成果要求**：几篇、什么级别、署名与单位要求；
5. **送审与答辩的校内截止**：什么时候交论文、盲审几份、学位评定委员会一年开几次会。

第 4 项如果要求发表，**从投稿到见刊的周期要倒推**——这比课程安排更早地约束你的选题。细节见 [硕士阶段](../timelines/硕士阶段时间线.md)。

### 二、与导师的第一次正式谈话

不是"老师好，我来了"，而是一次有准备的对话。带四个问题去：

- **方向**：组里现在有哪几条线，我可能从哪条进入；
- **节奏**：你期望的汇报频率是什么（每周/每两周），用什么形式（当面/文档）；
- **标准**：毕业需要达到什么，组里对投稿与署名的惯例是什么；
- **资源**：数据、设备、经费、合作者，我需要提前准备什么。

谈完写一段纪要发给导师确认。这不是形式主义——**把口头共识写成文字，是后面避免误会最有效的方式**。

### 三、课程与学分规划

- 把难度高的必修课尽量前置，给后面论文期留出整块时间；
- 避免同一学期堆三门以上硬课，研究生课程的阅读量常被低估；
- 想清楚哪些课"必须学好"（与方向相关、可能出论文），哪些"及格即可"。

### 四、进组与起步

- **先复现，再创新**：找组里一篇已完成的工作，从数据到图走通，这是最快熟悉方法的方式；
- **建立文献入口**：用一个文献管理工具 + 一张"读了什么、结论是什么"的表，别靠记忆；
- **每周一次记录**：写"做了什么、卡在哪、下一步"，三行即可。三个月后它会变成你的进度证据。

## Step 3 · 第一个月结束时的复盘

用五个问题自查：

- [ ] 我能说出毕业要满足的四个硬条件，以及各自的截止时间吗？
- [ ] 我知道下一次开题（或中期）在哪个学期吗？
- [ ] 我和导师确认过汇报频率与形式吗？
- [ ] 我这学期的课表里，有没有"可以砍"的课？
- [ ] 我手上有没有一件正在推进的具体工作（不是"在读文献"）？

五问里有两问答不上，第二个月就该补，而不是拖到开题前。

## 三种特殊情形

- **导师还没定（入学后双选）**：第一个月是观察期。看三件事——近三年学生的毕业时间、组会频率、学生愿不愿意说真话。判断标准见 [选导师](../../book/04-升学、就业还是出国.md#study-choose-supervisor)。
- **跨专业入学**：先补两门本科核心课（旁听或自学），否则后面的课程会一直被动；同时把"跨学科"讲成优势而不是短板。
- **非全日制或在职**：入学就问清上课方式、出勤要求与最长学习年限，把工作排期与课程表对齐；论文阶段的时间要按"只有周末"来估。

## 第一个月检查清单

**手续**：报到注册、学籍核对、校园卡与账号、住宿与工位、医保体检、奖助申请。

**学业**：培养方案五个日期、选课确认、课程难度排序。

**科研**：导师第一次正式谈话 + 纪要、组会时间、复现任务、文献工具。

**记录**：每周三行进展、口径本（导师改过的稿子与标准说法）。
