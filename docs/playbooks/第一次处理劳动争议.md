# Playbook：第一次处理劳动争议

适用情形：欠薪、违法解除、未缴社保、加班费争议。程序与时效见 [离职与纠纷维权：时间线](../timelines/离职与纠纷维权.md)。

## 第 1 步：当天固定证据（1–2 小时）

按 [纠纷证据清单](../tools/纠纷证据清单.md) 逐项核对，优先保存会消失的东西：企业微信/钉钉聊天、考勤系统截图、内部系统里的工时记录。

**完成标志**：核心事实能用一句话说清（时间 + 对方 + 行为 + 金额），且有对应证据。

## 第 2 步：书面催告（30 分钟）

发一封邮件（抄送自己）给 HR 与直属上级：

> 主题：关于 X 月工资发放的确认
> 内容：说明欠薪月份与金额、请求在 X 个工作日内结清、请书面回复。

**要点**：只陈述事实与请求，不写情绪与评价。这封邮件是后续所有程序的起点。

## 第 3 步：走官方渠道（半天）

- 拨 12333 说明情况，问清本地的受理机构与所需材料；
- 到辖区劳动保障监察机构提交投诉（身份证明、劳动合同、欠薪事实证明）；
- 保留受理回执与经办人联系方式。

**常见结果**：监察介入后公司限期支付，多数欠薪在此解决。

## 第 4 步：写仲裁申请书（1–2 小时）

若未解决，向劳动合同履行地或用人单位所在地的劳动人事争议仲裁委员会提交：

| 部分 | 写什么 |
| --- | --- |
| 请求事项 | 支付 X 月工资 X 元、补缴社保、支付经济补偿 X 元（逐项、金额明确） |
| 事实与理由 | 按时间线写：入职时间、岗位、约定薪资、事实经过、沟通记录 |
| 证据清单 | 与请求一一对应，标注证明目的 |
| 附件 | 身份证、劳动合同、流水、聊天记录等复印件 |

**要点**：请求金额自己先算清并写明算法；不懂格式可先到窗口咨询或用免费法律咨询。

## 第 5 步：开庭准备（开庭前 3 天）

- 把证据按争议点排序，每份标注「证明什么」；
- 预演三个问题：为什么是这个金额？为什么此时提出？对方可能的抗辩是什么、如何回应；
- 若对方提出调解，先算清自己的底线（金额与时间）再答复。

## 第 6 步：结案与善后

- 无论调解还是裁决，都要求书面文件；
- 拿到钱后核对金额与到账时间；
- 处理社保补缴、离职证明与档案（见 [离职、换工作与社保衔接](../rights/离职与社保衔接.md)）。

## 三个提醒

1. **一年时效是硬线**：劳动关系终止后的欠薪争议要在一年内提出；
2. **不要签放弃声明换速度**：书面放弃后追讨会非常困难；
3. **复杂情形先咨询**：涉及工伤、竞业、股权、违法解除赔偿金时，先做一次专业咨询再决定路径。
