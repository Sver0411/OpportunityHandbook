# Playbook：大学生兼职与校园诈骗风险

诈骗的核心不是"你笨"，而是**对方掌握了你缺的东西**：缺钱、缺机会、缺信息。这篇只讲两件事：**转账前怎么核**、**已经出事怎么止损**。

## 一、兼职与求职：八种常见结构

| 类型 | 话术 | 真实结构 | 判断信号 |
| --- | --- | --- | --- |
| 刷单返利 | "先垫付，完成任务连本带佣返还" | 前几单小额返现建立信任，之后要求大额垫付 | 任何要求你先付钱的"任务" |
| 押金/服装费/培训费 | "入职先交 300 元押金，满一个月退" | 收费后拖延或失联 | 正规用工不向劳动者收押金 |
| 虚假招聘 | "高薪、轻松、无需经验、日结" | 岗位不存在，或与实际严重不符 | 薪资明显高于市场且门槛极低 |
| 冒充招聘方 | 假冒 HR、学校老师、企业名义 | 用私人号联系、发假工牌与假合同 | 官方渠道查不到该岗位 |
| 出租/出借账户 | "借你银行卡走个账，给你 500" | 你的账户被用于洗钱，你可能承担法律责任 | 任何"借卡、借号、借身份" |
| 实习名义贷款 | "先交培训费，入职后从工资扣" | 诱导签培训贷/分期，课没上完债已上身 | 要求下载借贷 App、签分期 |
| 付费内推/保录用 | "交钱保进大厂，不进全退" | 收钱后失联，或退费条件极苛刻 | 正规内推不收费 |
| 虚假竞赛/证书 | "交报名费即获奖，证书可用于加分" | 奖项无认可度，证书不被承认 | 主办方查不到、评奖无标准 |

**一条通用规则**：**任何要求你先付钱、先垫付、先借出账户的"机会"，默认拒绝。**

## 二、资助与校园场景

| 场景 | 话术 | 怎么做 |
| --- | --- | --- |
| 假助学金通知 | "你获得 3000 元助学金，先交 200 元手续费" | 正规资助不收费；去学生资助中心当面核 |
| 假辅导员收费 | 头像、昵称与辅导员一致，私聊收班费/材料费 | 打电话给辅导员本人或班里核实；班费走公开渠道 |
| 冒充同学借钱 | "我手机丢了，先帮我转 2000，明天还" | 用另一个渠道（电话/当面）确认 |
| 二手交易/兼职群 | 低价转让、押金保留、扫码付款 | 走平台担保交易，不私下转账 |
| 验证码/人脸识别 | "帮我收个验证码""对着镜头眨眨眼" | 验证码与生物信息等于你的身份，不外借 |

## 三、转账前的四步核验

1. **找独立入口**：不用对方给的链接或二维码，自己搜学校官网、企业官网、招聘平台官方页面；
2. **核主体**：企业查工商登记（国家企业信用信息公示系统）；学校部门打官网公布的电话；
3. **问收费依据**：收什么费、依据是什么、能不能开票、退费条件写在哪；
4. **交叉验证**：至少用一个对方控制之外的渠道确认（学校老师、官网电话、平台客服）。

四步里任何一步走不通，就停。

## 四、已经出事：按情形止损

### 1. 刚刚转账

- **立刻联系银行/支付平台**：说明被骗，申请紧急止付、冻结对方账户；转账后越快越有可能拦住；
- **保留凭证**：转账记录、订单号、对方账号、聊天记录，全部截图；
- **拨打 110 报警**，或到就近派出所报案；涉及电信网络诈骗可拨 96110 咨询/举报；
- 不要因为"金额小、怕丢人"不报警——报案记录也是后续处理的依据。

### 2. 银行卡/支付账户信息泄露

- 立即修改密码、关闭免密支付、挂失或换卡；
- 查近期交易，发现异常立刻争议处理；
- 若账户被用于他人走账，尽快向银行与公安说明，保留你不知情的证据。

### 3. 身份证件/个人信息泄露

- 记录泄露了哪些信息（身份证号、手机号、人脸、学籍）；
- 关注是否出现异常贷款、注册、绑卡；必要时查询个人征信报告；
- 向学校保卫处与辅导员报备，涉及冒用身份可报警。

### 4. 对方要求"再转一笔才能退款"

**这是二次诈骗的典型话术**。停止转账，保存记录，报警。任何"解冻费、保证金、税费"都是同一个剧本。

### 5. 被威胁、骚扰

- 不单独见面，保存聊天与录音；
- 告诉可信任的人（同学、辅导员、家人）；
- 涉及人身安全直接报警；涉及校园内人员，同时向学校保卫处/学生工作部门反映。

### 6. 平台或商家欺诈

- 平台内举报 + 要求平台披露商家信息；
- 消费者纠纷拨 12315；网络违法与不良信息可向 12377 举报；
- 涉及金额较大或拒不处理，走报警或诉讼。

**不要承诺"一定能追回"**：能否追回取决于资金流向、止付速度与案件侦办，没人能保证。

## 五、证据留存清单

- [ ] 对方账号/手机号/微信号/QQ/邮箱
- [ ] 聊天记录（完整截图，含时间）
- [ ] 转账记录（银行流水、支付凭证、订单号）
- [ ] 招聘页面/广告截图（含网址）
- [ ] 合同、协议、收据（拍照）
- [ ] 通话录音（合法取得）
- [ ] 报案回执/受案编号

**保存方式**：原图存本地 + 云盘各一份，不要只留在聊天窗口里。

## 六、兼职风险检查清单（接活前逐项打勾）

- [ ] 招聘信息能在企业官网/正规平台查到
- [ ] 不收取任何押金、服装费、培训费、材料费
- [ ] 不要求下载借贷 App、不签分期
- [ ] 不要求出借银行卡、支付账户、手机号、身份证
- [ ] 工作内容具体（做什么、在哪、几小时、谁带）
- [ ] 报酬写清金额、结算周期与方式（日结/月结、转账还是现金）
- [ ] 有书面协议或至少聊天记录明确约定
- [ ] 工作地点是公开场所，第一次不单独赴约
- [ ] 告诉一位同学或家人你去哪、几点回

任一项不满足，先别去。

## 七、给家长/室友的一段话（可直接转发）

> 学校不会通过私聊收学费、班费或助学金手续费；正规兼职不收费、不借卡；任何"先转账再返利"都是诈骗。遇到拿不准的，先打学校官网电话或 110/96110 核实。
