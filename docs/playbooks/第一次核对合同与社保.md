# Playbook：第一次核对合同与社保

适用时机：**拿到书面 Offer 之后、签字之前**。核对清单见 [劳动合同要看哪些条款](../rights/劳动合同要看哪些条款.md)。

## 第 1 步：先要电子版（10 分钟）

- 向 HR 要合同的电子版，说「想先看一下条款，明天回复」——这是常规请求，不必解释理由；
- 同时确认：Offer 里写的岗位、薪资结构、报到时间是否与合同一致。

**完成标志**：手里有一份可搜索的合同文本。

## 第 2 步：按清单逐条对照（30 分钟）

| 要核对的 | 具体问题 | 记下答案 |
| --- | --- | --- |
| 签约主体 | 与我签约的公司全称，与我会去工作的公司是否一致？ | |
| 试用期 | 多长？试用期薪资是多少（不得低于约定工资的 80% 且不低于当地最低工资）？ | |
| 薪资结构 | 基本/绩效/奖金各占多少？发放日？绩效按什么算？ | |
| 社保与公积金 | 从哪个月开始缴？**缴纳基数**按什么口径？公积金比例多少？ | |
| 工时 | 标准工时还是其他？加班怎么认定与结算？ | |
| 解除与违约金 | 有没有服务期、竞业、违约金条款？补偿标准写了吗？ | |
| 工作地点 | 是否写得很宽（如「公司指定」）？ | |

## 第 3 步：用一句话问清三件事（微信或邮件都行）

- 「社保和公积金的缴纳基数按什么计算？是税前工资还是按最低基数？」（追问基数是最关键的一步）
- 「试用期薪资与转正后的差异是多少？转正时间具体是哪一天？」
- 「绩效奖金的考核周期与历史实际发放情况大概是怎样的？」

**要点**：问基数不是不信任，而是常规问题；对方回避或含糊，本身就是信息。

## 第 4 步：把口头承诺落到书面

- 把面试中谈过的条件（岗位、薪资结构、报到时间、是否远程/弹性）用邮件复述给 HR：**「按今天沟通，我理解的是……，如果无误我这边就确认」**；
- 对方回复确认后，把邮件存档（这一封邮件的价值高于任何口头承诺）。

## 第 5 步：签字与归档

- 签完自己留一份原件或扫描件；
- 与 Offer、入职通知一起放进同一个文件夹；
- 入职当月结束前，到人社 App 查一次参保记录，确认基数与月份对得上。

## 这一步做完你会得到什么

一份可以随时取用的劳动关系材料包（合同、Offer、承诺邮件、参保记录），
它在换工作、贷款、生育报销、劳动争议等场合都会被用到。
