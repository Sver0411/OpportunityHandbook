# 赛后整理与复用

比赛结束后的两天决定这次参赛是「一次经历」还是「一份长期资产」。

## 尽快做的四件事

1. **归档产出**：代码、数据、报告、演示材料、截图，统一放进一个目录并写清版本；
2. **写一页复盘**：题目与评分项、我们的方案、结果、卡点、下次改什么；
3. **转成可展示形态**：把作品整理成作品集条目或一页案例（问题—动作—结果—限制）；
4. **记录人名与角色**：队友、指导老师、评委给过的具体意见——这些是后续申请与求职时的素材。

拖过一两周，细节就只剩下「参加过一个比赛」。

## 复盘的结构

| 项 | 内容 |
| --- | --- |
| 目标与评分项 | 我们以为要做什么、实际权重是什么 |
| 我们的方案 | 关键取舍与理由 |
| 结果 | 得分/名次/未获奖的原因（能问就问） |
| 卡点 | 哪一步最耗时、为什么 |
| 下次改 | 具体三条 |

**「未获奖的原因」值得主动问**：评委或组织方通常愿意给一句反馈。

## 转成作品集与简历

- 作品集条目：问题 → 你的角色 → 方法 → 结果（数字）→ 限制；
- 简历 bullet：一句问题 + 一句动作 + 一个可核对的结果；
- 面试准备：按 [项目面试：从第一句开始的追问链](../job-search/项目面试.md) 准备被追问的部分（尤其「你负责什么」）。

未获奖也可以写：写清过程与产出，而不是写「参与」。

## 下届是否再参加

判断依据：

- 这次的核心卡点是能力问题还是时间问题？能力问题可以在一年内补齐，时间问题换赛事更划算；
- 奖项在你的目标通道里是否被认可（本校认定目录、目标单位）；
- 你是否有更好的替代（项目、实习、科研）。

连续参赛但不复盘，等于每年重复同样的错误。

## 自检

- 我的产出归档了吗？别人能看懂吗？
- 我写下了至少三条「下次改」吗？
- 我能用一段话讲清「我在这个团队里做了什么」吗？
