# 复试与申请面试

复试与申请面试考的是**你是否真的做过、能不能讲清、匹不匹配**，不是记忆力。

## 先读官方文件

国内复试：目标院校研究生院公布的复试办法（形式、权重、专业课范围、材料清单）。海外面试：项目页面的面试说明与常见流程。**所有准备以此为准**。

## 五类问题与准备要点

### 1. 自我介绍（1–3 分钟）

结构：我是谁（学校、专业、年级）→ 我做过什么（一两件具体的）→ 我想做什么（方向）→ 为什么申请这里（一句）。

不要背简历，不要从小学讲起。

### 2. 项目与研究经历深挖

按 [项目面试：从第一句开始的追问链](../job-search/项目面试.md) 准备：为什么做、为什么这么设计、有没有别的方案、怎么验证、失败过什么、你负责哪部分。

**跨专业或经历较少时**：把课程项目、自学成果讲成完整过程（问题—方法—结果—限制），同样有效。

### 3. 专业问题

国内复试常考本科主干课与目标方向基础；海外面试可能问研究相关的基础概念。复习方式：按清单过一遍核心课，能当场推导，不背结论。

### 4. 研究匹配（research fit）

- 你读过我们组/项目的哪篇工作？具体哪个部分与你相关？
- 你的经历如何支持你在这里做研究？
- 你为什么选这个方向（用经历回答，不用感受）。

### 5. 反问

准备两三个能显示判断力的问题：组里近两年的主要方向是什么？新生第一年通常做什么？如果方向调整，决策流程是怎样的？

## 答不上来怎么办

不要编。三种可用的答法：

- 说清已知的相邻知识，再说明未知部分；
- 给出你会如何查清（哪份文档、什么方法）;
- 直接承认「这部分我没有系统做过」，并给出一个可验证的推理。

面试官对编造的容忍度远低于对「不知道」的容忍度。

## 国内复试与海外面试的差异

| | 国内复试 | 海外申请面试 |
| --- | --- | --- |
| 形式 | 差额面试，常含笔试 / 专业面 / 英语环节 | 多为导师或委员会面谈，偏研究匹配 |
| 权重 | 由院校复试办法规定 | 由项目与导师决定 |
| 语言 | 中文为主，可能含英语环节 | 全英文 |
| 关键 | 专业课 + 材料真实性 | 研究问题与匹配度 |

## 材料与细节

提前确认材料清单（成绩单、政审表、证件、语言成绩）、提交时间与形式（线上/线下）。线下复试要算好差旅与时间。

## 自检

- 我的一分钟自我介绍能脱稿吗？
- 我的项目追问链能答三层吗？
- 我能说出一篇目标导师的具体工作并指出与我的关联吗？
