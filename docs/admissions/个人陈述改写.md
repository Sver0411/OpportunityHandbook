# SOP / PS：从空洞到具体

个人陈述要回答的只有三个问题：**你想做什么、你为此做过什么、为什么是这个项目。** 评审要的是证据，不是抒情。

## 差版本诊断

> 从小我就对人工智能充满热情。大学期间我努力学习，成绩优异，积极参加各类活动，锻炼了团队协作能力。我希望能到贵校深造，为实现人生理想打下坚实基础。

问题：没有一件事是具体的。「热情」无法验证，「成绩优异」没有数字，「团队协作」没有事件，「贵校」可以换成任何学校。这类文字的唯一效果是占满字数。

## 第一轮修改：换成事实

> 在本科阶段我做过两件相关的事：一是复现了 X 方法在 Y 数据集上的结果，过程中发现原论文的预处理顺序会影响结论，我记录了这一差异；二是为课程项目实现了 Z 系统，用 A 指标把处理时间从 12 分钟降到 4 分钟。这两件事让我确认自己更愿意做「把方法落地并验证」的工作。

改动：每句话都能指向一个具体动作或数字。

## 第二轮修改：加上判断与方向

> 我关注的是「小样本条件下的稳定性」这一类问题。在复现 X 时我发现，报告里的提升在不同数据划分下并不稳定，这个现象我在报告里单独写了一节。我希望在硕士阶段继续研究：在什么数据条件下，这类方法才可靠，以及如何刻画这个边界。贵校 A 实验室近两年的 B 工作正是在做条件刻画，我在读它时注意到它对相似度指标的处理方式与我的实验假设接近。

改动：给出了方向、判断依据，并**具体指向了项目里的某个人或某项工作**。

## 十个句子级改写对照

| 差 | 好 |
| --- | --- |
| 我热爱这个领域 | 我为它投入了 X 个月，完成了 Y |
| 成绩优异 | 专业排名前 X%，核心课均分 Y |
| 有团队协作能力 | 在 Z 项目中协调三人分工，按时交付 |
| 贵校学术氛围浓厚 | 我读了 A 的 B 论文，其中 C 部分与我的问题相关 |
| 我学习能力强 | 我用三个月自学 D 并完成 E |
| 我希望提升自己 | 我希望解决 F 问题，因为它影响 G |
| 我的缺点是追求完美 | 我的短板是 H；我用 I 方式弥补 |
| 我从小就对 X 感兴趣 | 我第一次接触 X 是在 J，之后做了 K |
| 贵校是我的梦想 | 我选择它是因为 L（课程/导师/资源） |
| 我会努力学习 | 入学后我计划做 M，并已准备 N |

## 不同项目怎么定制

- 授课型：强调课程与职业目标、你能带来什么；
- 研究型：强调研究问题、方法与匹配的导师；
- 换方向：一段解释动机（用经历，不用感受）+ 一段证明已具备基础（课程、项目、自学成果）。

**每所学校都要重写「为什么是它」那一段。**

## 自检

- 我的每一段有没有一个可核对的事实？
- 「为什么是这个项目」里，有没有出现只有这所学校才成立的细节？
- 删掉形容词之后，还剩多少信息？
