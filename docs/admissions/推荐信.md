# 推荐信：怎么拿到一封有力的信

推荐信的价值来自**具体**：推荐人能否写出你做过什么、遇到问题怎么处理、在同期学生中处于什么位置。头衔只在第一句起作用。

## 找谁写

优先级排序：

1. 带过你**具体工作**的人（课题、实习、项目）——能写细节；
2. 上过课且给过你反馈、记得你的人；
3. 头衔高但与你没有共事经历的人（效果通常最弱）。

一封来自了解你的青年教师的细节信，常常比一封大牌教授的模板信有用。

## 强信与弱信的差别

| | 弱 | 强 |
| --- | --- | --- |
| 内容 | 「该生学习认真，态度端正」 | 「他在 X 问题上的实验设计与我的预期不同，但结果更好，说明他有独立判断」 |
| 量化 | 无 | 「在同期 30 名学生中排前 2」 |
| 具体事件 | 无 | 一次失败与改进、一次主动提出的方案 |
| 可核对 | 无 | 指向论文、代码库、报告 |

## 给推荐人的材料包

提前四周以上，一次发齐：

```
1. 我的简历 / 成绩单
2. 我在你手下做过的具体工作清单（项目名、时间、我负责的部分、结果）
3. 申请清单：项目名称、方向、截止日期、提交方式
4. 我想被强调的三件事（一句话一条）
5. 提交方式的说明（在线系统链接、是否需要机构邮箱）
```

这不是「代写」，而是**帮推荐人节省回忆成本**——他仍然自己写，只是写得更具体。

## 时间线与提醒

- T-6 周：口头确认意愿（问「你愿意写吗，能否写强推荐」）；
- T-4 周：发出材料包；
- T-2 周：确认进度，问是否需要补充材料；
- T-1 周：礼貌提醒（附截止日期）；
- 截止后：感谢并告知结果。

**不要**：临截止才问、一次让同一位老师写十所学校却不给清单、把「愿意写」当成「会写强推荐」。

## 自己这边要做的事

- 让推荐人看到你的成长：定期的进展汇报、一次有质量的成果；
- 在材料里提供「能写进信里的事实」（数字、事件、对比）；
- 如果推荐人要求你自己起稿，也要写成事实清单，不要写成赞美散文。

## 自检

- 我的推荐人知道我具体做过什么吗？
- 我给的清单里有没有可核对的结果？
- 我是否在截止前留出了提醒的余地？
