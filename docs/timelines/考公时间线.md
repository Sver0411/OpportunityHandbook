# 考公时间线

判断见 [考公、选调与事业单位](../../book/01-先决定下一步往哪里走/01-认识你面前的几条主要路线.md#paths-public-sector)；操作见 [考公与考编怎么准备](../../book/05-备考与应试/09-考公与考编怎么准备.md)、[笔试：行测与申论](../../book/05-备考与应试/10-笔试：行测与申论.md)、[面试与后续环节](../../book/05-备考与应试/11-面试与后续环节.md)；资料用 [岗位筛选表](../tools/岗位筛选表.md) 与 [Playbook：第一次准备考公笔试](../playbooks/第一次准备考公笔试.md)。

**一个前提**：公考的公告、岗位表、分数线与各环节时间**每年由国家公务员局与各省人事考试网重新发布**，本条时间线写的是阶段顺序与相对节奏，不是固定日期。国考公告见国家公务员局（http://www.scs.gov.cn/），事业单位见中国人事考试网（http://www.cpta.com.cn/），省考见各省人事考试网（认准 .gov.cn 域名，逐省核实）。

## 两条主线：国考与省考

| | 国考（中央机关及直属机构） | 省考（省级公务员） |
| --- | --- | --- |
| 公告与报名 | 通常在前一年秋天 | 多在春季，部分省份下半年还有一次 |
| 笔试 | 通常在公告后一个多月 | 报名后约 1–2 个月 |
| 成绩 | 次年初 | 笔试后 1–2 个月 |
| 面试与后续 | 成绩后 1–3 个月 | 成绩后 1–2 个月 |
| 报考条件 | 统一公告，部分岗位有专项要求 | 各省不同，**专业目录与基层年限口径逐省不同** |

**同时准备两个方向是可以的**：公告时间不冲突，但备考内容有共通部分（行测与申论），详见 [笔试：行测与申论](../../book/05-备考与应试/10-笔试：行测与申论.md)。

## 按阶段倒排

### 阶段一：定方向（报名前 3–6 个月）

- 确认自己要考国考还是省考、哪一类卷、考哪几科；
- 查专业目录，确认自己的专业对应哪个名称/代码（见 [岗位表怎么读](../../book/05-备考与应试/09-考公与考编怎么准备.md#exam-job-table)）；
- 确认应届身份与基层年限口径（见 [应届身份与基层年限怎么算](../../book/05-备考与应试/09-考公与考编怎么准备.md#exam-fresh-grad-and-years)）。

**这一阶段最容易被跳过，而它决定后面能不能报。**

### 阶段二：公告与报名（公告发布后 1–2 周内）

- 读公告正文，把报名、审核、缴费、准考证、笔试日期抄进日历；
- 下载岗位表，用 Excel 四步筛到十几行；
- 报名并完成缴费——**缴费未完成视为报名无效**。

### 阶段三：笔试（报名后 1–2 个月）

- 按周排期，做真题定位，主攻两三个模块；
- 考前一周只做真题与错题，不刷新题。

### 阶段四：成绩与进面（笔试后 1–2 个月）

- 关注成绩与进面名单；
- **同步准备面试**，不要等进面通知再开始（见 [面试与后续环节](../../book/05-备考与应试/11-面试与后续环节.md)）。

### 阶段五：面试、体检、考察、公示、入职（成绩后 2–5 个月）

- 面试前两周集中练题、录音复盘；
- 资格复审的材料提前一周准备（证明需要盖章）；
- 体检前避免熬夜与剧烈运动；
- 考察阶段提前与现单位/学校沟通；
- 公示期保持低调。

**这一阶段常跨三四个月**，期间你一直处在「不确定」状态。做决定时要把这段时间的收入与机会成本算进去。

## 硬截止清单（错过通常无法补救）

| 环节 | 说明 |
| --- | --- |
| 报名截止 | 不能补报 |
| 资格审查改报窗口 | 极短 |
| 缴费截止 | 忘缴 = 报名无效 |
| 准考证打印 | 有时间窗口 |
| 笔试 | 固定 |
| 资格复审材料提交 | 通常只给一两天 |

**这五项是公考最常见的翻车点**，详见 [从报名到上岸的完整流程](../../book/05-备考与应试/09-考公与考编怎么准备.md#exam-apply-to-onboard)。

## 错过了这一次怎么办

| 情况 | 应对 |
| --- | --- |
| 错过报名 | 等下一次公告（国考与部分省考一年一次，部分省考一年两次） |
| 报名了没缴费 | 一般无法补缴，按公告为准 |
| 笔试没去 | 视同缺考，等下一次 |
| 进了面试没通过 | 继续积累，等下次；经验对面试帮助很大 |
| 体检政审被卡 | 针对具体原因准备，下次注意 |

**不要把「错过一次」当成终点**：公考的窗口一年只有一到两次，合理安排优先级比抓住某一次更重要。

## 什么时候不该照这条时间线走

- 你的目标岗位专业目录口径与往年不同（**逐年核对**）；
- 你在同一时期还有校招、考研、实习等并行安排——先分主线，见 [可以同时准备几条路线](../../book/04-升学、就业还是出国/01-先决定主线.md#fork-parallel-tracks)；
- 你是省考某省的定向招录、服务基层项目等特殊类别——政策口径逐省不同，以本省公告为准。
