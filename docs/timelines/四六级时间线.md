# 四六级时间线

判断见 [四六级与校内英语](../../book/02-在学校里先把基础打好/05-语言.md#english-cet)；操作见 [四六级分项怎么练](../../book/02-在学校里先把基础打好/07-四六级怎么准备.md#cet-section-training)、[四六级报名与考试流程](../../book/02-在学校里先把基础打好/07-四六级怎么准备.md#cet-apply-process)；排期用 [四六级备考排期表](../tools/四六级备考排期表.md)，步骤见 [Playbook：第一次考四六级](../playbooks/第一次考四六级.md)。

**一个前提**：四六级按**考次**组织，报名与考试由**学校统一组织**。考次数量、资格口径、报名方式、耳机要求、成绩单领取时间**各校不同，一律以本校教务处当考次通知为准**。考试本身的官方信息见教育部教育考试院（https://cet.neea.edu.cn/）。

## 为什么必须倒排

四六级时间线比考研简单，但**更容易被错过**，原因有两个：

1. **报名窗口短**，通常只有几天，且不通过个人渠道通知——只在班级群、教务通知里出现；
2. **错过报名等半年**，一年只有固定的考次次数。

所以这一条时间线的重点不是「学多久」，而是「别错过报名」。

## 按考次倒排

### 考前 8–12 周：决定要不要考、查规定

- 确认校内是否把四级与**毕业/学位**挂钩（教务处文件，见 [校内规定说不过就不给毕业，怎么办](../../book/02-在学校里先把基础打好/08-四六级分数的用途与校内规定.md#cet-school-requirement)）；
- 确认你要考的四级还是六级、你的资格是否满足（见 [四六级分数在各场景的用途对照](../../book/02-在学校里先把基础打好/08-四六级分数的用途与校内规定.md#cet-score-usage)）；
- 做一套真题定位，把分数拆到题型上。

### 考前 6–8 周：等考次通知 + 开始训练

- **盯教务处/学院通知**：考次安排、报名时间、费用、地点会在这个窗口出来；
- 通知一出来，立刻把报名截止日与考试日写进日历；
- 按 [四六级备考排期表](../tools/四六级备考排期表.md) 开始每周计划：听力精听 + 阅读长句拆解为主。

### 考前 2–4 周：报名 + 缴费

- 按学校要求提交报名信息；
- **缴费必须完成**，未缴费视为报名无效；
- 确认考试地点与耳机要求（部分考场提供耳机，部分要求自带）。

### 考前 1 周：减量

- 不再刷新题，只看错题与卡点清单；
- 做一次整套听力保持手感；
- 确认准考证、证件与考试时间地点。

### 考当天

带：二代身份证、准考证、黑色签字笔、2B 铅笔、橡皮。

### 考后 1–8 周：查分与领证

- 成绩由教育部教育考试院统一管理，学校通知与发放；
- **注意成绩单领取时间**：集中发放，错过要单独申请；
- 核对成绩单上的姓名与学号。

## 硬截止与软节奏

**硬截止（错过通常只能等下一次）**：

| 节点 | 说明 |
| --- | --- |
| 报名截止 | 不补报 |
| 缴费截止 | 未缴 = 无效 |
| 准考证/考试 | 固定 |
| 成绩单领取 | 集中发放，错过单独申请 |

**软节奏（可以调整）**：每天训练时长、做多少套真题、什么时候开始。这些影响分数，但不影响能否考。

## 三种倒排错误

| 错误 | 后果 |
| --- | --- |
| 按去年日期安排今年计划 | 考次变了，直接错过报名 |
| 只等班级群通知 | 换班、请假、通知已读的人容易漏 |
| 考前两周才开始突击 | 听力阅读来不及，成绩上不去 |

第一条最常见：**考次安排每年可能变，通知时间也可能变**。以当年通知为准，不要按经验推断。

## 什么时候不该照这条时间线走

- 你的目标是**真实英语能力**（留学、涉外岗、研究）——那应该单独练使用场景，见 [英语为什么仍然重要](../../book/02-在学校里先把基础打好/05-语言.md#skill-english)；
- 你已经确认校内**没有**四六级硬要求，且目标单位也不看——那这条时间线与你无关；
- 你在准备考研或保研——英语是其中一科但不是四六级，节奏不同，见 [考研科目复习与专业课](../../book/04-升学、就业还是出国/10-考研科目复习与专业课.md)。
