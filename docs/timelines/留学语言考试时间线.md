# 留学语言考试时间线

方法见 [雅思还是托福：按目标项目倒推](../../book/05-备考与应试.md#lang-test-choice) 与 [小分不达标、成绩复议与二刷](../../book/05-备考与应试.md#lang-test-score-issues)；排期用 [留学语言考试排期表](../tools/留学语言考试排期表.md)；申请季整体节奏见 [留学申请时间线](留学申请时间线.md)。

**前提**：考试的报名时间、考位数量、机考范围、出分周期与成绩有效期**由考试主办方定，且每年可能调整**。这条线只写**倒排方法**，具体日期一律以官方为准——雅思见教育部教育考试院（https://ielts.neea.cn/），托福见 ETS（https://www.ets.org/toefl/）。

## 一、四步倒排（核心）

```
材料截止日（多数早于申请截止日）
  ↓ 减去出分与送分周期
考试日期上限
  ↓ 减去备考周期
报名日期
```

| 步骤 | 要算出来的 | 依据 |
| --- | --- | --- |
| 1 最晚到手日 | 目标项目要求语言成绩在手的日期 | 项目官网的申请材料清单 |
| 2 出分周期 | 考试日 + 出分天数 + 送分天数 | 官方当年说明（会变） |
| 3 备考周期 | 按你的起点水平定（见排期表） | 模考或上次成绩 |
| 4 报名与考位 | 报名开放窗口与考位余量 | 官方报名系统 |

**常见错误是按「我准备好了」定考期**，而不是按截止日倒排。前者容易错过投递窗口，后者不会。

## 二、考期选择的三个约束

| 约束 | 说明 |
| --- | --- |
| 考位数量 | 热门城市与周末考位有限，要早约 |
| 考位范围 | **不同考位可投递的学校范围可能不同**，报名前确认目标项目是否接受 |
| 场次冲突 | 与实习、工作、其他考试撞车时，可选范围变小 |

**一次约两场**（不同月份）是常见做法：第一次当尝试，第二次当缓冲。第二次也要早约——考位满了就没了。

## 三、二刷与复议的时间位置

| 动作 | 时间位置 | 注意 |
| --- | --- | --- |
| 二刷 | 第一次之后 2–3 个月 | 太短提升有限，太长状态回落 |
| 成绩复议 | 出分后尽快 | 有时限与费用，多数只有一次机会 |
| 换项目 | 越早越好 | 有的项目分批录取，早申请更有利 |

**关键**：如果时间紧，**先按现有成绩投**，别把希望押在复议上——等复核再送分往往赶不上材料截止（见 [小分不达标、成绩复议与二刷](../../book/05-备考与应试.md#lang-test-score-issues)）。

## 四、申请季的三种时间冲突

| 冲突 | 应对 |
| --- | --- |
| 申请截止在出分之前 | 考试往前挪一个考期 |
| 材料截止比申请截止更早 | **以材料截止为准**倒排 |
| 需要多次送分 | 提前查清送分耗时（官方当年说明） |

## 五、什么时候不要按这条线走

- 你的目标是**真实英语能力**（涉外岗、研究、汇报）而不是申学校——那应该练使用场景（见 [英语为什么仍然重要](../../book/02-在学校里先把基础打好.md#skill-english)）；
- 目标项目接受校内语言测试或语言班证明——先确认，可能不必考；
- 你在准备四六级或考研英语——那是另一条线，节奏与用途都不同（见 [四六级怎么准备](../../book/05-备考与应试.md)）。
