# 博士申请时间线

判断与方法见主线 [博士](../../book/07-当职业开始出现分岔.md#research-phd-worth-it)。


博士申请与硕士不同：**导师与经费往往比项目截止日期更早决定结果**。

## 提前 12–18 个月：定研究方向

- 明确想研究什么、国内还是海外、哪个组在做这个方向。
- 读目标导师近三年的论文，判断方向是否真的匹配。

## 提前 9–12 个月：是否需要联系导师

- 对**明确要求导师接收、导师制较强，或项目页面建议提前联系**的项目，尽早联系潜在导师：附简历、成绩单与研究兴趣，具体到为什么找他。
- 对**委员会制招生**（由招生委员会统一评审）的项目，先看项目官方说明是否鼓励提前联系；不鼓励时把精力放在研究计划与推荐信上。
- 国内「申请考核制」院校的差异更大：有的院系要求先确定导师意向，有的按统一材料评审，**以目标院系当年招生办法为准**。

## 提前 3–9 个月：递交与面试

- 准备 Research Proposal、推荐信（研究型项目通常要 2–3 封）。
- 面试会深挖你的研究经历：做过什么、为什么这样做、结果怎么解释。

## 录取后：确认资助

- 确认奖学金 / 助研岗位的覆盖范围与年限，这是博士能不能安心读完的关键。
