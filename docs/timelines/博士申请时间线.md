# 博士申请时间线

判断与方法见主线 [博士](../../book/07-当职业开始出现分岔.md#research-phd-worth-it)。


博士申请与硕士不同：**导师与经费往往比项目截止日期更早决定结果**。

## 提前 12–18 个月：定研究方向

- 明确想研究什么、国内还是海外、哪个组在做这个方向。
- 读目标导师近三年的论文，判断方向是否真的匹配。

## 提前 9–12 个月：是否需要联系导师

- 对**明确要求导师接收、导师制较强，或项目页面建议提前联系**的项目，尽早联系潜在导师：附简历、成绩单与研究兴趣，具体到为什么找他。
- 对**委员会制招生**（由招生委员会统一评审）的项目，先看项目官方说明是否鼓励提前联系；不鼓励时把精力放在研究计划与推荐信上。
- 国内「申请考核制」院校的差异更大：有的院系要求先确定导师意向，有的按统一材料评审，**以目标院系当年招生办法为准**。

## 提前 3–9 个月：递交与面试

- 准备 Research Proposal、推荐信（研究型项目通常要 2–3 封）。
- 面试会深挖你的研究经历：做过什么、为什么这样做、结果怎么解释。

## 录取后：确认资助

- 确认奖学金 / 助研岗位的覆盖范围与年限，这是博士能不能安心读完的关键。

## 各阶段要完成什么

| 阶段 | 任务 | 说明 |
| --- | --- | --- |
| 提前 12 个月 | 确定方向、筛选导师与项目 | 方向不清晰时优先读文献，而不是先写文书 |
| 提前 9–12 个月 | 联系导师（导师制项目）、准备语言与标化 | 委员会制项目先看项目说明是否鼓励联系 |
| 提前 6–9 个月 | 写研究计划/个人陈述、约推荐信 | 研究计划需要与导师方向匹配 |
| 提交后 | 面谈、补充材料 | 面谈常见形式：学术报告 + 提问 |
| 录取后 | 比较资助、签证与入学 | 资助条款（助教职责、年限）必须逐条看清 |

## 硬截止与软节奏

**硬截止**：项目申请截止（博士多为固定批次）、推荐信提交、奖学金申请窗口、签证与入学注册。

**软节奏**：联系导师的时间、研究计划的修改轮次、面谈准备。

## 申请不顺利时怎么办

- **导师不回复**：间隔 7–10 天礼貌跟进一次，同时并行联系其他导师；不要只押一位；
- **没有研究经历**：优先补一段可展示的研究工作（复现报告、论文、暑研），比再考一次标化更有用；
- **研究计划写不出**：把范围缩小到「一个能在一年内做完的小问题」，并与目标导师的方向挂钩；
- **全被拒**：常见出路是先读硕士（研究型优先）、做一年研究助理（RA）、或先就业再申请——三条都要同时评估成本，见 [升学还是工作](../../book/04-当你开始面对第一次重要分流.md#fork-study-or-work)。

## 材料与核实点

- 项目官网的申请要求（是否需要提前联系导师、是否要求研究计划）；
- 资助页面（奖学金、助研岗位、是否需要额外申请、有无义务）；
- 目标国家的签证与资金证明要求（见 [常用官方来源清单](../sources/常用官方来源清单.md)）。
