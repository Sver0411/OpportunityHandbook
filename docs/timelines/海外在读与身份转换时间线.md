# 海外在读与身份转换

申请结束不等于排期结束。留学这条路真正紧的几年是**在读期间**：课程要维持身份、实习要提前申请许可、毕业后的工签有窗口期，而求职的启动时间比多数人以为的早一整年。

判断要不要出国、去哪，见 [留学值不值得](../../book/04-升学、就业还是出国.md#overseas-is-it-for-me) 与 [国家和地区怎么选](../../book/04-升学、就业还是出国.md#overseas-choose-country)。这篇只排时间。

一个前提要先说清：**各国的制度差别极大**，同一句话在美国成立，在英国、加拿大、澳大利亚可能完全不同。所以下面给的是"每类节点要在什么时候查、查谁"，具体天数一律以学校国际学生办公室与移民主管部门的当年规定为准。

## 先确认四件事（入学第一个月）

| 要确认的 | 为什么它先于课程 | 去哪确认 |
| --- | --- | --- |
| 签证类型与工作权利 | 能不能实习、每周能工作几小时、校内校外是否不同，直接决定你的排期 | 签证页、学校国际学生办公室（ISSO/ISS） |
| 项目时长与实际毕业时间 | 一年制与两年制的求职窗口差一整年 | 项目手册、院系教务 |
| 实习许可怎么申请 | 有的需提前数月、有的与课程学分绑定 | 国际学生办公室的书面说明 |
| 毕业后的工作许可与转换路径 | 决定你在毕业前多久必须开始找工作 | 移民主管部门官网 |

这四项在 Orientation 期间就能问完，但多数人拖到要实习时才问，那时已经来不及。

同时把生活侧的手续办掉：本地手机号、银行账户、税号或社保号（如适用）、医疗保险、住址登记（部分国家强制）。这些不是"生活琐事"，**没有税号或社保号，很多实习无法入职**。

## 第一学期：把身份维持住

在读期间最容易被忽略的一条：**身份是靠注册学分和成绩维持的**。

- 全日制学分要求：低于下限可能被视为不合规，休学、退课都要先问国际学生办公室；
- 成绩要求：部分项目与签证身份挂钩，出现学术警告要立刻处理；
- 打工时限：校内工作与校外工作规则不同，超时打工是常见风险，代价可能是身份失效。

这一学期还有一件正事：**选课要为求职让路**。把难度高的必修课尽量前置，给毕业前的求职季留出可支配时间。

## 暑期：实习许可要提前几个月申请

暑期实习是海外求职的关键一环，但它不是一个"投简历"的动作，而是一个**许可申请 + 雇主配合 + 学校审批**的流程。

| 步骤 | 大致提前量 | 常卡在哪 |
| --- | --- | --- |
| 确定实习形式（与专业相关、是否计学分） | 提前一学期 | 部分许可要求实习与专业直接相关 |
| 拿到雇主 offer 与录用信 | 提前数月 | 很多公司按统一时间线发实习 offer |
| 向学校提交许可申请 | 提前数周到数月 | 学校处理需要时间，不接受加急 |
| 获批后再入职 | — | 未获批就上岗属于违规 |

**顺序不能颠倒**：先有 offer，再申请许可，获批后才上岗。反过来做（先上岗再补许可）在很多国家是直接违规。

## 毕业前一年：求职季比毕业早一整年

这是整条时间线上最反直觉的一段。多数国家的校招按"毕业前一年"启动：

- **两年制硕士**：入学后的第一个秋天就是秋招季，此时你才刚适应课程；
- **一年制硕士**：入学即进入求职季，几乎没有缓冲；
- **本科**：倒数第二年的暑期实习决定毕业时的选择面。

所以"到了国外先安顿下来，第二年再找工作"这个节奏，在一年制与两年制项目里都会错过主窗口。正确的顺序是：**第一学期就开始投，把课程与求职并行**，而不是等语言和生活都顺了再说。

具体投递节奏可参照 [校招](校招时间线.md)，只是把"国内秋招"换成目标国家的招聘季。

## 毕业前后：工签窗口与失业期

毕业不是终点，是一段有期限的身份过渡。要盯的是三个数字：

| 数字 | 含义 | 后果 |
| --- | --- | --- |
| 申请窗口 | 毕业后工作许可可以开始申请的时点（有的允许毕业前就申请） | 错过窗口 = 失去合法工作身份 |
| 生效与失业期上限 | 许可生效后累计可以处于无工作状态的天数 | 超过上限，身份可能终止 |
| 转换或延期的时间点 | 从实习身份转工作签证的时间线（如抽签类制度） | 错过一轮 = 等一年 |

不同国家的对应制度名称不同（美国是 OPT 与 H-1B，英国是毕业生签证，加拿大是毕业后工签，澳大利亚是临时毕业生签证），**规则与天数每年都可能调整**，一律以移民主管部门官网与学校国际学生办公室的书面说明为准，不要用学长学姐的经验年份。

一条实务建议：**在毕业前 6 个月做一张"身份日历"**，把申请开启日、截止日、失业期起算点、转换节点写在同一张纸上。这类日期一旦错过，通常没有补救通道。

## 硬截止与软节奏

**硬截止**：签证与身份相关的一切（注册学分、许可申请、工签窗口、失业期上限）、学期注册与退课期限、实习许可获批时点、招聘季的关键批次。

**软节奏**：语言提升、社交与社团、旅行、额外的课程或证书。

**关键原则**：身份类日期不可协商，学业与求职的安排都要绕着它排。反过来排（先安排实习再去补许可）是这类路径上最常见的翻车方式。

## 进度落后怎么补

- **错过了实习许可的申请时间**：先问学校能否改为与课程绑定的形式，或换成校内工作 / 研究助理；不要在没有许可的情况下上岗。
- **秋招没投**：春招与中小公司补录是主要入口；同时把毕业时间往后调一学期（如制度允许）也是一个真实选项，代价是学费与生活成本。
- **毕业时还没找到工作**：先算清失业期还剩多少天，把"能合法留下的时间"当作倒计时；同时准备回国或转第三国的方案，不要等到期限最后一周。
- **身份转换没抽中**：先看是否有延期、换雇主、读书续签等合法路径，再看回国的时间点与应届身份认定。
- **课程与身份冲突**：任何退课、休学、转项目，先问国际学生办公室，再动手。

## 官方核实点

- **学校国际学生办公室**：工作许可申请流程、学分与身份要求、毕业前后的书面指引（这是最直接的一手来源）；
- **移民主管部门**：美国的 USCIS、英国的 UKVI、加拿大的 IRCC、澳大利亚的内政部——工签种类、申请窗口、失业期规则；
- **目标国家招聘季信息**：公司校招页面与学校 career center 的年度日历；
- **中国驻当地使领馆教育处**：回国学历认证与留学人员相关手续的官方说明。

上面提到的所有天数与窗口都会变，引用时请以官网当前版本为准；本页不提供固定天数。

## 一个真实的人怎么用这条时间线

小许，两年制 CS 硕士，美国某州立大学。他的问题是"什么时候开始找工作"，答案是入学后第二个月。

| 时间 | 他做的事 | 时间线上的位置 |
| --- | --- | --- |
| 入学第 1 个月 | Orientation 上问清 CPT/OPT 规则，办了社保号与银行账户 | 确认四件事 |
| 第 1 学期 | 把两门难课前置，同时投第二年暑期实习 | 求职季 = 入学即开始 |
| 第 1 学期末 | 拿到一家公司的暑期实习 offer | 实习 offer |
| 寒假 | 向学校提交实习许可申请，等批复 | 许可提前量 |
| 暑期 | 实习十周，结束后拿到 return offer | 实习 → 转正 |
| 第 2 学期 | 确认毕业时间，毕业前按窗口提交 OPT 申请 | 工签窗口 |
| 毕业前后 | 用 OPT 入职；同期准备下一轮的工签抽签 | 身份转换 |

他复盘时提到一个细节：同组有位同学暑期才想起来申请许可，学校处理来不及，只能放弃那次实习——**能力没问题，是排期问题**。

## 本月就能做的一件事

打开学校国际学生办公室的网站，把"实习许可"与"毕业后工作许可"两页各存一份 PDF，标出申请开启日与截止日。
