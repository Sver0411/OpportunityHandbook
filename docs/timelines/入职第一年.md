# 入职第一年：钱与权益的时间线

第一年最容易出的问题不是能力，而是**该确认的没确认**：社保按最低基数缴、个税扣除没填、应急金没建、合同条款没看清。这条线按时间排开。

判断分配比例见 [第一个月的工资怎么分配](../../book/15-钱与生活基本盘/01-拿到钱的第一年.md#money-first-salary-split)；社保与个税的口径见 [社保到底保什么](../../book/15-钱与生活基本盘/02-社保公积金与税.md#money-social-insurance)。

## 时间线

| 时间 | 要做的动作 | 完成标志 |
| --- | --- | --- |
| 签合同前 | 逐条核对合同（主体、试用期、薪酬结构、工时、社保、解除与违约金） | 拿到电子版并留一份归档 |
| 入职当月 | 确认参保月份与缴纳基数、公积金比例 | 与 HR 书面确认，次月查到记录 |
| 入职第一个月 | 在个税 App 确认专项附加扣除（房租、赡养老人等） | 工资条上出现扣除项 |
| 第一个发薪日 | 核对实发与合同口径（试用期比例、绩效算法） | 有工资条或系统截图存档 |
| 前三个月 | 建应急金（先划出固定比例），开始记录支出一个月 | 有一个独立账户与 30 天记录 |
| 第 3–6 个月 | 查一次参保与公积金记录；确认医保能否正常使用 | 参保记录连续、医保可结算 |
| 第 6 个月 | 复盘一次「钱去了哪」并调整；确认是否有涨薪节点 | 三个最大支出项清楚，调过一次 |
| 转正时 | 确认转正薪资、绩效口径与社保基数是否调整 | 与 HR 确认并核对当月工资 |
| 年底 | 看总包（含奖金、公积金、补贴）与次年规划；次年 3–6 月做年度汇算 | 完成汇算，明确次年目标 |

## 三件最常被漏掉的事

1. **社保基数**：按最低基数缴会直接影响公积金贷款额度、生育津贴与将来养老金，入职时就问清；
2. **个税专项附加扣除**：不填等于先多缴、年底再退，早填早受益；
3. **合同与口头承诺的差距**：面试谈的条件没有写进合同或书面确认时，事后很难主张。

## 本月就能做的一件事

打开个人所得税 App，确认或补填专项附加扣除信息，并核对上个月的实发工资是否与合同口径一致。
