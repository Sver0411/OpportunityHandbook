# 校招时间线

判断与方法见主线 [校招是怎么运作的](../../book/05-从学校走向第一份工作.md#campus-recruiting-timeline)。


校招的窗口相对集中，但**不存在全国统一日历**。下面给出的是常见范围，用于倒排准备；每家公司的实际启动时间、批次划分与截止日期差异很大，**以目标单位当年的招聘公告为准**。

## 暑期前后：提前批（常见范围：6–8 月）

- 部分大厂与研究所提前发 offer，竞争相对小，但流程快，要提前准备好简历。
- 没拿到也不影响秋招，把它当成一次练手。

## 秋季学期：秋招集中期（常见范围：9–11 月）

- 8 月底更新简历，9 月开始大批投递；网申、笔试、面试轮次密集，用追踪表管理。
- Offer 决策也集中在这里：比较、谈薪、签约三方。

## 次年春季：春招与补录（常见范围：3–4 月）

- 岗位数量通常少于秋招，但对考研出分后转就业的人仍是一条现实路径。

## 全年通用的三条

- 内推可能帮助简历进入内部流程或被查看的机会，但不同公司机制不同，**不保证筛选通过或进入面试**。
- 每次面试后记录被问倒的问题，下一场就不重复踩坑。
- 签约前看清楚违约条款与报到时间。
