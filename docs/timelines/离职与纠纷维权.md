# 离职与纠纷维权：时间线

维权最怕的不是没道理，而是**时间过掉、证据散掉**。这条线按天排开，每一步都标出时限。

流程与证据细节见 [被欠薪与劳动仲裁](../rights/被欠薪与劳动仲裁.md) 与 [离职、换工作与社保衔接](../rights/离职与社保衔接.md)。

## 时间线

| 时间 | 动作 | 时限与要点 |
| --- | --- | --- |
| 发现当天 | 固定证据：合同、工资条、银行流水、打卡记录、沟通记录 | 越早越好；离职后账号与考勤记录常无法导出 |
| 1–3 天内 | 书面催告（邮件或带记录的渠道），说明金额与期限 | 留痕，不要只口头沟通 |
| 一周内 | 内部正式提出（HR、工会、上级），要求书面答复 | 为后续程序保留过程记录 |
| 两周内 | 若未解决：拨打 12333 或到劳动保障监察机构投诉 | 监察可责令限期支付 |
| 一个月内 | 申请调解（企业调解委员会、基层调解组织、工会） | 调解不成可转仲裁 |
| **一年内** | 申请劳动仲裁（时效：知道权利被侵害之日起一年；欠薪在劳动关系终止后一年内提出） | 仲裁前置，不收费；提交材料按受理机构清单 |
| 仲裁受理后 | 45 日内一般应作出裁决（复杂案件可延长） | 关注开庭与举证期限，逾期提交可能不被采纳 |
| 裁决后 | 不服裁决的，在法定期限内向人民法院起诉 | 具体期限以裁决书告知为准 |
| 全程伴随 | 社保衔接、离职证明、档案与户口处理 | 见 [离职、换工作与社保衔接](../rights/离职与社保衔接.md) |

## 三个提醒

1. **一年时效是硬线**：超过之后即便有理也难以通过仲裁获得支持（劳动关系存续期间的欠薪争议不受该限制，但终止后要在一年内提出）；
2. **材料按清单准备，不按印象**：不同情形（欠薪、违法解除、加班费、工伤）需要的证据不同，提交前先确认清单；
3. **不要签放弃声明换速度**：一旦书面放弃，后续追讨会非常困难。

## 什么时候要谨慎

- 涉及工伤、竞业、股权、违法解除赔偿金等复杂情形，先做一次专业咨询（12348 法律援助、工会职工法律援助或执业律师）；
- 与用人单位协商解除时，补偿金额与支付时间务必要写进协议，口头承诺不作数；
- 本页只给顺序与时限，不构成法律意见。

## 本月就能做的一件事

把你手上的劳动关系材料（合同、最近三个月的工资条与流水、考勤截图）整理到一个文件夹并做一次云端备份——不用等到出事。
