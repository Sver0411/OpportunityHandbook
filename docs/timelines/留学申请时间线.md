# 留学申请时间线

判断与方法见主线 [国家和地区怎么选](../../book/04-当你开始面对第一次重要分流.md#overseas-choose-country)。


留学申请按**入学前一年的秋季递交**倒排，语言成绩是最容易卡住的一环。

## 入学前 18 个月：定方向

- 确定国家、学位类型（授课型 / 研究型）与专业方向。
- 查目标项目的硬要求：GPA、语言、先修课程、作品集。

## 入学前 12–15 个月：语言与材料

- 考出语言成绩（有效期通常两年，注意别考太早）。
- 找推荐人沟通；研究型项目开始套磁与准备 Proposal。

## 入学前 9–12 个月：递交

- 9–12 月是多数项目的主申请窗口，英国多为滚动录取，越早越有利。
- 文书反复改：SOP 讲清「为什么是这个项目、为什么是你」。

## 入学前 3–6 个月：结果与行前

- 收到 offer 后注意接受截止日期与押金。
- 办签证、体检、住宿；核对学历认证与成绩单寄送要求。
