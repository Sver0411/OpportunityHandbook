# 留学申请时间线

判断与方法见主线 [国家和地区怎么选](../../book/04-当你开始面对第一次重要分流.md#overseas-choose-country)。


这一页给的是**研究生申请的通用倒排框架**，不是统一申请日历：不同国家、不同学位类型（授课型 / 研究型 / 博士）以及不同入学季的时间线差别很大。用它来安排准备节奏，具体日期以目标项目当年官网为准；各国家制度差异见 09 专题手册的国家与地区各页。

## 入学前 18 个月：定方向

- 确定国家、学位类型（授课型 / 研究型）与专业方向。
- 查目标项目的硬要求：GPA、语言、先修课程、作品集。

## 入学前 12–15 个月：语言与材料

- 考出语言成绩（有效期通常两年，注意别考太早）。
- 找推荐人沟通；研究型项目开始套磁与准备 Proposal。

## 入学前 9–12 个月：递交

- 9–12 月是不少项目的主申请窗口；部分国家与项目采用滚动录取（先到先审），越早递交通常越有利，但也有项目只在固定批次评审——以目标项目官网说明为准。
- 文书反复改：SOP 讲清「为什么是这个项目、为什么是你」。

## 入学前 3–6 个月：结果与行前

- 收到 offer 后注意接受截止日期与押金。
- 办签证、体检、住宿；核对学历认证与成绩单寄送要求。
