# 保研时间线

判断与方法见主线 [保研](../../book/04-当你开始面对第一次重要分流.md#study-baoyan)。


保研的节奏可以这样理解：**资格来自前几年的累积，选择集中在最后一个学年**。下面给出的是常见流程，帮助倒排准备；每一步的具体时间、是否举办、如何计算，都由你所在学院与目标院校当年的实际办法决定。

## 大一到大三上：攒资格

- 目标是本校推免办法里的硬条件：加权排名、无挂科记录、英语成绩。
- 加分项按本校细则核实（竞赛、论文、专利的认定范围逐年会变）。
- 每学期末核对一次自己在专业里的位置，别等到大三才看。

## 材料准备（贯穿大三）

- 简历、成绩单、专家推荐信、个人陈述。
- 关注目标院校是否举办**夏令营或预推免**：有的学校办，有的不办；举办时间、申请门槛与考核方式各校不同，以目标学院通知为准。

## 夏令营 / 预推免（如目标院校有）

- 这类活动通常集中在暑期到秋季之间，可以同时申请多所，注意每所的截止日期与材料要求不同。
- 拿到夏令营或预推免的意向，不等于已经录取：最终结果以**教育部推免服务系统里的正式待录取通知**为准。

## 本校资格确认与系统填报（秋季）

- 本校公示推免名单与成绩排名，先确认自己是否具备推免资格（排除条款、成绩口径都以本校办法为准）。
- 在教育部推免服务系统中完成志愿填报与待录取确认；系统开放时间、可填志愿数量与锁定规则每年由官方公布，逾期未确认视为放弃。
