# 保研时间线

判断与方法见主线 [保研](../../book/04-当你开始面对第一次重要分流.md#study-baoyan)。


保研的窗口比多数人以为的早：**名额由前三年成绩决定，机会集中在大三暑假**。

## 大一到大三上：攒资格

- 目标是本校推免办法里的硬条件：加权排名、无挂科记录、英语成绩。
- 加分项按本校细则核实（竞赛、论文、专利的认定范围逐年会变）。
- 每学期末核对一次自己在专业里的位置，别等到大三才看。

## 大三下学期（3–5 月）：准备材料

- 简历、成绩单、专家推荐信、个人陈述。
- 关注目标院校的夏令营通知，通常 5–6 月发布，7 月举办。

## 暑假（7–8 月）：夏令营

- 这是拿外校 offer 的主战场，可以投多所，注意每所的截止日期不同。
- 九月推免是补录机会，但名额明显少于夏令营。

## 大四上（9 月）：确认资格与接受 offer

- 本校公示推免名单，确认自己的资格。
- 在系统里确认接受哪所学校的录取，逾期视为放弃。
