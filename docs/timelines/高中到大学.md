# 高中到大学

判断与方法见主线 [选学校与选专业](../../book/01-先决定下一步往哪里走.md#choose-school-vs-major)。


出分到入学之间大约有两个月，事情不多，但有几件是**过了这个窗口就补不回来的**。

## 出分前：把选择想清楚

- 出分前按估分列一份「冲 / 稳 / 保」清单，不要等出分后再从零开始查学校。
- 每一档里都先查这四件事：目标专业今年的录取位次、学费与住宿、转专业政策、城市与通勤。

## 出分后 72 小时：填志愿

- 用**位次**而不是分数去比往年数据；分数线每年波动，位次稳定得多。
- 服从调剂与否要想清楚：不服从的风险是退档，服从的风险是被调到不喜欢的专业。
- 填完后核对一遍批次、时间节点和确认状态，这一年因漏确认而滑档的案例并不少。

## 录取到入学：能提前做的三件事

- **英语不要断**：无论之后走哪条路，入学分级考试和四六级都会用到。
- **了解你的学校规则**：转专业、辅修、保研细则，入学后第一时间找到官方文件。
- **建立一次真实接触**：联系一位本专业的学长学姐，问清楚这个专业四年里真正在做什么。
