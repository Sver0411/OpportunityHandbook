# 高中到大学

判断与方法见主线 [选学校与选专业](../../book/01-先决定下一步往哪里走.md#choose-school-vs-major)。


从出分到入学通常有两三个月，事情不多，但有几件是**过了这个窗口就补不回来的**。下面按「出分前 / 出分后 / 录取之后」三段给出常见节奏，**具体日期一律以本省教育考试院与目标高校当年的正式公告为准**。

## 出分前：把选择想清楚

- 出分前按估分列一份「冲 / 稳 / 保」清单，不要等出分后再从零开始查学校。
- 每一档里都先查这四件事：目标专业今年的录取位次、学费与住宿、转专业政策、城市与通勤。

## 出分后：立即进入志愿填报窗口

- 用**位次**而不是分数去比往年数据；分数线每年波动，位次稳定得多。
- 服从调剂与否要想清楚：不服从的风险是退档，服从的风险是被调到不喜欢的专业。
- 填完后核对批次、时间节点与确认状态；**各省填报开始时间、截止时间、批次设置与确认方式都不同**，第一步是打开本省教育考试院当年的正式安排，不要按往年日期推算。

## 录取到入学：能提前做的三件事

- **英语不要断**：入学分级考试、四六级以及之后的多数路径都还要用英语，暑假保持手感比开学后补更省力。
- **了解你的学校规则**：转专业、辅修、保研细则，入学后第一时间找到官方文件。
- **建立一次真实接触**：联系一位本专业的学长学姐，问清楚这个专业四年里真正在做什么。

## 每一步为什么要这样做

| 步骤 | 为什么在这个时点 | 常见失误 |
| --- | --- | --- |
| 出分前估分与收集信息 | 出分后时间很短，信息要提前准备 | 出分后才从零查学校与专业 |
| 出分后立即填报 | 各省窗口只有几天 | 按往年日期推算，错过截止 |
| 录取确认 | 部分批次需要主动确认 | 忘记确认导致退档 |
| 录取后准备 | 分级考试、宿舍、转专业政策都需要提前了解 | 入学后才第一次看学校规则 |

## 硬截止与软节奏

**硬截止**：志愿填报开始与截止时间、批次确认、部分批次的征集志愿、录取通知书要求的报到材料。

**软节奏**：专业与城市的研究深度、与学长学姐的沟通时间。

## 出了问题的补救路径

- **滑档或退档**：关注本省的征集志愿（补录）批次，时间通常很短，需要盯紧官方渠道；
- **被不喜欢的专业录取**：先查该校的转专业政策（名额、成绩要求、考核方式），这比入学后被动等待更有效；
- **录取后想复读**：这是重大决定，需要考虑分数能否提升、时间成本与家庭承受度；如需放弃录取，按省级招办与学校规定办理手续；
- **想换学校但不想复读**：评估考研、专升本（专科）、转学（部分院校允许）等路径。

## 必须去官方核实的信息

- 本省教育考试院：志愿填报时间、批次、投档规则、征集志愿安排；
- 目标高校本科招生网：招生章程、专业录取规则、转专业政策、学费与住宿；
- 录取通知书与入学须知：报到材料、缴费方式、住宿申请。
