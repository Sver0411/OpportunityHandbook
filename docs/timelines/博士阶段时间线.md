# 博士阶段

判断与方法见主线 [读博期间该积累什么](../../book/04-升学、就业还是出国.md#phd-during-plan)。

博士的时间线不是"几年做完一件事"，而是一串**必须先过关才能进入下一段**的关卡：资格考、开题、中期考核、预答辩、送审、答辩。每一道不通过，改写的不是这一周的计划，而是毕业年份。

所以这条时间线要回答的不是"每天做什么"，而是三个问题：**每道关卡在哪一学期、不通过会怎样、要提前多久准备**。这三个问题都只有本校研究生院能给出准确答案，下面的位置是常见范围，用来帮你判断自己现在是超前还是落后。

## 先确认四件事

入学第一个月，把这四项从研究生院和院系文件里抄出来。四项不清楚，后面所有排期都是猜的。

1. **学制与最长学习年限**。名义学制和最长年限是两回事，最长年限才是硬约束——它决定你最多有几次重来的机会。
2. **有没有资格考（或综合考试）**。在第几学期、考几次、不通过是补考还是分流。
3. **毕业成果要求**。几篇、什么级别、署名与单位要求、是否接受录用通知或在审状态。这一项直接决定你什么时候必须开始投稿。
4. **学位论文流程**。开题在第几学期、中期考核考什么、预答辩是否强制、送审几份、走哪个平台、答辩与学位评定委员会一年几次。

第 3 项对博士尤其关键：从投稿到接收的周期常见在半年到一年，加上修改与见刊，按两年估比较稳。**如果学校要求发表才能答辩，投稿时间就要落在入学后第二年之前**，这比任何课程安排都更早地约束选题。

## 博一：把方法和问题同时立住

这一年通常被课程和资格考占去大半，剩下的时间要用来做两件不能拖的事。

- **练熟方法**。找组里一篇已完成的工作复现一遍，从数据到图到结论走通。复现是性价比最高的一次训练，也是判断"这个组的方法我能不能掌握"的最快方式，方法细节见 [科研手册](../manuals/科研手册.md)；
- **把问题问小**。博士开题最常见的失败是把题目定成"一个领域"，而不是"一个能在一到两年内回答的问题"。判断标准是一条：能不能用一句话说清"我做出什么结果，就算回答了它"。

开题的时间位置差异很大：有的学校在博一下，有的在博二上，直博与硕博连读又不同。**开题越晚，后面每道关卡都被压缩**，宁可早开、后面微调，也不要为了"想清楚"拖到最后一学期。

## 博二：第一件完整的工作与中期考核

这一年决定后面顺不顺，因为它要同时交出两样东西。

**第一件完整的工作**。从提出问题到写成可投稿的稿子，完整走一遍。见过完整流程的人，后面做任何课题都快；没走过的人，会在写作和投稿环节反复卡住。这件工作不必是博士论文的核心，但必须是**你自己能讲清每一处选择**的工作。

**中期考核**。常见安排是博二末到博三初，看的是进展而不是成果数量。要准备的材料通常包括已完成工作、下一步计划、以及导师的评价意见。它的现实意义是：**这是一个官方给你的、可以调整方向的节点**——如果主课题明显做不动，在这里改比在预答辩前改代价小得多。

这一年还要开始对外露面：投一次会议、放一次公开代码、与合作者建立联系。埋头两年不出现，毕业时会发现自己没有任何外部可见的东西。

## 博三：主成果、预答辩与送审

这是最紧的一年，几条线会同时压过来。

| 时间 | 要做的事 | 关键判断 |
| --- | --- | --- |
| 上半学期 | 主成果成稿、投稿；补齐支撑实验 | 论文的"主张"是否只有一条主线，多了就拆 |
| 送审前四到六个月 | 定稿、内部预审、按导师意见大改 | 这时还能改结构，再晚只能改措辞 |
| 送审前一到三个月 | 预答辩；提交送审材料、查重 | 预答辩的意见要真的改，不是走流程 |
| 送审期 | 等待盲审或外审结果 | 提前问清复审与重新送审的规则 |
| 答辩前一个月 | 答辩材料、演示、逐条准备提问 | 用文末的答辩演示结构示例搭框架 |

如果学制是四年，主成果的接收通常要落在博三结束前；三年制则更紧，博二就得把投稿发出去。**判断自己是否落后，不看"做了多少实验"，看"有没有一篇进入审稿流程"**。

## 最后一年：答辩与去向并行

答辩本身只是一两个小时，但它和求职完全重叠，必须并行排。

三条去向的准备周期差别很大，别用同一套材料应付：

- **高校教职**：看论文、教学经历与方向匹配，招聘批次常在前一年秋冬就启动；
- **博士后**：看导师、方向与经费，流动站与工作站的信息在中国博士后网（https://www.chinapostdoctor.org.cn/）与设站单位公告发布；
- **产业界研发**：看工程能力与项目经历，实习与内推的作用比论文更大。

一个常见错误是把求职全部推到答辩之后。答辩通过到入职之间还有离校、档案、报到等手续，见 [毕业去向与离校手续总清单](../playbooks/毕业去向与离校手续总清单.md)。

## 六道关卡：位置、后果与准备时间

| 关卡 | 常见位置 | 不通过的后果 | 什么时候开始准备 |
| --- | --- | --- | --- |
| 资格考 / 综合考试 | 博一末到博二上 | 补考，或按学校规定分流 | 入学就拿到考纲与历年范围 |
| 开题 | 博一下到博二上 | 重新开题，损失一学期以上 | 提前一学期 |
| 中期考核 | 博二末到博三上 | 限期整改，或按学校规定分流 | 提前一学期 |
| 预答辩 | 送审前一到三个月 | 修改后再次预答辩 | 提前两个月 |
| 送审 / 盲审 | 答辩前一到三个月 | 修改后复审，或顺延到下一批次 | 提前四到六个月定稿 |
| 答辩与学位申请 | 学校集中批次 | 顺延到下一次学位评定委员会会议 | 按会议日历倒排 |

这张表的用法是**倒着读**：先找到你们学校学位评定委员会今年的开会日期，往前推到送审截止，再往前推到预答辩、定稿、投稿。倒推出来的那条线上，每一个日期都比"还有几年"更能约束你。

## 硬截止与软节奏

**硬截止**：资格考、开题答辩、中期考核、送审提交、答辩与学位申请、学籍最长年限、资助与奖学金的年度考核。

**软节奏**：额外的合作论文、会议投稿数量、教学与助教投入、开源与科普。

**关键原则**：每年至少留下一件可交付的东西——一篇进入审稿的稿子、一份可运行的数据与代码、一次通过的开题或中期。**连续的"在做了但还没结果"是博士阶段最危险的状态**，因为它不触发任何警报，直到送审前才暴露。

## 卡住时怎么补

- **开题反复被否**：把题目缩到"一个变量、一个场景、一个可比较的基线"。开题要的是可完成，不是宏大。
- **主实验做不出来**：先判断是"方法不对"还是"问题本身不成立"。前者换方法，后者换问题——把失败组的数据整理成负结果与方法分析，本身可以成为一篇小论文的素材。
- **论文数量不够**：把已有工作重新切分，但要注意自我重复与学术规范，一稿多投与切分过细都属于学术不端；更稳的做法是补一个能带来新结论的增量实验。
- **盲审没过**：按意见分"必须改"与"可以解释"两类，逐条书面回应，先问清学院对修改后复审与重新送审的规定，两者时间成本差很多。
- **明显要延期**：尽早和导师、学院谈，确认延期的手续、资助与住宿安排。拖到截止前才说，能争取的空间最小。
- **不想继续了**：转硕、休学、退学都是制度内的路径，不是失败。走之前先弄清学分与学位能否转换、已发表成果的署名怎么处理、以及退学对档案与应届身份的影响。这个决定值得单独花两周想清楚，而不是在崩溃的某一晚做出。判断顺序见 [延期、换方向还是退出](../../book/04-升学、就业还是出国.md#phd-delay-or-quit)。

## 官方核实点

- **本校研究生院**：学籍与最长年限、资格考规定、开题与中期考核办法、预答辩与送审流程、学位授予实施细则；
- **院系研究生教务**：本年度批次与材料清单、盲审份数与送审平台、答辩安排；
- **学信网**（https://www.chsi.com.cn/）：查学籍与学历；学位证书查询在 https://www.chsi.com.cn/xwcx/ ；
- **中国博士后网**（https://www.chinapostdoctor.org.cn/）：博士后流动站、招收与进站政策；
- **目标单位人事处或招聘系统**：教职与研发岗的批次与材料要求。

各校在资格考、盲审份数、成果认定与答辩批次上的差别很大，上面所有位置都应以本校研究生院与院系的当年文件为准，不要用别人的毕业年份直接套。

## 一个真实的人怎么用这条时间线

小林，四年制博士（申请考核制），材料方向。博二下中期考核前，主课题的关键实验连续三次做不出预期结果。

| 时间 | 他做的事 | 关卡位置 |
| --- | --- | --- |
| 博一 | 复现组里一篇旧工作，把表征与数据处理流程走通 | 练方法 |
| 博一下 | 开题，题目是"某类材料在特定条件下的性能调控" | 开题 |
| 博二上 | 主实验三次失败，开始怀疑问题本身 | 主工作受阻 |
| 博二下 | 把失败组整理成"条件—结果"的负结果分析，投了一个方法类期刊；同时把主课题缩到一个变量上 | 中期考核 |
| 博三上 | 小文章接收；主课题有了第一条可重复的结果 | 主成果起步 |
| 博三下 | 主成果成稿投稿；预答辩 | 预答辩 |
| 博四上 | 送审、盲审通过；同期投高校教职与博士后 | 送审 + 求职并行 |
| 博四下 | 答辩、学位申请、离校 | 答辩 |

他复盘时说得最实在的一句是：**"那三次失败如果只是重做，我可能到现在还没有一篇在审的稿子。"** 让他过关的不是实验成功，而是把已经发生的失败变成了一件可交付的东西。
