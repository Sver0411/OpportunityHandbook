# 本科四年

判断与方法见主线 [学业、实践和生活怎么平衡](../../book/02-在学校里先把基础打好.md#study-life-balance)。


四年时间不够做所有事，关键是**每一学年都完成那件不可逆的事**。

## 大一：把规则搞清楚

- 摸清学校的转专业、辅修、保研细则，这些文件决定后面三年哪些路还开着。
- 英语与数学这类长周期科目不要松，它们是最难临时补的。
- 允许自己探索：参加两三个社团或活动，判断哪些值得继续。

## 大二：选定主线

- 在「保研 / 考研 / 出国 / 就业」之间做第一次倾向性选择，不用锁死，但要开始倾斜资源。
- 完成第一个**可写进简历的项目或实践**，哪怕是课程项目认真做完。
- 成绩仍然重要：保研看三年加权，大二掉队最难追。

## 大三：产出与分流

- 保研线：抓成绩与排名，参加夏令营；考研线：确定目标院校开始复习；就业线：找第一段实习。
- 科研线：进实验室，确认自己是否适合。
- 这一年结束时应能回答：我的主线是什么，备选是什么。

## 大四：执行与收尾

- 秋招、考研初试、申请递交都集中在上学期，按各自时间线倒排。
- 下学期：复试、答辩、毕业手续；把四年的产出整理成可展示的形式。
