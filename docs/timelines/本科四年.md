# 本科四年

判断与方法见主线 [学业、实践和生活怎么平衡](../../book/02-在学校里先把基础打好.md#study-life-balance)。


四年时间不够做所有事，关键是**每一学年都完成那件不可逆的事**。下面按学年给出的是常见节奏，每个人的专业、目标与起点差别很大，**不必按格执行**；涉及资格与考试的部分，以你所在学校与主管部门当年的规定为准。

## 大一：把规则搞清楚

- 摸清学校的转专业、辅修、保研细则，这些文件决定后面三年哪些路还开着。
- 英语与数学这类长周期科目不要松，它们是最难临时补的。
- 允许自己探索：参加两三个社团或活动，判断哪些值得继续。

## 大二：选定主线

- 在「保研 / 考研 / 出国 / 就业」之间做第一次倾向性选择，不用锁死，但要开始倾斜资源。
- 完成第一个**可写进简历的项目或实践**，哪怕是课程项目认真做完。
- 成绩仍然重要：保研看三年加权，大二掉队最难追。

## 大三：产出与分流

- 保研线：抓成绩与排名，参加夏令营；考研线：确定目标院校开始复习；就业线：找第一段实习。
- 科研线：进实验室，确认自己是否适合。
- 这一年结束时应能回答：我的主线是什么，备选是什么。

## 大四：执行与收尾

- 秋招、考研初试、申请递交都集中在上学期，按各自时间线倒排。
- 下学期：复试、答辩、毕业手续；把四年的产出整理成可展示的形式。

## 每学年的核心任务与判断信号

| 学年 | 核心任务 | 判断信号（做到了就说明方向对） |
| --- | --- | --- |
| 大一 | 适应学习方式、把基础课与英语打好、试一个社团或项目 | 能找到自己的学习节奏，知道哪门课吃力 |
| 大二 | 确定大致方向、开始积累第一个可展示成果 | 有一个能讲清的项目或一次真实经历 |
| 大三 | 分流准备（保研/考研/留学/就业）、争取实习或科研 | 有一条主线在推进，而不是同时准备四条 |
| 大四 | 完成分流、毕业设计、入职或升学衔接 | 有明确的下一步安排，且已有可展示成果 |

## 硬截止与软节奏

**硬截止**：考试与重修报名、四六级与考研报名、推免材料与公示、留学申请截止、校招网申与签约、毕业学分与答辩资格审核。

**软节奏**：社团与活动、项目进度、技能学习、实习投递。

**关键原则**：硬截止全部写进日历；软节奏可以砍，但**每学年至少留下一件可展示的成果**。

## 进度落后怎么补

- **大一大二成绩不理想**：先确认哪些通道还开放（考研、留学、就业），把它们对应的材料准备起来，而不是回补已经过去的排名；
- **大二还没有项目**：从「每周都会遇到的麻烦」里挑一个，两周做出最小版本；
- **大三才决定留学**：先查语言考试时间与申请截止，把语言与文书并行推进；必要时顺延一年；
- **大三才想保研**：先核对本校推免办法的资格与加分，判断是否有现实可能；不行就转向考研或就业；
- **大四学分不够**：立刻核对毕业学分要求与重修安排，这是硬约束。

## 官方核实点

- 本校教务处：学分与毕业要求、重修与转专业规则；
- 本校研究生院/学院：推免办法与夏令营通知；
- 目标院校/考试机构：报名与截止时间；
- 学校就业中心：三方协议与派遣规定。
