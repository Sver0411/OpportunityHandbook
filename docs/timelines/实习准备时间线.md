# 实习准备时间线

实习不是「想投就能投」：不同类型的实习有各自的窗口，而准备的起点通常要提前一个学期。这条线按「准备 → 投递 → 面试 → 入职」倒排，适用于第一次找实习的在校生。

判断该先做项目还是先找实习，见 [实习和项目怎么选](../../book/03-做项目、打比赛、进实验室/06-实习准备.md#internship-vs-project)；实习与研究的取舍见 [实习有什么用](../../book/03-做项目、打比赛、进实验室/06-实习准备.md#internship-worth-it)。

## 倒排时间线

| 距目标实习开始 | 做什么 | 完成标志 |
| --- | --- | --- |
| 约 9 个月 | 补齐可展示的东西：一个完整项目、一份能看的代码或作品、一次真实的问题解决 | 有一项能在面试里讲五分钟的产出 |
| 约 6 个月 | 确定目标岗位类型（研发、数据、产品、运营等），按 JD 反推要补的技能 | 有一张目标岗位清单与技能差距表 |
| 约 4–5 个月 | 写第一版简历并请人改；准备作品集或演示 | 简历能投，且知道每条写的依据 |
| 约 3–4 个月 | 开始投递：官网 + 内推 + 平台并行；建立投递追踪表 | 每周有固定投递量，记录每家的进度 |
| 约 2–3 个月 | 面试与笔试：每次面试后 24 小时内记录被问倒的问题并补上 | 面试题在自己整理，不再重复犯错 |
| 约 1 个月 | 谈时间与地点：确认每周到岗天数、是否可远程、是否影响课程或论文 | 与导师/家人沟通完成 |
| 实习期 | 按“每周写一份进展”执行；主动争取有难度的任务 | 有可写进简历的两三件事 |
| 结束前 2–4 周 | 确认留用评估方式与时间；准备复盘与总结 | 明确是否有转正机会 |

## 常见的时间误区

- **等到期末或暑假才开始**：大厂的实习窗口往往提前一季甚至半年开放；
- **只在招聘平台投**：官网与内推能显著提高被看到的概率；
- **把课程与实习对立**：多数岗位接受每周 3–4 天，提前和导师或教务沟通通常比硬扛更可行；
- **只准备技术**：行为面与项目追问同样决定结果，见 [行为面](../../book/06-从学校走向第一份工作/04-笔试与面试.md#interview-behavioral)。
