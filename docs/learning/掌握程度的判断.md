# 如何判断自己真的掌握

「学过」和「会」之间隔着一次验收。难点在于：不同能力的验收方式完全不同，用同一套测试硬套会得出错误结论。

## 编程

- **验收任务**：关掉教程，从空文件写一个能跑的小程序；给它加一个错误处理；解释关键行的作用；
- **追问**：这个数据结构为什么选它？复杂度是多少？换个输入会怎样？
- **不通过的表现**：能看懂代码但写不出来；报错就卡住。

## 数学 / 统计

- **验收任务**：不看推导，自己把关键结论推一遍；用一个真实数据算一遍并解释每个量；
- **追问**：这个方法的前提条件是什么？违反会怎样？
- **不通过的表现**：会套公式，说不出适用条件。

## 语言

- **验收任务**：读一篇目标领域的原文并说出要点；就一个话题连续说三分钟；写一段 150 字的邮件；
- **追问**：这个词在专业语境里有没有别的意思？
- **不通过的表现**：只能做选择题；遇到真实材料就退回到翻译工具。

## 工程工具（Git、构建、部署、调试器）

- **验收任务**：在一个新仓库里走完「建分支 → 改 → 提交 → 合并 → 回退」；用调试器定位一个断点问题；
- **追问**：如果合并冲突了怎么办？这个命令的副作用是什么？
- **不通过的表现**：只会复制粘贴命令，不知道在做什么。

## 写作

- **验收任务**：给一个陌生读者写一段说明，他读完能照做；把 800 字压成 400 字而不丢信息；
- **追问**：这段的中心句是哪一句？删掉会怎样？
- **不通过的表现**：堆形容词、结论藏在最后、术语前后不一致。

## 通用检验三条

1. **独立复现**：没有教程、没有别人帮忙；
2. **解释取舍**：说得清为什么这么做；
3. **说清边界**：知道它在什么情况下不成立。

三条里缺任何一条，都建议先别在简历上写「掌握」，写「了解」更安全——面试追问两层就会见底。

## 自检

- 我这门能力的验收任务做过了吗？
- 我能不能向别人讲清它的适用边界？
- 我在简历上的描述与真实水平一致吗？
