# 账号、数据与隐私

数字资产出事的特点是**补救成本远高于预防成本**。下面这份清单按「先做什么最省事、最有效」排序。

## 一、今天就该做的四件事

| 动作 | 具体做法 | 挡掉什么 |
| --- | --- | --- |
| 打开二次验证 | 邮箱、支付、社交、云盘优先；用验证器 App 优于短信 | 密码泄露后被直接登录 |
| 关键账号用不同密码 | 至少邮箱、支付、主社交三套密码互不相同 | 一处泄露被撞库到全部 |
| 用密码管理器 | 记住一个主密码即可 | 因为记不住而重复用同一个密码 |
| 关掉不必要的授权 | 逐项检查第三方登录与「便捷登录」 | 长期挂在后台的数据读取 |

## 二、身份信息与简历

- **简历会流转**：投递平台、猎头、面试群，都会留副本。因此简历里**不写身份证号、家庭住址、银行卡**，必要信息在录用阶段再提供；
- **证件照与证件复印件**：加水印或注明用途（如「仅用于 XX 公司入职」），不要裸发；
- **人脸与验证码不交给任何人**：「远程视频认证」「帮我收个验证码」几乎全是骗局；
- **查询类操作自己来**：征信、社保、学籍都在官方渠道免费查（见 [遇到纠纷找谁](../rights/遇到纠纷找谁.md)），不必找中介。

## 三、几类高频骗局

| 类型 | 典型话术 | 识别要点 |
| --- | --- | --- |
| 招聘类 | 「入职前先交培训费/押金」「先交钱买设备」 | 任何入职前收费都是红线 |
| 兼职刷单 | 「垫付后返现」 | 需要你先出钱的都不是工作 |
| 租房类 | 「看房先付定金」「租金贷」 | 未看房不付；不签不明贷款 |
| 冒充客服/公检法 | 「账户涉案」「需要你把钱转到安全账户」 | 公检法不会电话办案，更不会要求转账 |
| 熟人借钱 | 头像与声音都能伪造 | 换渠道核实（打电话给本人） |
| 付费查征信/学历 | 「付费快速查询」 | 官方渠道免费 |

## 四、出事后第一步做什么

1. **立即止损**：改密码、冻结账户、关闭支付授权、挂失卡；
2. **留证据**：截图带时间、转账记录、对方账号与话术；
3. **走官方渠道**：报警（110）、支付平台与银行客服、国家反诈中心 App；
4. **通知相关方**：如果泄露涉及公司资料或他人信息，按单位流程上报，别自己压着。

## 什么时候要谨慎

- 涉及公司数据、客户信息、未公开业务信息时，优先遵守单位的合规与保密要求，个人习惯不能覆盖它；
- 不要为了「清理干净」而把设备交给不熟的维修点而不备份与退出账号；
- 本页不涉及技术对抗（如加固设备）；如涉及高价值目标，应咨询专业安全人员。
