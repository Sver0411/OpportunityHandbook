# 城市选择与落户

时间节点见 [城市选择](../timelines/城市选择时间线.md)；判断框架见 [城市要不要纳入选择](../../book/01-先决定下一步往哪里走.md#choose-city)。

城市不是一个"好或不好"的问题，而是**四笔账**：收入、成本、落户、退路。这四笔账在不同城市的大小关系不一样，所以要分开算。

## 三类城市的真实差异

| 维度 | 一线 | 新一线/强二线 | 家乡（三四线） |
| --- | --- | --- | --- |
| 岗位数量 | 多，换工作成本低 | 中等，集中在少数行业 | 少，往往只有一两家可选 |
| 起薪 | 高 | 中等 | 低 |
| 房租占收入 | 高（常见三成以上） | 中等 | 低（常可住家里） |
| 落户 | 收紧或积分 | 多数对本科应届放开 | 基本无门槛 |
| 职业上限 | 高，但竞争激烈 | 取决于行业 | 低，但稳定性可能更高 |
| 退出成本 | 高（房租、押金、人脉重建） | 中 | 低 |

**一个反直觉的结论**：一线与强二线的"可支配结余"经常接近，差异主要在**岗位密度**与**职业上限**，而不是账面工资。

## 落户的四条路径

1. **应届生落户**：门槛最低，通常看学历与就业单位，毕业当年办理，**过期就要走别的路径**；
2. **居住证转户口**：需要社保与居住年限，常见 3—7 年，逐年累计；
3. **积分落户**：学历、社保、纳税、年龄、荣誉都算分，按年度名额排队；
4. **人才引进**：面向特定学历、职称或技能等级，条件与名额按城市公布。

**判断顺序**：先确认自己能不能走应届路径（这是唯一"一次机会"的通道），再考虑其他三条。很多人在毕业后两年才发现，自己已经错过了最省事的那条。

## 补贴：三类与两个坑

**三类常见补贴**：

- **生活/安家补贴**：一次性或分年发放，通常要求落户 + 社保连续缴纳；
- **租房补贴**：按月或按年发，要求无自有住房、租住备案；
- **购房补贴**：门槛最高，多与人才认定挂钩。

**两个坑**：

- **时限**：多数要求"毕业 N 年内"或"入职 N 个月内"申请，过期不补；
- **中途离职**：分年发放的补贴，离职或社保断缴可能停发甚至追回。

要做的动作很简单：入职第一周查人社局官网，把条件、材料、截止日抄进日历。

## 同岗不同城：一张对照表怎么填

不要只比月薪，按这五列填：

| 列 | 怎么填 |
| --- | --- |
| 到手月薪 | 扣完五险一金与个税 |
| 房租 | 通勤 45 分钟内的真实租金 |
| 通勤与餐饮 | 按月估算，含交通卡与外卖差价 |
| 落户与补贴 | 能否落、补贴金额与年限 |
| 退路 | 这座城市里，同行业还有几家可跳 |

最后一行最容易被忽略：**"只有一家公司"的城市，议价能力接近于零。**

## 什么时候该回家乡

三种情形值得认真考虑：

- **行业在家乡有对应的产业**（如本地有制造业集群、医院、学校）；
- **家庭需要照顾**，且远程支持成本高于回去；
- **职业目标本身是稳定型**（考编、教师、国企本地分支）。

三种情形不建议：

- 家乡没有你的行业，只能转行；
- 回去的唯一理由是"房价低"，但收入也低一个量级；
- 把回家当成"暂时歇一歇"，却没有时间盒。

## 换城市的成本

换城市不是换一份工作，是换一整套生活基础设施：房租押金、社保转移、档案、朋友圈、通勤路线。

**成本最低的窗口是工作 1—2 年内**：此时履历还新鲜、包袱少、用人单位愿意接受异地候选人。越往后，越依赖内推与行业人脉，跨城求职的难度上升。
