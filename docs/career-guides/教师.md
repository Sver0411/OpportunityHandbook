# 教师（中小学 / 高校 / 培训）
用一句话概括：**把一门学科的知识与思维方式，稳定地传给学生**——并且要能应付真实课堂。

## 三类岗位

| 类型 | 准入 | 特点 |
| --- | --- | --- |
| 中小学（公办） | 教师资格证 + 招聘考试（编制/合同制） | 稳定、作息与假期规律、非教学工作占比不小 |
| 高校（教职） | 学位 + 科研产出（见 [研究员 / 高校教职](研究员与高校教职.md)） | 科研与教学双线 |
| 培训 / 民办 | 教师资格证（多数要求）+ 机构考核 | 市场化、强度大、政策影响明显 |

## 招聘流程（中小学公办，大致）

公告 → 报名与资格审核 → 笔试（教育知识与学科） → 面试（试讲/说课） → 体检与政审 → 录用。**具体要求以当年当地公告为准。**

## 硬技能与准备

- 学科功底：能讲清概念与常见错误；
- 教学能力：试讲（10–15 分钟）是最常考的环节，需要练到熟练；
- 班级管理：处理课堂纪律与家校沟通；
- 证书：教师资格证（分学段与学科，注意匹配招聘要求）、普通话等级（语文科目要求更高）。

## 面试（试讲）怎么准备

- 挑一个真实教学难点（不是最容易讲的章节）；
- 结构：导入 → 讲解 → 练习 → 小结；
- 练 3 次并录音：语速、板书/课件、时间控制；
- 准备「学生答错时你怎么处理」的回答。

## 课时、班主任和评价机制要提前问清

看学校的管理风格与班主任工作强度；新手期最需要的是有经验的带教老师。

## 骨干教师、教研、管理与高校路径

骨干教师 / 学科组长、教研与课程开发、教育管理（教务/年级）、教育科技公司、转培训或教研。

## 喜欢学科不等于喜欢教学

- 以为「会做题就能教书」（课堂管理与表达同样是门槛）；
- 忽视非教学工作的时间占比（备课、批改、家校沟通、各类活动）；
- 不核对学生与家长的实际情况（地域差异很大）。

## 做一次微型教学并根据反馈改第二版

给三位真实学生讲一次 20 分钟的课（或录一次试讲），观察自己是否享受「把别人讲懂」的过程。


## “教师”内部至少有三套完全不同的职业系统

中小学教师、高校教师、职业教育/培训机构的准入、评价和日常差异很大。中小学更重课堂、班级管理与学科教学；高校还承担科研与服务；培训机构受市场和招生影响更大。

因此先确定你想教谁、在什么制度里教，再谈“适不适合当老师”。

## 真正的教学能力怎么形成

会一道题不等于会教。教学要完成：

目标 → 诊断学生起点 → 设计解释 → 练习 → 反馈 → 再教学。

一个好老师能识别“学生错在哪种理解”，而不是只重复正确答案。

可以用一次微型教学来验证：选一个概念，给不同基础的人讲，记录他们哪里没懂，再改教法。这个循环比背教学法术语更有用。

## 中小学岗位还要看课堂之外

真实工作可能包括备课、批改、家校沟通、班主任事务、教研、考试组织和行政任务。判断岗位时要问课时量、班级规模、班主任要求、评价方式和编制/合同性质。

## 高校教师不要和“只做科研”混淆

高校岗位通常同时存在教学、科研、学生指导和服务。不同学校对论文、基金、教学和聘期考核权重不同。准备这条路时应该直接查目标学校真实招聘条件，而不是只看学位门槛。
