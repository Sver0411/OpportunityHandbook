# 财务与金融分析

用一句话概括：**用数字解释业务，并支持决策**。岗位差异极大，先分清方向再准备。

## 常见方向

| 方向 | 典型岗位 | 核心工作 |
| --- | --- | --- |
| 企业财务 | 财务分析（FP&A）、会计、成本 | 预算、分析、报表与合规 |
| 审计 / 税务 | 审计助理、税务顾问 | 核查、合规、报表与税筹 |
| 金融前端 | 投行分析师、行研 | 建模、尽调、报告 |
| 金融中后台 | 风控、量化支持、运营 | 模型、数据、流程 |
| 投资 | 投资分析、PE/VC 分析 | 尽调、估值、投后 |

## 证书、模型和业务理解分别在哪起作用

- 企业财务与审计：本科可入，看重 CPA/ACCA 等证书与实习；
- 投行与行研：学历与实习门槛高（名校、强实习），工作强度大；
- 风控与量化：数理与编程能力要求高。

证书部分见 [证书值不值得考：六步判断](../certifications/判断体系.md)——**先确认目标岗位的要求，再决定考哪个**。

## 能力证据

- 一份完整的三表建模（含假设与敏感性）；
- 一份行业或公司分析报告（有数据来源与判断）；
- 一次真实的流程改进（例如把月度结账时间缩短）；
- 财务岗特别看细节与合规意识，简历上避免模糊表述。

## 面试考法

- 财务：会计基础题、案例分析（给报表找异常）；
- 金融：估值方法、财务建模测试、行业理解；
- 通用：为什么这个岗位、你怎么处理数据错误。

## 第一份岗位决定你积累哪类财务资本

看是否有轮岗与真实决策接触（只做录单与对账的岗位成长慢）；金融前端要评估强度与可持续性。

## 企业财务、投研、战略和管理的分叉

财务 BP/财务经理、投资方向、风控、转咨询或企业战略。

## 会 Excel 不等于会分析

- 只考证不做实务；
- 忽视 Excel 与建模等基本功；
- 不看行业（金融不同子行业差异极大）。

## 用公开公司做一次带情景的分析

选一家上市公司，用公开财报做一次完整分析与估值，写成 5 页报告。


## “财务”和“金融分析”不要混成一个岗位

企业财务更接近预算、核算、管理报表、经营分析与内控；证券/投研更强调行业、公司、估值和投资判断；FP&A 介于财务与业务之间；投行、资管、风控又是另一套工作。

看岗位时先问：你是在**记录和解释经营结果**，还是在**预测和判断未来价值**。两者需要的证据完全不同。

## 一份分析工作怎样从数字走到决策

成熟分析不是把 Excel 做满，而是回答：

1. 指标为什么变；
2. 是一次性还是结构性；
3. 哪个假设最敏感；
4. 管理层/投资者能做什么；
5. 如果判断错了，最早会看到什么信号。

例如收入下降 8%，不要停在同比环比。继续拆量、价、客户结构、区域、产品组合、一次性因素，再把变化映射到现金流与后续风险。

## 项目怎么证明自己不只是“会模型”

可以选一家公开公司或一个业务案例：
- 重建三张报表或核心经营模型；
- 明确关键假设；
- 做情景分析；
- 找最敏感变量；
- 写一页结论和反方证据。

重点不是“估值目标价”，而是你如何把事实、假设和判断分开。

## 证书什么时候真的重要

会计、审计、部分金融岗位的资格与职业路径差异很大。不要把 CFA/CPA/ACCA 等证书统一理解成“金融加分项”。先看目标岗位和地区是否把它当准入、晋升条件或行业信号，再决定投入。
