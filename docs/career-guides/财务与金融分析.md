# 财务与金融分析

用一句话概括：**用数字解释业务，并支持决策**。岗位差异极大，先分清方向再准备。

## 常见方向

| 方向 | 典型岗位 | 核心工作 |
| --- | --- | --- |
| 企业财务 | 财务分析（FP&A）、会计、成本 | 预算、分析、报表与合规 |
| 审计 / 税务 | 审计助理、税务顾问 | 核查、合规、报表与税筹 |
| 金融前端 | 投行分析师、行研 | 建模、尽调、报告 |
| 金融中后台 | 风控、量化支持、运营 | 模型、数据、流程 |
| 投资 | 投资分析、PE/VC 分析 | 尽调、估值、投后 |

## 招聘与门槛

- 企业财务与审计：本科可入，看重 CPA/ACCA 等证书与实习；
- 投行与行研：学历与实习门槛高（名校、强实习），工作强度大；
- 风控与量化：数理与编程能力要求高。

证书部分见 [证书值不值得考：六步判断](../certifications/判断体系.md)——**先确认目标岗位的要求，再决定考哪个**。

## 能力证据

- 一份完整的三表建模（含假设与敏感性）；
- 一份行业或公司分析报告（有数据来源与判断）；
- 一次真实的流程改进（例如把月度结账时间缩短）；
- 财务岗特别看细节与合规意识，简历上避免模糊表述。

## 面试考法

- 财务：会计基础题、案例分析（给报表找异常）；
- 金融：估值方法、财务建模测试、行业理解；
- 通用：为什么这个岗位、你怎么处理数据错误。

## 第一份工作怎么看

看是否有轮岗与真实决策接触（只做录单与对账的岗位成长慢）；金融前端要评估强度与可持续性。

## 3–5 年出口

财务 BP/财务经理、投资方向、风控、转咨询或企业战略。

## 常见误区

- 只考证不做实务；
- 忽视 Excel 与建模等基本功；
- 不看行业（金融不同子行业差异极大）。

## 低成本试法

选一家上市公司，用公开财报做一次完整分析与估值，写成 5 页报告。

## 一天通常是这样的（企业财务）

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 9:00 | 核对昨日收款与银行流水差异 | 差异要查到笔 |
| 10:00 | 更新月度滚动预测（收入、成本、费用三块） | 假设要写清 |
| 11:30 | 与业务部门确认一笔大额费用的归属期间 | 权责发生制 |
| 14:00–16:00 | 做成本结构分析：材料占比上升 3 个点 | 找驱动因素 |
| 16:00 | 把分析写成一页简报：结论 + 建议 + 依据 | 业务方只看结论 |
| 17:00 | 检查月末结账清单 | 清单化避免漏项 |

## 一次真实的面试问答（原话）

> **面试官**：给你这份报表，你觉得哪里异常？
> **候选人**：应收账款周转天数从 45 天涨到 62 天，同时收入增长只有 5%——说明不是业务扩张带来的，更可能是收款政策或客户结构变化。我会先按客户和账龄拆开看。
>
> **面试官**：如果是大客户延期呢？
> **候选人**：那要评估两件事：一是现金流影响（是否需要短期融资），二是坏账风险（是否要计提）。我都会写进简报里。
>
> **面试官**：你会用哪些工具？
> **候选人**：Excel 为主，透视表 + 简单函数足够；数据量大或需要复用时会用 SQL 取数。

**要点**：财务面试题通常是**给一份报表找异常**，考的是敏感度与拆解顺序。

## 财务分析首先是口径，不是 Excel 技巧

收入、利润、现金流、预算、估值都依赖定义。真实工作常见的是数据来自多个系统、口径不一致、业务解释与会计处理不同。分析师要能把数字追到来源，并说明假设。

## 一份分析怎么从数字变成决策

先明确决策问题，再建立驱动因素：销量、价格、成本、周转或资金成本；做基准情景和敏感性分析；最后指出哪些变量最影响结果。模型越复杂，不代表判断越好。

## 职业分叉

企业 FP&A、投研、投行、风险、审计和商业分析的日常差异很大。选方向时不要只看“金融”标签，要看产出物、工作节奏、监管/资格要求和客户是谁。
