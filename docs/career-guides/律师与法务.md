# 律师与法务

用一句话概括：**把复杂事实压缩成法律上站得住的主张，并让别人接受它。**

## 先分清三条路

| 路径 | 入口 | 日常 | 收入结构 |
| --- | --- | --- | --- |
| 律师（律所） | 法考 + 实习 1 年 + 执业证 | 检索、写文书、会见、开庭、尽调 | 授薪或提成，差异极大 |
| 法务（企业） | 校招/社招，法考加分但非必需 | 合同审核、合规、争议处理、培训 | 固定工资 + 奖金 |
| 公检法（公务员） | 公务员考试（部分岗位要求法考） | 办案、文书、提审、出庭 | 编制工资 |

三条路的准备方式不同：**律师看实习与案源能力，法务看行业理解与合同功底，公检法看考试。**

## 律师：法考只是入场券

```
法学本科（或其他专业 + 法考）
  → 国家统一法律职业资格考试
  → 律所实习 1 年（实习律师）
  → 申请执业证
  → 独立或授薪执业
```

- **法考**：通过率不高，需要系统备考；通过后才有资格申请实习；
- **实习期**：一年，收入通常很低，是这段路最难受的部分；
- **执业初期**：授薪律师拿固定工资，提成律师要自己找案源——**案源能力决定收入上限**；
- **业务方向**：诉讼（民商、刑事、行政）与非诉（IPO、并购、合规、知识产权）差别很大，非诉更看院校、英语与项目经验。

## 法务：在企业里做"内部律师"

- **日常**：合同审核（占大头）、合规制度、劳动纠纷、知识产权、外部律所管理；
- **门槛**：法律专业或法考背景，行业理解往往比法条记忆更重要；
- **优势**：作息相对稳定、收入可预期、能接触业务；
- **劣势**：晋升通道有限（法务总监是少数），重大诉讼仍要外聘律所。

## 招聘与门槛

- **律所**：看院校、法考、实习经历、英语（非诉尤其）；红圈所与精品所竞争激烈，起薪高但强度大；
- **法务**：看行业经验与合同功底，校招名额少，多在社招；
- **公检法**：看公务员考试成绩、法考（部分岗位）、政审与体检。

## 面试会问什么

- "这个案子你先查什么？"——考检索与要件思维；
- "合同里这条对谁有利？怎么改？"——法务岗必问；
- "为什么做律师/法务？"——考稳定性，律所怕培养一年就走。

## 第一份工作怎么看

律师看**带你的合伙人**：有没有案子给你做、愿不愿意教、业务方向是否有前景。法务看**行业与公司阶段**：成熟企业的合规体系能学到方法，初创公司给你更大空间但更杂。

## 3–5 年出口

- **律师**：授薪 → 独立 → 合伙人；或转法务、转合规；
- **法务**：法务专员 → 法务经理 → 法务总监；或转律所；
- **交叉方向**：合规、知识产权、劳动人事、上市公司董秘办；
- **公共方向**：仲裁机构、法律援助、法学教育。

## 常见误区

- **以为过了法考就能赚钱**：法考只是资格，案源与经验才是收入来源；
- **忽略实习期**：一年低薪是必经阶段，家庭现金流要提前准备；
- **只看诉讼**：非诉业务量大、收入稳定，但要求英语与项目经验；
- **把法务当"清闲"**：合同量与跨部门沟通并不轻松，出事时压力集中。

## 低成本试法

去法院旁听一次民事庭审（公开庭审可旁听），或找一位律师朋友要一份已公开的判决书，尝试自己写一份 500 字的案情摘要与争点归纳。做完你会知道自己是喜欢"抠条文"还是"跑事实"。

## 一天通常是这样的

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 9:00 | 看邮件与客户消息，排当天优先级 | 紧急事项先回 |
| 9:30 | 检索法条与类案，整理争点 | 类案检索是基本功 |
| 11:00 | 写起诉状/答辩状/合同修改意见 | 文书占大量时间 |
| 14:00 | 会见客户或与对方律师沟通 | 记录要点与时间 |
| 16:00 | 开庭准备或尽调材料核对 | 证据目录不能出错 |
| 18:00 | 补充文书、回复客户 | 开庭前常加班 |

## 一次面试追问的典型走向

下面这段按面试与复盘里常见的追问整理，用来说明答法的结构，不是某位候选人的原话。

> **面试官**：这个买卖合同纠纷，你先看什么？
> **候选人**：先看合同效力与履行节点，再看有没有书面变更、验收单和对账记录，最后看诉讼时效。
>
> **面试官**：对方说已经口头同意延期，你怎么处理？
> **候选人**：口头变更很难证明，我会找履行行为佐证——比如延期后的收货记录、微信沟通；如果没有，就按原合同主张违约责任，同时评估调解空间。
>
> **面试官**：你觉得这个案子最大的风险是什么？
> **候选人**：证据链不完整，尤其是验收环节。所以第一步不是起诉，是补证据或固定对方自认。

**要点**：案例题答"法律关系—证据—风险—方案"，不要一上来背法条。
