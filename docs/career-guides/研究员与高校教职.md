# 研究员 / 高校教职

用一句话概括：以**产出新知识**为主业，评价标准是同行认可（论文、项目、学生培养）。

## 两条主要路径

| | 高校教职 | 企业研究岗 |
| --- | --- | --- |
| 核心产出 | 论文、课题、教学 | 论文/专利 + 可落地的技术 |
| 评价周期 | 长（3–6 年考核期） | 相对短（与业务节奏挂钩） |
| 稳定性 | 编制内较稳，但「非升即走」普遍 | 与公司业务绑定 |
| 收入结构 | 基本工资 + 项目/绩效 | 市场化薪资 + 奖金/股权 |

## 需要准备的证据（按重要性）

1. **代表性论文**（数量之外更看影响力与连续性）；
2. **项目与经费**（主持或核心参与）；
3. **推荐与合作网络**（同行背书在评审中作用很大）；
4. **教学与学生培养**（高校岗必看）。

## 时间表（大致）

博士期间完成 2–4 篇代表作 → 博士后或企业研究岗 2–4 年 → 申请教职 / 研究岗。不同国家与学科差异大，**以目标单位的招聘公告与要求为准**。

## 企业与高校的差异

- 企业更看「技术能否落地」，对论文的容忍度与要求因公司而异；
- 高校更看学术独立性与长期方向，短期产出压力同样存在；
- 从企业回高校通常比反向更难（需要论文与独立方向）。

## 常见误区

- 以为「博士毕业就能进高校」（教职竞争激烈，常需博士后经历与代表作）；
- 忽视教学与团队能力（面试与考核都会看）；
- 不做长期方向规划，三年考核期内频繁换题。

## 低成本试法

在读期间完整做完一次从问题到投稿的研究闭环（含返修），并观察自己是否享受这个过程。

## “做研究”与“做学术职业”不是同一件事

高校和研究机构除了研究，还包含申请经费、写作、指导学生、评审、教学、合作与行政。越往后，个人动手做实验的时间往往越少，更多时间用于定义问题和组织资源。决定是否走这条路前，要区分“喜欢研究”与“喜欢这种职业结构”。

## 从博士到独立研究者

关键变化不是论文数量，而是能否持续提出可做的问题、形成独立方向、获得资源、指导别人并建立合作网络。博士后阶段常用于补独立性和方向；教职招聘则会看研究计划、代表作、推荐和与院系的匹配。具体制度随国家与机构差异很大。

## 低成本验证

不要只靠“喜欢读论文”判断。尽量经历一次完整研究循环，再尝试带一个更小的任务给别人、做一次正式报告、参与评审或课程助教。你会更接近真实职业体验。
