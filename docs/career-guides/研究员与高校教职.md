# 研究员 / 高校教职

用一句话概括：以**产出新知识**为主业，评价标准是同行认可（论文、项目、学生培养）。

## 两条主要路径

| | 高校教职 | 企业研究岗 |
| --- | --- | --- |
| 核心产出 | 论文、课题、教学 | 论文/专利 + 可落地的技术 |
| 评价周期 | 长（3–6 年考核期） | 相对短（与业务节奏挂钩） |
| 稳定性 | 编制内较稳，但「非升即走」普遍 | 与公司业务绑定 |
| 收入结构 | 基本工资 + 项目/绩效 | 市场化薪资 + 奖金/股权 |

## 需要准备的证据（按重要性）

1. **代表性论文**（数量之外更看影响力与连续性）；
2. **项目与经费**（主持或核心参与）；
3. **推荐与合作网络**（同行背书在评审中作用很大）；
4. **教学与学生培养**（高校岗必看）。

## 时间表（大致）

博士期间完成 2–4 篇代表作 → 博士后或企业研究岗 2–4 年 → 申请教职 / 研究岗。不同国家与学科差异大，**以目标单位的招聘公告与要求为准**。

## 企业与高校的差异

- 企业更看「技术能否落地」，对论文的容忍度与要求因公司而异；
- 高校更看学术独立性与长期方向，短期产出压力同样存在；
- 从企业回高校通常比反向更难（需要论文与独立方向）。

## 常见误判

- 以为「博士毕业就能进高校」（教职竞争激烈，常需博士后经历与代表作）；
- 忽视教学与团队能力（面试与考核都会看）；
- 不做长期方向规划，三年考核期内频繁换题。

## 低成本试法

在读期间完整做完一次从问题到投稿的研究闭环（含返修），并观察自己是否享受这个过程。


## 这不是一条单一职业路径

高校教职、研究所研究员、企业研究科学家虽然都做研究，但评价机制、资源来源和日常压力完全不同。

高校通常同时承担研究、教学、学生指导和行政；科研院所更集中在项目与论文；企业研究强调研究价值与公司方向的连接，可能更关注产品化或战略影响。

## 真正的工作不是“自由研究”

越往后，研究者越需要做大量“研究之外”的工作：
- 找经费；
- 招学生/成员；
- 写 proposal；
- 管项目；
- 合作；
- 审稿；
- 教学；
- 组织会议；
- 解释研究价值。

如果只喜欢“自己做实验”，但非常排斥这些活动，就要认真区分“喜欢研究”和“适合 PI/教职”。

## 从博士到独立研究者，变化最大的是问题所有权

博士主要证明自己能完成研究；独立研究者要证明自己能：
- 连续提出值得做的问题；
- 获得资源；
- 组织别人完成；
- 建立稳定产出；
- 形成方向识别度。

论文数量只是结果之一。

## 判断一个机会时看什么

不要只看学校名或 title。继续核实：
- 合同期限和考核；
- tenure / 非升即走规则；
- teaching load；
- 启动经费；
- 实验空间；
- 招生名额；
- 评价是否偏论文、项目还是产业转化；
- 课题组是否真正有自主权。

这些会直接决定你的日常。
