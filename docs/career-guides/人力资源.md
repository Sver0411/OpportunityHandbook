# 人力资源（HR）

用一句话概括：**通过招人、留人、评价人和处理人的问题，让组织能持续交付。**

## 五个模块，不是一份工作

| 模块 | 做什么 | 适合谁 |
| --- | --- | --- |
| 招聘（TA） | 筛简历、约面、渠道运营、雇主品牌 | 沟通强、抗压、结果导向 |
| 薪酬绩效（C&B） | 薪酬结构、调薪、绩效方案、数据测算 | 对数字敏感、逻辑严谨 |
| 培训与发展（TD/L&D） | 课程设计、带教体系、学习项目 | 表达与项目管理 |
| 员工关系（ER） | 劳动合同、纠纷、离职、合规 | 熟悉劳动法、能处理冲突 |
| HRBP | 嵌入业务部门，做组织与人的问题 | 懂业务、能做判断 |

**入门通常从招聘或员工关系开始**，因为这两块事务量大、上手快；薪酬绩效与 OD 门槛更高。

## 日常与层级

| 层级 | 主要工作 |
| --- | --- |
| 专员 | 筛简历、安排面试、办入离职、维护台账 |
| 主管 / 经理 | 渠道与流程、绩效落地、员工关系处理 |
| HRD / HRVP | 组织设计、人才盘点、薪酬策略、与业务一号位对话 |

## 招聘与门槛

- **专业不限**，但大厂校招看学校、实习与沟通表现；
- **硬技能**：Excel（数据透视、VLOOKUP）、劳动法基础、面试方法（结构化面试）；
- **加分**：行业理解、数据分析、英语（外企）；
- **证书**：人力资源管理师等证书作用有限，实习与项目更重要。

## 面试会问什么

- "业务部门要你在两周内招到 5 个人，你怎么做？"——考渠道与优先级；
- "员工要仲裁，你怎么处理？"——考劳动法与证据意识；
- "你怎么判断一个候选人合适？"——考结构化面试，不是"感觉"。

## 第一份工作怎么看

优先看**HR 团队是否被业务需要**：如果 HR 只做考勤与办手续，成长有限；如果 HRBP 能参与业务会议、做人才盘点，你能学到真正的组织能力。

## 3–5 年出口

- **HRBP**：最主流的方向，要求懂业务；
- **C&B / OD**：专业壁垒高，薪资上限也高；
- **招聘专家 / 猎头**：结果导向，收入与业绩挂钩；
- **人力资源服务**：咨询、培训、外包、创业；
- **转业务**：懂人的 HR 转运营、销售管理有优势。

## 常见误区

- **以为 HR 就是招人**：招聘只是入口，薪酬、绩效、员工关系才是专业壁垒；
- **不懂劳动法**：一次违法解除可能带来仲裁与赔偿，HR 是第一责任人；
- **只做事务不做业务**：不参加业务会、不懂岗位，就永远只能执行；
- **把"会聊天"当能力**：结构化面试、数据测算、方案设计才是硬功夫。

## 低成本试法

帮一个学生社团或小团队做一次**完整的招聘**：写 JD、发渠道、筛简历、面试 3 个人、给录用建议。做完你会知道自己是喜欢"对人"还是"对流程"。

## 一天通常是这样的

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 9:00 | 看简历池、回复候选人 | 上午是约面高峰 |
| 10:00 | 面试 2–3 位候选人 | 结构化提问 + 记录 |
| 13:30 | 与业务部门对齐岗位要求 | 需求常变，要留余地 |
| 15:00 | 办入离职、处理员工咨询 | 合同与社保不能出错 |
| 16:30 | 更新招聘台账与周报 | 数据要能对上 |
| 17:30 | 跟进 offer 与背调 | 候选人放鸽子是常态 |

## 一次面试追问的典型走向

下面这段按面试与复盘里常见的追问整理，用来说明答法的结构，不是某位候选人的原话。

> **面试官**：业务部门说这个人必须两周到岗，你怎么排？
> **候选人**：先确认岗位的硬条件与非硬条件，硬条件不放松，非硬条件用来扩大池子；同时并行三条渠道——内部推荐、招聘平台、猎头。
>
> **面试官**：候选人都嫌薪资低怎么办？
> **候选人**：先看是预算真的低，还是岗位定位错了。如果预算不能动，就调整画像，找经验略浅但能培养的人，并把成长空间讲清楚。
>
> **面试官**：业务坚持要一个不符合画像的人，你怎么办？
> **候选人**：把风险写下来——试用期可能不达标、团队结构会失衡——让对方确认；HR 不做否决，但要把代价说清楚。

**要点**：HR 题答"需求—渠道—风险—共识"，不要只说"我会努力沟通"。
