# 运营

用一句话概括：**用一套可重复的动作，把某个指标稳定地拉上去。**

## 六种运营，指标不同

| 方向 | 主要动作 | 核心指标 |
| --- | --- | --- |
| 内容运营 | 选题、生产、分发、栏目化 | 阅读、互动、粉丝增长 |
| 用户运营 | 分层、社群、激励、生命周期 | 留存、活跃、转化 |
| 活动运营 | 策划、资源协调、执行、复盘 | 参与人数、转化、ROI |
| 电商运营 | 商品、页面、价格、投放 | GMV、转化率、客单价 |
| 产品运营 | 功能推广、反馈收集、迭代 | 使用率、留存、NPS |
| 增长 | 渠道实验、裂变、漏斗优化 | 获客成本、转化率 |

**面试问"你做过什么运营"，一定要能说清指标。** 只说"负责公众号"没有意义。

## 日常与层级

| 层级 | 主要工作 |
| --- | --- |
| 专员 | 执行具体动作：写文案、发内容、拉群、跑活动 |
| 主管 / 经理 | 定策略、管预算、带小团队、对指标负责 |
| 总监 | 业务线目标、资源分配、跨部门协同 |

## 招聘与门槛

- **专业不限**，校招看实习与作品（账号、活动案例、数据复盘）；
- **硬技能**：Excel/SQL 基础、文案、活动执行、数据看板；
- **加分**：投放（信息流/搜索）、剪辑、社群、行业理解。

## 面试会问什么

- "你负责的账号，三个月的数据变化是什么？"——考真实经历；
- "活动只有 5000 元预算，你怎么花？"——考资源分配；
- "这个指标掉了 20%，你怎么排查？"——考分析顺序。

## 第一份工作怎么看

优先看**有没有明确的指标与权限**：只让你发内容、不给数据、不让做实验的岗位，做两年也学不到运营；能接触预算、投放与复盘的岗位成长快得多。

## 3–5 年出口

- **专业线**：内容 / 用户 / 增长专家；
- **管理线**：运营经理 → 运营总监；
- **转岗**：产品经理（懂用户）、市场（懂投放）、销售（懂转化）；
- **行业化**：电商、教育、医疗、金融的运营差别很大，早选行业比早选公司更重要。

## 常见误区

- **把运营当打杂**：没有指标的运营只是执行，做再久也不增值；
- **只看阅读量**：阅读不等于转化，要看清业务真正要什么；
- **不会看数据**：不会算漏斗与留存，就无法判断动作有没有用；
- **频繁换行业**：每个行业的用户与渠道逻辑都不同，三年换三个行业等于一直从零开始。

## 低成本试法

选一个小红书/公众号/视频号账号，给自己定一个 30 天目标（例如涨粉 200 或转化 20 单），完整做一次选题—发布—复盘。做完你会知道自己是喜欢"内容"还是"数据"。

## 一天通常是这样的

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 9:30 | 看昨日数据：流量、转化、留存 | 先定位异常 |
| 10:00 | 选题会或与设计/产品对齐素材 | 排期要留缓冲 |
| 11:00 | 写文案、改页面、配置活动 | 细节决定转化 |
| 14:00 | 投放调整或社群维护 | 预算花在哪要说清 |
| 16:00 | 跨部门沟通：产品、技术、客服 | 需求要写成文档 |
| 17:30 | 复盘当日动作与明日排期 | 记录实验与结果 |

## 一次面试追问的典型走向

下面这段按面试与复盘里常见的追问整理，用来说明答法的结构，不是某位候选人的原话。

> **面试官**：你负责的活动，最终转化率是多少？
> **候选人**：报名转化 12%，到场率 65%，现场下单 8%。比上一次高，是因为把报名表单从 6 项减到 3 项，并在前一天做了提醒。
>
> **面试官**：怎么确定是表单的功劳？
> **候选人**：同一渠道、同一时间窗口做了 A/B，对照组保持原表单；样本不大，所以只当作方向性结论，没有直接复制到其他渠道。
>
> **面试官**：如果预算砍一半，你怎么做？
> **候选人**：先保转化最高的渠道，把品牌曝光类投放停掉；同时把活动从线下改成线上+小规模线下，保住核心体验。

**要点**：运营题答"指标—动作—验证—取舍"，每个结论都要有数据支撑。
