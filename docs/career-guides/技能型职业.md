# 技能型职业（电工 / 焊工 / 护理等）
用一句话概括：靠**可当场验证的操作能力**换收入，客户与雇主看的是活儿。

## 典型方向与准入

| 方向 | 准入要求（以官方目录为准） | 常见路径 |
| --- | --- | --- |
| 电工 / 焊工 / 制冷 | 特种作业操作证（部分工种为法定准入） | 学徒 → 持证 → 等级晋升 |
| 护理 / 养老照护 | 职业技能等级认定 | 机构就业 → 等级晋升 |
| 汽修 / 数控 / 机电 | 职业技能等级 | 学徒 → 技术员 → 班组 |
| 烹饪 / 美发 | 部分需资格证书 | 学徒 → 独立 → 开店 |

**准入类证件是硬门槛**（无证不能上岗）；水平评价类与技能等级由社会化认定，价值看用人单位认可度。查 [证书类型对照](../certifications/类型对照.md)。

## 收入结构

- 底薪 + 计件/工时 + 加班 + 补贴；
- 影响收入的三件事：证书等级、能干的活难度、所在地区产业需求；
- 上升空间来自「稀缺度」：能处理疑难工艺的人单价明显更高。

## 职业健康与年龄

多数技能工种有体力消耗与职业健康风险（粉尘、噪声、腰颈损伤）。**选方向时把这个算进去**，并了解防护规范。

## 发展与创业

1. **等级晋升**：中级 → 高级 → 技师 → 高级技师；
2. **带团队**：班组长、工段技术管理；
3. **自己接单或开店**：需要客户来源、报价与合同能力（见 [定价与报价](../entrepreneurship/定价与报价.md)）。

## 地域与行业周期

需求与产业带、基建和消费景气度相关（装修、制造、养老）。选择方向时看长期需求，而不是单年工资。

## 常见误区

- 以为「没门槛」（准入类考试并不轻松）；
- 只看工资上限，忽略稳定性与健康成本；
- 不保留服务记录与客户评价——技能职业的「简历」就是这些。

## 低成本试法

跟一位师傅做一天活，或报一个短期实操班，体验体力与节奏；同时查目标城市该工种的招聘数量与薪资区间。

## 技能型职业的“高手”通常体现在稳定性和安全

电工、焊工、机修、护理、数控等岗位差异很大，但共同点是结果必须在真实环境中稳定重复，并遵守安全与规范。一次做成功不代表能上岗，很多职业还有法定或行业资格要求。

## 学习路径更像“示范—练习—反馈—独立作业”

最有效的证据不是课程结业，而是能独立完成典型任务、解释风险点、在异常情况下正确停下来。选择培训时重点看实操时数、设备、师资、真实考核和就业去向，而不是证书数量。

## 长期发展不只有“继续干”

常见方向包括高级技师、质量/工艺、班组管理、培训、设备/服务创业。不同职业的健康风险、体力要求和职业寿命也不同，选择前要把这些现实成本算进去。
