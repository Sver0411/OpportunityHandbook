# 制造业研发

用一句话概括：把产品从图纸/工艺要求做到**能量产且稳定**。

## 两类岗位

| | 研发中心（R&D） | 工厂（工艺/制造工程） |
| --- | --- | --- |
| 关注点 | 新产品、新工艺开发 | 良率、节拍、成本、设备 |
| 周期 | 项目制，数月到数年 | 日循环 + 改善项目 |
| 常见职位 | 结构/电子/工艺研发、材料、仿真 | 工艺工程师、设备工程师、质量工程师 |

## 日常与层级

- 初级：跟进试产、做测试与数据整理、写工艺文件；
- 中级：独立负责一个模块或一条产线指标；
- 资深：平台方案、跨部门推动、供应链协同。

节奏受产线影响：试产期需要驻场，量产期以稳定与改善为主。

## 行业分布与地域

消费电子、汽车（含新能源）、家电、装备制造、半导体。产业带集中在珠三角、长三角与部分中西部园区——**地域与行业选择对职业路径影响很大**。

## 招聘与门槛

- 硬技能：工艺与材料基础、图纸与公差、数据分析、设备与仪器；
- 加分：六西格玛、精益改善、自动化项目经验；
- 学历：本科为主（半导体与材料研发偏硕士）。

## 项目与面试怎么准备

- 证据：一次改善项目的量化结果（良率、节拍、成本下降多少）、一次问题定位的过程；
- 面试考法：工艺原理题、异常分析题（给现象找原因）、项目细节追问；
- 高频考点：**用数据说清改善幅度**，而不是「参与了某项目」。

## 第一份工作怎么看

看是否有机会跟完一个完整项目（只做单一工序维护的成长有限）与产线的规范程度。

## 3–5 年出口

技术专家（工艺/材料/设备）、项目管理、质量与体系、转产品或采购、转研发中心。

## 常见误判

- 低估现场经验的价值（制造业的判断力来自产线）；
- 忽视数据与统计能力；
- 只选公司不看行业周期。

## 低成本试法

在实习或课程项目里完整跟一次「发现问题 → 分析 → 改善 → 验证」，并算出改善幅度。
