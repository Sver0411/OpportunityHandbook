# 制造业研发

用一句话概括：把产品从图纸/工艺要求做到**能量产且稳定**。

## 两类岗位

| | 研发中心（R&D） | 工厂（工艺/制造工程） |
| --- | --- | --- |
| 关注点 | 新产品、新工艺开发 | 良率、节拍、成本、设备 |
| 周期 | 项目制，数月到数年 | 日循环 + 改善项目 |
| 常见职位 | 结构/电子/工艺研发、材料、仿真 | 工艺工程师、设备工程师、质量工程师 |

## 日常与层级

- 初级：跟进试产、做测试与数据整理、写工艺文件；
- 中级：独立负责一个模块或一条产线指标；
- 资深：平台方案、跨部门推动、供应链协同。

节奏受产线影响：试产期需要驻场，量产期以稳定与改善为主。

## 行业分布与地域

消费电子、汽车（含新能源）、家电、装备制造、半导体。产业带集中在珠三角、长三角与部分中西部园区——**地域与行业选择对职业路径影响很大**。

## 招聘与门槛

- 硬技能：工艺与材料基础、图纸与公差、数据分析、设备与仪器；
- 加分：六西格玛、精益改善、自动化项目经验；
- 学历：本科为主（半导体与材料研发偏硕士）。

## 项目与面试怎么准备

- 证据：一次改善项目的量化结果（良率、节拍、成本下降多少）、一次问题定位的过程；
- 面试考法：工艺原理题、异常分析题（给现象找原因）、项目细节追问；
- 高频考点：**用数据说清改善幅度**，而不是「参与了某项目」。

## 第一份工作怎么看

看是否有机会跟完一个完整项目（只做单一工序维护的成长有限）与产线的规范程度。

## 3–5 年出口

技术专家（工艺/材料/设备）、项目管理、质量与体系、转产品或采购、转研发中心。

## 常见误区

- 低估现场经验的价值（制造业的判断力来自产线）；
- 忽视数据与统计能力；
- 只选公司不看行业周期。

## 低成本试法

在实习或课程项目里完整跟一次「发现问题 → 分析 → 改善 → 验证」，并算出改善幅度。

## 一天通常是这样的（工艺方向）

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 8:30 | 产线早会：昨天的直通率与异常项 | 数字先看趋势 |
| 9:00 | 现场看异常：某工位不良率从 0.8% 升到 1.5% | 先看 5M 变化 |
| 10:30 | 拉数据：按班次、设备、物料批次拆开对比 | 找最大差异项 |
| 13:30 | 定位到某批物料尺寸偏差，与供应商沟通 | 记录沟通与结论 |
| 15:00 | 做小批量验证：换料后不良率回到 0.7% | 用数据确认 |
| 16:30 | 写改善报告：现象、定位、措施、验证结果 | 报告是部门资产 |

## 一次真实的面试问答（原话）

> **面试官**：你做过最成功的一次改善是什么？
> **候选人**：螺钉滑牙问题。我先整理了两个月的 148 条异常记录，归成 6 类，发现集中在 3 个原因上；调整扭矩参数并更换一家供应商的批料后，该工序不良率从 1.8% 降到 0.6%。
>
> **面试官**：怎么确认是这两个原因，而不是季节性波动？
> **候选人**：我保留了一个月的验证期，用同一工位、同一班次对比，并且把改前改后的数据都留下了。
>
> **面试官**：如果改善无效呢？
> **候选人**：我会先扩大数据范围确认是否测量问题——制造业常见的坑是量具本身漂移。

**要点**：制造业面试看的是**你有没有真的用数据定位过问题**。

## 制造研发的核心是“把设计变成可重复制造”

实验室里做出一个样品和产线上稳定做出一万件，是两种能力。真实工作会遇到工艺窗口、良率、供应商、设备能力、质量标准、变更管理和成本。很多问题不是单个零件坏，而是多个小偏差叠加。

## 一次问题怎么闭环

发现良率下降后，先冻结口径与批次，按人机料法环拆变量，找最近变更，做对照与验证，再更新工艺文件和控制计划。只“调到好了”不算闭环，因为下一批还会回来。

## 项目证据

最有价值的是“问题前后”：缺陷率、节拍、成本或稳定性怎样变化，你负责了什么验证，方案有没有被固化进流程。涉密时不暴露公司数据，也可以写相对变化、方法和责任边界。
