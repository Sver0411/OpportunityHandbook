# 制造业研发

用一句话概括：把产品从图纸/工艺要求做到**能量产且稳定**。

## 两类岗位

| | 研发中心（R&D） | 工厂（工艺/制造工程） |
| --- | --- | --- |
| 关注点 | 新产品、新工艺开发 | 良率、节拍、成本、设备 |
| 周期 | 项目制，数月到数年 | 日循环 + 改善项目 |
| 常见职位 | 结构/电子/工艺研发、材料、仿真 | 工艺工程师、设备工程师、质量工程师 |

## 日常与层级

- 初级：跟进试产、做测试与数据整理、写工艺文件；
- 中级：独立负责一个模块或一条产线指标；
- 资深：平台方案、跨部门推动、供应链协同。

节奏受产线影响：试产期需要驻场，量产期以稳定与改善为主。

## 行业分布与地域

消费电子、汽车（含新能源）、家电、装备制造、半导体。产业带集中在珠三角、长三角与部分中西部园区——**地域与行业选择对职业路径影响很大**。

## 招聘与门槛

- 硬技能：工艺与材料基础、图纸与公差、数据分析、设备与仪器；
- 加分：六西格玛、精益改善、自动化项目经验；
- 学历：本科为主（半导体与材料研发偏硕士）。

## 项目与面试怎么准备

- 证据：一次改善项目的量化结果（良率、节拍、成本下降多少）、一次问题定位的过程；
- 面试考法：工艺原理题、异常分析题（给现象找原因）、项目细节追问；
- 高频考点：**用数据说清改善幅度**，而不是「参与了某项目」。

## 第一份工作怎么看

看是否有机会跟完一个完整项目（只做单一工序维护的成长有限）与产线的规范程度。

## 3–5 年出口

技术专家（工艺/材料/设备）、项目管理、质量与体系、转产品或采购、转研发中心。

## 常见误判

- 低估现场经验的价值（制造业的判断力来自产线）；
- 忽视数据与统计能力；
- 只选公司不看行业周期。

## 低成本试法

在实习或课程项目里完整跟一次「发现问题 → 分析 → 改善 → 验证」，并算出改善幅度。


## 制造研发的核心是“设计必须穿过现实世界”

软件可以快速回滚，实体产品一旦开模、下单、进产线，错误成本会迅速放大。制造研发因此特别重视验证、变更控制、供应链和可制造性。

## 一个产品从样机到量产会经历什么

概念 → 设计 → 样机 → DVT/验证 → 小批试产 → 工艺优化 → 量产 → 质量问题闭环。

不同公司叫法不同，但核心相似：每一阶段都在减少未知。

研发工程师不仅要回答“设计能不能工作”，还要回答：
- 供应商能不能稳定做出来；
- 公差叠加后还成立吗；
- 成本能不能接受；
- 测试怎么做；
- 现场坏了怎么追批次；
- 改一颗料会影响哪些认证和库存。

## 现场问题为什么特别锻炼人

量产后最难的问题往往是低概率、跨部门、无法在实验室复现。你需要把现场数据、批次、工艺、物料和设计一起对齐。

一次完整的 8D/问题闭环经历，往往比“参与某产品研发”更能证明工程判断。

## 第一份工作该不该去工厂

取决于岗位。能接触试产、产线和失效分析通常很有价值；如果长期只是维护文档或做重复性变更，成长会受限。看岗位时重点问你是否能参与完整问题闭环和设计决策。
