# 硬件工程师

用一句话概括：把电路从原理图变成**能稳定量产**的实体产品。

## 日常与层级

| 层级 | 主要工作 |
| --- | --- |
| 初级 | 器件选型、原理图与 PCB 绘制、单板调试 |
| 中级 | 方案设计、信号完整性/电源完整性基础、EMC 整改、测试规范 |
| 资深 | 平台方案、成本与良率取舍、供应商与产线协作、带人 |

典型节奏：设计 → 打样 → 调试 → 改版 → 认证 → 量产。**一轮迭代以周为单位**，比软件慢得多。

## 团队与相邻岗位

与嵌入式、结构、测试、采购、产线协作。与嵌入式工程师的边界：硬件负责电气特性与器件，固件负责驱动与逻辑。

## 常见岗位名称

硬件工程师、电路设计工程师、模拟/数字电路工程师、电源工程师、射频工程师、PCB 工程师。

## 招聘与门槛

- 硬技能：模拟与数字电路基础、常用仪器（示波器、电源、万用表）、原理图/PCB 工具；
- 加分：EMC 整改、电源设计、量产经验；
- 学历：本科为主，核心岗位偏好硕士（与器件、射频相关性高）。

## 项目与面试怎么准备

- 证据：设计文件与迭代版本、测试数据（精度、良率）、故障模式清单、可复现的搭建说明；
- 面试考法：电路基础题、调试经历、一次失败设计的原因与改法；
- 「成品照片」几乎不加分，**测试数据与失败记录才加分**。

## 第一份工作怎么看

看团队是否有完整的验证与测试流程（只做绘图不做验证的岗位成长有限）。

## 3–5 年出口

专项方向（电源、射频、信号完整性）、系统架构、硬件产品经理、供应商/器件方向。

## 地域分布

集中在消费电子与汽车电子产业带（珠三角、长三角、部分中西部电子产业园区）。

## 常见误判

- 只看重「画板子」的技能，忽视测试与量产；
- 低估采购与产线协作的复杂度；
- 忽视行业周期（消费电子与汽车电子节奏差异很大）。

## 低成本试法

做一个完整的小系统（传感器 + 供电 + 通信），自己打样调试一次，记录每次改版的原因。


## 硬件工作不是“画完板子就结束”

一个板卡从需求到量产通常经历：器件选择 → 原理图 → PCB → DFM/可制造性检查 → 打样 → Bring-up → SI/PI/EMC/热等验证 → 改版 → 小批试产 → 量产问题。

真正成熟的硬件工程师会一直追到“为什么这块板在批量、温度、供电波动和真实装配条件下仍然可靠”。

## Bring-up 是最能暴露能力的阶段

新板第一次上电，不应该直接全部插满然后祈祷。更稳的做法是按电源域和关键链路逐步验证：

- 先查短路和阻抗；
- 限流上电；
- 看各路电压、纹波和时序；
- 验证时钟、复位；
- 再接核心器件与通信；
- 最后跑整机功能。

每一步都留下测量点和期望值。这样出问题时你知道从哪一层开始缩小，而不是“换元件试试”。

## 一个能打动面试官的硬件项目要留下什么

除了原理图和 PCB，最好还有：
- 关键器件为什么这样选；
- 电源预算和热预算；
- 一次改版前后的问题对比；
- 示波器/逻辑分析仪截图与解释；
- EMC、信号完整性或电源完整性的验证思路；
- BOM 成本与替代料考虑；
- 生产测试点和可制造性考虑。

这会把“会画板”变成“能把板做成产品”。

## 第一份工作最值得看的不是板层数

更重要的是：能不能参与 bring-up、是否跟产线/供应商接触、有没有资深工程师带 review、问题能不能追到量产。只长期做局部改版和资料维护，和参与完整硬件周期，几年后能力结构会完全不同。
