# 护士

用一句话概括：**在医嘱与病人之间，负责把治疗安全地落到具体的人身上。**

## 路径与资格

```
护理专业（中专 / 大专 / 本科）
  → 护士执业资格考试（一般毕业当年可考）
  → 注册取得护士执业证书
  → 临床岗位（多数医院有 1–3 个月岗前培训）
```

- **执业资格**是硬门槛，没有证不能独立执行护理操作；
- **学历**：三甲医院多要求本科，县域医院与基层大专可进；中专主要面向基层与养老机构；
- **编制**：公立医院有编制、人事代理、合同制几种，同岗不同酬，签约前问清。

## 日常与层级

| 层级 | 主要工作 |
| --- | --- |
| 护士（N0–N1） | 管床、执行医嘱、输液给药、观察病情、写护理记录 |
| 护师 / 责任护士 | 带组、处理疑难操作、带教新人、参与质控 |
| 主管护师及以上 | 专科护理、护理门诊、质控与培训 |
| 护士长 / 护理部 | 排班、人力、质量与安全管理 |

## 专科方向比"科室"更重要

同样是护士，路径差别很大：

- **重症（ICU）、急诊、手术室**：技术密度高、夜班与压力大，成长快；
- **伤口造口、静疗（PICC）、糖尿病教育**：可做专科护士与护理门诊，职业寿命更长；
- **儿科、产科**：沟通与家属管理压力大；
- **血透、内镜、导管室**：相对规律，但依赖设备与排班。

**专科护士认证**（各省与各学会组织）是拉开差距的关键，比"换一家更大的医院"更有效。

## 招聘与门槛

- 公告在 hospital 官网、当地卫健委、校招平台；
- 笔试（护理基础）+ 操作考试 + 面试，部分医院有身高与体检要求（以公告为准）；
- 有实习经历、操作熟练、能接受夜班，是面试真正看的三件事。

## 面试会问什么

- "病人输液后出现寒战，你先做什么？"——考应急顺序；
- "家属情绪激动，质疑用药，你怎么处理？"——考沟通与边界；
- "能接受夜班吗？多久轮一次？"——考现实预期。

## 第一份工作怎么看

优先看三件事：**带教制度、科室类型、有没有编制机会**。第一年能不能有人带，决定你操作规范不规范；科室决定你练什么技术；编制决定长期待遇。

## 3–5 年出口

- **专科护士**：ICU、手术室、伤口、静疗、糖尿病教育；
- **护理管理**：责任组长 → 护士长 → 护理部；
- **社区与养老**：社区卫生服务中心、养老机构、居家护理，夜班少但收入结构不同；
- **产业方向**：器械与耗材临床支持、保险健康管理、护理培训；
- **海外执业**：美国 NCLEX-RN、英国 NMC、澳洲 AHPRA 等，需要语言成绩与注册流程，周期长、费用高。

## 常见误区

- **把护理当"打针发药"**：病情观察、记录、宣教与应急占很大比重，写错记录会有法律后果；
- **忽略夜班成本**：轮班对睡眠与家庭生活的影响是长期的，选岗时要问清班次；
- **不考执业证**：没有证只能做辅助岗，待遇与晋升都受限；
- **把护理当跳板**：转行成本不低，早想清楚比三年后再转更省。

## 低成本试法

去医院做一次**一天的陪诊或志愿服务**（或跟一位护士朋友上一个班），记录：走了多少步、几点吃饭、写了几页记录。护理的日常与想象差距很大，这一天比任何描述都有效。

## 一天通常是这样的

| 时间 | 做什么 | 备注 |
| --- | --- | --- |
| 7:30 | 接班：听交班、看重点病人 | 先掌握危重与当日手术 |
| 8:00 | 晨间护理、测生命体征、执行上午医嘱 | 输液高峰在上午 |
| 10:00 | 巡视、换液、处理呼叫 | 走的路比坐的时间多 |
| 12:00 | 记录、交接、简单午餐 | 记录不能拖到下班 |
| 14:00 | 下午治疗、宣教、术前准备 | 家属沟通多在这个时段 |
| 17:00 | 交班、补记录 | 夜班同事接班后才算结束 |

## 一次面试追问的典型走向

下面这段按面试与复盘里常见的追问整理，用来说明答法的结构，不是某位候选人的原话。

> **面试官**：输液过程中病人突然寒战、发热，你怎么处理？
> **候选人**：先停药、保留剩余药液与输液器，换生理盐水维持通路，同时测体温血压、通知医生。
>
> **面试官**：为什么要保留药液？
> **候选人**：可能是输液反应，也可能是药物问题，保留实物才能追溯；同时要记录发生时间与处理过程。
>
> **面试官**：家属在旁边很紧张，你怎么说？
> **候选人**：先告诉他我们已经在处理、目前生命体征是多少，再说下一步会做什么；不承诺"没事"，只讲已知事实。

**要点**：应急题答"先停药/先安全—保留证据—通知—记录—沟通"，顺序不能乱。
