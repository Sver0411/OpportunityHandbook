# 联系导师与套磁

「套磁」不是玄学，它是一次**专业沟通**：你要让对方在很短时间里判断三件事——你是否了解他的工作、你是否有能力做研究、你是否值得花名额与经费。这一页按操作顺序展开。

## 一、先判断：你到底需不需要联系导师

不同招生体系规则完全不同，先看清再动手：

| 体系 | 招生方式 | 是否需要提前联系 | 说明 |
| --- | --- | --- | --- |
| 美国研究型项目 | 委员会制为主 | 项目页面建议联系时再联系 | 录取与经费常由委员会决定，导师承诺未必有效 |
| 美国部分项目 / 导师制强的项目 | 导师有较大话语权 | 建议提前联系 | 先看项目说明是否鼓励 |
| 日本大学院 | 导师制，需内诺的情况常见 | 通常必须 | 出愿前先确认导师是否接收 |
| 欧洲部分国家 | 岗位制博士（雇员制） | 按招聘公告申请 | 这类更像找工作，按职位申请流程走 |
| 国内申请考核制 | 院系材料评审 + 导师意见 | 依院系办法 | 有的要求先确定导师意向，有的统一评审 |
| 英国 / 澳洲研究型 | 需先有导师同意指导 | 通常必须 | 申请前需找到 supervisor |

**判断方法**：打开目标项目的招生页面，搜 「contact」、「supervisor」、「prospective students」。**页面说不用联系，就不要硬套模板发信**——那会浪费你的时间，也会让导师反感。

## 二、筛选导师：从 5 个维度缩小到 3–5 位

1. **方向匹配**：读他近三年论文的标题与摘要，判断现在做的和你想做的是否一致（方向会迁移，别只看个人主页的旧描述）；
2. **产出节奏与署名**：近三年是否有稳定产出？一作是学生还是他自己？这关系到你能否拿到一作；
3. **经费状况**：有没有在研项目（项目页面、致谢里的基金号、实验室页面都能看线索）；
4. **毕业生去向**：近几届学生去了哪、读博还是就业、是否延期；
5. **指导风格**：只能问组里的人（这是最关键但最不可见的一项）。

把结果填进 [导师筛选表](../tools/导师筛选表.md)，横向比较后再决定联系谁——**不要同时给五位导师群发**。

## 三、发邮件前的准备（比写信本身更重要）

准备好三样东西，缺一样就容易写成空信：

- **一页简历（CV）**：教育背景、研究/项目经历、技能、联系方式。以证据为主，不写形容词；
- **一段研究兴趣**：100–150 字，说清你对**哪个具体问题**感兴趣、为什么、你能用什么方法；
- **能看的作品**：代码仓库、论文、技术报告、复现报告。**有链接比有描述有力得多**。

## 四、邮件怎么写

**标题**：直白到能一眼看懂。例如：

```
Prospective PhD applicant (Fall 2027) — interested in your work on <具体方向>
```

避免 「Hello Professor」、「A question」、「Self-introduction」 这类无法检索的标题。

**正文结构**（控制在 200–300 词）：

1. **一句自我介绍**：你是谁、目前在哪、什么专业、什么时候毕业；
2. **两到三句研究匹配**：读过他哪篇具体论文（写标题或方向），你的哪段经历与之相关，你想做什么小问题；
3. **一句你的能力证明**：会什么方法、做过什么项目、能提供什么技能（编程、实验、数据分析）；
4. **一句请求**：询问他明年是否有招生计划/项目位置，并说明附件；
5. **结尾**：署名 + 单位 + 联系方式 + 主页/仓库链接。

**附件**：PDF 格式的 CV（文件名写清楚：`CV_姓名_方向.pdf`）。研究计划不是必需，除非对方明确要求——**没想清楚就附研究计划，反而暴露准备不足**。

### 正例（要点）

```
主题：Prospective PhD applicant (Fall 2027) — interested in <方向>

尊敬的 X 教授：

我是 <学校> <专业> 的本科生/硕士生，预计 2027 年 6 月毕业，计划申请 2027 年秋季入学的博士项目。

我读了您 2025 年关于 <具体问题> 的论文，尤其是 <具体方法/结论> 的部分。
我在 <项目/论文> 中做过 <相关工作>，用的是 <方法>，遇到的主要困难是 <具体问题>。
如果明年您计划招收学生，我很希望能围绕 <你设想的小问题> 做一些工作。

附件是我的简历；代码与复现报告在 <链接>。
感谢您的时间。

<姓名> | <学校> | <邮箱> | <主页>
```

### 反例（常见错误）

- 群发痕迹明显（称呼写错、方向写成大类、附件是通用模板）；
- 只写「我对您的研究很感兴趣，希望能加入您的课题组」——没有具体到任何工作；
- 一封信写 1500 词，讲自己从小到大的经历；
- 附上十页材料、要求对方评价你的想法；
- 在信里问录取概率、要求承诺名额。

## 五、回复与跟进

| 对方的回复 | 通常意味着 | 你的动作 |
| --- | --- | --- |
| 明确表示有名额并约谈 | 有兴趣 | 尽快准备面谈，见第六节 |
| 「欢迎申请，按流程走」 | 不承诺，属正常 | 按项目流程申请，申请后发一封简短更新邮件 |
| 「明年不确定/经费待定」 | 有门槛的模糊 | 隔一个月礼貌询问一次进展 |
| 转给博士生/秘书 | 不直接参与 | 跟被转的人认真沟通，他能影响导师判断 |
| 一周以上无回复 | 常见，不一定是拒绝 | 7–10 天后发一封简短 follow-up；仍无回复就换下一位 |
| 明确说没有位置 | 结论清晰 | 道谢并转向他人，不要争辩 |

**Follow-up 邮件写法**：一句话提醒 + 一条新信息（例如论文被接收、项目上线、成绩更新），控制在 80 词以内。**不要重复发送同一封信**。

## 六、面谈前准备与可能的问题

准备清单：

- 你自己的研究：3 分钟讲清问题、方法、结果、你负责的部分；
- 对方的工作：至少精读两篇，能提出一个具体问题（不是「您下一步做什么」这类空问）；
- 你的计划：想做的问题、为什么、需要什么资源；
- 反问对方的问题（下面列了几个真正有用的）。

导师可能问：你之前做什么？为什么想做这个方向？你打算做什么问题？会不会编程/做实验？能否接受 <某地> 与 <某强度>？毕业后的打算？

你可以反问（这些能帮你判断得更准）：

- 组里现在有几位学生，通常同时带几位？
- 经费情况如何，学生一般通过什么方式获得资助？
- 学生一般几年毕业，最近三位毕业生的去向是？
- 组会频率与形式？您通常多久和学生单独讨论一次？
- 课题是学生自选还是项目驱动？

## 七、不同体系的差异小结

- **美国**：委员会制优先，联系导师是加分不是决定项；申请材料与推荐信权重高；
- **日本**：导师内诺常常是前提，沟通要更正式（敬语、说明来意、可能需要面试与笔试）；
- **欧洲**：岗位制博士按招聘流程（相当于应聘），合同、薪资与假期按当地劳动规定；
- **中国香港/新加坡**：导师话语权较大，提前沟通有效，注意项目与资助的绑定关系；
- **英国/澳洲**：需要先确定 supervisor，通常还要提交 research proposal。
