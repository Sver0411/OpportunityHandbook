# 论文写作与投稿

论文不是「把做过的事按顺序写下来」，而是**用证据说服一个怀疑的读者**。这一页按写作顺序、投稿流程、审稿沟通三部分讲。

## 一、写作顺序：不要从引言开始

推荐的顺序（能显著减少返工）：

```
1. 图表 → 把结果与对照整理成图，图定了，故事就定了
2. 方法 → 写清让同行能复现的程度
3. 结果 → 客观陈述，不带解释
4. 讨论 → 解释含义、边界、与已有工作的差异
5. 引言 → 最后写，因为它要精准呼应你实际做出来的贡献
6. 摘要与标题 → 最后写，写完请同组的人读一遍
```

**为什么最后写引言**：写作过程中你常会发现贡献与最初设想不同，先写引言会反复重写。

## 二、每一部分要回答的问题

| 部分 | 读者在问 | 常见问题 |
| --- | --- | --- |
| 标题与摘要 | 这是做什么的、值不值得读 | 抽象堆砌，没有具体结论 |
| 引言 | 为什么值得做、与已有工作差别 | 只讲领域重要性，不讲缺口 |
| 方法 | 怎么做、能不能复现 | 缺少超参、环境、数据处理细节 |
| 结果 | 看到了什么 | 混入解释与推测 |
| 讨论 | 意味着什么、边界在哪 | 过度外推，不提限制 |
| 图表 | 一眼能否读懂 | 坐标轴、单位、误差棒缺失 |

## 三、审稿人在意什么

- **结论是否被数据支持**：超出数据范围的外推是最常见的拒稿理由；
- **增量是否足够**：不是「没人做过」，而是「比已有工作好在哪里」；
- **可否复现**：方法描述、数据与代码的可用性；
- **对照是否公平**：调参预算、数据量是否一致；
- **写作是否清楚**：结构、术语一致、图表自洽。

写完之后用这五条自查一遍，比请人润色更有效。

## 四、选刊与投稿

选刊的三条判据：**范围匹配、周期可接受、审稿口碑可信**。查法：读近三期的目录，看是否有同类工作；查期刊官网的审稿周期说明；问导师与同行的实际经验。

投稿前检查清单：

- 格式与字数符合期刊要求（参考文献格式最容易出错）；
- 作者列表与顺序已与所有作者确认（见署名规则）；
- 数据与代码可用性声明、伦理声明、利益冲突声明齐全；
- 附信（cover letter）一页：讲清贡献与为什么适合该刊；
- 推荐/回避审稿人（如期刊要求）。

## 五、审稿流程与时间预期

```
投稿 → 编辑初审（几天到两周，可能直接拒稿）
→ 送外审（1–6 个月，常见 2–4 个月）
→ 决定：接收 / 小修 / 大修 / 拒稿
→ 修改并回复（通常给 1–3 个月）
→ 可能第二轮外审 → 接收
```

**时间预期要写进计划**：从投稿到接收，几个月到一年以上都属正常。**不要把毕业或申请卡在一篇论文的接收时间上**。

## 六、怎么回审稿意见

结构上逐条对应，每条分三块：

```
审稿人意见（原文摘录）
我们的回应（同意/部分同意/不同意，并说明理由）
对应的修改（在文中哪一处、改成什么）
```

原则：

- **先谢后答，不辩解**：审稿人花时间读了你的稿子；
- **能改就改**：除非明显误解，否则优先修改而不是争论；
- **不同意要有证据**：给出数据或文献，而不是情绪；
- **列出所有修改点**：包括未采纳意见的理由。

## 七、被拒之后

- **先分类拒稿原因**：范围不符（换刊）、增量不足（补实验或改定位）、方法问题（补对照）、写作问题（改结构）；
- **不要当天转投**：先把审稿意见当作免费的评审，改完再投下一家；
- **保留一份「意见 → 修改」对照表**：这些意见往往在下一篇论文里同样适用；
- **注意期刊政策**：一稿多投在多数期刊属违规；转投前确认是否需要披露之前的审稿意见。

## 八、常见写作问题清单

- 摘要没有结论，只有过程；
- 引言没有明确缺口，只堆文献；
- 方法与结果混写，读者分不清哪些是观察、哪些是解释；
- 图表没有误差棒、没有单位、颜色不可辨识；
- 术语前后不一致（同一个概念三种叫法）；
- 过度使用「显著」「大幅」而没有统计支持——这与本项目对正文的要求一致（见写作规范）。
