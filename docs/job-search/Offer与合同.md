# Offer、薪酬结构与劳动合同

Offer 上的数字不能直接比较。同一句「年薪 30 万」，结构不同，到手可能相差很大。

## 薪酬结构逐项核对

| 项目 | 关键问题 |
| --- | --- |
| base（月薪 × 月数） | 几薪？12 / 13 / 14？是否有绩效挂钩部分 |
| bonus（奖金） | 目标比例？历史兑现情况？按个人还是公司系数 |
| RSU / 股票 | 授予数量、归属节奏（vesting）、当前估值口径 |
| option（期权） | 行权价、成熟期、离职后期权如何处理、稀释 |
| sign-on（签字费） | 一次性还是分期？是否有最低服务期（clawback） |
| 试用期 | 时长、工资比例（法定下限）、转正条件 |
| 社保公积金 | 缴纳基数与比例（按全额还是按最低基数） |
| 加班与调休 | 加班费计算方式、是否有调休 |
| relocation | 搬迁补贴、是否需返还 |
| severance（离职补偿） | 合同约定与法定标准的差异 |

## 一个完整案例

> Offer A：月薪 18k × 13，绩效奖金 0–3 个月，社保按 12k 基数缴，试用期 6 个月 80% 工资。
> Offer B：月薪 16k × 14，无绩效浮动，社保按全额缴，试用期 3 个月 100% 工资，另有 2 万签字费（需服务满 1 年）。

表面看 A 的月薪更高。算年现金：A ≈ 18×13 + 期望奖金（假设 1.5 个月）= 约 26 万；B ≈ 16×14 + 2 万 = 约 24.4 万。再看社保基数：A 的公积金每月少缴的部分，实际到手优势进一步缩小。B 的试用期工资更高、周期更短。

**结论取决于你在意什么**：短期现金流看 A，稳定性与公积金看 B。这类比较要用表格算，不能凭感觉。见 [Offer 对比表](../tools/Offer对比表.md) 与 [薪资和总包怎么看](../../book/05-从学校走向第一份工作.md#offer-total-comp)。

## 合同与法律要点（中国内地）

- 试用期长度与试用期工资有法定上下限，具体条款见《劳动合同法》；
- **违约金只有两种情形可以约定**：服务期（用人单位出资培训）与竞业限制；
- 竞业限制最长两年，且用人单位需在限制期内按月支付经济补偿；
- 社保自用工之日起应办理登记，缴纳基数不得低于法定下限。

上述条款的官方文本见 [中国政府网](https://www.gov.cn/) 与当地人社部门公告；涉及较大金额或争议时咨询专业人士。

## 签字前必须确认的五件事

1. 岗位、职级、工作地点是否写进书面 Offer；
2. 薪酬结构的每一项是否写明（尤其奖金与股权的授予与归属条件）；
3. 试用期长度、工资比例、转正标准；
4. 竞业与保密条款的范围、期限与补偿；
5. 违约与解约的流程与费用。

口头承诺一律要求写进书面文件。
