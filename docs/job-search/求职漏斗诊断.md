# 求职失败诊断：从 0 回复到 Offer 质量差

「投了很多都没结果」几乎总是卡在某一环。把它拆成环节，逐环诊断，比继续加大投递量有效。

## 漏斗与对应问题

| 卡在哪 | 通常的问题 | 先检查什么 |
| --- | --- | --- |
| 0 回复 | 简历与岗位不匹配、渠道单一 | 简历关键词是否对齐 JD；是否只用了招聘平台 |
| 有回复无测评 | 流程推进慢或岗位已满 | 是否投递时间太晚；是否只投少量公司 |
| 测评挂 | 题型不熟、时间管理差 | 是否做过目标公司的题型；是否在难题上耗时过多 |
| 一面挂 | 基础不牢、表达不清 | 知识清单是否过了一遍；能否 30 秒讲清思路 |
| 终面挂 | 项目深度不够、判断力被质疑 | 项目追问链能否答三层；有没有失败与取舍的例子 |
| Offer 少 | 面试转化率低或投递面太窄 | 统计各环节转化率，定位最弱一环 |
| Offer 质量差 | 目标岗位定位偏低或准备不足 | 是否只投了「够得着」的岗位；技能差距是否未补 |

## 怎么算自己的转化率

记录每一环的数量，算出：投递→回复、回复→测评、测评→面试、面试→Offer。**转化率最低的那一环就是当前瓶颈**，其余环节先不动。记录表见 [求职漏斗诊断表](../tools/求职漏斗诊断表.md)。

一条可操作的起点：累计 20–30 次投递后再看比例，样本太小容易误判。

## 各环的具体动作

- **0 回复**：把一份简历改成三份针对性版本；增加内推与官网直投；对照 [一份 JD 到底怎么拆](JD拆解.md) 做关键词对齐；
- **测评挂**：按题型分类限时练，先摸底再练；
- **一面挂**：按 [技术面试全流程](技术面试.md) 的清单补基础，练「思考出声」；
- **终面挂**：把项目追问链写出来，逐层补证据；
- **Offer 少或质量差**：回看定位——是否只投了低于自身水平的岗位，或目标岗位的门槛项一直没补。

## 情绪与节奏

求职周期本来就是数周到数月。设一个现金流与心理的缓冲线：钱能撑几个月、每周安排几次投递与几场模拟。缓冲不足时先接受一份过渡工作保住节奏，不必把它当成失败。

## 自检

- 我各环节的转化率分别是多少？最弱的是哪一环？
- 我改的是材料、渠道，还是只增加了投递量？
- 上一次面试的卡点，这次补了吗？
