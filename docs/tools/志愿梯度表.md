# 志愿梯度表

填志愿时最怕两件事：**顺序拍脑袋**、**章程没看全**。这张表把两件事都放到纸面上。

## 表长什么样

| 顺序 | 档位 | 院校 | 专业组 / 专业 | 近三年最低位次 | 招生数 | 我的位次差 | 章程要点（级差/单科/体检/进档不退） | 服从调剂 | 备注 |
| ---: | --- | --- | --- | --- | ---: | --- | --- | --- | --- |
| 1 | 冲 |  |  |  |  |  |  | 是 / 否 |  |
| 2 | 冲 |  |  |  |  |  |  |  |  |
| 3 | 稳 |  |  |  |  |  |  |  |  |
| 4 | 稳 |  |  |  |  |  |  |  |  |
| 5 | 稳 |  |  |  |  |  |  |  |  |
| 6 | 保 |  |  |  |  |  |  |  |  |
| 7 | 保 |  |  |  |  |  |  |  |  |

## 怎么填

1. **先写位次，不写分数**：在「近三年最低位次」一列写三个数字（如 11800 / 12300 / 12700），趋势一眼能看出来；
2. **算位次差**：你的位次减去往年最低位次。负数 = 你在它之后（冲），正数 = 你在它之前（稳或保）；
3. **按差值排序**：从最难的排到最稳的，顺序就是志愿顺序；
4. **填章程要点**：只抄会影响录取的四项——专业级差、单科要求、体检限制、是否承诺进档不退；
5. **决定调剂**：冲的学校若不能接受被调剂，就在备注里写明，考虑换一所。

## 一个示例（数字仅作示意）

| 顺序 | 档位 | 院校 | 专业组 | 近三年最低位次 | 招生数 | 位次差 | 章程要点 | 调剂 |
| ---: | --- | --- | --- | --- | ---: | --- | --- | --- |
| 1 | 冲 | A 大学 | 03 组 | 10200 / 10500 / 10800 | 12 | −1500 | 有专业级差 2-1-0；外语≥120 | 是 |
| 2 | 稳 | B 大学 | 01 组 | 11900 / 12100 / 12400 | 30 | +100 | 分数优先；无色觉限制 | 是 |
| 3 | 保 | C 大学 | 05 组 | 14500 / 14800 / 15100 | 45 | +2600 | 承诺进档不退 | 是 |

（位次 12000 的人：第 1 行差 −1500 属冲，第 2 行差 +100 属稳，第 3 行差 +2600 属保。）

## 提交前六项检查

- [ ] 所有院校与专业代码核对过（代码每年可能变）
- [ ] 批次、选科要求与自己的条件一致
- [ ] 冲的学校要么勾了调剂，要么接受退档风险
- [ ] 章程里的单科与体检要求逐条看过
- [ ] 志愿顺序与真实偏好一致（不是按学校名气排）
- [ ] 保存后退出重登，确认状态「已提交」并截图
