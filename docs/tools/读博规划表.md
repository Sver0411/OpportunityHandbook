## 怎么填

- **可核实成果**：别人能点开链接或拿到文件核对的，才算；「参与过某项目」不算；
- **方法与工具沉淀**：写下可复用的做法（口径、脚本、模板），而不是「学会了某个库」；
- **合作与关系**：写出具体的人与协作方式，方便判断毕业后谁还愿意与你合作；
- **对外露出**：会议、开源、公开分享都算；一年一次都没有，说明毕业时的外部可见度会很低。

## 三个自查问题

1. 这一年新增的东西里，有几项**不需要导师背书**就能证明是你的？
2. 如果毕业时间推迟一年，多出来的时间会投到哪一项上？
3. 现在整理一份「毕业后能拿出的东西」清单，能写满一页吗？
