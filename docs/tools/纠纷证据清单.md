# 纠纷证据清单

流程与求助顺序见 [被欠薪与劳动仲裁](../rights/被欠薪与劳动仲裁.md) 与 [遇到纠纷找谁](../rights/遇到纠纷找谁.md)。

## 表格模板

> 下表列数较多，手机上可横向滑动查看；建议复制到表格软件长期维护。

| 类别 | 证据 | 获取方式 | 保存位置 | 是否已留 |
| --- | --- | --- | --- | --- |
| 劳动关系 | 劳动合同、录用通知、工牌 | 入职时索取/拍照 | 云端 + 本地 | ☐ |
| 金额 | 工资条、银行流水、报销单 | 银行导出、HR 索取 | 云端 | ☐ |
| 出勤 | 打卡记录、排班表、加班审批 | 系统截图/申请导出 | 本地 | ☐ |
| 事实经过 | 时间线（何时发生、谁在场、说了什么） | 自己写，当天记 | 云端 | ☐ |
| 沟通 | 聊天记录、邮件、通话录音 | 截图带日期；录音注意合法取得 | 云端 | ☐ |
| 解除 | 解除通知、谈话记录、账号停用时间 | 保留原件 | 本地 | ☐ |
| 对方主体 | 公司全称、统一社会信用代码、经办人 | 工商公示信息查询 | 文本文件 | ☐ |
| 消费/租房 | 合同、付款凭证、房屋现状照片 | 付款时保存 | 云端 | ☐ |

## 三个必填结论

1. **核心事实一句话**：___（时间 + 对方 + 行为 + 金额）；
2. **缺失的证据与补齐方式**：___；
3. **走哪条渠道与时限**：___（劳动监察/仲裁/12315/报警；仲裁时效一年）。

## 怎么填

- 当天记，不靠回忆；先截屏再整理，避免记录被清理；
- 涉及他人隐私与公司秘密时只保留必要部分，提交时按受理机构要求提供；
- 录音取证注意合法性与场合，不确定时先咨询。
