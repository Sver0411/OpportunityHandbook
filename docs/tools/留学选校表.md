## 怎么填写

- **项目类型**：授课型 / 研究型 / 博士，学位产出与是否需要导师完全不同，见 [授课型与研究型硕士](../../book/04-当你开始面对第一次重要分流.md#overseas-taught-vs-research-master)；
- **语言与小分**：把「总分」与「小分」分开填，很多项目总分够但小分不达标；
- **截止日期**：分轮次的项目要写清是第几轮，滚动录取要标注「先到先审」；
- **资助**：区分国家/政府奖学金、院校奖学金、导师项目经费与助研岗位，来源与截止时间各不相同，见 [奖学金与 Funding](../../book/04-当你开始面对第一次重要分流.md#overseas-funding)；
- **毕业路径**：这一栏必须填**官方**规则（毕业后的工作许可）而不是论坛说法。

## 项目数量

项目数量取决于申请成本（申请费、文书工作量）与匹配度，**不需要为了凑数量设定固定目标**。质量接近时，优先保留「失败后还能接受」的选项。
