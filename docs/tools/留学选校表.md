# 留学选校表

留学值不值得先在主线判断：[留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)。

选校最容易犯的错是只看排名。把项目放进表里，你会发现真正影响结果的是要求与成本。

## 表头怎么设

- 项目名称、学制、授课型还是研究型
- 硬要求：GPA 最低线、语言成绩、先修课程
- 材料清单与截止日期
- 总成本：学费、生活费、奖学金覆盖率
- 匹配度：课程设置与你的目标是否一致

## 怎么用

先按硬要求筛掉不合格的，再按成本筛掉承受不起的，剩下的按匹配度排序。通常保留 6–10 个项目比较合理，分冲刺、主申、保底三档。
