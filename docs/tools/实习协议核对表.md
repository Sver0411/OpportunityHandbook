# 实习协议核对表

配套 [实习协议与实习权益](../../book/04-升学、就业还是出国.md#internship-agreement-rights) 与 [Playbook：第一次找实习](../playbooks/第一次找实习.md)。

## 一、签约前 10 项

| # | 核对项 | 合格标准 | 结果 |
| ---: | --- | --- | --- |
| 1 | 企业主体 | 工商登记可查，状态正常，办公地址一致 | 通过 / 待核实 / 不通过 |
| 2 | 岗位与团队 | 写清岗位名称、所在团队、带教人 |  |
| 3 | 期限 | 起止日期明确，不写"视情况延长" |  |
| 4 | 工时 | 每周几天、每天几小时、是否加班及补偿 |  |
| 5 | 报酬 | 金额/计算方式、发放日、支付方式 |  |
| 6 | 收费 | 无押金、培训费、服装费、材料费、内推费 |  |
| 7 | 保险 | 意外险/雇主责任险由谁投保、保额多少 |  |
| 8 | 保密与知识产权 | 保密范围、成果归属、能否用于作品集 |  |
| 9 | 解除 | 提前几天通知、违约金情形 |  |
| 10 | 学校要求 | 是否需要备案、学分认定、指导老师签字 |  |

**1、6 两项不通过 → 直接放弃。** 其余"待核实"的，问清后再签。

## 二、协议条款要点

| 条款 | 要看什么 | 常见坑 |
| --- | --- | --- |
| 期限 | 起止日、能否续签 | 只写"实习期"不写具体日期 |
| 岗位 | 名称与职责 | "参与项目"这类模糊表述 |
| 地点 | 具体办公地址 | 实际被派到另一个城市 |
| 报酬 | 数字、周期、税费 | "补贴面议""转正后补发" |
| 工时 | 每周上限、加班处理 | 默认 996 却不写 |
| 保险 | 险种与保额 | 只说"有保险"不给凭证 |
| 知识产权 | 成果归属、许可范围 | 一律归公司，作品集也不能用 |
| 解除 | 通知期与违约 | 提前走扣全部报酬 |

## 三、出问题时的顺序

1. 书面沟通（邮件/消息），写明事实与诉求；
2. 找带教、HR、学校指导老师；
3. 固定证据：协议、考勤、工资流水、任务记录；
4. 判断是否构成劳动关系：固定工时、考勤管理、按月发薪、纳入组织；
5. 构成 → 12333 或劳动监察；不构成 → 按民事争议处理，必要时咨询律师。

## 四、结束时 checklist

- [ ] 实习证明/评价（岗位、时间、工作内容、盖章）
- [ ] 成果脱敏（去掉公司数据与未公开信息）
- [ ] 一条具体反馈（做得好/可以更好）
- [ ] 交接记录（文件、账号、设备）
- [ ] 报酬结清
- [ ] 简历写法确认不泄密、不夸大
