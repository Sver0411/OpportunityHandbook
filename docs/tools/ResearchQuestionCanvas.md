# Research Question Canvas

用途：在开题或投稿前把研究问题想清楚。**写不满一页说明还没想好。**

## 一页模板

```
现象（observation）
  我观察到的具体事实（哪个数据、什么条件、哪次实验）：

缺口（gap）
  现有工作做到了什么：
  在什么条件下失效 / 没被解释：

假设（hypothesis）
  如果 …… 那么 …… 因为 ……

研究问题（RQ）
  一句话问句：

贡献（contribution）
  类型：新方法 / 新数据 / 新发现 / 新系统 / 新框架
  用一句话说清它是什么：

可证伪（falsifiability）
  什么结果会证明我错了：

可行性（feasibility）
  数据来源：        设备/被试：
  时间预算：        需要的技能：
  最大风险与备选：

计划产出
  论文 / 报告 / 系统 / 数据集 / 代码：
```

## 填写要点

- 「现象」必须能举出具体例子；
- 「缺口」要指向条件或机制，不能只说「研究得少」；
- 「可证伪」写不出来，说明问题还不成立；
- 「可行性」里的数据与设备要写实际能拿到的，不是理想情况。

## 什么时候重写

- 数据拿不到 → 降级问题（缩小规模或换数据集）；
- 文献显示已有答案 → 前移缺口（问更细的条件）；
- 结果不支持假设 → 缩小主张，把「更好」改成「在什么条件下有效」。

## 示例：填好的一页

```
现象（observation）
  在 3 个公开长尾数据集上，小样本类别（<500 条）的召回普遍低于整体准确率
  20 个点以上；现有改进方法的报告均只给整体指标。

缺口（gap）
  已有工作证明了「重采样能提升整体指标」，但没有说明它在什么数据条件下失效；
  我看到的现象（相似度高的类别上收益消失）在文献里没有解释。

假设（hypothesis）
  如果类别间相似度高，则重采样的收益会随相似度上升而下降，因为重采样放大了
  相似类别之间的决策混淆。

研究问题（RQ）
  重采样的收益与「类别相似度 / 类别样本量」的关系能否被一个可测量的条件指标刻画？

贡献（contribution）
  类型：新发现（条件刻画）
  用一句话说清：给出该类方法有效的条件边界，并说明越界后的负面影响。

可证伪（falsifiability）
  如果收益与相似度无系统性关系（相关性接近 0），则假设不成立。

可行性（feasibility）
  数据：3 个公开长尾数据集（已下载）  设备：1 张消费级 GPU
  时间：14 周  技能：已掌握训练与评估脚本
  最大风险：相似度指标不好定义 → 备选：用类间距离的替代度量

计划产出
  会议论文一篇 + 可复现脚本与实验记录
```
