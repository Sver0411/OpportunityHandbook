# Research Question Canvas

用途：在开题或投稿前把研究问题想清楚。**写不满一页说明还没想好。**

## 一页模板

```
现象（observation）
  我观察到的具体事实（哪个数据、什么条件、哪次实验）：

缺口（gap）
  现有工作做到了什么：
  在什么条件下失效 / 没被解释：

假设（hypothesis）
  如果 …… 那么 …… 因为 ……

研究问题（RQ）
  一句话问句：

贡献（contribution）
  类型：新方法 / 新数据 / 新发现 / 新系统 / 新框架
  用一句话说清它是什么：

可证伪（falsifiability）
  什么结果会证明我错了：

可行性（feasibility）
  数据来源：        设备/被试：
  时间预算：        需要的技能：
  最大风险与备选：

计划产出
  论文 / 报告 / 系统 / 数据集 / 代码：
```

## 填写要点

- 「现象」必须能举出具体例子；
- 「缺口」要指向条件或机制，不能只说「研究得少」；
- 「可证伪」写不出来，说明问题还不成立；
- 「可行性」里的数据与设备要写实际能拿到的，不是理想情况。

## 什么时候重写

- 数据拿不到 → 降级问题（缩小规模或换数据集）；
- 文献显示已有答案 → 前移缺口（问更细的条件）；
- 结果不支持假设 → 缩小主张，把「更好」改成「在什么条件下有效」。
