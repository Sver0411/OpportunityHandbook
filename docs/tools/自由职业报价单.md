# 自由职业报价单模板

用途：把报价变成书面文件。**报价单同时是范围说明书**，写清楚能挡掉大部分后期争议。

## 模板

```
报价单
客户：                  日期：
项目名称：              报价有效期：14 天

一、交付物
1. <交付物名称>：<格式、数量、验收标准>
2. ……

二、不包含
- <明确排除项 1>
- <明确排除项 2>

三、时间安排
启动：            首版交付：            终版交付：
前提：客户需在 <日期> 前提供 <材料>

四、修改
包含 <n> 轮修改；超出部分按 <单价> 计费。

五、费用与付款
总额：<金额>
付款结构：预付 <30%–50%>；里程碑 1 <金额>；尾款 <金额>（验收后 <n> 日内）

六、知识产权
交付物使用权归客户；署名权与作品展示权归乙方（可协商）。

七、其他
- 报价基于上述范围；范围变更将重新评估时间与费用。
- 逾期付款按 <约定> 处理。
```

## 填写要点

- 「不包含」至少写两条——它是防止范围膨胀的关键；
- 付款节点与交付节点绑定，不要只写「完成后付」；
- 修改轮次写数字，不写「适当修改」；
- 有效期写清楚，避免客户几个月后按旧价下单。

## 常见遗漏

| 遗漏 | 后果 |
| --- | --- |
| 没写修改轮次 | 无限修改 |
| 没写验收期限 | 客户长期不反馈，尾款拖着 |
| 没写知识产权 | 作品不能进作品集，或归属争议 |
| 没写前提假设 | 客户材料延迟导致你被追责 |

## 示例：一份真实的报价单

```
报价单
客户：XX 培训            日期：2026-10-06        有效期：14 天

一、交付物
1. 学员报名页（移动端优先）：支持填表、重复报名校验
2. 名单管理页：按课程/时间筛选，标记已缴费
3. 名单导出：CSV，字段含姓名、电话、课程、时间、缴费状态

二、不包含
- 在线支付与退款流程
- 营销落地页与优惠券
- 多校区数据隔离

三、时间安排
启动：10-07      首版交付：10-18      终版交付：10-27
前提：客户需在 10-07 前提供课程清单与现有名单样例

四、修改
包含 2 轮；超出部分 500 元/轮

五、费用与付款
总额：12,000 元
预付 4,800（40%，开工前）｜首版验收 4,800｜尾款 2,400（终版验收后 7 日内）

六、知识产权
交付物使用权归客户；乙方保留作品展示权（已与客户确认可在作品集展示）

七、其他
- 报价基于上述范围，范围变更将重新评估时间与费用。
- 需求变更以邮件确认为准。
```

**这份报价单挡住了三次潜在纠纷**：加了导出（明确写进范围）、拒绝了「家长端」（写进不包含）、尾款节点明确（验收确认后 7 日）。
