# 求职追踪表

校招期间同时推进几十家公司，靠记忆一定出错。用一张表把状态外化。

## 表头怎么设

- 公司、岗位、投递渠道、投递日期
- 当前阶段（投递 / 笔试 / 一面 / 二面 / HR 面 / Offer）
- 下一次动作与时间点
- 关键反馈（被问倒的问题、面试官提到的要求）

## 怎么用

每天更新一次状态，每周复盘一次转化率：哪一类岗位笔试过得多、哪一类一面就被拒。转化率低的那一类，问题通常出在简历与方向不匹配，而不是面试技巧。
