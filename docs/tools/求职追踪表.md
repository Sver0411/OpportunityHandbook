# 求职追踪表

投递节奏见主线 [校招是怎么运作的](../../book/05-从学校走向第一份工作.md#campus-recruiting-timeline)，渠道与简历见 [没经验怎么找实习](../../book/03-开始积累真正能留下来的经历.md#internship-how-to-find)。

## 为什么一定要记录

求职失败多半不是「投得不够多」，而是**没有数据**：哪一轮挂掉、挂了几个、简历通过率多少，这些决定你该改简历还是改定位（见 [长期找不到工作怎么办](../../book/05-从学校走向第一份工作.md#job-hunting-long-search)）。这张表就是你的数据来源。

## 每列怎么填

- **渠道**：官网 / 平台 / 内推 / 学校就业网 / 招聘会——两周后对比各渠道的回复率，就知道该把时间投在哪；
- **当前阶段**：投递 → 笔试 → 一面 → 二面 → HR 面 → Offer；阶段写清楚才不会漏跟进；
- **下一动作 + 截止时间**：这两列是真正驱动进度的，写完立刻排进日历；
- **面试反馈**：每场面试后 24 小时内写一句「哪道题答得不好」，见 [专业面](../../book/05-从学校走向第一份工作.md#job-hunting-interview)；
- **最终结果**：录用 / 拒绝 / 自己放弃（写清原因，它是下一轮的判断依据）。

## 复盘节奏

每两周花二十分钟过一遍：投递量、通过率、卡在哪一轮。通过率低于 5% 是简历与定位问题；面试挂得多是表达或匹配问题——两类问题的解法完全不同。
