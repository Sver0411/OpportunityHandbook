# 转行 Bridge Plan

转行前先判断什么，见主线 [转行前先判断什么](../../book/07-当职业开始出现分岔.md#switch-before-decide)；过渡机会的概念见 [Bridge Opportunity](../../book/07-当职业开始出现分岔.md#career-bridge-opportunity)。

## 计划模板（可直接复制填写）

```text
当前岗位：
目标岗位：
（目标岗位的 2–3 条硬性要求，来自真实 JD）

已有能力（能拿出证据的）：
已有行业经验（可迁移的）：
缺口（技能 / 经验 / 证书 / 人脉）：

Bridge Opportunity（同时沾着两边的位置）：
  · 候选一：
  · 候选二：

3 个月动作（可检查的）：
  · 第 1 个月：
  · 第 2 个月：
  · 第 3 个月：

可验证成果（做完以后能拿给别人看什么）：

市场反馈（投递 / 面试 / 从业者访谈的结论）：

是否继续（继续 / 调整 / 停止，以及判断依据）：
```

## 怎么用才有效

- **目标岗位一栏必须来自真实 JD**，不要写「我想做数据相关的工作」这种模糊方向；
- **缺口要分类**：技能可以自学补；经验要靠过渡岗位；证书有明确考试周期；人脉靠社群与访谈——四类解法不同；
- **3 个月动作必须可检查**：写「完成一个数据分析项目并公开」而不是「多学习」；
- **可验证成果**是这张计划的核心，见 [什么叫可验证成果](../../book/00-从这里开始.md#judge-verifiable-outcomes)；
- **市场反馈**决定继续还是调整：投了三十份没有面试，说明缺口判断有误，回到上一栏重写。
