# 转行 Bridge Plan

转行前先判断什么，见主线 [转行前先判断什么](../../book/07-当职业开始出现分岔.md#switch-before-decide)。

Bridge Plan 的作用是避免「先辞职再想」。它把转行拆成四段，每段都有可检查的产出。

## 四段结构

- 现状：你现在能交付什么，有哪些可迁移的东西
- 目标：目标岗位的具体要求（从 JD 里抄，不要凭印象）
- 缺口：现状与目标之间差什么，按重要性排序
- 桥接动作：三个月内能完成、并且能被验证的两三件事

## 怎么检查

每个月问一次：桥接动作有没有产出可展示的东西？如果没有，说明计划停留在「学习」，需要改成「交付」。
