# 论文精读表（Paper Reading Sheet）

用途：读完一篇留下**能用的东西**，而不是一堆划线。也用于反向评审自己的稿件。

## 模板

| 字段 | 内容 |
| --- | --- |
| 文献 | 标题、作者、年份、发表处 |
| 一句话贡献 | 只用一句 |
| 问题 | 它要解决什么 |
| 主张（claims） | 逐条列出 |
| 证据（evidence） | 每条主张对应哪张表/图 |
| 方法 | 关键设计、与已有方法的差异 |
| 数据与设置 | 数据集、规模、划分、指标 |
| 基线 | 和谁比、公平吗 |
| 消融 | 去掉什么后结论如何 |
| 局限 | 作者写的 + 你发现的 |
| 可复用 | 方法、数据集、代码、指标口径 |
| 可反驳 | 哪个结论你不信，为什么 |
| 与我的关系 | 我用得上哪一部分 |

## 填写要点

- 「主张—证据」两栏必须一一对应，缺对应的地方就是可疑之处；
- 「局限」至少写两条（包含你自己发现的）；
- 「可复用」写具体（某段流程、某个指标定义），不写「思路有启发」。

## 什么时候用

- 读新领域的前 5 篇：建立地图；
- 写相关工作章节：逐篇填，最后合并；
- 投稿前：拿自己的稿件当被读对象填一遍，找出「主张没有证据」的地方。
