# 导师筛选表

选导师不要只看名气。把候选导师放进同一张表里比，差异才会显现。

## 表头怎么设

- 研究方向与你的匹配度
- 指导方式（放养还是手把手）、组会频率
- 近三年毕业生的去向
- 组内是否有稳定的资助与设备
- 风险信号（延期比例、学生评价、是否常年在外）

## 怎么用

先填公开信息（学院主页、实验室主页、论文署名），再找组内学生聊一次，把听到的与看到的对照。任何一项出现明显矛盾，都要谨慎。
