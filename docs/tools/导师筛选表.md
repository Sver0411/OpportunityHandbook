# 导师筛选表

判断要不要跟这位导师，见主线 [怎么找导师](../../book/03-开始积累真正能留下来的经历.md#research-find-supervisor) 与 [怎么判断一个实验室](../../book/03-开始积累真正能留下来的经历.md#research-choosing-a-lab)。本页只提供可直接使用的表格。

## 怎么用

每个候选导师一行（或复制一份表格）。前四列查官网与论文可以填，**后四列必须问组里的在读或刚毕业的学生**——这也是这份表的价值所在。填完之后横向比较，而不是凭某一条印象做决定。

## 每列怎么判断

- **方向匹配**：读他近三年的论文摘要，确认现在做的和你想做的是不是一回事（方向会迁移）；
- **指导方式**：手把手还是放养？你是不是需要被推着走的人？这一列只有问学生才准；
- **经费 / 资助**：组里有没有在研项目，助研津贴与设备条件如何，见 [Grant](../../book/04-当你开始面对第一次重要分流.md#funding-grant)；
- **毕业生去向**：近几届学生去了哪、几时毕业；去向是最好的风向标；
- **风险信号**：常年不指导、学生延期比例高、没有稳定资助、学生评价普遍回避——出现任何一项都要多问几层。
