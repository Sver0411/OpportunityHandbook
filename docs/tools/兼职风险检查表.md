# 兼职风险检查表

配套 [Playbook：大学生兼职与校园诈骗风险](../playbooks/兼职与校园诈骗风险.md)。用法：把这张表发给对方之前，先自己填一遍；**任一项填"不通过"，就不要去**。

## 一、接活前（12 项）

| # | 检查项 | 通过标准 | 结果 |
| ---: | --- | --- | --- |
| 1 | 招聘信息来源 | 企业官网/正规招聘平台/学校就业网可查 | 通过 / 不通过 |
| 2 | 企业主体 | 国家企业信用信息公示系统能查到，状态正常 | 通过 / 不通过 |
| 3 | 联系人身份 | 有公司邮箱/座机，不只有私人微信 | 通过 / 不通过 |
| 4 | 收费 | 不收押金、服装费、培训费、材料费、保证金 | 通过 / 不通过 |
| 5 | 贷款/分期 | 不要求下载借贷 App、不签分期、不"先学后付" | 通过 / 不通过 |
| 6 | 账户出借 | 不要求借银行卡、支付账户、手机号、身份证 | 通过 / 不通过 |
| 7 | 工作内容 | 能说清做什么、在哪做、几小时、谁带 | 通过 / 不通过 |
| 8 | 报酬 | 金额、结算周期、支付方式写清 | 通过 / 不通过 |
| 9 | 书面约定 | 有协议或聊天记录明确上述内容 | 通过 / 不通过 |
| 10 | 地点 | 公开场所；第一次不单独赴约 | 通过 / 不通过 |
| 11 | 人身安全 | 已告诉一位同学或家人地点与返回时间 | 通过 / 不通过 |
| 12 | 学业冲突 | 不占用上课与考试周，周工时可控 | 通过 / 不通过 |

**任一项不通过 → 不接。** 待核实的项，核实完再决定。

## 二、报酬与结算（5 项）

| # | 检查项 | 说明 |
| ---: | --- | --- |
| 1 | 计薪方式 | 按小时/按件/按天，写清单价 |
| 2 | 结算周期 | 日结/周结/月结，具体到哪一天 |
| 3 | 支付方式 | 转账到本人账户，留流水 |
| 4 | 扣款条件 | 迟到、差错、未完成怎么扣，事先说清 |
| 5 | 拖欠处理 | 拖欠时找谁、多久算拖欠、怎么留证 |

## 三、证据留存（7 项）

出问题时，下面这些决定了你能不能维权：

- [ ] 招聘页面截图（含网址与时间）
- [ ] 聊天记录（完整，不删）
- [ ] 对方账号、手机号、微信号
- [ ] 转账记录/订单号
- [ ] 协议或收据照片
- [ ] 考勤/排班/任务记录
- [ ] 工作成果与交付记录（文件、截图）

## 四、出事后第一步（按情形）

| 情形 | 第一步 |
| --- | --- |
| 刚转账 | 联系银行/支付平台止付 → 110 报警 → 保存记录 |
| 被要求再转一笔才能退 | 停止转账，保存记录，报警 |
| 账户/信息泄露 | 改密、挂失、查异常交易与征信 |
| 拖欠工资 | 固定证据 → 与对方书面沟通 → 12333 或劳动监察 |
| 人身威胁/骚扰 | 不单独见面，告诉可信任的人，报警 |
| 平台商家欺诈 | 平台举报 → 12315 → 必要时报警 |
