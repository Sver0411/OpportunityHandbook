# 探索复盘模板

方向探索失败最常见的原因不是「试得太少」，而是**试过就忘了**。三个月后你能回忆起的只有「当时感觉还行」或「挺累的」，这两句话不能支撑任何决定。

所以这个模板的核心要求是：**在尝试结束的 48 小时内写下，不超过半页。** 隔得越久，记录越像事后编的故事。

## 六个问题

每个问题只写能落到具体事实上的一句话。写不出来就写「写不出来」，那也是信息。

**1. 我喜欢吗？**
不是「有没有兴趣」，而是：在做这件事的过程中，哪一段我愿意主动多做一会儿？哪一段我一直在拖延？

**2. 我擅长吗？**
和我同起点、同样投入时间的人比，我的产出处于什么位置？如果身边没人可比，就和自己其他尝试横向比。

**3. 别人认可吗？**
有没有具体的人（不是我自己）对结果给出过评价？是具体的技术反馈，还是社交层面的鼓励？后者不算。

**4. 我愿意继续吗？**
如果现在给我下一个同样的任务，我的第一反应是想接还是想推？按第一反应写，不要按「应该」写。

**5. 留下了什么？**
用一句话回答：这件事结束后，我手上多了一件**别人能看或能用**的东西吗？如果有，是什么（链接/文件/作品/证明）？如果没有，为什么没有？

**6. 打开了什么？**
因为这次尝试，多出了哪些具体机会或人？值得再联系的有谁？

## 记录格式

```
日期：
尝试内容（一句话）：
实际投入：__ 小时 / __ 周

1. 喜欢： 
2. 擅长： 
3. 认可： 
4. 继续： 
5. 留下： 
6. 打开： 

下一步（要么具体行动 + 截止日期，要么写「到此为止」）：
```

## 怎么用这些记录

- **攒到 5–10 条再回看。** 单次记录说明不了问题；多次记录里反复出现的「喜欢」和「擅长」才有指向。
- **看「留下」这一栏的空白率。** 如果连续几次都是空的，问题不在方向选择，而在尝试方式——每次都只做体验，不做产出。
- **注意「认可」栏全是礼貌性反馈的情况。** 说明你的尝试还没有进入有反馈压力的环境（比如正式比赛、开源 review、真实用户），这类环境才是有效实验。
- **不要用「继续」栏替代决定。** 这一栏写的是意愿，不是决定；决定要结合时间成本与当时的其他选择来做。

## 两个反模式

**把「不喜欢」当成失败。** 排除法也是收获。一次明确告诉你「不要再做这个」的尝试，价值不低于一次确认「我要做这个」的尝试。

**把「喜欢」当成方向。** 喜欢只是必要条件之一。三个条件同时成立才值得追加投入：**愿意做、能做出比别人好的结果、有人愿意为这个结果付出（给钱、给名额、给机会）**。
