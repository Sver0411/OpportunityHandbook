**沟通时的四句话**：我是谁 → 具体问题与时间 → 依据哪条制度提出什么请求 → 希望何时得到答复。

## 五、书面申请草稿（照此填写）

```
标题：关于××的申诉/复核申请
一、基本情况
  姓名 / 学号 / 学院 / 专业 / 联系电话
二、事实经过（按时间顺序，只写事实）
  ×年×月×日，……
三、依据
  学校《××办法》第×条；《普通高等学校学生管理规定》第×条
四、请求
  （具体：撤销/变更/重新核定/允许补考或补作）
五、附件
  1. 决定书复印件  2. 成绩单  3. 聊天记录截图
```

## 六、提交与跟进

- [ ] 当面递交并要签收，或线上提交后截图"提交成功"
- [ ] 记录受理编号/经办人/答复期限
- [ ] 到期未答复，书面催问一次并留存
- [ ] 拿到书面结论后，判断是否进入下一层渠道
