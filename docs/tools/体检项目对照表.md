# 体检项目对照表

项目如何选、报告异常怎么跟进，见 [体检怎么选、医保怎么用](../../book/17-身体与心理的可持续性.md#health-checkup-and-insurance)。

## 表格模板

> 下表列数较多，手机上可横向滑动查看；建议复制到表格软件长期维护。

| 分组 | 项目 | 适用情形 | 频率参考 | 我的安排 |
| --- | --- | --- | --- | --- |
| 基础 | 身高体重、血压、内外科 | 所有人 | 每年 | |
| 基础 | 血常规、尿常规、肝肾功能、血脂血糖 | 所有人 | 每年 | |
| 基础 | 胸片、心电图、腹部超声 | 所有人 | 每年或按医生建议 | |
| 按需 | 女性宫颈与乳腺相关筛查 | 按指南与年龄 | 按指南 | |
| 按需 | 胃肠镜 | 40 岁以上或有家族史/症状 | 按医生建议 | |
| 按需 | 职业病相关项 | 特定岗位（粉尘、噪声、化学） | 按单位与法规要求 | |
| 谨慎 | 无指征的全身 CT、肿瘤标志物大套餐 | — | 不建议常规做 | |
| 谨慎 | 反复同类检查 | 已做过且无症状 | 不重复 | |

## 三个必填结论

1. **今年要做的项目**：___（按风险，不按价格）；
2. **需要复查的异常项与时间**：___；
3. **去哪家机构与费用承担方式**：___（单位体检 / 医保 / 自费）。

## 怎么填

- 先勾基础项，再按家族史、年龄、性别与职业勾加项；
- 报告异常不要自行检索下结论，按提示到对应专科复查；
- 保存每年报告，用趋势而不是单次数值判断。
