# 联系导师邮件模板

写「套磁信」失败的最常见原因是：整封信里除了自我介绍，没有任何关于收信人的信息。导师一天收到几十封标题是「老师您好，我想读您的研究生」的邮件，唯一能让他们停下来的是**你读过他在做什么，并且你能说出一件具体的事**。

下面是结构，不是范文。套用句子而不替换里面的具体内容，效果和群发一样。

## 一、标题

写清三件事：身份 + 意图 + 时间。

```
2027 年秋季入学博士申请咨询 · [你的名字] · [你现在的学校/单位]
```

不要用「老师您好」「求指点」「紧急」这类无法检索的标题。

## 二、正文结构

**第 1 段（2–3 句）：为什么是这位导师，具体到工作。**

不是说「我对您的研究方向很感兴趣」，而是说清你读了什么、哪一点让你觉得和自己的问题有关。可以引用某一篇的具体做法或结论，但**不要假装读懂了你不懂的东西**——被追问时会更难堪。

**第 2 段（3–5 句）：你是谁，能提供什么。**

- 现在的学校、专业、年级（或已毕业多久）。
- 做过的、和该方向相关的一件具体事：课程项目、毕业论文、开源贡献、复现、实习。给出链接或材料名。
- 会用的工具、方法或语言（只写真的会用的）。
- 成绩单里能说明问题的部分（如果排名靠前就写排名；不靠前就不写，不要含糊其辞）。

**第 3 段（2–3 句）：你要什么，什么时候要。**

明确说清：是想申请硕士、博士、暑研、RA、访问学生，还是只想问一个具体问题。附上你的时间：什么时候可以开始、能投入多久。

**第 4 段（1–2 句）：附什么，能不能进一步聊。**

列出附件（简历 PDF、成绩单、作品或代码链接）。说明你愿意先做一个小任务来证明自己——这对招生方是低成本的验证方式。

**结尾**：署名 + 学校邮箱（不要用昵称邮箱）。

## 三、发送前自查

- [ ] 收信人姓名与职称拼写正确，没有群发痕迹（没有「尊敬的各位老师」）。
- [ ] 至少有一句话只可能对这一位导师说。
- [ ] 附件是 PDF，文件名带你的名字（例如 `姓名-简历-2027博士申请.pdf`）。
- [ ] 全文能在一屏内读完，没有超过 300 字。
- [ ] 没有写「我会努力学习」「我很有毅力」这类无法验证的话。
- [ ] 抄送/密送列表是空的。
- [ ] 发出前查过该导师的官方页面，确认他今年是否招生（很多院系会公示招生名额与方式）。

## 四、发送节奏

- 同一院系**一次只联系一位**导师，等回复再联系下一位。同时联系同组多位导师，在这个圈子里会很快传开。
- 一周到十天没有回复是常态，可以在原邮件后回一封简短提醒（不要新建邮件、不要重复长信）。
- 收到「今年不招」也是有效信息，把它记进你的备选清单，明年可以再问。

## 五、容易被忽略的两件事

**不要问官网上写着的问题。** 招生名额、申请截止日期、语言要求、材料清单，这些都在招生页面里。问这些会直接暴露你没有做功课。

**不要附上你无法解释的材料。** 简历里写了的东西，面试或邮件追问时都要能展开讲。写不出来的项目不如不写。

## 证据与来源

- 本页是沟通方法模板，属于综合性实践建议，没有统计意义上的效力证据。
- 各院校的招生方式、导师招生名额、申请材料清单以**招生单位当年发布的招生简章与院系官网**为准；不同单位差异很大，需要按具体项目核实。
- 学科差异明显：部分学科以入学后轮转（rotation）分配导师，部分学科需要提前确定导师。本模板适用于后者。
