# 新生入学检查表

配套 [Playbook：大学新生入学与第一个月](../playbooks/大学新生入学与第一个月.md)。用法：打印或在备忘录里复制一份，**每完成一项就写上日期与凭证位置**。

## 一、报到前（出发前 1–2 周）

| # | 事项 | 怎么算完成 | 凭证/记录 |
| ---: | --- | --- | --- |
| 1 | 录取信息核对 | 省考试院/学校官网查到的结果与通知书一致 | 查询截图 |
| 2 | 通知书真伪 | 学校公章、校长签名、EMS 信息一致 | 通知书与快递单照片 |
| 3 | 报到安排 | 日期、校区、是否预报到都确认 | 官方通知截图 |
| 4 | 材料备齐 | 身份证、通知书、照片、党团材料、困难证明（如需） | 材料清单打勾 |
| 5 | 学费住宿费 | 官方渠道缴纳，或已申请绿色通道 | 缴费凭证/回执 |
| 6 | 助学贷款 | 已申请或已问清办理流程与截止时间 | 合同/受理单 |
| 7 | 户口 | 明确迁或不迁，并问过家里与派出所 | 结论与依据 |
| 8 | 档案 | 明确寄送还是自带；自带保持密封 | 寄送单号/接收单 |
| 9 | 医保 | 知道参保方式与时间 | 通知截图 |
| 10 | 行程与住宿 | 到校路线、提前一晚住宿已定 | 订单 |
| 11 | 官方联系方式 | 招生办、学院、辅导员电话已存 | 通讯录 |
| 12 | 防骗底线 | 知道"不向个人账户转账、不点陌生链接、不填验证码" | — |

## 二、到校第一周（六件事 + 四份文件）

| # | 事项 | 去哪办 | 完成标志 |
| ---: | --- | --- | --- |
| 1 | 报到注册 | 迎新点/学院 | 拿到报到单、学生证/校园卡 |
| 2 | 住宿登记 | 宿舍楼管/后勤 | 拿到钥匙、知道维修电话 |
| 3 | 校园网与系统账号 | 网络中心/信息化办 | 能登录教务与图书馆 |
| 4 | 见辅导员 | 学院 | 加班级群、存办公室位置 |
| 5 | 找三个部门 | 教务/图书馆/资助中心 | 知道办公时间与流程 |
| 6 | 参保 | 校医院/学生处 | 参保凭证 |
| 7 | 学生手册 | 学院/官网 | 电子版存好 |
| 8 | 培养方案 | 教务系统 | 知道总学分与实践环节 |
| 9 | 选课规则 | 教务系统/学院 | 知道选退课时间与绩点算法 |
| 10 | 学院实施细则 | 学院官网 | 转专业、评优、推免口径 |

## 三、第一个月复盘

| 问题 | 回答 | 下一步 |
| --- | --- | --- |
| 每门课的考核方式与绩点算法都清楚吗？ |  | 不清楚的列出来，第二周问老师 |
| 有一门课已经跟不上吗？ |  | 答疑/找学长/看退课窗口 |
| 社团与活动占了多少小时？ |  | 超过每周 6 小时就砍掉一个 |
| 生活费实际花了多少，和预算差多少？ |  | 调整下月预算 |
| 缴费、住宿、参保凭证都在同一个文件夹吗？ |  | 补齐缺的 |
| 有没有需要求助但还没开口的事？ |  | 按"找谁"表行动 |

## 使用说明与风险提示

- **所有材料要求以本校新生须知为准**：这张表是通用骨架，不代替学校通知；
- **凭证统一命名**：`年份-事项-金额或编号`，例如 `2026-学费-8000`，存在同一文件夹；
- **不要提前购买推销品**：上门推销、群里的"新生必备清单"、收费"新生指导"都不必买；
- **涉及转账的操作只走学校官方渠道**：任何人通过私聊要求付款，先打学校官方电话核实。
