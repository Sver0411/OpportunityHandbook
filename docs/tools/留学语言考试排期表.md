# 留学语言考试排期表

方法见 [雅思还是托福：按目标项目倒推](../../book/05-备考与应试/03-留学语言考试怎么准备.md#lang-test-choice) 与 [小分不达标、成绩复议与二刷](../../book/05-备考与应试/03-留学语言考试怎么准备.md#lang-test-score-issues)；选校配合 [留学选校表](留学选校表.md)。

**填表顺序**：第 1 节先填（它决定后面所有日期）→ 第 2 节倒排 → 第 3 节填备考 → 第 4 节决策点。

## 1、目标分数（先填这一张）

| 项目 | 总分要求 | 我的目标（留余量） | 口语 | 听力 | 阅读 | 写作 | 截止日 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| （示例）X 大学 Y 项目 | 6.5 | 7.0 | 6.5 | 6.5 | 7.0 | 6.5 | 材料截止 ___ |
|  |  |  |  |  |  |  |  |

**为什么要留余量**：实际拿分常比模考低（口语、写作尤其明显）。目标 = 要求 + 0.5 通常更稳。

**必须逐校填**：不同项目要求不同，同一学校的不同项目也可能不同。查项目官网的语言要求栏。

## 2、四步倒排

| 步骤 | 做什么 | 结果 |
| --- | --- | --- |
| 1 定最晚到手日 | 以**材料截止日**为准（多数早于申请截止日） | 一个日期 |
| 2 减去出分周期 | 官方公布的出分天数 + 送分时间 | 考试日期上限 |
| 3 减去备考周期 | 见第 3 节，按起点水平定 | 报名日期 |
| 4 选考位与场次 | 按考试日期倒推可约的考位 | 具体的报名动作 |

**填这一段**：

| 项 | 我的值 |
| --- | --- |
| 材料截止日 |  |
| 需要留的缓冲（建议 2–4 周） |  |
| 考试日期上限 |  |
| 建议的考试日期（留一个更早的备选） |  |

**一次约两场**不同月份的做法很常见：第一次当尝试，第二次当缓冲，第二次要早约（考位有限）。

## 3、备考周期按起点定

| 起点（模考或上次成绩） | 建议周期 |
| --- | --- |
| 离目标差 1 分以上，或从没考过 | 2–3 个月 |
| 离目标差 0.5 以内 | 6–10 周 |
| 已有成绩，只差小分 | 定向补短板 4–8 周 |

**每周安排**（复制这一段填）：

| 周次 | 听力 | 阅读 | 口语 | 写作 | 本周完成标志 |
| --- | --- | --- | --- | --- | --- |
| 第 1 周 |  |  |  |  | 模考定位 |
| 第 2 周 |  |  |  |  |  |
| … |  |  |  |  |  |
| 最后一周 | 整套模考 | 整套模考 | 录音自评 | 找反馈 | 考前减量 |

**填表规则**：短板那项的每周时间至少占三成。

## 4、决策点（考完之后才用得上）

| 情况 | 决策 | 依据 |
| --- | --- | --- |
| 总分与小分都达标 | 直接送分投递 | — |
| 总分达标、小分差一点 | 先看目标项目能不能接受；不能则考虑二刷或换项目 | 见 [小分不达标](../../book/05-备考与应试/03-留学语言考试怎么准备.md#lang-test-score-issues) |
| 明显低于目标，但自己觉得考砸了 | 二刷（间隔 2–3 个月） | 同上 |
| 明显低于目标，且确实没准备好 | 二刷或换项目，取决于时间 | 同上 |
| 分数与自我感觉差距大 | 可申请成绩复核 | 复核有时限，别耽误投递 |

## 怎么填才不填错

- **截止日以材料截止为准**，不是申请截止；部分项目材料截止早几个月；
- **考位要确认成绩适用范围**：不同考位可投递的学校范围可能不同，报名前查清；
- **小分逐项填**，不要只填总分——拒信多数出在小分；
- **出分与送分时间以官方当年说明为准**（https://ielts.neea.cn/ 、https://www.ets.org/toefl/），不要按往年印象排。
