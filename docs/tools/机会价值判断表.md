# 机会价值判断表

这张表把 [怎么判断一个机会值不值得](../../book/00-从这里开始.md) 里的判断框架做成可以直接填的形式。它不替你决定，只负责把「感觉挺好」拆成能回答的问题。

使用时先看一个原则：**任何一项填不出来，都不要用「应该还行吧」糊过去。** 填不出来本身就是一种判断——说明你还没有足够信息，需要先去找信息，而不是先做决定。

## 第三栏：四个必答问题

1. **这次结束以后，我能拿出一件别人能核查的东西吗？** 如果答案是「只能说自己参加过」，价值通常有限。
2. **不参加的话，我本来会用这些时间做什么？** 把那个替代方案写在旁边。如果替代方案明显更好，答案已经出来了。
3. **这件事和我现在的目标之间，是必经之路还是加分项？** 必经之路（学历门槛、执业资格）优先级高；加分项要排在必经之路之后。
4. **如果我现在不做，一年后还有机会做吗？** 只在窗口期开一次的机会（应届身份、某年政策、某位导师招生）要单独加权。

## 怎么读结果

- **换回栏全空、付出栏很满**：这是一次消费（体验、社交、自我感动），不是投资。可以做，但要承认它是什么，不要记成职业资本。
- **换回栏有东西，但「能验证吗」全是「只有自己知道」**：短期可能有用，长期价值取决于你能不能把它转成公开或可核查的成果。
- **两个机会比较时**：先把两边都填一遍，然后只看两栏里**只有一边有**的项目，忽略两边都有的。两边都有的项在比较里没有信息量。

## 常见误区

- **把「过程」当「成果」。** 「我在这个项目里学到了很多」不是成果；「我做出了 X，被 Y 用在了 Z」才是。
- **高估含金量低但名字响的机会。** 名字响属于第一栏的「声誉」，但声誉必须由可验证的成果支撑，否则别人一追问就露。
- **漏算机会成本。** 时间是最容易被漏掉的一项，因为它不花现金。
- **把「拒绝好机会」当损失。** 机会成本是双向的：接受一个机会也需要理由，不只是拒绝需要理由。

## 什么时候不必填这张表

这张表是为「选择成本高、信息又不够」的场景设计的。下面两种情况不要用它：

- **小额、可逆的决定**（听一次讲座、试一门课）：直接去做，试错成本低于填表的时间；
- **信息严重不足时**：第一栏填不出来，往往是因为你还不了解这件事。此时正确的动作是去收集信息（问从业者、读官方规则），而不是继续硬填。

**填表不能替代调研。** 它的作用是在你掌握了基本情况之后，把散落的判断组织成可比较的结构。

## 两栏都填满却仍然选不出来

这通常说明你在比较的其实是三件以上的事，或者你在回避一个不想面对的问题。两种处理：

- **把「只有一边有」的项目单独拎出来**，看是不是某一项的权重压倒性地高——户口、家庭所在地、健康，这类约束一旦出现，其余项的比较基本失去意义；
- **问自己：如果必须今天决定，我会选哪个，为什么？** 第一反应的答案往往暴露真实偏好，之后的推演都是在为它找理由。

如果第一选择和理性分析长期冲突，值得停下来想清楚冲突来自哪里。多数时候答案是某个你没写进表里的约束：家庭期待、伴侣安排、身体条件。
