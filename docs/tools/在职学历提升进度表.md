# 在职学历提升进度表

判断见 [统招专升本与成人教育怎么选](../../book/05-备考与应试.md#zsb-path-choice)，时间结构见 [在职学历提升](../timelines/在职学历提升时间线.md)。

**填表顺序**：第 1 节填用途与约束（事实）→ 第 2 节填通道 → 第 3 节把节点写成日期 → 第 4 节核学位条件 → 第 5 节写退路。**先填事实，再填判断。**

## 1、用途与约束

| 问题 | 我的答案 | 依据（写清来源与日期） |
| --- | --- | --- |
| 这个学历用来做什么（考编/评职称/考研/换行业） |  |  |
| 目标岗位或考试对"学习形式"怎么要求 |  | 公告第几条，哪天发布 |
| 是否要求"第一学历" |  |  |
| 我每周能稳定投入几小时 |  |  |
| 能否接受 2 年、3 年、4 年的周期 |  |  |
| 单位是否知情、是否影响现职 |  |  |

> 第 2 行是整张表的关键。公告写"全日制"的岗位，非全日制报不了；这一条决定后面所有选择。

| 节点 | 本省/本校规定的时间 | 我这一年的日期 | 提前多久准备 |

> 每一格都要写"我从哪看到的"（考试院公告/院校通知/学位细则）。凭印象填的日期等于没填。

## 4、学位条件自查

毕业证与学位证是两件事。下面四项逐项抄目标院校的学位细则：

- [ ] 课程平均分要求（是多少、怎么算、含不含重修）
- [ ] 学位外语或主干课考试（考什么、几次机会、什么时候考）
- [ ] 论文成绩要求（"良好"以上还是"及格"即可）
- [ ] 申请期限（毕业后多久内必须申请）

**这四项要在第一年核完。** 多数人到最后一年才发现平均分不够，而那时已经没有课可以拉分了。

## 5、退路（最容易被跳过的一节）

- 如果这次报名错过：下一次是什么时候，中间这几个月做什么；
- 如果连续两科不过：换科目、换考区还是换通道；
- 如果单位不认：转向哪个岗位或哪类单位，需要补什么；
- 如果中途放弃：已考的科目成绩能保留多久（各省规定不同），是否值得保留。

## 怎么填才不填错

1. **先填用途，再填通道**。顺序反了，会选一条读完才发现用不上的路。
2. **日期优先于计划**。"今年考完"不是节点，"某月某日前完成报名"才是。
3. **给重考留位置**。计划里至少预留一次重考与一次答辩顺延，否则第一次意外就会让整条线失效。
4. **每学期更新一次**。政策与考期会变，去年的日期不能直接套。
