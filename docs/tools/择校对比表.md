# 考研择校对比表

方法见 [考研怎么定目标校：择校的操作步骤](../../book/04-升学、就业还是出国/09-考研择校与信息透明度.md#kaoyan-choose-school-steps) 与 [怎么判断压分与信息透明度](../../book/04-升学、就业还是出国/09-考研择校与信息透明度.md#kaoyan-school-picking)；节奏见 [考研时间线](../timelines/考研时间线.md)。

留学选校用 [留学选校表](留学选校表.md)，方向与导师筛选用 [导师筛选表](导师筛选表.md)。**这张表只管考研**。

## 表一：候选池（先宽后窄）

按专业代码从研招网专业目录（https://yz.chsi.com.cn/zsml/）把开设该专业的招生单位全部列出，先不筛学校。

| 学校 | 专业代码 | 初试科目 | 专业课自命题/统考 | 学制 | 学费 | 备注（为什么先留着） |
| --- | --- | --- | --- | --- | --- | --- |
| （示例）X 大学 A 学院 | 081200 | 408 + 英二 | 统考 | 3 年 | 官网学费标准 | 专业课统考，复习可迁移 |
|  |  |  |  |  |  |  |

**用法**：填满再砍。砍除条件只有三条——不招这个代码、专业课与你不一致、近三年复试线上行且未扩招。

## 表二：五字段对比（砍到十所以内后填）

| 学校 | 招生总人数 | 推免占比 | 统考名额（推算） | 近三年复试线 | 复试比例 | 学制/学费 | 判断 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| （示例）X 大学 A 学院 | 40 | 约 60% | 约 16 | 2023：___ / 2024：___ / 2025：___ | 1:1.3 | 3 年 / ___ | 统考名额偏少，谨慎 |

**统考名额 = 招生总人数 − 推免人数**。推免人数通常不单独公布，可用「总人数 × 推免比例」推算，或直接问研招办。这个数字是分数的**主因**，比任何难度评价都可靠。

| 学校 | 近三年复试线中位数 | 我的预估分数 | 差额 | 定位 |
| --- | --- | --- | --- | --- |
| （示例）X 大学 A 学院 | ___ | ___ | +___ | 主选 / 冲刺 / 保底 / 放弃 |

用**中间年份**做参照，不用最高或最低的一年。

| --- | --- | --- | --- | --- |
| 主选 1 |  |  |  |  |

| 平行 |  |  |  |  |
| 保底 |  |  |  |  |

**关键约束**：多数年份同一批次只能填报一个第一志愿，平行志愿在调剂环节使用。所以「主选」只有一个真正生效，其余是调剂备选。

## 怎么填才不填错

- **专业课自命题**：填「是/否」，不要留空。留空会让后面算错换校成本（见 [考研怎么定目标校：择校的操作步骤](../../book/04-升学、就业还是出国/09-考研择校与信息透明度.md#kaoyan-choose-school-steps)）；
- **数据必须标年份**：三列数据写成「2023/2024/2025」，不要只写一个数；
- **来源要记在哪一列**：给每行加一列「数据来源」，写清是招生简章、复试录取办法还是拟录取名单，三个来源的可靠性不同；
- **不要用论坛数据填表**：论坛可以帮你找到官网，但表里的数字应来自招生单位官方文件。

## 去哪核

- 招生专业目录、报考点：中国研究生招生信息网。https://yz.chsi.com.cn/zsml/
- 招生简章、复试录取办法、拟录取名单、参考书目：目标院校研究生院官网（逐校核实，认准 .edu.cn 域名）。
- 考研报名、网上/现场确认、成绩查询、复试与拟录取确认都通过研招网完成（https://yz.chsi.com.cn/）。

硬信息（人数、分数、时间）以官方文件为准，本表只是记录用的结构，不替代官方数据。
