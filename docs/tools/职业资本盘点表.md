# 职业资本盘点表

判断自己有多少「资本」，要分开看四类，不能混在一起算。

## 四类资本

- 可复用能力：换公司换行业还在的技能
- 可验证成果：能展示、能被第三方确认的东西
- 关系：愿意为你背书的人
- 声誉：别人提到你时会说什么

## 怎么用

每半年填一次。如果四列里只有「能力」在增长，说明你做的事情没有留下证据，需要改成能产出的项目。如果只有「成果」在增长而「关系」是空的，说明你一直在单打独斗。
