## 怎么填

- **证据**：能被第三方核实的东西——作品、仓库、文档、论文、合同、评价。写不出证据的「能力」先降级处理；
- **成果**：尽量带数字与口径，见 [怎么证明自己的成果](../../book/06-进入职场以后继续积累.md#work-prove-results)；
- **关系 / 声誉**：谁能为你背书、在被问到时会怎么评价你。这一栏常被忽略，但换工作时它往往最先起作用；
- **最近一次使用**：超过一年没用的技能，实际水平要打折扣；
- **可迁移到哪里**：区分「行业资本」（换行会贬值）与「可迁移资本」（换行仍保值）；
- **下一步补什么**：只写一到两项，写多了等于没写。

## 多久盘点一次

每年一次（或换工作、考虑转行之前）。盘点的作用不是自我表扬，而是把「我觉得我挺行」换成一张能对照目标岗位要求的清单。
