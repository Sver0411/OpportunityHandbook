## 5、判断：能不能比

填完之后逐条检查：

- [ ] 两个学校的报录比，口径一致吗（都含/都不含推免）？
- [ ] 分数是同一年、同一专业代码吗？
- [ ] 就业数据的分母一致吗？
- [ ] 薪酬数据有口径说明吗？没有就不用于比较。
- [ ] 有没有一列是"听说"或"机构估算"？有就标注，别混进官方数据。

五条里有两条打不上勾，说明这组数据只能看趋势，不能比高低。

## 6、还要问人的三件事

公开数据里通常缺三样，只能问在读学生或学长：

1. 实际录取人数与计划差多少；
2. 复试刷人比例与偏好（是否看重本科出身）；
3. 导师与课题组的真实情况（是否放养、毕业要求）。

## 怎么填才不填错

1. **先固定口径，再填数字**：口径不写清的数字，三个月后你自己也看不懂；
2. **只填官方来源**：机构估算可以记，但要单独一列标注；
3. **一年一张表**：跨年对比时，把口径变化写在备注；
4. **别追求填满**：填不满的格子，说明信息还不够，这正是你要去补的。
