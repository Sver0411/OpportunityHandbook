# 本科毕设进度表

配套 [Playbook：本科毕业论文与毕业设计](../playbooks/本科毕业论文与毕业设计.md)。用法：先按学校的真实截止日填"目标周"，再倒推每个阶段。

## 主表

| 阶段 | 起止周 | 本阶段产出 | 检查点（怎么算过关） | 风险与备选 |
| --- | --- | --- | --- | --- |
| 选题 | W1–W2 | 题目 + 一页说明 | 能用一句话说清问题、方法、产出 | 题目过大 → 砍一半 |
| 文献 | W2–W4 | 20–40 篇清单 + 笔记 | 能说出 3 篇与本题最相关的差异 | 读不完 → 先读综述与 5 篇核心 |
| 开题 | W4–W5 | 开题报告/任务书 | 导师签字/学院通过 | 不过 → 按意见改，留一周缓冲 |
| 方案设计 | W5–W6 | 技术路线 + 时间表 | 有备选方案与失败预案 | 方案不可行 → 缩范围 |
| 实施 | W6–W12 | 实验记录/代码/设计稿 | 核心步骤至少跑通一次 | 反复失败 → 记录条件、找人复现 |
| 中期 | W10–W11 | 进度报告 | 核心链路可演示或有数据 | 落后 → 启动缩题 |
| 数据整理 | W12–W13 | 图表与数据表 | 口径统一、可追溯 | 数据不足 → 缩小结论 |
| 撰写 | W13–W15 | 初稿 | 每章有明确论点与证据 | 写不动 → 先写结果与方法 |
| 导师审核 | W15–W16 | 修改稿 | 导师同意提交 | 反馈慢 → 约时间当面过 |
| 查重 | W16 | 检测报告 | 按学校要求处理重复 | 重复高 → 先改格式再查 |
| 答辩 | W17 | PPT + 讲稿 | 计时演练两遍 | 超时 → 砍背景页 |
| 提交 | W18 | 最终版 + 附件 | 格式、签字、归档齐全 | 格式不合格 → 对照模板逐项核 |

以上周次是**示意**，按你学校的实际周数等比缩放。

## 缩题优先级（落后时按这个顺序砍）

1. 砍"锦上添花"的扩展实验/额外功能；
2. 砍次要章节（保留问题、方法、核心结果、讨论）；
3. 缩小样本量或场景范围，并在局限里写清；
4. 最后才考虑申请延期——**先问清学院政策与对毕业时间的影响**。

**不要砍**：数据真实性、方法说明、结果的可复现信息。

## 每周十分钟自查

- [ ] 本周产出写进记录了吗（实验记录/代码提交/设计稿）？
- [ ] 与上周比，核心问题向前推进了吗？
- [ ] 下周的检查点是什么？需要谁配合？
- [ ] 有没有出现"看起来忙但没产出"的情况？

连续两周答不上第一个问题，就按缩题优先级处理，并找导师谈一次。
