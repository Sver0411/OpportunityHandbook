# 求职漏斗诊断表

用途：把「投了很多没结果」拆成环节数据，找到真正的瓶颈。

## 模板

| 环节 | 数量 | 转化率 | 判断 |
| --- | --- | --- | --- |
| 投递 | | — | 样本是否够（建议累计 20–30 次再看比例） |
| 简历通过（有回复） | | 通过/投递 | <10% → 简历或匹配度问题 |
| 测评 | | 测评/通过 | 通过率低 → 题型不熟或时间管理 |
| 一面 | | 一面/测评 | 挂得多 → 基础或表达 |
| 二面 / 终面 | | 终面/一面 | 挂得多 → 项目深度或判断力 |
| Offer | | Offer/终面 | 少 → 定位偏高或竞争激烈 |

## 对应动作

| 卡点 | 动作 |
| --- | --- |
| 0 回复 | 改三份针对性简历；关键词对齐 JD；增加内推与官网直投 |
| 测评挂 | 按题型限时训练；先摸底再练 |
| 一面挂 | 补核心知识清单；练「思考出声」 |
| 终面挂 | 补项目追问链（为什么/取舍/失败/重做） |
| Offer 少 | 回看定位：是否只投了高于或低于自身水平的岗位 |
| Offer 质量差 | 检查目标岗位层次与技能差距，扩大投递面 |

## 记录纪律

- 每次投递都登记（公司、岗位、时间、状态、下一步）；
- 两周复盘一次，只调**最弱环节**的动作；
- 不要通过加大投递量来解决材料问题。

## 样本太小时怎么办

转化率只有在样本够的时候才有意义。**累计投递少于 20–30 次时，不要根据比例下结论**——投三次挂两次，可能只是运气。

样本不足时改用定性判断：

- 有回复的那几次，对方提到了哪些匹配点？那是你的优势所在；
- 挂掉的那几次，反馈里有没有重复出现的词？那才是真问题；
- 完全没有回复的岗位，你和它的差距是「量」还是「质」——缺关键词，还是缺经历？

## 同一环节反复卡住，往深一层看

表面卡点和真实原因常常不在同一层：

| 表面现象 | 先别急着改 | 往下问一层 |
| --- | --- | --- |
| 简历没回复 | 排版、措辞 | 你投的岗位和你的经历是不是同一类？ |
| 一面就挂 | 表达不好 | 核心知识是不是真的不成体系？ |
| 终面挂 | 紧张 | 项目是不是经不起追问链？ |
| Offer 少 | 面试技巧 | 定位是不是整体偏高或偏低？ |

改表层动作（多投、多背题）收效通常有限，因为瓶颈在下一层。

## 记录怎么做才不费力

诊断表能起作用的前提是记录成本足够低。两种可行做法：

- **极简版**：一张表，每次投递只写五列（日期、公司、岗位、渠道、状态），每周补一次；
- **工具版**：用看板或表格软件管理，把「状态」做成可筛选字段。

不要一开始就设计复杂的字段体系——坚持不下来的记录表等于没有。先记起来，再逐步加字段。
