# 求职漏斗诊断表

用途：把「投了很多没结果」拆成环节数据，找到真正的瓶颈。

## 模板

| 环节 | 数量 | 转化率 | 判断 |
| --- | --- | --- | --- |
| 投递 | | — | 样本是否够（建议累计 20–30 次再看比例） |
| 简历通过（有回复） | | 通过/投递 | <10% → 简历或匹配度问题 |
| 测评 | | 测评/通过 | 通过率低 → 题型不熟或时间管理 |
| 一面 | | 一面/测评 | 挂得多 → 基础或表达 |
| 二面 / 终面 | | 终面/一面 | 挂得多 → 项目深度或判断力 |
| Offer | | Offer/终面 | 少 → 定位偏高或竞争激烈 |

## 对应动作

| 卡点 | 动作 |
| --- | --- |
| 0 回复 | 改三份针对性简历；关键词对齐 JD；增加内推与官网直投 |
| 测评挂 | 按题型限时训练；先摸底再练 |
| 一面挂 | 补核心知识清单；练「思考出声」 |
| 终面挂 | 补项目追问链（为什么/取舍/失败/重做） |
| Offer 少 | 回看定位：是否只投了高于或低于自身水平的岗位 |
| Offer 质量差 | 检查目标岗位层次与技能差距，扩大投递面 |

## 记录纪律

- 每次投递都登记（公司、岗位、时间、状态、下一步）；
- 两周复盘一次，只调**最弱环节**的动作；
- 不要通过加大投递量来解决材料问题。
