# README 检查表

发布前逐项打勾。**陌生的读者照 README 第一次就能跑通**，才算合格。

## 必查（全部通过才算合格）

- [ ] 一句话说清这是什么、解决什么问题；
- [ ] 说明用途与边界（不做什么）；
- [ ] 前置条件：语言/运行时版本、依赖、硬件（如适用）；
- [ ] 安装步骤：命令可直接复制；
- [ ] 运行示例：给出输入与**期望输出**；
- [ ] 目录结构或架构说明（三行以内即可）；
- [ ] 已知限制（**没有这一栏的项目可信度会下降**）；
- [ ] 许可证说明。

## 加分项（按项目类型选）

- [ ] 截图或 GIF（30 秒看懂）；
- [ ] 在线演示地址；
- [ ] 硬件接线图与供电说明（IoT/硬件必写）；
- [ ] Benchmark 结果与测量条件；
- [ ] 测试如何运行、覆盖了什么；
- [ ] 变更日志与版本号；
- [ ] 贡献指南（开源项目必写）。

## 常见不合格

| 现象 | 问题 |
| --- | --- |
| README 只有技术栈 | 读者不知道它能干什么 |
| 命令跑不通 | 缺少前置条件或版本 |
| 截图是旧版本 | 与实际不符 |
| 没有限制说明 | 可信度低，被追问即崩 |
| 示例代码无法复制 | 用图片贴代码 |

## 检查方式

找一位不了解项目的人，只给他 README，看他在 10 分钟内能否跑起来。**他的第一个卡点就是你要补的地方。**
