# 实验记录模板

用途：让每一次运行都可追溯。**记录的标准是「别人（或三个月后的你）能复现」。**

## 模板（每次运行一份）

```
## 基本信息
日期：            实验编号：
目的：这次要验证什么（一句话假设）

## 配置
代码版本 / 提交号：
数据集与版本：      划分方式：
随机种子：          运行命令：
环境：OS / 运行时 / 硬件：
关键超参：

## 过程记录
开始与结束时间：
遇到的异常与处理：
中途改动（如果有，为什么改）：

## 结果
指标定义与口径：
数值（含波动 / 重复次数）：
与基线对比：
截图或输出文件位置：

## 结论与下一步
支持假设吗？为什么：
限制与异常现象：
下一步：
```

## 三条纪律

1. **失败的运行也记**（否则「从未失败」是假象）；
2. **口径先写后跑**，跑完不改；
3. **原始输出归档**，不只留整理后的表格。

## 与数据集成的做法

- 每个实验一个文件，命名带日期与编号；
- 汇总表（`results.csv`）只放指标与配置引用，正文从记录里抄；
- 论文/报告的每个数字都能追到某一条记录。
