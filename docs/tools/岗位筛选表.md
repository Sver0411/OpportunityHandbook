# 岗位筛选表

配合 [岗位表怎么读](../../book/01-先决定下一步往哪里走/10-考公与考编怎么准备.md#exam-job-table) 使用：先在 Excel 里按四道硬条件筛，再把候选填进下面两张表。

## 表一：硬条件核对（能报 / 不能报）

> 下表列数较多，手机上可横向滑动查看；建议复制到表格软件长期维护。

| 候选岗位 | 专业符合（按目录） | 学历学位符合 | 应届口径符合 | 基层年限符合 | 备注里的其他条件 | 结论 |
| --- | --- | --- | --- | --- | --- | --- |
| | ☐ | ☐ | ☐ | ☐ | | 能报 / 不能报 |
| | ☐ | ☐ | ☐ | ☐ | | 能报 / 不能报 |
| | ☐ | ☐ | ☐ | ☐ | | 能报 / 不能报 |

**规则**：任何一列打不了勾，就直接划掉——不要「到时候再说」。专业一列必须按专业目录核对，不能凭名称相似。

## 表二：软条件排序（值得报 / 不值得报）

| 候选岗位 | 地点（是否接受长期） | 单位性质 | 招人数 | 往年进面分数 | 服务期 | 我的排序 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | A / B / C |
| | | | | | | A / B / C |
| | | | | | | A / B / C |

排序建议：**地点 > 单位性质 > 竞争度 > 服务期**。分数来自本省往年公示；找不到就留空，并在备注里写「无数据，风险自担」。

## 表三：报名期跟踪（防止错过与被取消）

| 时间节点 | 日期 | 是否已完成 | 备注 |
| --- | --- | --- | --- |
| 公告发布 | | ☐ | 把公告 PDF 存下来 |
| 报名开始 / 截止 | | ☐ | 留 2 天缓冲 |
| 缴费截止 | | ☐ | **最容易被忘** |
| 准考证打印 | | ☐ | 多打一份 |
| 笔试日期 | | ☐ | 提前看考点路线 |
| 成绩公布 | | ☐ | |
| 面试确认截止 | | ☐ | 别错过 |

## 三个必填结论

1. **最终报哪个岗位**：______（只填一个，多数考试限报一个）；
2. **两个备选**：______ / ______（用于判断岗位是否被取消或自己被退回）；
3. **如果这次没上，第二步计划**：______（继续考编、换省考、还是投入工作）——这一步决定你敢不敢全力备考。

## 怎么用

- 表一在 Excel 里做初筛（按专业、学历、应届、基层年限四列筛完，只剩十几行再填进来）；
- 表二每周更新一次分数与人数信息；
- 表三设两个闹钟：报名截止前 3 天、缴费截止前 2 天；
- 考完把这张表留着——下次考编时直接复用格式，只换岗位数据。
