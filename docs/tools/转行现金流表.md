# 转行现金流表

为什么先算这个，见主线 [转行期的钱怎么安排](../../book/08-晋升、跳槽还是转行.md#career-change-cashflow)。

## 表格模板（可直接复制）

> 下表列数较多，手机上可横向滑动查看；建议复制到表格软件长期维护。

| 项目 | 金额（元/月） | 是否刚性 | 说明 |
| --- | --- | --- | --- |
| 房租 / 房贷 | （示例）4 500 | 是 | 合同到明年 8 月，提前退租违约金 1 个月 |
| 日常生活 | 3 000 | 部分 | 探索期可压到 2 200 |
| 社保与公积金 | 1 200 | 是 | 灵活就业自缴，按月计入 |
| 家人固定支持 | 2 000 | 是 | 父母医疗与生活 |
| 保险与通讯 | 400 | 是 | 不能断缴 |
| **刚性支出合计** | 11 100 | — | |
| **可变现资产** | 88 000 | — | 现金 + 可快速赎回部分 |
| **可支撑月数** | 7.9 个月 | — | 可变现资产 ÷ 刚性支出 |

## 三行结论（填完必须写）

1. **可支撑月数**：低于 6 个月时不要辞职，改在职探索；
2. **降薪承受线**：最低可接受月收入 ___ 元，最多能撑 ___ 个月；
3. **停止信号**：连续两个月动用应急储备、或需要借消费贷时，先回到有收入的位置。

## 分阶段填法

| 阶段 | 常见时长 | 收入状态 | 支出策略 |
| --- | --- | --- | --- |
| 探索期（在职） | 3–12 个月 | 正常工资 | 不降生活水平，学习与验证优先 |
| 切换期 | 3–9 个月 | 可能降薪或空窗 | 保刚性、压可变 |
| 回升期 | 12–24 个月 | 逐步回升 | 按最坏情况做预算 |
