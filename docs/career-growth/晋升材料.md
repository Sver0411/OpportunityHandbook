# 晋升：证据、影响与流程

晋升的基本规则：**先按目标职级的方式工作，再让证据被有权决定的人看见。**

## 评审实际在判断什么

| 维度 | 具体问题 |
| --- | --- |
| 影响范围 | 你的产出影响一个人、一个团队，还是跨团队 |
| 独立程度 | 是你执行别人定义的问题，还是你定义问题 |
| 复杂度 | 处理的是常规任务，还是模糊、有冲突、有取舍的事 |
| 持续性 | 是偶发的一次，还是稳定输出 |
| 是否已被认可 | 别人是否主动依赖你的判断 |

「做了很多事」不是证据，「解决了一个别人解决不了的问题，并让结果可核对」才是。

## 材料怎么写

一条合格的晋升材料包含四段：**背景 → 我的判断与动作 → 结果（可核对）→ 影响范围**。

- 用数字与事实，不用形容词；
- 每条尽量能指向一个外部凭据（上线记录、文档、被采纳的标准、数据看板）；
- 单独列一节「我定义的问题」：哪些事是没人要求、由你提出的；
- 附上别人的评价（同事、跨团队合作方），比自述更有说服力。

## 可见度与支持者

- 让关键的人知道你在做什么：定期同步、评审、分享，而不是只在评审会上首次出现；
- 找一位**愿意为你在评审会上说话的人**（通常是直属上级或合作过的资深同事）；
- 提前一个周期开始准备：评审前两周才开始收集证据通常来不及。

## 时间点与流程

评审周期因公司而异。要提前问清：评审的节奏、需要哪些角色背书、材料由谁提交、评审关注哪些维度。这些信息通常在内部制度文件里，不要在评审前一周才去问。

## 晋升被拒

- 先问一个具体问题：「差距在哪一项，能不能举一个例子」；
- 拿到具体的差距项之后，把它转成下一周期的目标，并请上级确认「做到这个程度是否就够」；
- 如果连续两次被拒、且理由始终是模糊的「还不够」，那可能不是能力问题，而是**通道问题**（编制、上限、团队结构）——这时考虑换环境比继续投入更理性。

## 什么情况应该考虑换公司

- 你的职级上限由团队规模决定，而团队在收缩；
- 关键项目长期分配给别人，你拿不到能证明下一级的活；
- 薪酬与市场价差距持续扩大，而内部调整无望；
- 你已经按下一级的方式工作了一年，却拿不到对应的评审机会。

## 自检

- 我的材料里，有几条是「我定义的问题」？
- 有谁能替我在评审会上说明我的影响？
- 如果被拒，我拿到的是具体差距，还是模糊评价？
