# 学科竞赛

学科竞赛（数学、物理、化学、生物、信息学、电子设计等）的核心价值是**用可比的成绩证明学科基础**。它和「做项目」证明的是不同的东西：项目证明你能做出东西，学科竞赛证明你在标准问题上有多强。

## 常见赛事与它们的差别

| 赛事类型 | 形式 | 训练方式 | 主要用途 |
| --- | --- | --- | --- |
| 数学类（大学生数学竞赛等） | 笔试，偏理论与计算 | 刷题 + 补理论 | 数学基础证明，部分校内有认定 |
| 程序设计 / 算法（ICPC、蓝桥杯等） | 现场编程，按过题数排名 | 长期刷题与组队模拟赛 | 工程与算法能力，企业认可度较高 |
| 电子设计 / 智能车等 | 实物作品 + 答辩 | 备赛数月，硬件调试 | 动手能力，产出可演示作品 |
| 学科知识类（含中学生五科竞赛） | 笔试，分级评奖 | 系统训练，周期长 | 升学通道（**以当年政策为准**） |

**注意两点**：一是同一名称的赛事在不同层级（校赛/省赛/国赛/国际赛）的含金量差别极大；二是**中学生学科竞赛与升学挂钩的政策每年调整**，不要用旧政策推算资格。

## 备赛现实

- **算法类**：训练密度决定上限。有效做法是「按主题补短板 + 每场赛后把没做出来的题补完」；只刷难题不补基础，比赛时容易崩；
- **数学类**：先确认考纲与题型，再按模块练；证明题需要写清推导过程，**光有答案不得分**；
- **工程类**：备赛通常 2–6 个月，硬件调试会吃掉大部分时间。**给文档与答辩预留至少一周**，很多队伍在这里失分。

## 评奖与认定

- 奖项等级（一等/二等/三等、金/银/铜）与名额比例由主办方章程规定，**逐届核实**；
- 校内认定（保研加分、评奖评优、学分认定）由各校规定，**同一奖项在不同学校可能完全不被认定**；
- 就业场景中，企业更关心你在竞赛中**解决过什么类型的问题**，而不是奖项名称——准备好讲一次具体的解题过程。

## 值不值得参加：四个判断

1. 目标通道是否认它（本校保研细则 / 目标企业 JD / 目标项目申请材料）；
2. 时间投入是否与关键节点冲突（考研、实习面试、课程考核）；
3. 训练能否顺带提升你需要的能力（算法岗 → 算法竞赛；硬件岗 → 电子设计）；
4. 是否已有同类更强的证据（有实习与项目的同学，竞赛的边际收益会下降）。

## 赛后必须做的两件事（72 小时内）

1. 把解题思路或作品整理成可展示材料（题解、代码、演示视频、设计文档）；
2. 写一页复盘：哪些题/模块做不出来、原因是什么、下次怎么补。
