# 商业与创业竞赛

商业与创业类竞赛分两种，评价逻辑完全不同：**案例分析赛考「分析能力」**，**创业计划赛考「构想是否可信、团队能否执行」**。

## 两类赛事的差别

| 类型 | 形式 | 评委关注 | 常见失分点 |
| --- | --- | --- | --- |
| 案例分析赛 | 给定企业/行业材料，限时分析并汇报 | 结构化拆解、数据支撑、结论可落地 | 无框架地罗列信息、结论无法执行 |
| 创业计划赛 | 提交商业计划书 + 路演 | 需求真实性、方案可信度、团队匹配度 | 市场规模靠二手报告堆砌、忽略竞争与成本 |
| 商业模拟/沙盘 | 按规则经营决策 | 决策依据与复盘 | 只看结果不看过程 |

## 案例分析赛怎么做

```

1. 20 分钟读材料：先抓「决策问题是什么」（是要不要进入某市场，还是如何扭亏）
2. 明确判断标准：利润、份额、风险、可行性，选 2–3 个
3. 拆解：把问题拆成可分析的模块（市场、竞争、成本、能力）
4. 量化：能算就算（单位经济、盈亏平衡），比形容词有力
5. 收口：给出一个明确建议 + 三条落地动作 + 主要风险
```

**注意**：案例赛通常没有唯一答案，评的是**逻辑是否自洽、假设是否标明、建议是否可执行**。

## 创业计划赛怎么做

- **需求真实性**：有没有人已经在付钱买类似的东西？采访过几个目标用户？（**没有访谈证据的项目通常排在后面**）
- **最小验证**：即使没上线，也要说明你做过什么验证（手工交付、预售、问卷、原型测试）；
- **单位经济**：一份产品/服务的收入、成本、获客方式，能算清才有说服力；
- **竞争**：用户现在用什么替代方案，你凭什么被选择；
- **团队**：谁负责什么、为什么是你做这件事；
- **财务与里程碑**：不要只写三年后收入，要写未来 6 个月做什么、验证什么。

## 路演与答辩

- 10 分钟讲清：问题 → 方案 → 证据 → 商业模式 → 团队 → 要什么；
- 准备被追问的点：数据来源、市场规模算法、竞争对手、成本结构、失败预案；
- **答不出时诚实说明**，比临时编造更好。

## 投入产出判断

- 目标是咨询/金融/产品方向，且缺少结构化分析训练 → 案例赛价值较高；
- 目标是自己创业 → 竞赛的价值在于**外部检验与同侪反馈**，但真实用户验证更有价值；
- 只为「简历多一行」→ 优先级通常低于实习与项目；
- 注意时间冲突：案例赛与创业计划赛常集中在学期中，容易与课程和实习面试撞车。
