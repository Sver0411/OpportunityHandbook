# 加拿大

判断方法一律在主线：是否留学见 [留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)，成本回收见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。

加拿大的关键规则是学习许可与毕业后工作许可（Post-Graduation Work Permit）。

## 官方规则

- 学习许可与毕业后工作许可由加拿大移民部门发布；逐项核实。

- 各省教育部门与院校官网：逐校核实。
