# 加拿大

加拿大的关键规则是学习许可与毕业后工作许可（Post-Graduation Work Permit）。

## 官方规则

- 学习许可与毕业后工作许可由加拿大移民部门发布；逐项核实。

## 来源与更新

最后核实：2026-09-21

- 加拿大移民、难民及公民部官方页面。https://www.canada.ca/en/immigration-refugees-citizenship.html
- 各省教育部门与院校官网：逐校核实。
