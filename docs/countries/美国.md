# 美国

判断方法一律在主线：是否赴美见 [国内还是海外](../../book/04-当你开始面对第一次重要分流.md#fork-home-or-abroad)，成本核算见 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost)。美国的核心变量是**身份与工作许可**，本页把它讲清楚，并给出官方查询入口。

## 教育体系与项目类型

- **本科**：四年制学士学位为主，前两年多为通识教育；
- **社区学院（Community College）**：两年制，授予副学士学位（Associate Degree），常见路径是毕业后**转学（Transfer）**进入四年制大学完成后两年——学分能否转、转多少，由目标院校的转学政策决定；
- **硕士**：分授课型与含论文/研究成分的项目，学制常见 1–2 年；
- **博士**：通常为 5 年以上的研究型学位，很多项目**本科毕业可直接申请**；
- 容易混淆的还有**研究生证书类项目（Graduate Certificate）**：多为职业导向的非学位课程，与学位项目不是一回事。

## 申请方式

**院校自主招生**，没有全国统一申请系统（部分本科申请使用 Common App 等第三方平台，但录取决定权在院校）。要素通常包括：成绩单、语言成绩、推荐信、个人陈述/短文；研究型项目一般要求提前**联系教授**。**是否存在笔试、面试、滚动录取，各校差异很大，以目标项目当年招生页面为准。**

## 语言与标化考试

常见的是 **TOEFL / IELTS / Duolingo**（语言）与 **GRE / GMAT**（研究生标化，近年不少项目已放宽或取消要求）。**不要按统一分数准备**：先读目标项目的「Admissions Requirements」，确认接受哪些考试、总分与**小分**要求，再决定考哪一门。

## 学费与资金

查询路径：目标院校官网的 **Tuition & Fees** 页面（区分国际学生费率）、以及 **Financial Aid / Funding** 页面。资助类别要分清：

- 学校奖学金（Merit-based，常随录取评估）；
- **助教 / 助研（TA / RA）**：研究型学位常见的资助形式，通常与工作职责绑定，有时附带学费减免；
- 院系或导师的**研究经费（funding）**：研究型项目尤其常见，可以直接问导师是否有位置；
- **政府与外部奖学金**：如本国公派渠道、行业组织奖学金。

**具体金额每校每年都在变，本页不给统一数字。**

## 学生身份与签证

- **F-1**：全日制学生的学生身份；申请签证前先获得学校签发的 **I-20 表格**，并且该校必须是 **SEVP 认证学校（SEVP-certified school）**——查学校是否被认证，以 SEVP / Study in the States 官方查询为准；
- **visa 与 status 是两件事**：F-1 既用来表示**非移民学生类别 / 身份（status）**，也指护照上的 **F-1 学生签证**。签证主要用于申请**入境**；入境之后的合法停留与学习，取决于 **F-1 status 是否持续有效**——它由你的学校、SEVIS 记录与是否遵守身份规则共同维持。这也是为什么「签证还在有效期内」并不等于「身份没有问题」。
- 身份相关的高频风险点：未按规定选课或不足全日制、未经授权工作、离境过久、转学未按流程办理。

## 学习期间的工作规则

- **校内工作（On-campus）**：F-1 学生通常可在校内工作，具体时数与条件以学校国际学生办公室（OISS/ISSS）与 USCIS 规定为准；
- **CPT（Curricular Practical Training）**：与课程直接相关的实习许可，通常需要事先获得学校批准（多数情况要求已有工作 offer），**未经授权的工作会严重影响身份**；
- 校外工作一般需要额外授权，不要按「可以打零工」的假设行动。

## 毕业后的工作路径

- **OPT（Optional Practical Training）**：与所学专业相关的毕业后工作许可，需要在规定时间窗口内申请，累计期限一般为一学年对应的时长；
- **STEM OPT 延期**：在符合条件的情况下，STEM 专业可申请延长，但附带更严格的雇主与培训计划要求；
- **H-1B 等工作签证**：通常需要雇主担保并受名额与抽签机制影响；
- 本页不列具体月数与条件——**OPT/STEM OPT 的期限、雇主要求与报告义务会调整，以 USCIS 与 Study in the States 当年说明为准**。

## 学历与执业资格

回国使用学历需办理教育部留学服务中心的国（境）外学历学位认证。**受监管职业**（医师、律师、工程师、注册会计师、护理等）在美国及各州通常有单独的执照考试与注册要求，学位本身不等于执业资格。

## 容易混淆的概念

**F-1 不是签证本身**（它是身份类别，签证是入境凭证）；**I-20 不是录取通知书**（它是学校向政府出具的资格文件）；**CPT 与 OPT 不能随意混用**（前者在校期间、绑定课程，后者毕业后、需另行申请）；**TA/RA 是工作而非奖学金**（通常有职责与考核）。
