# 新加坡

新加坡需核实院校项目与政府资助与服务义务；学生准证与工作准证规则以官方页面为准。

## 官方规则

- 新加坡移民与关卡局（ICA）官方页面；人力部（MOM）工作准证官方页面。
- 各公立大学官网的项目、学费与奖学金说明。
