# 新加坡

判断方法一律在主线：是否留学见 [留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)，成本核算见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。新加坡的核心变量是**学校类型（公立/私立）、资助义务与工作准证**。

## 教育体系与项目类型

- **自治大学（Autonomous Universities）**：新加坡的公立大学体系（如 NUS、NTU、SMU 等），学位含金量与政府资助政策与私立院校差别明显；
- **理工学院（Polytechnic）**：三年制文凭（Diploma）层次，偏应用；与大学之间存在升学通道（视成绩与院校政策）；
- **Coursework 硕士**：以课程与学分毕业，常见一年（部分 1.5–2 年）；
- **Research 硕士与 PhD**：研究型学位，通常可获得研究奖学金或助研资助；
- **私立院校**：多与海外大学合作授予学位，**学位由合作大学颁发**——认可度取决于合作方与项目本身，报读前要核对学历是否可被目标单位/认证机构接受。

## 申请方式与考试

院校自主招生。本科多以 A-Level、IB、高考或国际课程成绩申请，语言成绩（IELTS/TOEFL）与标化考试（SAT/ACT 等）视院校而定；研究生申请看成绩单、推荐信、个人陈述，研究型项目需要联系导师。**是否有笔试面试、是否滚动录取，以院校官方招生页面为准。**

## 学费与资助：Tuition Grant 的注意点

- **Tuition Grant（学费补助）**：新加坡政府对符合条件的学生提供学费补助，但**部分类别的国际学生接受补助时需签署服务承诺（bond）**——毕业后需在当地注册公司工作一定年限。按 MOE 的官方说明，接受补助的**国际学生与永久居民在毕业后须履行 3 年服务承诺（bond）**，须在新加坡实体全职工作以完成义务；延期、违约与保证金（banker's guarantee）等规则另有专门页面。**具体条款以 MOE 官方页面与院校资助说明为准**；
- **其他资助**：院校奖学金、研究型学位的**研究奖学金（Research Scholarship）与助研岗位**、以及本国公派/外部奖学金；
- **学费**：国际学生费率由院校公布，**不同专业与是否有补助差别很大**。

## 学生身份与签证

- 由**新加坡移民与关卡局（ICA）**签发 **Student's Pass**；通常需要院校的**录取与注册**作为前提，并通过 ICA 的 Student's Pass 在线系统（SOLAR）办理；
- 就读期间的工作受**工作准证豁免条件**限制（例如与课程相关的实习、假期工作等情形），**具体规则以 ICA 与人力部（MOM）官方说明为准**；
- 影响身份的事项：出勤不足、未按时更新准证、违规工作、转学未按流程办理。

## 毕业后的工作路径

新加坡没有「毕业后自动工作签证」这一类安排，需要在毕业前后**自行申请工作准证**：常见路径是获得雇主聘用后由雇主申请 **Employment Pass（EP，面向专业人士）**或 **S Pass**，条件与薪资门槛随政策调整，**以 MOM 官方页面为准**。学位的意义在于满足准证的学历要求，**不等于自动获得工作资格**。

## 学历与执业资格

回国使用学历需办理教育部留学服务中心认证；私立院校与海外大学合作授予的学位，认证材料的完整性尤其重要。**受监管职业**（医师、护士、教师、律师、工程师、会计等）在新加坡有各自的注册机构与准入要求，**学位不等于执业资格**。

## 容易混淆的概念

**自治大学 ≠ 私立院校**（资助与学位来源不同）；**Tuition Grant ≠ 奖学金**（它是补助，可能附带服务承诺）；**Student's Pass ≠ 工作许可**（读期间工作的情形有严格限定）；**学位 ≠ 工作准证资格**（毕业后需雇主申请相应准证）。
