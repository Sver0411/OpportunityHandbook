# 中国香港

判断方法一律在主线：是否升学见 [升学还是工作](../../book/04-当你开始面对第一次重要分流.md#fork-study-or-work)，成本核算见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。本页只讲中国香港自己的制度与查询入口。

## 院校与学位类型

中国香港的大学分为**教资会资助院校**（UGC-funded，八所公立大学）与自资院校，两者的学费结构与资助政策不同；授课语言以英文为主，部分课程以中文授课。

学位类型与常见混淆点：

- **授课型硕士（Taught Postgraduate，TPg）**：以课程和学分毕业，学制常见一年（部分 1.5–2 年），主要换学历与职业入场资格；
- **研究型学位（Research Postgraduate，RPg）**：包括**研究型硕士（MPhil）**与**博士（PhD）**。MPhil 是独立的研究型硕士学位，**不是「读博的前两年」**，也不是其他地区「研究生」的对应物；
- 部分院校的 PhD 允许本科毕业生直接申请（视院校与学科要求），也有 MPhil 转 PhD 的通道——**具体以目标院校研究生院官方说明为准**。

## 申请方式与考试

多数课程由**院校自行招生**（无统一申请系统），通常需要在线申请、成绩单、推荐信与个人陈述；研究型项目一般需要**提前联系导师**并提交研究计划。语言要求常见为雅思或托福（部分接受大学英语六级或校内英语测试），个别项目要求 GMAT/GRE；**不同院校与专业的分数要求差异很大，一律以目标项目当年招生页面为准**。

## 学费与资助

- **学费**：教资会资助课程与自资课程的学费差异明显，非本地学生与本地学生的收费也不同；
- **资助类别**：政府奖学金（含针对非本地学生的奖学金计划）、院校奖学金与助学金、研究型学位的**研究生奖学金（RPg 学生通常对应某种津贴或资助）**、以及研究项目经费支持的助研岗位。资助是否附带义务（例如服务承诺）要逐项核对官方条款。

## 学生身份与签证

- 由中国香港特别行政区**入境事务处**管理，非本地学生需要申请**学生签证 / 进入许可**；
- 关键点：必须由**录取院校**作为保证人递交申请，获准后才可来港就读；在港期间的**逗留条件**（可否工作、工作时数）写在签证条款里，学期内与假期的规则不同；
- 影响身份的事项（超时工作、转学、停学、逾期逗留）会直接影响后续续签与留港资格——规则以入境事务处官方页面为准。

## 毕业后的在港工作安排

**IANG（Immigration Arrangements for Non-local Graduates，非本地毕业生留港／回港就业安排）**：合资格的非本地毕业生可申请在港工作，**无需先获得雇主聘用**，并可在获批后的一段时间内自由工作或转换工作（具体期限与资格以入境事务处现行规定为准）。IANG 不是永久居留：长期居留需要在港连续通常居住满相应年限并按入境事务处的居留政策单独申请。

## 容易混淆的概念

- **MPhil ≠ 硕士预科**，它是研究型学位；
- **IANG ≠ 永久居留**，它是一段可工作的逗留安排；
- **教资会资助 ≠ 学费全免**，资助主要指院校办学经费与部分学生资助；
- 部分**受监管职业**（教师、医护、法律、工程、会计等）有各自的注册或执业要求，学位本身不等于执业资格。
