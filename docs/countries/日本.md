# 日本

判断方法一律在主线：是否留学见 [留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)，成本回收见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。

## 先分清四个容易混淆的概念

- **语言学校**：教授日语的教育机构，不是大学，也不是大学院申请的固定前置步骤。是否需要读语言学校，取决于你的日语水平、目标学校的招生方式与申请渠道——日语达到要求、能直接参加入试或用英语项目申请的人，不需要经过语言学校。
- **研究生（Research Student / 非学位生）**：日本大学院的预备身份，通常在导师研究室做研究，为参加正式入试做准备。它**不是**中国语境里的「硕士」——中国的「研究生」指硕士/博士生，日本的「研究生」是非学位生，两者翻译相同、含义完全不同。
- **修士（博士前期课程）**：相当于其他地区的硕士，是正式学位课程，需要通过大学院的入学考试（或申请制项目）进入。
- **博士（博士后期课程）**：正式学位课程。

## 两条常见路线（并非唯一路径）

- **直接参加入试**：日语或英语达到要求的人，可以直接报考大学院的修士/博士入试，或申请英文授课项目，不必经过语言学校或研究生阶段；
- **先作研究生再考**：先以非学位生身份进入研究室、在导师指导下准备正式入试——是否走这条路取决于学校要求与个人情况。

具体到每所学校：招不招研究生、入试方式、出愿材料、是否有英文项目，都以**目标大学官方招生页面**为准；同一所大学不同研究科的规则也可能不同。

## 官方信息入口

- **出入国在留管理厅**：在留资格（留学签证）的申请与变更规则。https://www.moj.go.jp/isa/
- **文部科学省（MEXT）**：高等教育与奖学金制度（含国费留学）的官方说明。
- **日本学生支援机构（JASSO）**：私费留学生奖学金、宿舍与生活信息。https://www.jasso.go.jp/
- **目标大学官网**：招生要项（出愿要项）、学费、入学试验要点——逐校核实。

## 容易误解的地方

- 「研究生」不等于硕士（见上）；
- 语言学校不是申请大学院的必要条件；
- 修士入试多数有校内笔试与面试，与欧美申请制不同，备考方式要按目标研究科的过去问（历年真题）准备；
- 打工与在留资格挂钩，超出许可范围的打工会影响在留资格，规则以出入国在留管理厅为准。
