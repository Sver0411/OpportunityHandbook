# 日本

日本的路径通常是语言学校 → 研究生（预科）→ 修士 → 博士；在留资格与签证事项由日本出入国在留管理厅发布。

## 官方规则

- 日本出入国在留管理厅：在留资格相关官方说明。
- 文部科学省与日本学生支援机构（JASSO）：奖学金与留学信息。
