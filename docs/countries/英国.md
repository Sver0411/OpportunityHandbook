# 英国

判断方法一律在主线：是否赴英见 [国内还是海外](../../book/04-当你开始面对第一次重要分流.md#fork-home-or-abroad)，成本核算见 [留学总成本](../../book/04-当你开始面对第一次重要分流.md#overseas-total-cost)。英国的核心变量是**学生签证（CAS + 担保资质）与毕业后留英时长**。

## 教育体系与项目类型

- **本科**：英格兰、威尔士、北爱尔兰通常三年，苏格兰通常四年；
- **授课型硕士（Taught Master's）**：以课程与学分毕业。**一年制是常见形式之一，但不是所有英国硕士的统一结构**——也有 1.5–2 年、含实习或行业项目的课程，具体看项目页面；
- **研究型硕士（Research Master's）**：以研究训练与论文为主，常见形式为 **MPhil** 或 MRes；MPhil 是独立学位，**不等于「博士前两年」**，但确实是不少研究者的过渡阶段；
- **博士（PhD/DPhil）**：通常三到四年，直接申请（本科或硕士毕业）与研究型硕士转入的情况都存在。

## 申请方式

通过 **UCAS**（本科）或**院校自主网申**（研究生）申请。材料通常包括成绩单、推荐信与个人陈述；研究型项目一般需要**先联系导师**并提交研究计划。**是否面试、是否滚动录取，各校差异很大。**

## 语言与入学考试

常见的语言考试为 **IELTS for UKVI / 普通雅思 / TOEFL / PTE**；部分专业要求 GMAT/GRE。**注意「UKVI 版」与普通版的使用场景不同**（是否需要 UKVI 版本取决于你的签证路径与院校要求），具体以院校与 GOV.UK 说明为准。

## 学费与资助

查院校官网的 **Tuition fees**（区分国际学生费率）与 **Scholarships / Funding** 页面。资助来源包括院校奖学金、院系助研/助教岗位（研究型常见）、以及政府与国际组织奖学金项目（本国公派渠道、目标国政府奖学金等）。**本页不给统一金额。**

## 学生签证（Student visa）与 CAS

- 由**英国内政部 / UKVI**管理。申请学生签证需要**持牌担保机构（licensed Student sponsor）**签发的 **CAS（Confirmation of Acceptance for Studies）**，并且需要满足资金证明与英语要求；
- 通常需要的材料：CAS 参考号、满足存期的资金证明、英语成绩（或豁免情形）、以及**移民健康附加费（IHS）**；
- **ATAS**：特定敏感学科方向（多为理工科研究生课程与研究）需要先获得 **ATAS 证书**，学校才会签发 CAS；换专业、换研究方向或延长超过一定期限时可能需要重新申请。**是否需要 ATAS 以 GOV.UK 与院校说明为准**；
- 学习期间的工作规则（学期内时数、假期全职、不能自雇或经营公司等）写在签证条件里，**以 GOV.UK 现行页面为准**。

## 毕业后的工作路径：Graduate Route

**Graduate Route** 允许符合条件的毕业生在英国工作或找工作，**不需要雇主担保、没有最低薪资门槛**，但**不能续签**，也不直接通向永久居留；其时长规则近年调整过：

- 博士或其他博士层级资格通常为**三年**；
- 学士与硕士的时长**已从两年调整为 18 个月**，适用于**2027 年 1 月 1 日及之后**提交的申请（在此之前提交的申请仍按当时规则）；
- 申请的前提是院校已向 UKVI 确认你成功完成课程，且必须在**学生签证有效期内、在英国境内**提交；**一生只能申请一次**。

后续长期留英通常需要切换到其他路线（如 **Skilled Worker** 等工作签证），条件以 GOV.UK 为准。**Graduate Route ≠ 永久居留**。

## 学历与执业资格

回国使用学历需办理教育部留学服务中心认证。**受监管职业**（医师、护士、教师、律师、建筑师、工程师等）在英国有各自的注册机构与要求，**学位不等于执业资格**。

## 容易混淆的概念

**CAS ≠ 录取通知书**（它是担保方出具的签证凭证）；**授课型硕士 ≠ 研究型硕士**；**Graduate Route ≠ 工作签证**（不需担保但也不通向永居）；**MPhil ≠ 博士阶段**；**ATAS ≠ 语言考试**（它是安全审查证书）。
