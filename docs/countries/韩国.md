# 韩国

判断方法一律在主线：是否留学见 [留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)，成本核算见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。韩国的主要变量是**语言（TOPIK）与签证类别（D-2 / D-4）**。

## 教育体系与项目类型

- **本科（학부）**：通常四年；
- **大学院（대학원）**：即研究生院，含**硕士（석사）**与**博士（박사）**，硕博连读也存在。注意韩语里「大学院」对应研究生阶段，**不是**中国的「大学」；
- **语言研修（어학당）**：大学附属语学院的语言课程，常见作为升学的过渡，持相应签证（见下）；**语言研修不等于学位项目**；
- **英文授课项目**：部分院校与专业开设全英文课程，可不依赖韩语入学，但选择面小于韩语项目。

## 申请方式与考试

院校自主招生（部分有集中申请期）。材料通常为成绩单、毕业/预毕业证明、语言成绩、推荐信、学习计划；**部分院校有面试或校考**，艺术类专业另有作品集或实操考试。是否需要 **TOPIK（韩国语能力考试）** 等级、要求几级，**不同院校与专业差异很大**，以目标院校外国学生招生简章为准。

## 学费与资助

- **学费**：国立与私立差异明显，理工/医学类通常高于人文社科；查院校官网的「외국인전형（外国学生招生）」页面下的学费与奖学说明；
- **资助类别**：**GKS（Global Korea Scholarship，韩国政府邀请奖学金）**——覆盖学费与生活补助，有独立申请窗口与名额；院校自设的外国学生奖学金（常按 TOPIK 等级或成绩减免部分学费）；教授研究经费支持的助研岗位；以及本国公派渠道；
- **GKS 等的义务与覆盖范围以当年官方公告为准**，不要用往年的条款推算。

## 学生身份与签证

- 韩国的外国人居留事务由**法务部 / 出入国·外国人政策本部**管理，居留许可与变更通过 **Hi Korea（hikorea.go.kr）**等官方系统办理；
- **D-2（留学）**：学位课程（本科、硕士、博士）使用的居留资格；
- **D-4（一般研修）**：语言研修等非学位课程常用的资格；
- 影响身份的事项：未按规定选课或不足学分、未经许可打工、超过工作时数、休学与转学未申报、居留期限管理——**规则与工作许可（时间制就业许可）以法务部与 Hi Korea 现行说明为准**。

## 学习期间的工作

学生打工通常需要**事前获得时间制就业许可**，且对工作类型与时数有限制（学期内与假期不同）。**不要以「同学都在打工」作为依据**，许可与限制以官方规定为准。

## 毕业后的工作与求职路径

韩国的路径通常是：毕业后申请**求职（구직）类居留资格**以便在韩找工作 → 找到工作后转为**就业类居留资格**（如 E-7 等，资格条件与雇主类型相关）。各资格的条件、时长与雇主资质要求由法务部规定，且经常调整，**必须在毕业前查官方页面**。本页不预测留韩成功率。

## 学历与执业资格

回国使用学历需办理教育部留学服务中心认证。**受监管职业**（医师、护士、教师、建筑师、律师等）在韩国通常由国家考试与注册程序管理，**学位不等于执业资格**。

## 容易混淆的概念

**大学院 = 研究生院**（不是大学）；**D-2 ≠ D-4**（学位课程 vs 语言研修，两者的打工与延期规则不同）；**语学院结业 ≠ 入学资格**（仍需按院校招生流程申请）；**GKS 不是自动获得**（有独立申请窗口与筛选）。
