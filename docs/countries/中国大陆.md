# 中国大陆

判断方法一律在主线：怎么选路线见 [先决定下一步往哪里走](../../book/01-先决定下一步往哪里走.md)，要不要继续读书见 [升学还是工作](../../book/04-当你开始面对第一次重要分流.md#fork-study-or-work)。本页只讲制度变量与查询入口。

## 学历层次与容易混淆的概念

- **专科（高职）**：学制通常三年，属于高等教育但不是学位教育，毕业获得毕业证书而非学位证书；
- **本科**：通常四年（部分专业五年），完成学业并符合条件授予**学士学位**；
- **职业本科**：本科层次、偏实践培养，学历层次是本科，见 [职业本科](../../book/01-先决定下一步往哪里走.md#vocational-undergraduate)；
- **硕士与博士**：研究生教育。硕士分**学术学位（学硕）**与**专业学位（专硕）**，2023 年教育部的分类发展意见明确两者「同等重要」、培养定位不同，见 [学硕和专硕](../../book/04-当你开始面对第一次重要分流.md#study-academic-vs-professional)；
- **全日制与非全日制**：这是**学习形式**的区别，不是学位层次的区别。两者执行相同的招生政策和标准，学历学位证书具有同等法律地位和相同效力，但非全日制毕业证书会标注「非全日制」（依据教研厅〔2016〕2 号）。

最容易混淆的三组：**学历 ≠ 学位**（毕业证与学位证是两件事，部分岗位要求「学历学位双证」）；**学硕 ≠ 专硕**（培养与出口不同，但官方口径没有高低之分）；**全日制 ≠ 学位类型**（非全日制也可以拿到同一层次的学位）。

## 招生方式怎么查

- **本科**：以高考成绩为主，各省教育考试院发布志愿填报与录取办法——**逐省核实**，规则每年调整；
- **研究生**：分**推免**（推荐免试，免初试）与**统考**（全国统一考试 + 复试）。推免资格与名额写在你**本校**的推免办法文件里；统考的报名、初试、复试与调剂规则写在教育部《全国硕士研究生招生工作管理规定》与中国研究生招生信息网，两套规则完全不同，不要混用；
- **博士**：以「申请考核制」为常见形式，各招生单位的材料与考核要求差异很大，必须逐校核实招生简章。

## 奖助与资助

国内学生资助体系是「奖、助、贷、勤、补、免」六类叠加：奖优类（国家奖学金、励志奖学金、学业奖学金）、助困类（国家助学金按家庭经济困难认定申请）、**国家助学贷款**（在校期间财政贴息，见 [国家助学贷款](../../book/01-先决定下一步往哪里走.md#funding-student-loan)）。具体金额与名额近年多次提标扩面，以财政部、教育部当年度文件与本校通知为准。

## 学历认证与职业资格

- **国内学历查询**：学信网（中国高等教育学生信息网）是学历学籍查询的官方入口；
- **国（境）外学历回国使用**：需要办理教育部留学服务中心的国（境）外学历学位认证，见 [学历学位认证](日本.md) 一类的国家页说明与 CSCSE 官方页面；
- **职业资格**：先查它是否在人社部《国家职业资格目录》里。准入类是法定门槛（无证不得上岗），水平评价类技能资格已退出目录、改为社会化职业技能等级认定，见 [法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates)。

注意：**学位不等于执业资格**。医学、法律、教育、建筑等受监管职业通常另有从业资格考试或注册要求，考取与注册条件以行业主管部门官方规定为准。

## 容易误解的地方

- 「研究生」在大陆是指硕士与博士（含在读），与此相关的就业、落户政策常按「学历层次」而非「学位」表述；
- 专升本有多种形式（统招专升本与成人教育类），含金量与报考资格差别很大，见 [专升本](../../book/01-先决定下一步往哪里走.md#study-zhuanshengben)；
- 应届毕业生身份有明确时限（国家规定的择业期为二年，各地执行口径不同），会影响校招与部分招考报名资格，见 [间隔年](../../book/01-先决定下一步往哪里走.md#paths-gap-year)。
