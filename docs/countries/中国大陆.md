# 中国大陆

判断方法一律在主线：是否留学见 [留学值不值得](../../book/04-当你开始面对第一次重要分流.md#overseas-is-it-for-me)，成本回收见 [为教育投入多少钱才合理](../../book/01-先决定下一步往哪里走.md#education-cost-budget)。

在中国大陆读书与就业，规则集中在几类官方渠道：研究生招生（研招网）、学籍学历（学信网）、职业资格与技能等级（人社部与行业主管部门）。

## 常用核对入口

- 研究生招生：中国研究生招生信息网。
- 学籍学历：学信网。
- 职业资格：《国家职业资格目录》，人社部。

## 怎么用本手册

- 升学判断见第一章与第四章；就业与职场积累见第五章之后。
