# 教育

判断方法一律在主线：[怎么了解一个行业](../../book/02-在学校里先把基础打好.md#understand-industry)、[法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates)。

## 四条主要路径

- **学校教师**：幼儿园、中小学、中职/高职、高校。中小学与幼儿园教师需要**教师资格证**，公办学校入职还需通过教师招聘考试（各地公告为准）；
- **高等教育**：高校教师通常要求硕士以上学历，且近年越来越多岗位要求博士；进入路径与科研产出密切相关（见 [科研与高校](科研与高校.md)）；
- **职业教育与培训**：职业技能培训、考证培训、企业培训（L&D）。能力导向，看课程与教学效果；
- **教育产品与运营**：课程设计、教研、产品、内容、社群运营，属于互联网/内容行业的分支，看项目与数据。

教育行政与教育政策方向（教育局、教研机构、教育类公益组织）另有招录与选拔方式。

## 硬门槛

- **教师资格**：中小学教师资格考试由教育部教育考试院主办，报名条件（学历、专业、在校生年级）与考试科目录在官方公告里；**取得教师资格证是法定要求**，但不等于能入职——公办教师岗还要通过各地教师招聘考试；
- **普通话水平**：教师岗普遍要求达到相应等级（以当地公告为准）；
- 高校教师：学历与科研产出是主要门槛，部分岗位对海外经历或博士后经历有偏好；
- 培训机构：义务教育阶段的学科类培训受严格监管，入职前需核实机构的合规资质。

## 日常工作是什么样

- 中小学教师：备课、上课、批改、班级管理、家校沟通；工作时间常延伸到课后与假期；
- 高校教师：教学 + 科研 + 学生指导，非升即走的考核压力在部分高校比较明显；
- 培训/教研：设计课程、磨课、迭代内容，节奏与招生周期相关；
- 教育产品：需求调研、课程研发、数据复盘，接近互联网产品岗的工作方式。

## 什么最被看重

- 教师岗：**资格证 + 学科专业背景 + 实习/代课经历**；面试试讲是关键环节；
- 高校岗：学历（博士为主）+ 论文与项目；
- 培训与产品岗：课程作品、教学效果数据、项目经历；跨专业进入的通道主要在教研与产品侧。

## 怎么低成本试一次

- 去做一次真实的试讲或带一次课（家教、支教、机构兼职），体验课堂与反馈；
- 参与一次课程设计或教研项目，看自己是否喜欢反复打磨内容；
- 想做教育产品，就完整做一个课程或学习工具的小项目，拿到真实用户体验。

## 常见误解

- 「喜欢某个学科就能当老师」——课堂管理、沟通与耐心往往比学科知识更决定体验；
- 「教师资格证考了就能进编制」——证书只是前提，招录考试与名额才是关键；
- 「教育行业都一样」——学校、培训、教育产品的监管环境与工作方式差异很大。
