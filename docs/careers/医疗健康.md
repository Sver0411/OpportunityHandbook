# 医疗健康

判断方法一律在主线：[怎么判断一个选择值不值得](../../book/00-从这里开始.md#judge-worth-it)、[法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates)。

## 先分清「临床」与「非临床」

**临床与执业方向（强监管）**
- **临床医师**：需要医学专业学历与规范化培养路径，通过国家医师资格考试并注册后才能执业；
- **护理**：需要护理专业学历并通过护士执业资格考试；
- **医技类**（检验、影像、康复、病理等）：多数有对应的专业技术资格或执业要求；
- **药学**：部分岗位需要执业药师资格。

**产业与支撑方向（相对不依赖执业资格）**
- **医疗器械与制药**：研发、注册法规、质量管理、临床研究（CRA/CRC）、生产；
- **医疗信息化与 AI**：数据、系统、算法，受数据与医疗合规约束；
- **健康管理、保险与咨询**：偏业务与合规；
- **医院管理与运营**：行政、绩效、供应链等。

**最容易犯的误解**是「医疗行业 = 医生」。非临床方向的岗位数量不少，且很多不要求医学学位。

## 门槛怎么判断

- **临床类**：先查行业主管部门与考试机构的官方文件——学历层次、专业范围、规培要求、考试科目与报考年限都写得很明确，不能用「相近专业」推测；
- **非临床类**：按 JD 判断。器械研发看工程/生物医学背景与项目；注册法规看对《医疗器械监督管理条例》等法规的熟悉程度与文档能力；临床研究看 GCP 培训与项目经验。

## 日常工作是什么样

- 临床：门诊/病房/手术/值班，工作节奏与排班强绑定，情绪负荷高；
- 护理：轮班、执行医嘱、与患者和家属高频沟通；
- 医技：熟练操作设备与判读结果，重复性较高但对准确性要求极严；
- 器械/制药：文档与验证流程占很大比重（研发、注册、质量三类工作都高度依赖文档）；
- 医疗信息化：在**合规约束**下做系统与数据，比一般行业更强调可追溯与权限。

## 什么最被看重

- 临床与护理：**学历层次 + 执业资格 + 规培/实习路径**，三者缺一不可；
- 医技与药学：对应专业 + 资格或职称；
- 产业方向：专业背景 + 项目/实习 + 对法规的理解；跨专业进入器械/制药/医疗信息化的通道是真实存在的。

## 一定要核实的事

**学位不等于执业资格。** 执业医师、护士、执业药师等都有独立的国家考试与注册制度，且**报考专业范围**通常限定得很具体；境外医学学历回国执业还涉及学历认证与资格认定。这类信息只认官方文件——国家卫生健康委、国家医学考试中心、国家药监局与人社部门的公告，不要按论坛经验准备。

## 怎么低成本试一次

- 在校期间尽量争取一次临床见习或医院实习，体验真实排班与沟通强度；
- 非临床方向可以做一次器械/制药相关的小项目（法规梳理、竞品分析、数据整理），或参加一次行业展会与讲座；
- 不确定能否接受临床路径时，早一点去问带教老师与高年级同学，而不是凭想象判断。
