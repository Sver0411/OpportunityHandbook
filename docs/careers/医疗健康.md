# 医疗健康

这个方向值不值得走，判断方法在主线：[怎么判断一个选择值不值得](../../book/00-从这里开始.md#judge-worth-it)、[怎么了解一个行业](../../book/02-在学校里先把基础打好.md#understand-industry)。

医疗健康方向的关键约束是**法定资格**（如医师/护士执业资格），门槛是硬性的，必须核对官方规定。

## 常见门槛

- 学历与实习；执业资格考试与注册；继续教育。
