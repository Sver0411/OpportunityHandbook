# 生命科学

判断方法一律在主线：[科研入门](../../book/03-开始积累真正能留下来的经历.md#research-undergrad-start)、[读博值不值得](../../book/07-当职业开始出现分岔.md#research-phd-worth-it)。

## 三条主要路径

- **学术研究**：高校与科研院所，路径与 [科研与高校](科研与高校.md) 相同，通常需要博士乃至博士后；
- **产业研发**：生物药/化学药研发、CRO/CDMO、诊断试剂、合成生物学；岗位包括研发、工艺开发、分析、QA/QC、注册、临床研究；
- **跨界方向**：生物信息与计算生物学（编程 + 生物）、医疗器械、医药投资与咨询、科学传播。

**最容易犯的误解**是「学生物只能做科研或转行」：CRO/CDMO、诊断、注册与临床研究吸纳了大量本科与硕士学历的人，尤其是具备规范文档能力的候选人。

## 每天在做什么

- 湿实验：养细胞、跑电泳、做纯化或检测，重复性与记录规范性是核心；
- 生物信息：写脚本、处理测序数据、做统计与可视化；
- 产业端：工艺放大、验证与偏差处理、注册资料的撰写与递交、临床监查；
- 投资/咨询：读文献与招股书、做技术尽调、写报告。

## 什么最被看重

| 方向 | 主要证据 | 学历权重 |
| --- | --- | --- |
| 学术研究 | 论文、课题、推荐信 | 博士为主 |
| 产业研发 | 实操技能（具体技术平台）+ 项目 | 硕士常见，本科岗位也有 |
| 工艺/分析/QA | 规范操作与文档能力 | 本科到硕士 |
| 注册/临床 | 法规理解 + 文档 + 沟通 | 本科到硕士 |
| 生信 | 编程 + 统计 + 生物背景 | 硕士常见 |

## 硬约束与合规

- 涉及人的研究、临床试验与药品/器械注册，受**药品监管法规**与伦理审查约束；相关岗位的能力很大一部分是「按规范做事」；
- 医疗相关执业（如在医院从事检验、影像）另有资格要求，见 [医疗健康](医疗健康.md)；
- 生物安全与实验废弃物处理有明确规定，进入实验室前必须完成安全培训。

## 怎么低成本试一次

进一个真实课题组或企业实验室做一段实习，重点体验三件事：重复性劳动的耐受度、记录规范的严格程度、以及是否愿意长期与不确定结果打交道。生信方向可以先用公开数据集完成一次完整分析。

## 常见误解

- 「生物都是天坑」——行业内部差异很大，产业端的岗位结构与薪资结构与学术端不同；
- 「有学历就行」——实验技能与规范意识在面试中会被具体追问；
- 「读博是唯一出路」——产业研发、注册、临床研究都有硕士乃至本科层级的路径。
