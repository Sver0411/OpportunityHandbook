# 设计与创意

判断方法一律在主线：[作品集](../../book/03-开始积累真正能留下来的经历.md#project-portfolio)、[设计与创作竞赛](../../book/03-开始积累真正能留下来的经历.md#competition-design-creative)。

## 方向拆解

- **视觉/平面**：品牌、海报、包装、插画；作品集与风格辨识度是主要门槛；
- **交互/体验（UX/UI）**：研究用户、画流程与界面、做可用性验证；需要同时展示思考过程与视觉；
- **工业/产品设计**：外观、结构与人机工程，常需与工程配合；
- **内容与叙事**：文案、编剧、视频、播客；产出即作品；
- **游戏与三维**：原画、建模、动画、关卡、技术美术；引擎能力与团队项目经验权重高；
- **创意管理与运营**：设计管理、创意策划、内容运营，偏流程与协作能力。

## 每天在做什么

接需求 → 理解约束 → 出方案 → 反复修改。**改稿是日常**，与需求方的沟通和解释能力常与设计能力同等重要；自由职业方向还要处理报价、合同与客户维护，见 [自由职业怎么开始](../../book/08-其他同样成立的人生路径.md#startup-freelance)。

## 什么最被看重

- **作品集**：三个打磨过的项目，胜过十个半成品；每个项目写清问题、你的决策与结果，见 [作品集](../../book/03-开始积累真正能留下来的经历.md#project-portfolio)；
- **过程可见**：交互与产品设计尤其看「为什么这样设计」；
- **真实项目**：商业项目、开源项目、比赛作品、真实用户反馈都算证据；
- **工具能力**：软件熟练度是基本功，不再构成差异。

## 门槛与资格

这个方向通常**没有法定准入资格**，作品与项目是主要门槛。需要留意的例外：涉及特种设计（如建筑设计、压力容器等）的岗位属于工程注册范畴（见 [技术与工程](技术与工程.md)）；医疗、金融等受监管行业的界面与内容设计会有合规要求。

## 怎么低成本试一次

- 参加一次短周期的创作活动（Game Jam、设计挑战、写作挑战），体验「限时交付」的真实状态，见 [设计与创作竞赛](../../book/03-开始积累真正能留下来的经历.md#competition-design-creative)；
- 接一个小额真实委托（哪怕是朋友的项目），完整体验需求、改稿与交付；
- 把自己的一个项目从「做完」推进到「有真实使用者」，见 [真实用户与反馈](../../book/03-开始积累真正能留下来的经历.md#project-users-feedback)。

## 常见误解

- 「有天赋才行」——多数岗位的差距来自刻意练习与反馈质量；
- 「作品多就好」——深度项目比数量重要；
- 「创意行业不用讲逻辑」——能把设计决策讲清楚的人更容易拿到好项目。

## 信息入口

- 各平台与社区的作品展示与征稿信息（用于了解行业标准）；
- 设计类与游戏类赛事的官方页面（逐项核实）；
- 招聘平台上的设计与创意岗 JD（判断门槛与工具要求）；
- 开源设计资源与素材授权说明（合规使用素材）。
