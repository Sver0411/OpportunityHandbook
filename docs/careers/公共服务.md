# 公共服务

判断方法一律在主线：[参军与公共服务](../../book/01-先决定下一步往哪里走.md#paths-military)、[要不要继续升学](../../book/05-从学校走向第一份工作.md#job-or-further-study)。

## 四条通道

- **公务员**：国考与省考，报名条件、职位表、笔试面试规则由招录公告公布；专业、学历、政治面貌与基层经历等限制差异很大；
- **事业单位**：教师、医护、科研辅助、文化体育等；招聘由各地与各主管单位组织，形式包括公开招聘考试与人才引进；
- **基层项目**：三支一扶、西部计划、选调生等，各有服务期与优待政策，见 [志愿活动](../../book/03-开始积累真正能留下来的经历.md#paths-volunteering)；
- **社会组织与公益**：基金会、社工机构、行业协会；社工有**社会工作者职业资格**（初级/中级/高级），部分岗位要求持证。

## 硬门槛在哪里

- **学历与专业**：公告里通常写明学历层次、专业范围与是否要求全日制；职位表是最权威的依据；
- **考试**：公务员考《行政职业能力测验》与《申论》（部分岗位加专业科目）；事业单位考试由各地确定；
- **资格证**：社工岗位普遍要求或优先考虑社工证；法律服务、公证等另有法定资格；
- **回避与审查**：政审、体检与回避制度是流程的一部分，不符合条件时无法通过。

## 日常工作是什么样

材料写作、会议与协调、接待与答复、政策执行与检查。基层单位的工作强度与所在地区、条线关系密切；评价体系偏过程合规与群众反馈，节奏与市场化岗位不同。

## 什么最被看重

- 笔试成绩 + 面试表现（结构化面试为主）；
- 写作与材料能力（进入后是核心工作技能）；
- 稳定性与长期承诺；
- 部分岗位看重基层经历与专业背景。

## 怎么判断与准备

第一步永远是打开**目标岗位当年的招录公告与职位表**，逐条核对报考条件（学历、专业代码、年限、户籍、政治面貌）。不要用往年的条件推算，也不要按论坛经验准备。

## 低成本试一次

参加一次事业单位或社工机构的志愿服务/实习，体验「材料 + 协调 + 执行」的日常；也可以先做一次完整的申论写作并请有经验的人批改，看自己是否适应这种输出方式。

## 常见误解

- 「考公只看分数」——岗位限制条件往往比分数更能决定成败；
- 「事业单位都一样」——教师、医护、科研辅助的考试与晋升路径差别很大；
- 「进了体制就是稳定到退休」——考核、轮岗与改革同样存在。
