# 法律与公共事务

判断方法一律在主线：[怎么了解一个岗位](../../book/02-在学校里先把基础打好.md#understand-role)、[法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates)。

## 先把岗位拆开

- **律师**：在律所执业，需要**法律职业资格**与律师执业证；业务方向差异极大（诉讼、非诉、资本市场、知识产权、劳动等）；
- **企业法务**：在企业内部处理合同、合规、纠纷与投融资支持；不少法务岗要求通过法律职业资格考试，但**不要求执业证**；
- **合规（Compliance）**：反洗钱、数据合规、出口管制、反腐败等，跨法律与业务，金融机构需求集中；
- **政策研究 / 智库**：写报告、做调研、跟踪政策，产出是分析与建议；
- **公共事务 / 政府关系（GR）**：与政府、协会、社区沟通，偏沟通与项目管理；
- **公职与事业单位岗位**：通过公开招录进入，考试与资格条件在公告里写得很明确。

**最容易犯的误解**是「法律相关岗位都要过法考」：企业法务、合规、政策研究里，法考是强加分项，但招聘条件差异很大——**以具体 JD 为准**。

## 硬门槛在哪里

- **律师**：必须先取得法律职业资格（通过国家统一法律职业资格考试），再申请律师执业证；报考的学历与专业条件由司法部当年公告规定；
- **法官、检察官、公证员等**：另有法定资格与招录程序；
- 企业法务、合规、政策岗：通常没有法定准入，但会用「是否通过法考」「是否有相关实习」筛人。

## 日常工作是什么样

- 律师：阅读大量材料、写文书、查法条与案例、与客户和对方沟通；非诉业务节奏受项目周期驱动；
- 法务：合同审查、风险提示、跨部门沟通，常要在业务需求与合规之间找平衡；
- 合规：规则梳理、流程设计、内部培训与调查；
- 政策研究：文献与访谈、数据分析、报告写作，观点需要经得起追问；
- 公共事务：会议、拜访、材料准备，成效衡量偏长期。

## 什么最被看重

- 律师：**资格 + 实习经历 + 具体业务方向**（方向越清晰越好）；
- 法务/合规：法律或相关专业背景 + 行业理解（金融、数据、出口等领域的合规尤其看行业知识）；
- 政策研究：分析写作能力 + 领域知识，学历与研究成果权重较高；
- 公共事务：沟通与协调能力 + 对政策流程的熟悉。

## 怎么判断门槛与试一次

用法条与公告核实硬门槛（司法部、国家公务员局与各地招录公告），再用 JD 判断软性偏好。低成本尝试的方式：参与一次真实的法律援助、模拟法庭、企业法务实习，或写一篇政策分析报告并请业内人点评——**看自己是否享受「读材料 + 写清楚」这项日常**。
