# 技能型职业

判断方法一律在主线：[学徒制与技能路线](../../book/01-先决定下一步往哪里走.md#apprenticeship)、[技能型职业的发展空间](../../book/01-先决定下一步往哪里走.md#trades-career-room)。

## 它到底考什么

能力、资格与经验，而不是学历。常见方向：电工、焊工、电梯、消防设施操作、汽车维修、数控与机电、烹饪、美容美发、养老照护、护理辅助、空调制冷等。

**关键区分**：属于**准入类**的职业资格（无证不得上岗，如部分特种作业、消防设施操作）与**职业技能等级**（能力分级，由用人单位与社会培训评价组织实施）是两件事，见 [法定准入型证书](../../book/02-在学校里先把基础打好.md#skill-occupational-certificates)。

## 入门路径

1. 找有师傅带的岗位（学徒、助理），前几年收入低但学习密度最高；
2. 同步考取对应资格与等级：**特种作业操作证**等法定要求的证书必须先拿到；
3. 从第一天起记录：做过什么活、用什么工艺、客户或工段反馈；
4. 3–5 年后进入等级晋升与团队带教阶段。

## 什么最被看重

- **证书**：法定要求的证书是入场券；等级证书影响能接的活与定价；
- **口碑与案例**：客户评价、返修率、工段记录；
- **稳定性平台**：有的工种依赖大型设备与企业，有的依赖散客与门店；
- **地域**：需求随产业带与城市更新节奏变化明显。

## 现实约束

前期收入低、体力消耗大；部分工种有职业健康风险与年龄相关限制；行业景气度受地产、消费等周期影响。这些在选方向时要一起算，见 [技能型职业的发展空间](../../book/01-先决定下一步往哪里走.md#trades-career-room)。

## 怎么判断门槛与试一次

- 收 20 条目标工种的招聘信息，统计「证书要求 / 经验要求 / 是否要求持证上岗」；
- 去当地人社部门与政务服务网站确认该职业的资格类别（准入还是水平评价）与培训评价机构名单；
- 用一到两周跟一次真实的活或实训课，体验体力与环境是否可接受。

## 常见误解

- 「技能路线不用学习」——准入类考试并不轻松，理论不过关会丢掉资格；
- 「拿证就会干活」——面试与试工考的是实操；
- 「只能干一辈子一线」——等级晋升、带团队、开店接单都是现实路径；
- 「必须读本科才有前途」——这条路上学历不是主要变量，资格与手艺才是。
