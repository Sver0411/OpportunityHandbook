# 科研与高校

判断方法一律在主线：[科研到底是什么](../../book/03-开始积累真正能留下来的经历.md#research-what-is-research)、[读博值不值得](../../book/07-当职业开始出现分岔.md#research-phd-worth-it)。

## 路径有哪些

- **学术路线**：本科科研 → 硕士/博士 → 博士后 → 讲师/助理教授 → 长聘岗位。每一级都有明确的产出要求（论文、项目、经费）；
- **科研机构**：中科院系统、部委研究院所、企业研究院、新型研发机构。评价口径与高校不同，偏任务与转化；
- **企业研究岗**：研究型岗位（如算法研究、材料研发、生物医药研发），产出要求介于学术与工程之间；
- **科研支撑岗**：实验技术、科研管理、期刊编辑、科研数据与信息化，是常被忽视但缺口真实的路径。

## 每天在做什么

读文献、做实验或计算、处理数据、写作与投稿、开会与汇报。**失败与返工的比重很高**，周期以月计；写作与沟通能力的重要性常被低估（见 [论文写作](../../book/04-当你开始面对第一次重要分流.md#research-writing-and-submission)）。

## 门槛的真实形态

- **学历**：高校教职与多数研究岗逐渐以博士为起点，部分岗位要求博士后经历；
- **产出**：论文、专利、项目、数据集与代码——**可验证的产出**是核心货币；
- **资助**：能否拿到经费（或进入有经费的课题组）决定研究条件与稳定性，见 [Grant](../../book/04-当你开始面对第一次重要分流.md#funding-grant)；
- **匹配度**：导师与课题组的适配度对体验影响很大，见 [怎么找导师](../../book/03-开始积累真正能留下来的经历.md#research-find-supervisor)。

## 怎么判断适不适合

按 [怎么判断自己是否喜欢科研](../../book/03-开始积累真正能留下来的经历.md#research-do-i-like-it) 的三条自测做一次，再用一段真实经历（进组半年以上）验证。**只看成功故事判断，误差会很大。**

## 常见误解

- 「读完博士就能进高校」——教职竞争激烈，且常要求博士后经历与持续产出；
- 「科研只适合聪明人」——更关键的是对长期不确定与重复劳动的耐受度；
- 「进了组就有产出」——产出取决于课题、经费、指导与自己的投入方式；
- 「科研能力只在学术圈有用」——方法训练（提出假设、设计验证、写清楚）在产业中同样值钱。

## 低成本尝试与信息入口

- 先进一个真实做研究的组做一个小任务（复现、数据清理、文献整理），见 [怎么找到第一次科研机会](../../book/03-开始积累真正能留下来的经历.md#research-undergrad-start)；
- 找 5 位博士毕业三年内的人访谈，问他们当年为什么读、现在怎样；
- 官方信息入口：国家自然科学基金委员会（项目与资助）https://www.nsfc.gov.cn/ ；教育部（研究生教育与学位政策）https://www.moe.gov.cn/ ；中国学位与研究生教育信息网（学位查询）https://www.chinadegrees.com.cn/ ；各高校人事处招聘页面（逐校核实）。
