# 官方入口速查：你要办的事，去哪办、去哪查

这份表的用途只有一个：**让你少走弯路、少花冤枉钱**。凡是涉及报名、考试、成绩、学历、社保、证书、投诉的事，官方入口都是免费的；需要付费的「代办」几乎都可以自己办。

用法：先在下表找到你要办的事，照着入口去查；**各省、各校、各单位有自己的系统，表里给的是国家级入口，省级与校级入口请以本省或本校公告为准**。

## 三条通用原则

1. **官方入口都是免费的**：报名、查成绩、查学历、办社保不需要付费；任何「付费代办/保过」都是风险信号；
2. **认准域名与主体**：`.gov.cn`、教育部/人社部/税务总局等官网为主；第三方页面可能滞后或收费；
3. **省事也要留痕**：办事后保存受理编号与截图，查询结果打印或存档——后续核对、申诉都要靠它。

## 什么时候要谨慎

- 表中的入口是**国家级**的：省级、市级、校级流程常有差异，务必以本省或本校公告为准；
- 政策类页面可能随时改版，本文只给入口与用途，不复述具体数字（具体口径看原文）；
- 不要在任何第三方平台填写身份证号、银行卡密码或短信验证码。
