# 核实记录

这一页讲的是**本项目在写内容时怎么核实**，以及哪些内容目前核实到什么程度。它不是免责声明，而是给读者的使用说明。

## 核实流程

```
1. 列出待核实清单：正文里所有「会变化的事实」（政策、考试、招生、签证、资格、资助、规则）
2. 找到官方来源：优先部委/主管部门/官方系统，其次院校与机构官网
3. 抄录关键条款：文号、生效日期、适用范围、原文表述
4. 记录核实日期：写入正文的「最后核实」，并保留链接
5. 交叉验证：涉及重大影响的（身份、资格、义务），至少两处官方来源
6. 判断结论：确认 / 收窄表述 / 标注为经验 / 不写
```

## 记录格式

每条事实对应一条记录：

```
主题：
站点与链接：
文件/页面名称与文号（如有）：
关键条款（摘录）：
核实日期：
结论：Official / Research-backed / Industry-data / Experience-based / Uncertain
备注（适用范围、地方差异、下次需要重核的点）：
```

## 五类证据在本项目里的含义

| 类型 | 含义 | 用法 |
| --- | --- | --- |
| Official | 主管部门或官方系统的规定 | 可以直接陈述规则，但必须标核实日期 |
| Research-backed | 学术研究与系统性证据支持 | 可用于说明趋势与机制，避免外推到个体 |
| Industry-data | 招聘数据、行业报告、公开统计 | 说明分布与常见要求，需注明样本口径 |
| Experience-based | 实践经验与从业者共识 | 只写方法与判断，不写成统计结论 |
| Uncertain | 无法可靠核实 | 收窄表述或直接不写 |

## 常见难点与处理

- **跨语言**：非中英文国家的官方页面优先查本国语言原页（翻译页常滞后或不完整）；必要时用官方英文版；
- **地方差异**：国内很多规则由省市执行（如志愿填报、专升本、落户、社保）。处理方式是**写清「以当地当年公告为准」并给出查询路径**，不写死具体日期与名额；
- **年度变动**：考试日程、签证规则、资助条款每年调整。处理方式是给机制与查询入口，不写「全国统一」的硬性结论；
- **院校自主**：转专业、保研、复试、PGWP 等与具体院校强绑定。处理方式是**逐校核实**并提示读者自查；
- **数据口径**：行业报告与招聘数据口径不一。处理方式是用区间与相对比较，不给单一精确值。

## 已知的核实边界

本项目内容中，以下部分**无法做到逐项实时核实**，已在正文中标注或收窄表述：

- 各国签证与毕业后工作许可的**最新条款**（变化频繁，以官方页面为准）；
- 各校招生细节（名额、分数线、复试办法）——按年份与学校变化；
- 竞赛的具体规则与评审标准——按主办方当年章程；
- 薪资、录取率等市场数字——来源口径不一，本项目不写具体数值；
- 部分受监管职业的**最新注册要求**（以主管部门文件为准）。

## 发现错误怎么办

如果读者发现事实错误，最有效的反馈方式是**附上官方来源链接与页面名称**。内容修正后会在正文与「最后核实」日期上体现。
