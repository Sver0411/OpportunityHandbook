# 二手来源与识别方法

二手来源不是不能用，但**它只能用来发现关键词，不能用来当事实**。这一页讲怎么识别、怎么核查。

## 二手来源的常见包装手法

| 手法 | 表现 | 为什么危险 |
| --- | --- | --- |
| 权威模糊 | 「据相关部门」「业内人士表示」 | 无法追溯，可能是推测 |
| 时间漂移 | 用三年前的规则讲今年的流程 | 制度类信息极易过期 |
| 数据无口径 | 「平均薪资 X 万」不说是谁、样本多少、哪一年 | 无法判断代表性 |
| 极端个案当规律 | 用一个成功故事推出普遍结论 | 忽略失败者（幸存者偏差） |
| 利益相关 | 培训机构讲「这个证必须考」 | 结论与销售目标一致 |
| 拼贴官方 | 引用真实文件名但改了内容 | 最容易被误信 |
| 情绪化标题 | 「彻底变天」「再不考就晚了」 | 目的是传播而非准确 |

## 核查四步法

1. **找原始文件**：顺着内容找它引用的政策、报告、公告原文（多数官方文件可直接搜到）；
2. **核对关键数字与时间**：文件名、文号、生效日期、适用范围是否与二手说法一致；
3. **确认发布主体**：官方网站域名、机构全称是否匹配；机构是否真实存在；
4. **交叉验证**：至少两个独立来源（最好其中一个为官方）指向同一结论。

**核查成本与结论重要性的关系**：影响你决策的（报名条件、分数线、签证规则、资助义务）必须查到官方原文；只影响氛围判断的（行业热度）可以用二手来源并明确标注。

## 把线索变成事实的操作示例

假设你在某公众号看到「某校今年新增 XX 专业硕士，接受跨专业申请」：

```
1. 打开该校研究生院官网 → 招生栏目 → 最新招生简章
2. 在专业目录里检索该专业名称，确认是否真的新增
3. 读报考条件：是否限制本科专业、是否需要工作经验
4. 记录：官方页面链接 + 查看日期 + 关键条款原文
5. 如果官网没有，就去省级教育考试院或教育部平台确认
```

结论只有三种：**确认（给链接与日期）／找不到（标为未核实，不写进正文）／与二手说法不符（以官方为准）**。

## 什么时候可以只用二手来源

- 了解领域氛围、常见问题、从业者体验（经验性内容）；
- 寻找关键词与官方入口（当作索引）；
- 判断某个说法的普遍程度（并明确标注为主观印象）。

**不能只靠二手来源的内容**：报名与考试条件、签证与身份规则、资助与义务条款、认证与资格要求、竞赛与招生规则。

## 在写作与分享中的做法

- 事实与判断分开写：事实给到原始链接，判断标注为经验；
- 会变化的信息标日期（本项目统一用「最后核实」）；
- 引用二手来源时说明它的层级（行业媒体、培训机构、个人博客）与可能的利益关系；
- **不确定就写不确定**，不要用模糊表达掩盖没核实。
