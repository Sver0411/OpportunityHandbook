# 怎么读报录比与专业就业率

择校方法见 [考研怎么定目标校](../../book/05-备考与应试.md#kaoyan-choose-school-steps)；这一页只讲数字怎么读。

择校时最容易犯的错，是拿两个**口径不同**的数字直接比较：A 校报录比 5:1、B 校 8:1，于是判断 A 更好考。实际上 A 可能是含推免后的数字，B 是不含推免的统考数字。

## 报录比：分子分母各是什么

**报录比 = 报考人数 ÷ 录取人数**。看起来简单，但有四个变量：

| 变量 | 影响 |
| --- | --- |
| 含不含推免 | 推免占名额，含推免的报录比会显得"容易" |
| 含不含调剂 | 调剂名额会拉低报录比 |
| 计划数 vs 实际录取 | 实际录取常与计划不同 |
| 报名人数 vs 确认人数 | 报名后弃考的人不少 |

**正确的比法**：只看"统考报名人数 ÷ 统考录取人数"，且用同一年的数据。如果学校只公布含推免的数字，就在备注里写清"口径不明"，不要拿它做跨校比较。

## 四个更容易误导的数字

**复试线**：只是进复试的最低门槛，不等于录取线。热门专业复试线之上还有大量人被刷。

**录取最低分**：比复试线有用，但要注意它可能是"专项计划"或"调剂"考生的分数。

**平均分**：被高分考生拉高，通常高于多数人的实际水平。

**招生人数**：要看"统考名额"，不是"总招生数"。一个专业招 30 人、推免 25 人，统考只剩 5 个名额。

## 专业就业率：三个口径问题

- **分子是什么**：签约、升学、灵活就业是否都算；
- **分母是谁**：全体毕业生，还是"参与调查"的毕业生；
- **专业目录怎么对**：不同学校的专业名称与内涵不同，"计算机科学与技术"在两校可能不是一回事。

**结论**：专业就业率适合看**趋势**与**相对位置**（同校内部比较），不适合跨校精确比较。

## 真正有用的四个动作

1. **拉三年数据**：单年数据受招生计划与经济周期影响大；
2. **看统考名额的变化**：名额缩减比分数上涨更值得警惕；
3. **看拟录取名单的分数分布**：不只看最低分，看中位数与分数密集区间；
4. **找在读学生问"实际录取多少人、刷了多少"**：这是公开数据里最缺的一环。

## 五个常见陷阱

- **用含推免的报录比判断难度**；
- **把复试线当录取线**；
- **只看一年数据**；
- **跨校比"就业率"**（口径不同）；
- **忽略专业目录差异**（同名不同内容）。

## 官方核实点

- **研招网**（https://yz.chsi.com.cn/）：专业目录、招生计划、报名与调剂；
- **目标院校研究生院**：招生简章、复试办法、拟录取名单公示；
- **目标院校就业信息网**：就业质量报告（分专业数据）；
- **省级教育考试院**：报考点与现场确认要求。

各校公布的数据颗粒度差异很大，能用什么数据取决于学校公开到什么程度，不要用估算替代。
