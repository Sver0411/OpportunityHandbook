# 常用官方来源清单

这一页按「你要解决什么问题」组织官方入口。**所有政策与规则以这些来源的当年度文件为准**，本页只保证入口正确，不保证条款不变。

## 教育制度与学历

- 教育部（政策、学籍学历、专业目录、学术规范）：https://www.moe.gov.cn/
- 中国高等教育学生信息网（学信网，学籍学历查询与认证）：https://www.chsi.com.cn/
- 教育部留学服务中心（国境外学历学位认证）：https://zwfw.cscse.edu.cn/
- 中国学位与研究生教育信息网（学位查询）：https://www.chinadegrees.com.cn/

## 考试与招生

- 中国研究生招生信息网（统考报名、推免服务系统、调剂）：https://yz.chsi.com.cn/
- 教育部教育考试院 / 中国教育考试网（教师资格、四六级等）：https://ntce.neea.edu.cn/
- 各省教育考试院（高考、专升本、志愿填报，逐省核实）
- 国家公务员局（国考公告与职位表）：https://www.scs.gov.cn/

## 职业资格与技能认定

- 人力资源社会保障部（国家职业资格目录、职称与技能人才政策）：https://www.mohrss.gov.cn/
- 中国人事考试网（专业技术人员资格考试报名与证书查验）：https://www.cpta.com.cn/
- 技能人才评价工作网（职业技能等级证书查询）：http://www.osta.org.cn/
- 应急管理部（特种作业操作证等）：https://www.mem.gov.cn/

## 签证、居留与毕业后工作

- 美国：USCIS、Study in the States（SEVP）、国务院签证。https://www.uscis.gov/ 、https://studyinthestates.dhs.gov/ 、https://travel.state.gov/
- 英国：GOV.UK 的 Student visa、Graduate visa、ATAS。https://www.gov.uk/student-visa
- 加拿大：IRCC（学习许可、DLI、PGWP）。https://www.canada.ca/en/immigration-refugees-citizenship/services/study-canada.html
- 澳大利亚：内政部（学生签证 500、485）与 CRICOS。https://immi.homeaffairs.gov.au/ 、https://cricos.education.gov.au/
- 新西兰：Immigration New Zealand、NZQA。https://www.immigration.govt.nz/ 、https://www.nzqa.govt.nz/
- 日本：出入国在留管理厅。https://www.moj.go.jp/isa/
- 韩国：法务部 / Hi Korea。https://www.hikorea.go.kr/
- 新加坡：ICA（学生准证）、MOM（工作准证）、MOE（Tuition Grant）。https://www.ica.gov.sg/
- 中国香港：入境事务处（学生签证、IANG）。https://www.immd.gov.hk/

## 资助与奖学金

- 国家留学基金委（公派留学与义务条款）：https://www.csc.edu.cn/
- 国家自然科学基金委员会（科研资助）：https://www.nsfc.gov.cn/
- 目标国政府奖学金与院校 funding 页面（逐项核实）

## 统计、行业与劳动

- 国家统计局（人口、就业、收入等宏观数据）：https://www.stats.gov.cn/
- 人力资源和社会保障部（劳动法规与社保政策）：https://www.mohrss.gov.cn/
- 国家市场监督管理总局（企业登记、行业监管）：https://www.samr.gov.cn/
- 国家税务总局（纳税与发票）：https://www.chinatax.gov.cn/

## 使用这些入口的四条注意事项

1. **看发布日期与生效日期**：同一政策可能有修订版本，优先看最新且已生效的；
2. **看适用范围**：全国性规定与地方规定、不同身份（本地生/国际生）差异很大；
3. **看是否还在有效**：目录类文件（如职业资格目录）会整体更新，不要引用旧版；
4. **保存链接与查看日期**：写进正文时标注「最后核实」，方便后续重核。
