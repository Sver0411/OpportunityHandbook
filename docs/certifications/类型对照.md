# 证书类型对照：准入 / 等级 / 行业 / 厂商 / 微证书
五类证书常被混为一谈，它们的法律含义与认可边界完全不同。

## 对照表

| 类型 | 例子 | 法律含义 | 认可边界 | 维护成本 |
| --- | --- | --- | --- | --- |
| 法定准入（职业资格） | 教师资格、医师资格、法律职业资格、注册会计师（执业） | 无证不得从事相应业务 | 全国通行（部分有地域注册要求） | 继续教育、定期注册 |
| 职业技能等级 | 电工、焊工、养老护理员等级证书 | 技能水平证明，部分与待遇挂钩 | 用人单位与地方政策 | 逐级报考 |
| 行业 / 专业认证 | 项目管理、财务类、部分国际认证 | 无法律效力，属能力信号 | 由行业认可度决定 | 年费 + 继续教育 |
| 厂商认证 | 云、数据库、网络设备厂商认证 | 无法律效力，绑定技术生态 | 使用该生态的岗位 | 版本升级重认证 |
| 微证书 / 结业证 | 在线课程证书、训练营结业证 | 无法律效力 | 多数时候等于「上过课」 | 无 |

## 职业案例

- **财务 / 会计**：执业类资格是硬门槛；管理会计类认证是加分；两者的报考条件（学历、年限）与继续教育要求都不同；
- **医疗**：执业资格是准入前提，且与规培、注册挂钩，缺一不可执业；
- **工程 / 建筑**：注册类工程师与建造师属准入或执业范围，需注意专业与年限限制；
- **IT**：厂商认证绑定生态，价值取决于目标岗位是否使用该生态；
- **教育**：教师资格证是准入门槛，但具体学段与学科要匹配招聘要求。

具体条款以行业主管部门与《国家职业资格目录》为准。

## 怎么判断一个证书属于哪一类

三个问题：**没有它能否从事该业务**（能 → 不是准入）；**谁发证**（国家目录 / 行业组织 / 厂商）；**有没有年费与继续教育**（有 → 维护成本要算进决策）。

## 常见混淆

- 把「培训结业证」当成职业资格；
- 把「厂商认证」当成行业通用标准；
- 以为「国家承认」等于「用人单位认」——前者看目录，后者看 JD。

## 自检

- 我打算考的这个证，法律上属于哪一类？
- 它的维护成本每年是多少？
- 目标岗位的 JD 里出现过它吗？
