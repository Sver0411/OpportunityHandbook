# Case：第一次去看心理科

这是一个虚构但贴近常见情形的过程，用来说明**该去的过程其实很普通**（数字为示意）。渠道与判断标准见 [情绪持续不好时找谁](../../book/17-身体与心理的可持续性/02-心理与求助.md#health-mental-support)。

## 背景

小周工作两年，近两个月：入睡困难、早上醒得早、对原本喜欢的活动失去兴趣、开会时注意力撑不住。他先自己调整作息、运动、减少加班，两周后没有改善。

## 第一步：用三条线判断是否需要专业帮助

- **持续性**：超过两周，且几乎每天；
- **功能受损**：睡眠、进食、工作效率都受影响；
- **危险信号**：没有自伤念头（有的话直接就医或拨打 120/110）。

三条里占了两条 → 属于应该就诊的情形，而不是「再扛一周」。

## 第二步：挂哪个科、怎么准备

- 通过医院官方渠道挂**精神科或心理科**（部分医院称「临床心理科」）；不确定时可先电话咨询；
- 就诊前写下三行：什么时候开始、最影响生活的是什么、有没有正在吃的药与过敏史；
- 请假：半天足够首次门诊；需要长期复诊时提前和上级说明时间安排。

## 第三步：就诊当天

- 医生问诊 + 量表评估，约 20–40 分钟；必要时建议进一步检查或用药；
- 费用：挂号与诊疗费按医院标准，医保按规定报销部分；具体比例以当地医保政策为准；
- **结果**：医生判断为中度情绪问题，建议规律复诊 + 心理治疗，未开药。

## 第四步：接下来一个月

- 每两周复诊一次，共两次；
- 同时进行了六次心理治疗（自费，单次价格区间较大，他选择的是医院内的治疗服务）；
- 工作侧调整：把最难的任务集中在上午，晚上固定不再处理消息。

**六周后的变化**：入睡时间从凌晨 1 点回到 23 点半，注意力恢复到他自评的七八成。

## 复盘出来的三条经验

1. **就诊不等于病情严重**：早点去，医生给出的方案通常更轻；
2. **准备三行信息能显著提高门诊效率**：医生最需要的是时间线与功能影响；
3. **把工作安排一起调整**：只靠治疗而不改节奏，改善会慢得多（见 [长期高强度怎么不垮](../../book/17-身体与心理的可持续性/01-节奏与身体.md#health-sustainable-pace)）。

## 这个案例不能说明什么

- 不代表所有人都不需要用药：是否用药由医生判断，本案例只是其中一种情形；
- 不代表治疗次数与费用固定：因人而异，也因机构与城市而异；
- 本案例不是医疗建议：任何症状的处理请以医生意见为准。
