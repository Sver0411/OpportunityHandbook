# Case：第一次自由职业客户

背景：工作三年，前端方向，业余接单。目标：跑通一次完整交易（不追求金额）。

## 线索来源

前同事介绍：一家做线下培训的小公司需要「把课程报名从微信群改成一个小程序」。

## 第一次沟通（40 分钟）

按 [找问题与用户访谈](../entrepreneurship/找问题与用户访谈.md) 的脚本问：

- 现在怎么处理：微信群接龙 + 手工记账；
- 痛点：每天要花 1 小时核名单，出现过错漏；
- 频率：每天；影响：直接影响收款确认；
- 期望：能自助报名、能看到名单、能导出。

他复述了一句需求：「你要的是每天不再花 1 小时核对名单，并且不丢单。」对方确认。**这句话后来成了验收标准。**

## 报价与范围

他报了 1.2 万，工期 3 周，明确排除项：不做支付、不做营销页面、不做多校区。付款结构：预付 40%，上线 40%，验收后 20%。

对方还价到 1 万，他让步的方式是**减范围**（去掉导出功能）而不是降价。最终 1 万，含导出，另加 2000 作为导出功能的加价——双方都接受。

## 合同与预付款

签了一页合同（范围、轮次、节点、付款、知识产权）。**预付款到账后才开工。**

## 范围变更（两次）

1. 第一周：对方加「微信通知」→ 他评估 2 天，加价 1500，写进变更记录；
2. 第二周：对方加「家长端查看」→ 他评估后拒绝加入当期，放进下一期报价。

**关键动作**：所有变更走邮件，写明对时间与费用的影响。

## 交付与验收

分两个里程碑交付：报名流程、名单管理。每个里程碑后请对方回一句「确认」。

上线后对方提出三处修改（合同含两轮），第三处他提前说明计费方式，对方选择放弃。

## 尾款拖延（唯一的纠纷）

尾款 2000 拖了三周。他的处理顺序：

1. 先拿到「验收无异议」的书面确认（这是催款前提）；
2. 到期前一天友好提醒；
3. 到期一周后电话沟通，对方说「财务流程慢」；
4. 他给了一个分期方案（本周 1000、下周 1000），对方接受。

**教训**：合同里应该写清「逾期付款的处理方式」，他当时没写。

## 复购与口碑

三个月后对方介绍了一个同行的客户（同样的需求）。他这次直接用了标准报价单与合同，周期缩短了一半。

## 复盘

| 做对了 | 做错了 |
| --- | --- |
| 预付款到账才开工 | 尾款条款没写逾期处理 |
| 让价时减范围而不是降价 | 第一次报价没有写有效期 |
| 变更全部书面记录 | 第二条变更拒绝得太晚（对方已有预期） |
| 交付确认拿到书面 | 没提前要客户评价 |

## 可复用要点

1. 用一句话复述需求并让对方确认——它同时是验收标准；
2. 议价时先让范围、再让时间、最后才让价格；
3. 变更先记录、评估、报价；
4. 尾款靠「交付确认 + 分期方案」，不要靠催；
5. 复购与推荐来自「按约定交付」，不是来自低价。
