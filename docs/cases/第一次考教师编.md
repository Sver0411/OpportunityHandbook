# Case：第一次考教师编

背景：小吴，师范院校英语专业，本科。目标：回老家所在市当初中英语老师。她大三下拿到教师资格证，大四开始考编。

## 第 1 步：第一年，她把教资的经验直接搬过来

教资她一次过，形成了一种判断：**"考教师就是考学科知识。"**

于是第一年她只做三件事：刷高考英语真题、背课标、练试讲。教育综合知识（教育学、心理学、教育法规）只看了两天。

## 第 2 步：笔试差三分

市里统考的成绩出来：学科 82，教育综合 51，总分差 3 分进面。

| 科目 | 她的分 | 进面平均 | 差距 |
| --- | --- | --- | --- |
| 学科专业知识 | 82 | 78 | +4 |
| 教育综合知识 | 51 | 68 | −17 |

她的学科是优势，但教育综合把总分拉了下来。**教师编的笔试是两科加权，不是只看学科。**

## 第 3 步：第二年换策略

她做了四个调整：

1. **重排时间**：教育综合占 60% 的复习时间，学科只保持手感；
2. **按题型练**：教育综合的选择题刷真题，简答与案例分析按"理论 + 材料 + 结论"写；
3. **去学校代课**：在一所乡镇中学代课一学期，教两个班英语；
4. **换报考策略**：从市区分较高的岗位，改报县里一所新建初中。

代课这件事的影响超出她预期：试讲时她不再"表演上课"，而是真的在讲一节课。

## 第 4 步：第二年上岸

| 环节 | 结果 |
| --- | --- |
| 笔试 | 教育综合 71，学科 85，进入面试（岗位第 3） |
| 面试（试讲） | 82.6，岗位第 2 |
| 体检政审 | 通过 |
| 公示聘用 | 入职县里新建初中 |

她复盘时提到一个细节：面试抽到的课题她代课时讲过，**导入用的是学生上周的错误句子**，评委当场笑了。

## 她认为最关键的四件事

1. **先看岗位表再决定考哪里**：市区的岗位竞争比县里高一个量级，第一年她没算这笔账；
2. **教育综合是拉分项**：学科大家都强，教育综合才分人；
3. **代课比报班有用**：真实课堂给的是"课堂感"，不是模板；
4. **教资的经验不能直接搬**：教资是准入，教师编是竞争性选拔，两套逻辑。

## 可复用要点

- 教师编笔试通常两科加权，**先算清楚哪一科能拉开差距**；
- 岗位选择是策略问题：市区/县区、新校/老校、学科紧缺程度都会影响竞争比；
- 试讲的评分点是"像不像在上课"，代课、支教、机构兼职都能补这一块；
- 教资一次过不代表教师编能一次过，两者的准备方式不同；
- 第一年没上岸不是终点，但要**换策略**，而不是把同样的方法再跑一遍。
