# 全额资助到底怎么找、怎么看、怎么比较

“全奖”不是一个标准化产品。两个都写着 funded 的项目，实际可能一个覆盖学费和生活费，另一个只免部分学费；一个保证多年，另一个每年续评；一个是奖学金，另一个要求承担 RA/TA 工作。

所以第一步不是问“有没有全奖”，而是把资金包拆开。

## 先把 Funding Package 拆成六栏

| 项目 | 要核实什么 |
| --- | --- |
| 学费 | 全免、部分减免还是先缴后返 |
| 生活费 | stipend / scholarship / salary，税前还是税后 |
| 保险 | 学校承担、部分承担还是自己买 |
| 一次性费用 | 入学费、注册费、签证、搬迁、设备 |
| 工作义务 | RA / TA / 项目雇员，每周职责和续聘条件 |
| 持续条件 | 保证几年、是否看 GPA、研究进展、导师经费 |

**只有把这六栏填满，才知道它是不是你理解的“全额”。**

## 钱通常从哪里来

### 项目或院系保证

部分博士项目会把 funding 写进正式 Offer：学费减免 + stipend/assistantship。重点看“保证多久”和条件，不要只看首页宣传。

### 导师/课题经费

研究型项目里，导师的 grant 可能支持 RA、学费或工资。这里最重要的问题不是“老师有项目吗”，而是：

> **你的名额和经费是否已经落到你身上，写进什么文件，保证多久。**

### 政府/国家项目

例如国家公派、目标国政府奖学金等。它们通常有独立资格、申请时间和义务，不能因为学校录取了就默认能拿。

### 学校奖学金与减免

可能按录取自动考虑，也可能要单独申请。查“是否需要额外申请”和截止时间。

### 外部基金会 / 行业机构

金额和持续期差异很大，适合补充，但不要把尚未获批的外部奖学金当作基本预算。

## 怎么查：不要从搜索引擎摘要开始

按下面顺序找，越靠前越可靠：

1. **项目官方 funding 页面**：先确认项目整体机制；
2. **Offer / award letter**：确认你本人拿到什么；
3. **Graduate school / financial aid 页面**：看统一政策；
4. **导师实验室与 grant 信息**：了解研究经费背景；
5. **政府奖学金官方页面**；
6. **学生经验帖**：只用来发现问题，不用来确认规则。

搜索时不要只搜 full scholarship。更有效的词包括：

funding / tuition waiver / stipend / assistantship / RA / TA / studentship / fellowship / salary / financial support

不同国家用词会变。

## 看到一个金额时，先问口径

例如页面写：

> Stipend: X per year

你还不知道：
- 是 9 个月还是 12 个月；
- 税前还是税后；
- 是否另含学费；
- 暑期是否继续；
- 医疗保险谁付；
- 是否每年调整；
- 当地房租与交通占多少。

因此比较 funding 不能只做“金额排行”，要做**净可支配资源 + 稳定性 + 义务**比较。

## RA / TA 不是免费钱

Assistantship 本质上是带职责的资助或雇佣安排。你要确认：

- 每周大致工作内容；
- 教学/批改/带实验占多少时间；
- 是否和导师研究直接相关；
- 如果更换导师会不会失去 funding；
- funding 与学业进度是否绑定；
- 假期和暑期是否继续。

一个钱更多但严重挤占研究时间的 package，未必更适合研究型学生。

## 拿到 Offer 后该问什么

如果文件没写清楚，可以直接向项目秘书、graduate coordinator 或导师确认：

- Tuition 是否全额覆盖？哪些 fee 不覆盖？
- Stipend / salary 的发放周期？
- Funding guarantee 的期限？
- 第二年以后需要满足什么条件？
- 保险、注册费、实验费谁承担？
- RA/TA 的具体职责？
- 暑期资金是否另算？
- 换导师、项目延期、休学会怎样？

把回复保存下来，不要只靠口头沟通。

## 一个比较示例

A：
- 学费全免；
- stipend 较高；
- 只保证第一年，之后依赖导师经费；
- 城市生活成本高。

B：
- stipend 略低；
- funding 写明保证多年；
- 医疗保险覆盖更完整；
- TA 义务明确；
- 城市成本较低。

这时不能简单说 A “奖更多”。如果你最在意财务可预测性，B 可能更稳；如果 A 的导师经费非常确定、研究匹配显著更好，结论又会变。

比较时把事实和判断分开写。

## 常见坑

- 把 eligible for scholarship 看成 guaranteed funding；
- 把 tuition waiver 当成全奖，忽略生活费；
- 只看年金额，不算税、保险和城市成本；
- 忽略 funding 只保证一年；
- 把导师说“应该有钱”当作正式承诺；
- 忘记外部奖学金可能有回国、服务或报告义务；
- 同时拿多项资助但规则禁止叠加。

## 什么时候应该因为资金放弃一个项目

如果学位周期很长，而资金只覆盖很短时间、后续来源完全不明，风险需要单独看。尤其是博士，不要把“以后再想办法”当成正常默认。

更好的决策问题是：

> 如果最乐观的奖学金没有拿到，我还能不能完成这个项目？

如果答案是否定的，这个项目的资金方案就还没有闭环。
