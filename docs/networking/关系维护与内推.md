# 关系维护与内推请求

关系不是「认识」，而是**对方在需要时会想起你**。维护靠的是低频率、有内容的互动。

## 弱关系为什么重要

真正带来机会的往往不是最亲近的几个人，而是「认识但不熟」的人：他们掌握你不知道的信息，且分布在不同圈子。这就意味着，维护范围要宽，但每次成本要低。

## 维护的三个轻动作

- **有内容再联系**：看到对方领域的一篇文章、一个工具、一个机会，转过去并说一句「想到你可能有用」；
- **一年几次一对一短消息**：不是节日群发，而是针对近况的具体问候；
- **公开互动**：对方发的内容下认真回应一次，比私聊「在吗」有效。

频率参考：**每位重要的关系，一年两三次有内容的互动**，比天天点赞有用。

## 什么时候可以要内推

- 你已经和目标岗位有明确匹配（读过 JD、确认过自己的证据）；
- 你与对方有过实质互动（聊过、合作过、共事过）；
- 对方在目标公司或了解目标团队。

**不要在**：完全没有交集时突然请求、把内推当群发工具、让对方替你写推荐语。

## 怎么开口（一次说清）

```
1. 你要什么：我在投 XX 公司的 XX 岗（附岗位链接）
2. 你的材料：简历 PDF 在这（不必让对方整理）
3. 匹配点：一句话说明我为什么合适（做过 X、有 Y 结果）
4. 给对方退出空间：如果不方便完全理解，我自己也会走官网投递
5. 后续：结果如何我都会告知你
```

写清第 4 条很重要——它把「人情压力」降下来，对方更愿意帮。

## 被拒或没有下文

- 对方说「暂时不招」也谢谢你，并问「如果下次有类似岗位，方便再麻烦你吗」；
- 没有回复就当你已经得到答案，不再追问；继续用官网投递，不必因此疏远；
- **不要**因为被拒就删好友或冷淡处理——圈子比想象的小。

## 内推之后

- 自己同步跟进官方流程，不要让内推人替你催；
- 结果出来（无论成败）都告知对方并致谢；
- 成功后，把「这份人情」转换成未来的回馈（给对方帮忙、推荐其他人）。

## 长期不变成「求人」

判断标准：你与对方的互动里，**主动给予的比例**。长期只索取的人会被自然筛掉。做法很简单：每次请求前，先想一件你能给对方的东西（信息、介绍、反馈）。

## 自检

- 我最近一次主动给别人提供价值是什么时候？
- 我的请求里，有没有写清材料和匹配点？
- 我给对方留了拒绝的空间吗？
