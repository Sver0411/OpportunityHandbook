# 会议与线下活动：第一次去做什么

第一次参会的常见结果是：听了几场分享、拿了资料、什么都没留下。原因是没有目标。

## 会前（一天）

- 看日程，圈出**三场**最相关的报告（不要贪多）；
- 查讲者名单，挑两位你想认识的人，读一下他们最近的公开内容；
- 给自己定一个最小目标：**认识两个人，问出一个真问题**；
- 准备好自我介绍（20 秒版）和三个问题。

## 现场动线

- 提前 20 分钟到场，先熟悉场地与茶歇区（社交主要发生在这里）；
- 报告结束后是提问与交流的最佳时机——讲者刚讲完自己最熟的内容；
- 茶歇时站在人多的地方，主动加入已有对话（先听，再补一句观点或提问）；
- 不要在整场活动里只盯着自己认识的人。

## 怎么搭话

三句话模板：

1. 「你也是做 X 的吗？」（确认共同点）；
2. 「你觉得刚才那场讲的 Y 怎么样？」（就现场内容提问，成本最低）；
3. 「我最近在做 Z，遇到一个问题是……」。（给出自己的具体处境）

对方愿意继续聊，就交换联系方式，并记一句**你能记住他的信息**（不是「加了微信」）。

## 听会与提问

- 听会记三样：新信息、可用的方法、可联系的讲者；
- 提问要具体：「在 X 条件下怎么处理 Y」比「你怎么看这个方向」更容易得到有价值回答；
- 会后立刻记下要点，当天写一段两百字总结。

## 会后跟进（关键）

48 小时内给聊过的人发一条消息：提到你们聊的内容 + 你能提供的价值 + 一个不着急的下一步。

例：

> 你好，昨天在会上聊到你们用 A 处理 B 的问题，我回去查了 C 方法，或许可以用在你们的场景。链接在这里。之后如果你们有 D 方面的讨论，我很想旁听。

## 内向者的方案

- 把目标从「认识一大群人」降为「认识两个人」；
- 提前准备好三个问题，减少现场即兴压力；
- 用「帮忙」代替「社交」：做志愿者、记录会议纪要、帮忙整理资料，这些角色会自然产生对话；
- 允许自己提前离场。

## 自检

- 我这次的最小目标是什么？达成了吗？
- 我有没有在 48 小时内跟进？
- 我记下了对方什么具体信息？
