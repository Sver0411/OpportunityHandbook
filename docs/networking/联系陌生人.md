# 怎么联系陌生从业者

联系陌生人的成本被高估了：**只要你的请求足够具体、足够小，多数人愿意回答**。

## 一封有效邮件（四段，200 字内）

```
主题：请教一个关于 X 岗的问题（学生，1 个问题）

王老师您好，
我是 XX 大学 XX 专业大三学生，正在了解 X 方向。
我读了您关于 Y 的分享，对其中的 Z 有一点疑问：<具体问题>。
如果您方便，能否占用 15 分钟请教？也可以只用文字回复我的问题。
附件是我的简历（一页），供您了解背景。
谢谢您。

李 XX
```

要点：说明身份、读过什么、问题具体、请求很小（15 分钟或文字回复）、给出背景但不写长篇自我介绍。

## 反面写法

> 「您好，我是学生，想了解一下这个行业，能加个微信吗？」

问题：没有具体问题、没有背景、请求模糊（「了解行业」是开放式索取）。这类消息的回复率极低。

## 信息型访谈的脚本（20 分钟）

```
0–2  分钟：自我介绍与来意（我在了解 X，想请您讲讲实际情况）
2–5  分钟：您的日常是什么样的（一天/一周在做什么）
5–12 分钟：具体问题（见下）
12–17 分钟：路径问题（您当年怎么进来的、新人最容易卡在哪）
17–20 分钟：收尾（我准备这样去做，您觉得还缺什么？）
```

四类好问题：

- 「上周你处理的最麻烦的一件事是什么？」
- 「这个岗位做得好的标准怎么衡量？」
- 「新人前半年最容易在哪里出问题？」
- 「如果重来，你还会选吗？为什么？」

## 对话示例（片段）

> 你：我看了你们最近的发布，里面提到把 X 换成 Y，主要考虑是什么？
> 对方：主要是维护成本……（讲了原因）
> 你：明白。那这个改动对延迟有影响吗？
> 对方：有一点，但我们更在意稳定性。
> 你：（记下来）这和我原来以为的不太一样——我以为这个场景延迟优先。

**关键动作**：把它当成真实对话，而不是念问题清单。听到与自己预期不同的地方，追问一句。

## 被无视怎么办

- 等 5–7 天，在**原邮件**下简短跟进一次（「可能您比较忙，如果方便时回复即可，也完全理解」）；
- 还不回就换下一位，不要追问第三次；
- 记住：没回复通常与你的水平无关，只是对方的时间问题。

## 收尾

无论结果如何，发一条简短感谢并说明你打算怎么做。一段时间后（如一个月）反馈结果——这是让一次对话变成一段关系的关键动作。

## 自检

- 我的请求具体到能在 15 分钟内完成吗？
- 我提前查过对方的公开资料吗？
- 我说清了自己的背景吗？
