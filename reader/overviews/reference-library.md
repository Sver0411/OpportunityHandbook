读方法之后，下一步通常是**安排时间、填写材料、动手执行或核对信息**。这一栏按用途集中提供时间线、工具、案例、行动步骤和风险核对，适合你已经知道要做什么、想立刻找到一份配套资料的时候。

五组分别是：[时间线](#/guide/library-timeline)、[工具与模板](#/guide/library-tool)、[完整案例](#/guide/library-case)、[行动步骤](#/guide/library-steps)、[风险与核实](#/guide/library-risk)，以及放术语和官方入口的[术语与官方入口](#/guide/references)。

## 怎么用这一栏

按你现在卡在哪一步来选：

| 你现在的问题 | 该找什么 |
| --- | --- |
| 「什么时候该做什么？」 | 时间线 |
| 「这件事怎么拆成可比较的字段？」 | 工具与模板 |
| 「别人走这条路时发生了什么？」 | 完整案例 |
| 「道理我都懂，具体怎么做？」 | 行动步骤 |
| 「哪些地方容易出事？」 | 风险与核实 |

**时间线给顺序，不给日期。** 每条时间线写的是倒排逻辑（先确定结果发生的时间，再往前推算每一步），具体日期一律以官方公告为准——[时间线检查表](#/doc/docs/tools/时间线检查表) 是通用的核对方法。

**工具的价值在于逼你填。** 表格不是作业，是把「感觉不错」换成「可比较字段」的过程。填不出来的格子，正是你还没搞清的地方。使用原则见[怎么用这些表](#/guide/reference-library)。

**案例用来对照，不是用来照抄。** 每个人的起点、资源和约束不同；案例的意义是让你看到**别人在岔路口怎么判断的**，而不是给你一套模板。

## 各组包含什么

**时间线**按人生阶段排列：从[高中到大学](#/doc/docs/timelines/高中到大学)、[本科四年](#/doc/docs/timelines/本科四年)，到[保研](#/doc/docs/timelines/保研时间线)、[考研](#/doc/docs/timelines/考研时间线)、[考公](#/doc/docs/timelines/考公时间线)、[留学申请](#/doc/docs/timelines/留学申请时间线)、[博士申请](#/doc/docs/timelines/博士申请时间线)，再到[校招](#/doc/docs/timelines/校招时间线)、[入职第一年](#/doc/docs/timelines/入职第一年)、[转行](#/doc/docs/timelines/转行时间线)。考试类另有三条：[四六级](#/doc/docs/timelines/四六级时间线)、[留学语言考试](#/doc/docs/timelines/留学语言考试时间线)、[专升本](#/doc/docs/timelines/专升本时间线)。

**工具与模板**按用途分组：做决定用[机会价值判断表](#/doc/docs/tools/机会价值判断表) 与 [Offer 对比表](#/doc/docs/tools/Offer对比表)；升学用[择校对比表](#/doc/docs/tools/择校对比表)、[留学选校表](#/doc/docs/tools/留学选校表)；科研用[实验记录模板](#/doc/docs/tools/实验记录模板)、[论文精读表](#/doc/docs/tools/论文精读表)；求职用[JD 拆解表](#/doc/docs/tools/JD拆解表)、[面试复盘表](#/doc/docs/tools/面试复盘表)；钱与权益用[日常账本与月度预算](#/doc/docs/tools/日常账本与月度预算)、[纠纷证据清单](#/doc/docs/tools/纠纷证据清单)。

**完整案例**给的是走完全程的记录：[第一次做真正的项目](#/doc/docs/cases/第一次做真正项目)、[本科生第一次进实验室](#/doc/docs/cases/本科生第一次科研)、[两个 Offer 怎么选](#/doc/docs/cases/两个Offer怎么选)、[第一次转行](#/doc/docs/cases/第一次转行)、[第一次被欠薪](#/doc/docs/cases/第一次被欠薪) 等，含失败与返工的分支。

**行动步骤**是「第一次做某事」的完整流程，例如 [Playbook：第一次准备考研](#/doc/docs/playbooks/第一次准备考研)、[Playbook：第一次找实习](#/doc/docs/playbooks/第一次找实习)、[Playbook：第一次谈薪](#/doc/docs/playbooks/第一次谈薪)，每篇都带检查点和停止条件。

**风险与核实**集中在「听起来划算但实际有坑」的地方：付费内推与保 offer、付费竞赛、证书堆砌、付费理财课、体检加项、包追回的法律服务等。它们的共同特征是**在你还没有产出之前先要钱**。

## 术语与官方入口

遇到不认识的词，先查[术语表](#/doc/docs/manuals/术语表)（同一个东西常有两种叫法，比如「保研」与「推免」）。

要办具体的事、需要权威来源时用这两个：[常用官方来源清单](#/doc/docs/sources/常用官方来源清单) 按领域列出可信来源，[官方入口速查：你要办的事，去哪办、去哪查](#/doc/docs/sources/官方入口速查) 按动作直达（报名、查成绩、查学历学籍、办社保公积金、投诉举报等）。判断一个来源可不可靠的方法见[二手来源与识别方法](#/doc/docs/sources/二手来源与识别方法)，本手册自己的核实过程与边界记录在[核实记录](#/doc/docs/sources/核实记录)。

## 什么时候要谨慎

- **资料会过期，判断方法不会**：表格与流程可以长期用，但里面的日期、比例、分数线、政策条件必须重新核对；
- 案例里的数字（薪资、时长、成功率）是个体经历，不代表你的情况；
- 涉及**报名、缴费、资格审核、投诉举报**的动作，一律以官方入口的最新公告为准——本栏给的是「去哪找」，不是「现在的规则是什么」。
